## VTX field

Visio Template XML File (.vtx) هو قالب رسم Microsoft Visio يُحفظ على القرص بتنسيق XML. يهدف القالب إلى توفير ملف بإعدادات أساسية يمكن استخدامها لإنشاء ملفات Visio متعددة بنفس الإعدادات. تعرف على المزيد حول هذا التنسيق هنا.
