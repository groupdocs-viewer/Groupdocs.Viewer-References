## VSX field

Visio Stencil XML File (.vsx) تشير إلى القوالب التي تتكون من رسومات وأشكال تُستخدم لإنشاء مخططات في Microsoft Visio. تُحفظ ملفات VSX بتنسيق XML وكان الدعم متاحًا حتى Visio 2013. تعرف على المزيد حول هذا التنسيق هنا.
