## VSTM field

Visio Macro-Enabled Drawing Template (.vstm) هي ملفات قالب تم إنشاؤها باستخدام Microsoft Visio وتدعم الماكرو. على عكس ملفات VSDX، يمكن للملفات التي تم إنشاؤها من قوالب VSTM تشغيل الماكرو المطور بلغة Visual Basic for Applications (VBA). تعرف على المزيد حول هذا التنسيق هنا.
