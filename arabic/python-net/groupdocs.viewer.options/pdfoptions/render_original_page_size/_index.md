## render_original_page_size property

تم ضبط حجم صفحة الإخراج ليتطابق مع حجم صفحة مستند PDF المصدر.

بشكل افتراضي، يقوم GroupDocs.Viewer بحساب حجم صفحة الصورة الناتجة لتحسين جودة العرض. فعّل هذا الخيار لضمان أن تكون صفحات الإخراج بنفس حجم صفحة مستند PDF الأصلي (بالبكسل). القيمة الافتراضية هي False.

هذا الخيار متاح للتحويل إلى صيغ PNG أو JPG.
