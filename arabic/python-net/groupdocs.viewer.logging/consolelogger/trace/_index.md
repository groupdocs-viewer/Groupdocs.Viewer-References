رسائل سجل التتبع توفر معلومات عامة مفيدة حول تدفق التطبيق.

```python
def trace(self, message):
    ...
```

| معامل | نوع | الوصف |
| :- | :- | :- |
| message | `str` | رسالة التتبع. |

| يُثير | الوصف |
| :- | :- |
| `ValueError` | يتم الرفع عندما تكون `message` None. |
