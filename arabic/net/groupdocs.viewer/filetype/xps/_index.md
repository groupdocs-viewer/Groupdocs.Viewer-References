## FileType.XPS field

XML Paper Specification File (.xps) يمثل ملفات تخطيط الصفحات المستندة إلى مواصفات XML Paper التي أنشأتها Microsoft. تم تطوير هذا التنسيق من قبل Microsoft كبديل لتنسيق ملف EMF وهو مشابه لتنسيق PDF، لكنه يستخدم XML في تخطيط ومظهر ومعلومات الطباعة للمستند. تعرف على المزيد حول هذا التنسيق [هنا](https://wiki.fileformat.com/page-description-language/xps).

```csharp
public static readonly FileType XPS;
```
