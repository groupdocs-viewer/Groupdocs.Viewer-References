## PdfOptions.RenderOriginalPageSize property

يضبط حجم صفحة الإخراج ليكون نفس حجم صفحة مستند PDF المصدر.

```csharp
public bool RenderOriginalPageSize { get; set; }
```

### ملاحظات

بشكل افتراضي، يقوم GroupDocs.Viewer بحساب حجم صفحة الصورة الناتجة لتحسين جودة العرض. فعّل هذا الخيار لضمان أن تكون صفحات الإخراج بنفس حجم صفحة مستند PDF المصدر (بالبكسل). القيمة الافتراضية هي `false`.

هذا الخيار متاح للعرض إلى صيغ PNG أو JPG.

للحصول على مثال شفرة، راجع [التوثيق](https://docs.groupdocs.com/viewer/net/render-pdf-documents/#preserve-the-size-of-document-pages).
