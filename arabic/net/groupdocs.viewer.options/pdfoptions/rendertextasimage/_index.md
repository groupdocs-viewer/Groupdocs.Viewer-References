## PdfOptions.RenderTextAsImage property

يفعل تصيير النصوص في ملفات PDF كصورة في إخراج HTML.

```csharp
public bool RenderTextAsImage { get; set; }
```

### ملاحظات

عندما يتم تعيين هذا الخيار إلى `true`، يقوم GroupDocs.Viewer بعرض النص كصورة في مخرجات HTML. يجعل ذلك النص غير قابل للتحديد ويعزز عرض الأحرف، مما يضمن مظهرًا شبيهًا بـ PDF في HTML. القيمة الافتراضية هي `false`.

هذا الخيار متاح للعرض إلى HTML.

للحصول على مثال على الشيفرة، راجع [التوثيق](https://docs.groupdocs.com/viewer/net/render-pdf-documents/#render-text-as-an-image).
