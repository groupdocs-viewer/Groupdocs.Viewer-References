## PdfOptions.EnableLayeredRendering property

يفعل تصيير النص والرسومات بترتيب Z الأصلي لمستند PDF عند تصيير إلى HTML.

```csharp
public bool EnableLayeredRendering { get; set; }
```

### ملاحظات

بشكل افتراضي، يقوم GroupDocs.Veiewer بعرض النص والرسومات كطبقة واحدة في HTML. يتيح لك هذا الخيار ترتيب الكائنات بنفس الترتيب الموجود في الملف المصدر. القيمة الافتراضية هي `false`.

للحصول على مثال شفرة، راجع [التوثيق](https://docs.groupdocs.com/viewer/net/render-pdf-documents/#enable-multi-layer-rendering).
