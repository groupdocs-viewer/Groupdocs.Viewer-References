## WordProcessingOptions.PageSize property

حجم صفحة الإخراج. القيمة الافتراضية هي Unspecified مما يعني أن حجم الصفحة المحدد في إعدادات الصفحة (Page Setup) يُستخدم. عند عرض ملفات HTM وHTML تكون حجم الصفحة الافتراضي مضبوطة على Letter 792 × 612 نقطة. نتيجةً لذلك قد لا يتناسب بعض المحتوى مع إطار الصفحة. اضبط حجم صفحة أكبر مثل A3 لتلائم المحتوى.

```csharp
public PageSize PageSize { get; set; }
```
