## WordProcessingOptions.HorizontalResolution property

يحصل أو يعيّن الدقة الأفقية للصور المُولَّدة بوحدة النقاط في البوصة. يُستخدم هذا الخيار عند عرض مستندات WordProcessing إلى صيغ PNG أو JPEG فقط.

```csharp
public int HorizontalResolution { get; set; }
```

### ملاحظات

القيمة الافتراضية هي 96 DPI. الحد الأدنى الممكن هو 72 DPI، الحد الأقصى الممكن هو 600 DPI. إذا كانت القيمة المحددة من قبل المستخدم خارج هذه الحدود، سيتم تطبيق الحد الأدنى أو الحد الأقصى الممكن.
