## PresentationOptions.RenderToPureHtml property

يفعل وضع عرض HTML جديد لمستندات العرض التقديمي — في هذا الوضع تُعرض ملفات العرض إلى **pure HTML/CSS markup**، دون صور SVG. بشكل افتراضي يكون معطلاً (`false`) — يُستخدم عارض HTML القائم على SVG الحالي.

```csharp
public bool RenderToPureHtml { get; set; }
```
