## SpreadsheetOptions.VerticalResolution property

يحصل أو يضبط الدقة العمودية للصور المُولدة بوحدة النقاط في البوصة. يُستخدم هذا الخيار فقط عند عرض الجداول الإلكترونية إلى صيغ PNG أو JPEG.

```csharp
public int VerticalResolution { get; set; }
```

### ملاحظات

القيمة الافتراضية هي 96 DPI. الحد الأدنى الممكن هو 72 DPI، الحد الأقصى الممكن هو 600 DPI. إذا كانت القيمة المحددة من قبل المستخدم خارج هذه الحدود، سيتم تطبيق الحد الأدنى أو الحد الأقصى الممكن.
