## BaseViewOptions.RenderHiddenPages property

يفعل عرض الصفحات المخفية.

```csharp
public bool RenderHiddenPages { get; set; }
```

### ملاحظات

قد تحتوي بعض الملفات، مثل العروض التقديمية أو جداول البيانات، على صفحات مخفية. بشكل افتراضي، لا يقوم GroupDocs.Viewer بعرض هذه الصفحات. للقيام بذلك، اضبط هذه الخاصية على `true`.

لمثال الكود، راجع [التوثيق](https://docs.groupdocs.com/viewer/net/render-presentations/#render-hidden-slides).
