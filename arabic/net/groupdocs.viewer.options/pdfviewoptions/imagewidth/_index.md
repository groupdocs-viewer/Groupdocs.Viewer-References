## PdfViewOptions.ImageWidth property

يضبط عرض صورة الإخراج (بالبكسل).

```csharp
public int ImageWidth { get; set; }
```

### ملاحظات

استخدم هذه الخاصية لتعيين عرض الصورة الناتجة (بالبكسل). يقوم GroupDocs.Viewer بتطبيق هذه الخاصية عند تحويل صورة واحدة إلى PDF. للحصول على تفاصيل، راجع [documentation](https://docs.groupdocs.com/viewer/net/set-image-size-limits-when-rendering-to-pdf/).

إذا قمت بتعيين هذه الخاصية، سيتم تجاهل الخاصية [`ImageMaxWidth`](../imagemaxwidth).
