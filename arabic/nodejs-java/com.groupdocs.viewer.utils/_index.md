الحزمة توفر فئات مساعدة ومفيدة لمختلف الوظائف.

هذه الفئات تقدم طرقًا مريحة ووظائف للمساعدة في عمليات مختلفة.

الفئات الرئيسية في هذه الحزمة هي:

 *  [MemoryCleaner](../../com.groupdocs.viewer.utils/memorycleaner) - Provides methods to clean up resources and free memory.
 *  [PathUtils](../../com.groupdocs.viewer.utils/pathutils) - Represents the type for working with paths.

لمزيد من التفاصيل حول استخدام الفئات المساعدة في حزمة com.groupdocs.viewer.utils، يرجى الرجوع إلى [GroupDocs.Viewer Documentation][].
