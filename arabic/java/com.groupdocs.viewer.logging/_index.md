توفر الحزمة فئات لتكوين نظام التسجيل في GroupDocs.Viewer.


باستخدام هذه الفئات، يمكنك التحكم في طريقة معالجة رسائل السجل، مثل كتابتها إلى
ملف أو توجيهها إلى تنفيذ محدد للمسجل.

الفئات الرئيسية في هذه الحزمة هي:

* [FileLogger](../../com.groupdocs.viewer.logging/filelogger) - Writes log messages to a file.
* [ViewerLogger](../../com.groupdocs.viewer.logging/viewerlogger) - Implements logging messages to an integrated or user-defined logger.


لمزيد من التفاصيل حول تكوين نظام التسجيل في GroupDocs.Viewer وتخصيص معالجة رسائل السجل،
يرجى الرجوع إلى [توثيق GroupDocs.Viewer](../https://docs.groupdocs.com/viewer/java/).



## الفئات

| فئة | الوصف |
| --- | --- |
| [FileLogger](../com.groupdocs.viewer.logging/filelogger) | يكتب رسائل السجل إلى ملف. |
| [ViewerLogger](../com.groupdocs.viewer.logging/viewerlogger) | مسجل العرض العالمي. |
