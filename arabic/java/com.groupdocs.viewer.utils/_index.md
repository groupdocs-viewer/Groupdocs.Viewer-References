توفر الحزمة فئات مساعدة ومفيدة لمختلف الوظائف.


تقدم هذه الفئات طرقًا ووظائف مريحة للمساعدة في عمليات مختلفة.

الفئات الرئيسية في هذه الحزمة هي:

* [CancellationToken](../../com.groupdocs.viewer.utils/cancellationtoken) - Propagates a request to cancel rendering.
* [CancellationTokenSource](../../com.groupdocs.viewer.utils/cancellationtokensource) - Creates and signals a [CancellationToken](../../com.groupdocs.viewer.utils/cancellationtoken).
* [MemoryCleaner](../../com.groupdocs.viewer.utils/memorycleaner) - Provides methods to clean up resources and free memory.
* [PathUtils](../../com.groupdocs.viewer.utils/pathutils) - Represents the type for working with paths.


لمزيد من التفاصيل حول استخدام الفئات المساعدة في حزمة com.groupdocs.viewer.utils،
يرجى الرجوع إلى [توثيق GroupDocs.Viewer](../https://docs.groupdocs.com/viewer/java/).

| فئة | الوصف |
| --- | --- |
| [CancellationToken](../com.groupdocs.viewer.utils/cancellationtoken) | ينشر إشعارًا بأن العملية يجب إلغاؤها. |
| [CancellationTokenSource](../com.groupdocs.viewer.utils/cancellationtokensource) | يشير إلى [CancellationToken](../com.groupdocs.viewer.utils/cancellationtoken) بأن العملية يجب إلغاؤها. |
| [MemoryCleaner](../com.groupdocs.viewer.utils/memorycleaner) | ينظف موارد مختلفة لتحرير الذاكرة. |
| [PathUtils](../com.groupdocs.viewer.utils/pathutils) | فئة PathUtils توفر طرقًا مساعدة للعمل مع مسارات الملفات. |
