توفر الحزمة فئات لتحديد خيارات إضافية عند تصيير المستندات.


يتضمن خيارات لعرض صيغ المستندات المختلفة، وتحديد الأذونات وإعدادات الأمان،
تحديد خصائص العلامة المائية، واسترجاع معلومات حول العروض.

الفئات الرئيسية في هذه الحزمة هي:

* [ArchiveOptions](../../com.groupdocs.viewer.options/archiveoptions) - Provides options for rendering archive files.
* [PdfOptions](../../com.groupdocs.viewer.options/pdfoptions) - Provides options for rendering PDF documents.
* [WordProcessingOptions](../../com.groupdocs.viewer.options/wordprocessingoptions) - Provides options for rendering word processing documents.


لمزيد من التفاصيل حول تكوين نظام التسجيل في GroupDocs.Viewer وتخصيص معالجة رسائل السجل،
يرجى الرجوع إلى [توثيق GroupDocs.Viewer](../https://docs.groupdocs.com/viewer/java/).
