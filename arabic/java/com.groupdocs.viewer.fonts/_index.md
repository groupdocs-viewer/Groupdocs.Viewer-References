توفر الحزمة فئات وتعدادات لإدارة الخطوط المستخدمة أثناء عملية التصيير.

الفئات والواجهات الرئيسية في هذه الحزمة هي:

* [FolderFontSource](../../com.groupdocs.viewer.fonts/folderfontsource) - Represents a folder that contains TrueType fonts.
* [FontSettings](../../com.groupdocs.viewer.fonts/fontsettings) - Provides methods for working with sources to look for TrueType fonts.
* [FontSource](../../com.groupdocs.viewer.fonts/fontsource) - Marker interface for the font sources.


لمزيد من التفاصيل حول العمل مع الخطوط في GroupDocs.Viewer، يرجى الرجوع إلى
[GroupDocs.Viewer Documentation](../https://docs.groupdocs.com/viewer/java/).



## الفئات

| فئة | الوصف |
| --- | --- |
| [FolderFontSource](../com.groupdocs.viewer.fonts/folderfontsource) | يمثل مجلدًا يحتوي على خطوط TrueType. |
| [FontFormat](../com.groupdocs.viewer.fonts/fontformat) | يمثل جميع صيغ الخطوط التي قد تكون موجودة في الفئة UsedFontInfo. |
| [FontSettings](../com.groupdocs.viewer.fonts/fontsettings) | يوفر طرقًا للعمل مع المصادر للبحث عن خطوط TrueType. |
| [FontStyles](../com.groupdocs.viewer.fonts/fontstyles) | يمثل 4 أنماط محتملة للخط، المستخدمة في المستند: عادي، غامق، مائل، أو غامق مائل. |
| [PdfFontInfo](../com.groupdocs.viewer.fonts/pdffontinfo) | يغلف المعلومات الوصفية والبيانات الثنائية لخط واحد من مستند PDF، تم تحميله في نسخة Viewer. |
| [PresentationFontInfo](../com.groupdocs.viewer.fonts/presentationfontinfo) | يغلف البيانات الوصفية والبيانات الثنائية لخط مستخدم في مستند Presentation، تم تحميله في نسخة Viewer. |
| [SpreadsheetFontInfo](../com.groupdocs.viewer.fonts/spreadsheetfontinfo) | يغلف المعلومات الوصفية والبيانات الثنائية لخط واحد من مستند Spreadsheet، تم تحميله في نسخة Viewer. |
| [WordProcessingFontInfo](../com.groupdocs.viewer.fonts/wordprocessingfontinfo) | يغلف المعلومات الوصفية والبيانات الثنائية لخط واحد من مستند WordProcessing، تم تحميله في نسخة Viewer. |
| [WordProcessingSubstitutedFontInfo](../com.groupdocs.viewer.fonts/wordprocessingsubstitutedfontinfo) | يغلف البيانات الوصفية والبيانات الثنائية لخط مستبدل واحد يُستخدم في مستند WordProcessing عبر GroupDocs.Viewer. |
