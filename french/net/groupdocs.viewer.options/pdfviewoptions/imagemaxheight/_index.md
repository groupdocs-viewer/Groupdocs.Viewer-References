## PdfViewOptions.ImageMaxHeight property

Définit la hauteur maximale d'une image de sortie (en pixels).

```csharp
public int ImageMaxHeight { get; set; }
```

### Remarques

Utilisez cette propriété pour définir la hauteur maximale de l'image de sortie (en pixels). GroupDocs.Viewer applique cette propriété lors du rendu d'une image unique en PDF. Pour plus de détails, consultez la [documentation](https://docs.groupdocs.com/viewer/net/set-image-size-limits-when-rendering-to-pdf/).

Si vous définissez la propriété [`ImageHeight`](../imageheight), cette propriété est ignorée.
