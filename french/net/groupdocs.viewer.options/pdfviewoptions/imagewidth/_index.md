## PdfViewOptions.ImageWidth property

Définit la largeur d'une image de sortie (en pixels).

```csharp
public int ImageWidth { get; set; }
```

### Remarques

Utilisez cette propriété pour définir la largeur de l'image de sortie (en pixels). GroupDocs.Viewer applique cette propriété lors du rendu d'une image unique en PDF. Pour plus de détails, consultez la [documentation](https://docs.groupdocs.com/viewer/net/set-image-size-limits-when-rendering-to-pdf/).

Si vous définissez cette propriété, la propriété [`ImageMaxWidth`](../imagemaxwidth) est ignorée.
