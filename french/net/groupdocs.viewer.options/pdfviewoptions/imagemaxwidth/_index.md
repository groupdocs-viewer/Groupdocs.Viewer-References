## PdfViewOptions.ImageMaxWidth property

Définit la largeur maximale d'une image de sortie (en pixels).

```csharp
public int ImageMaxWidth { get; set; }
```

### Remarques

Utilisez cette propriété pour définir la largeur maximale de l'image de sortie (en pixels). GroupDocs.Viewer applique cette propriété lors du rendu d'une image unique en PDF. Pour plus de détails, consultez la [documentation](https://docs.groupdocs.com/viewer/net/set-image-size-limits-when-rendering-to-pdf/).

Si vous définissez la propriété [`ImageWidth`](../imagewidth), cette propriété est ignorée.
