## PdfViewOptions.ImageHeight property

Définit la hauteur d'une image de sortie (en pixels).

```csharp
public int ImageHeight { get; set; }
```

### Remarques

Utilisez cette propriété pour définir la hauteur de l'image de sortie (en pixels). GroupDocs.Viewer applique cette propriété lors du rendu d'une image unique en HTML uniquement. Pour plus de détails, consultez la [documentation](https://docs.groupdocs.com/viewer/net/set-image-size-limits-when-rendering-to-pdf/).

Si vous définissez cette propriété, la propriété [`ImageMaxHeight`](../imagemaxheight) est ignorée.
