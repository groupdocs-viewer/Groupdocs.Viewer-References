## ArchiveOptions.FileName property

Définit le nom du fichier d'archive affiché.

```csharp
public FileName FileName { get; set; }
```

### Remarques

Par défaut, GroupDocs.Viewer affiche le nom du fichier d'archive dans l'en-tête de chaque page. Pour modifier ou masquer ce nom, définissez cette propriété.

Pour plus d'informations et un exemple de code, consultez la [documentation](https://docs.groupdocs.com/viewer/net/render-archive-files/#specify-the-archive-document-name).
