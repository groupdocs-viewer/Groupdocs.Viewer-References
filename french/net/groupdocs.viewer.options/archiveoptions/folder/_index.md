## ArchiveOptions.Folder property

Définit le dossier à rendre.

```csharp
public string Folder { get; set; }
```

### Remarques

Par défaut, GroupDocs.Viewer rend les éléments de tous les dossiers contenus dans l'archive. Pour rendre les éléments d'un dossier spécifique, définissez cette propriété.

Pour un exemple de code, consultez la [documentation](https://docs.groupdocs.com/viewer/net/render-archive-files/#render-a-specific-folder).
