## PdfOptimizationOptions.ResizeImages property

Permet de définir la résolution maximale dans le fichier PDF de sortie.

```csharp
public bool ResizeImages { get; set; }
```

### Remarques

Pour autoriser cette option, définissez la propriété [`CompressImages`](../compressimages) sur `true`. Cette option permet de définir la propriété [`MaxResolution`](../maxresolution). Pour un exemple de code, consultez cette [documentation](https://docs.groupdocs.com/viewer/net/optimization-pdf-set-max-resolution/).
