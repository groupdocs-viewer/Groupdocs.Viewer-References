## PdfOptimizationOptions.MaxResolution property

Définit la résolution maximale dans le fichier PDF de sortie.

```csharp
public int MaxResolution { get; set; }
```

### Remarques

Pour activer cette option, définissez les propriétés [`CompressImages`](../compressimages) et `MaxResolution` sur `true`.

La valeur par défaut est `300`.

Pour un exemple de code, consultez cette [documentation](https://docs.groupdocs.com/viewer/net/optimization-pdf-set-max-resolution/).
