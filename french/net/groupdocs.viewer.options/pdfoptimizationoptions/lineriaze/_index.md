## PdfOptimizationOptions.Lineriaze property

Active l'optimisation du fichier PDF de sortie pour la visualisation en ligne avec un navigateur web.

```csharp
public bool Lineriaze { get; set; }
```

### Remarques

Cette optimisation permet à un navigateur d'afficher les premières pages d'un fichier PDF lorsque vous ouvrez le document, au lieu d'attendre le téléchargement complet du fichier. Pour un exemple de code, consultez cette [documentation](https://docs.groupdocs.com/viewer/net/optimization-pdf-for-web/).
