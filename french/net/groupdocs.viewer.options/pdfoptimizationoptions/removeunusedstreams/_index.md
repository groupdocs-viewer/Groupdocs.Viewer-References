## PdfOptimizationOptions.RemoveUnusedStreams property

Supprime les flux inutilisés (orphelins) d'un fichier PDF, qui sont encore référencés dans le dictionnaire de ressources de la page mais ne sont jamais réellement utilisés dans le contenu de la page. Par défaut, elle est désactivée (`false`), son activation (`true`) réduira la taille du document PDF généré.

```csharp
public bool RemoveUnusedStreams { get; set; }
```
