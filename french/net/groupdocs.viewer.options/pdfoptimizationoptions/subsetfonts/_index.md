## PdfOptimizationOptions.SubsetFonts property

Sous-ensemble les polices dans le fichier PDF de sortie.

```csharp
public bool SubsetFonts { get; set; }
```

### Remarques

Si le fichier utilise des polices incorporées, il contient toutes les données de police. GroupDocs.Viewer peut sous‑échantillonner les polices incorporées pour réduire la taille du fichier. Pour un exemple de code, consultez cette [documentation](https://docs.groupdocs.com/viewer/net/optimization-pdf-subset-fonts/).
