## PdfOptimizationOptions.OptimizeSpreadsheets property

Active l'optimisation des feuilles de calcul dans les fichiers PDF.

```csharp
public bool OptimizeSpreadsheets { get; set; }
```

### Remarques

Cette optimisation permet de réduire la taille du fichier de sortie en configurant les lignes de bordure. De plus, elle supprime les caractères Arial et Times New Roman des codes 32‑127.

Pour un exemple de code, consultez cette [documentation](https://docs.groupdocs.com/viewer/net/optimization-pdf-spreadsheets/).
