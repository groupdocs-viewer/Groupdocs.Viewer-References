## JpgViewOptions.Quality property

Définit la qualité de l'image de sortie.

```csharp
public byte Quality { get; set; }
```

### Remarques

Utilisez cette propriété pour ajuster la qualité des images. La valeur doit être comprise entre 1 (qualité minimale) et 100. La valeur par défaut est 90.

Pour un exemple de code, consultez la [documentation](https://docs.groupdocs.com/viewer/net/image-viewer-adjust-quality-for-jpg/).
