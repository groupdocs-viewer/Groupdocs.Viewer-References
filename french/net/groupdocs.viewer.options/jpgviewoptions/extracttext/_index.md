## JpgViewOptions.ExtractText property

Active l'extraction de texte.

```csharp
public bool ExtractText { get; set; }
```

### Remarques

Utilisez cette propriété pour obtenir le texte contenu dans un document source ainsi que ses coordonnées. Vous pouvez ensuite utiliser ces données pour ajouter un texte sélectionnable sur l'image ou pour implémenter une recherche de texte dans le rendu basé sur l'image.

Pour un exemple de code, consultez la [documentation](https://docs.groupdocs.com/viewer/net/image-viewer-get-text-coordinates/).
