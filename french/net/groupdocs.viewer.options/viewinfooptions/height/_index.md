## ViewInfoOptions.Height property

La hauteur de l'image de sortie (en pixels, uniquement pour le rendu en PNG/JPG).

```csharp
public int Height { get; set; }
```

### Remarques

Utilisez cette propriété pour définir la hauteur de l'image de sortie (en pixels). Pour un exemple de code, consultez la [documentation](https://docs.groupdocs.com/viewer/net/image-viewer-adjust-image-size/).

Si vous définissez cette propriété, la propriété [`MaxHeight`](../maxheight) est ignorée.
