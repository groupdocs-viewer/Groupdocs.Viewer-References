## ViewInfoOptions.MaxWidth property

Définit la largeur maximale d'une image de sortie (en pixels, uniquement pour le rendu en PNG/JPG).

```csharp
public int MaxWidth { get; set; }
```

### Remarques

Utilisez cette propriété pour définir la largeur maximale de l'image de sortie (en pixels). Pour l'exemple de code, consultez la [documentation](https://docs.groupdocs.com/viewer/net/set-image-size-limits-when-rendering-to-png-jpg/).

Si vous définissez la propriété [`Width`](../width), cette propriété est ignorée.
