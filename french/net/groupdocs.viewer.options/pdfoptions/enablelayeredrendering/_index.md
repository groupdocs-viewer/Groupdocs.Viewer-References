## PdfOptions.EnableLayeredRendering property

Active le rendu du texte et des graphiques dans l'ordre Z du document PDF original lors du rendu en HTML.

```csharp
public bool EnableLayeredRendering { get; set; }
```

### Remarques

Par défaut, GroupDocs.Veiewer rend le texte et les graphiques comme une seule couche en HTML. Cette option vous permet d'organiser les objets dans le même ordre que dans le fichier source. La valeur par défaut est `false`.

Pour un exemple de code, consultez la [documentation](https://docs.groupdocs.com/viewer/net/render-pdf-documents/#enable-multi-layer-rendering).
