## PdfOptions.EnableFontHinting property

Active le hinting des polices.

```csharp
public bool EnableFontHinting { get; set; }
```

### Remarques

L'optimisation des polices ajuste la façon dont une police de contour est affichée. Applicable uniquement aux polices TTF utilisées dans le document source. Cette option est disponible pour le rendu aux formats PNG ou JPG. La valeur par défaut est `false`.

Pour un exemple de code, consultez la [documentation](https://docs.groupdocs.com/viewer/net/render-pdf-documents/#enable-font-hinting).
