## PdfOptions.RenderTextAsImage property

Active le rendu du texte des fichiers PDF sous forme d'image dans la sortie HTML.

```csharp
public bool RenderTextAsImage { get; set; }
```

### Remarques

Lorsque cette option est définie sur `true`, GroupDocs.Viewer rend le texte sous forme d’image dans la sortie HTML. Cela rend le texte non sélectionnable et améliore le rendu des caractères, assurant une apparence similaire à un PDF dans le HTML. La valeur par défaut est `false`.

Cette option est disponible pour le rendu en HTML.

Pour un exemple de code, voir la [documentation](https://docs.groupdocs.com/viewer/net/render-pdf-documents/#render-text-as-an-image).
