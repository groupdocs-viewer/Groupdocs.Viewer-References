## MailStorageOptions.MaxItems property

Définit le nombre maximal de messages ou d'éléments à rendre.

```csharp
public int MaxItems { get; set; }
```

### Remarques

Les fichiers de données de stockage du courrier peuvent être volumineux et la récupération de tous les messages peut prendre un temps considérable. Cette propriété limite le nombre maximal de messages ou d'éléments rendus. La valeur par défaut est 0 – tous les messages sont rendus.

Pour un exemple de code, consultez la [documentation](https://docs.groupdocs.com/viewer/net/render-lotus-notes-database-files/#limit-the-number-of-items-to-render).
