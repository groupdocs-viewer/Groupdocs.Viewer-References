## HtmlViewOptions.Minify property

Active la minification du contenu HTML et des ressources HTML.

```csharp
public bool Minify { get; set; }
```

### Remarques

La compression du contenu de sortie (HTML, CSS et SVG) est l'une des façons d'optimiser le fichier HTML. Pour ce faire, définissez cette propriété sur `true`.

Pour un exemple de code, consultez la [documentation](https://docs.groupdocs.com/viewer/net/minify-html/).
