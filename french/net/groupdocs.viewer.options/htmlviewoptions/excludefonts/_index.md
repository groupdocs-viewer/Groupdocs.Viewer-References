## HtmlViewOptions.ExcludeFonts property

Désactive l'ajout de toute police dans le document HTML.

```csharp
public bool ExcludeFonts { get; set; }
```

### Remarques

Par défaut, GroupDocs.Viewer intègre les polices utilisées dans le document dans le balisage HTML, et cette propriété a la valeur `false`. Pour empêcher l’intégration des polices, définissez cette propriété sur `true`.

Pour plus de détails et un exemple de code, consultez la [documentation](https://docs.groupdocs.com/viewer/net/exclude-fonts/).
