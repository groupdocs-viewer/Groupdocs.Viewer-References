## HtmlViewOptions.RemoveJavaScript property

Permet de supprimer le code source JavaScript des liens dans les documents HTML résultants, lors du rendu des documents d'entrée contenant des scripts. Par défaut, il est activé (`true`).

```csharp
public bool RemoveJavaScript { get; set; }
```
