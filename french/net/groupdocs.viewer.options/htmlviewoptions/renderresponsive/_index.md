## HtmlViewOptions.RenderResponsive property

Active le rendu adaptatif.

```csharp
public bool RenderResponsive { get; set; }
```

### Remarques

Le design réactif vise à faire en sorte que les pages web s’affichent correctement sur une variété d’appareils. Pour rendre avec une mise en page réactive, définissez cette propriété sur `true`.

Pour un exemple de code, consultez la [documentation](https://docs.groupdocs.com/viewer/net/render-with-responsive-layout/).
