## PresentationOptions.RenderToPureHtml property

Active un nouveau mode de rendu HTML pour les documents de présentation — dans ce mode, les fichiers de présentation sont rendus en **pure HTML/CSS markup**, sans images SVG. Par défaut, il est désactivé (`false`) — le rendu HTML basé sur SVG existant est utilisé.

```csharp
public bool RenderToPureHtml { get; set; }
```
