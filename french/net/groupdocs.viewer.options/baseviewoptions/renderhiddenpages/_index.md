## BaseViewOptions.RenderHiddenPages property

Active le rendu des pages cachées.

```csharp
public bool RenderHiddenPages { get; set; }
```

### Remarques

Certains fichiers, tels que des présentations ou des feuilles de calcul, peuvent contenir des pages cachées. Par défaut, GroupDocs.Viewer ne rend pas ces pages. Pour ce faire, définissez cette propriété sur `true`.

Pour un exemple de code, consultez la [documentation](https://docs.groupdocs.com/viewer/net/render-presentations/#render-hidden-slides).
