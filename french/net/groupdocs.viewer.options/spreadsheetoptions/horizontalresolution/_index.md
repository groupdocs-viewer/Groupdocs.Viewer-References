## SpreadsheetOptions.HorizontalResolution property

Obtient ou définit la résolution horizontale des images générées en points par pouce. Cette option n'est utilisée que lors du rendu des feuilles de calcul au format PNG ou JPEG.

```csharp
public int HorizontalResolution { get; set; }
```

### Remarques

La valeur par défaut est de 96 DPI. Valeur minimale possible - 72 DPI, valeur maximale possible - 600 DPI. Si la valeur spécifiée par l'utilisateur est hors de ces limites, la valeur minimale ou maximale possible sera appliquée.
