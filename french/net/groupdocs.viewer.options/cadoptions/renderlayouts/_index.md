## CadOptions.RenderLayouts property

Indique si les mises en page du document CAD doivent être rendues.

```csharp
public bool RenderLayouts { get; set; }
```

### Remarques

Cette option est disponible uniquement pour les dessins CAD qui prennent en charge les mises en page [`DXF`](../../../groupdocs.viewer/filetype/dxf), [`DWG`](../../../groupdocs.viewer/filetype/dwg), [`DWT`](../../../groupdocs.viewer/filetype/dwt) et [`DWF`](../../../groupdocs.viewer/filetype/dwf), ainsi que [`DWFX`](../../../groupdocs.viewer/filetype/dwfx). Par défaut, seul le Modèle est rendu.
