## CadOptions.LayoutName property

Le nom de la mise en page spécifique à rendre. Le nom de la mise en page est sensible à la casse.

```csharp
public string LayoutName { get; set; }
```

### Remarques

Cette option est disponible uniquement pour les dessins CAD qui prennent en charge les mises en page : [`DXF`](../../../groupdocs.viewer/filetype/dxf), [`DWG`](../../../groupdocs.viewer/filetype/dwg), [`DWT`](../../../groupdocs.viewer/filetype/dwt), [`DWF`](../../../groupdocs.viewer/filetype/dwf) et [`DWFX`](../../../groupdocs.viewer/filetype/dwfx) ; par défaut, seul le Modèle est rendu.
