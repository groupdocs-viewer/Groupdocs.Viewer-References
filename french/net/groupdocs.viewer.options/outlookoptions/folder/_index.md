## OutlookOptions.Folder property

Définit le nom du dossier (par ex. Inbox, Sent Item ou Deleted Items) à rendre.

```csharp
public string Folder { get; set; }
```

### Remarques

Lors du rendu d'un fichier de données Outlook, GroupDocs.Viewer rend les messages de tous les dossiers contenus dans le fichier (y compris les dossiers imbriqués). Utilisez cette propriété pour rendre les éléments d'un dossier spécifique.

Pour un exemple de code, consultez cette [documentation](https://docs.groupdocs.com/viewer/net/render-outlook-data-files/#render-a-specific-folder).
