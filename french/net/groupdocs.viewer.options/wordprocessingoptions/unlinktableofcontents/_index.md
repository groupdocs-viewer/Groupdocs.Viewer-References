## WordProcessingOptions.UnlinkTableOfContents property

Lors du rendu vers HTML ou PDF, vous pouvez définir cette option sur `true` pour désactiver la navigation depuis la table des matières. Pour le rendu HTML, les balises `a` avec des liens relatifs seront remplacées par des balises `span`, supprimant la fonctionnalité tout en conservant l'apparence visuelle. Pour le rendu PDF, la table des matières sera rendue en texte brut sans liens vers les sections du document.

```csharp
public bool UnlinkTableOfContents { get; set; }
```

### Remarques

La valeur par défaut est `false`.

Pour plus de détails, voir la [documentation](https://docs.groupdocs.com/viewer/net/render-word-documents/#unlink-table-of-contents).
