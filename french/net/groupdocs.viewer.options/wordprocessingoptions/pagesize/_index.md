## WordProcessingOptions.PageSize property

La taille de la page de sortie. La valeur par défaut est Unspecified, ce qui signifie qu'une taille de page définie dans les paramètres de page (Mise en page) est utilisée. Lors du rendu des fichiers HTM et HTML, la taille de page par défaut est définie sur Letter 792 x 612 points. En conséquence, une partie du contenu peut ne pas tenir dans le cadre de la page. Définissez une taille de page plus grande, par ex. A3, pour faire tenir le contenu.

public PageSize PageSize { get; set; }
