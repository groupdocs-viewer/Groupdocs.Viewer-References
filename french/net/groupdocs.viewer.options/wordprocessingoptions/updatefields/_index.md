## WordProcessingOptions.UpdateFields property

Obtient ou définit une valeur déterminant si les champs de certains types doivent être mis à jour avant d'enregistrer le document WordProcessing d'entrée aux formats de sortie HTML, PDF, PNG ou JPEG. La valeur par défaut pour cette propriété est `true` — les champs seront mis à jour avant l'enregistrement.

```csharp
public bool UpdateFields { get; set; }
```
