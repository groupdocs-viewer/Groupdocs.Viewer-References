## WordProcessingOptions.VerticalResolution property

Obtient ou définit la résolution verticale des images générées en points par pouce. Cette option est utilisée uniquement lors du rendu des documents WordProcessing au format PNG ou JPEG.

```csharp
public int VerticalResolution { get; set; }
```

### Remarques

La valeur par défaut est de 96 DPI. Valeur minimale possible - 72 DPI, valeur maximale possible - 600 DPI. Si la valeur spécifiée par l'utilisateur est hors de ces limites, la valeur minimale ou maximale possible sera appliquée.
