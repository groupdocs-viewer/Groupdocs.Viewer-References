## WordsPageNumberLocation enumeration

Contrôle si la numérotation des pages doit être appliquée de force au document WordProcessing chargé et, le cas échéant, où placer les numéros de page.

```csharp
public enum WordsPageNumberLocation : byte
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| NotApply | `0` | Laisse le document WordProcessing chargé intact. Valeur par défaut. |
| TopLeft | `1` | Place le numéro de page dans le coin supérieur gauche de la page. |
| TopCenter | `2` | Place le numéro de page au centre supérieur de la page. |
| TopRight | `3` | Place le numéro de page dans le coin supérieur droit de la page. |
| BottomLeft | `4` | Place le numéro de page dans le coin inférieur gauche de la page. |
| BottomCenter | `5` | Place le numéro de page au centre inférieur de la page. |
| BottomRight | `6` | Place le numéro de page dans le coin inférieur droit de la page. |
