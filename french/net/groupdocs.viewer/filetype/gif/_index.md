## FileType.GIF field

Le fichier Graphical Interchange Format (.gif) est un type d'image fortement compressée. Pour chaque image, le GIF autorise généralement jusqu'à 8 bits par pixel et jusqu'à 256 couleurs sont permises dans l'image. En savoir plus sur ce format de fichier [ici](https://wiki.fileformat.com/image/gif).
