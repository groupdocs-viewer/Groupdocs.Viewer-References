## FileType.VSTM field

Le modèle de dessin Visio avec macros (.vstm) est un fichier de modèle créé avec Microsoft Visio qui prend en charge les macros. Contrairement aux fichiers VSDX, les fichiers créés à partir de modèles VSTM peuvent exécuter des macros développées en code Visual Basic for Applications (VBA). En savoir plus sur ce format de fichier [ici](https://wiki.fileformat.com/image/vstm).
