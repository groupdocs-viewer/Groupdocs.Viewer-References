## FileType.PDF field

Le fichier Portable Document Format (.pdf) est un type de document créé par Adobe dans les années 1990. Le but de ce format de fichier était d'introduire une norme pour la représentation des documents et autres supports de référence dans un format indépendant des logiciels applicatifs, du matériel ainsi que du système d'exploitation.
