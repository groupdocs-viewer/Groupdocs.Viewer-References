## FileType.FromMediaType method

Mappe le type de média du fichier au type de fichier, par ex. 'application/pdf' sera mappé à [`PDF`](../pdf).

```csharp
public static FileType FromMediaType(string mediaType)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| mediaType | String | Type de média du fichier, par ex. application/pdf. |

### Valeur de retour

Renvoie le type de média correspondant lorsqu'il est trouvé, sinon renvoie le type de fichier par défaut [`Unknown`](../unknown).
