## Viewer.GetAllFonts method

Renvoie toutes les polices utilisées dans les documents chargés, y compris celles qui sont intégrées dans le document lui‑même et les polices système installées dans le système d'exploitation et utilisées dans le document.

```csharp
public IFontInfo[] GetAllFonts()
```

### Valeur de retour

Liste non nulle de toutes les polices utilisées dans le document, chargée dans cette instance de [`Viewer`](../../viewer).

Pour plus de détails, consultez la [documentation](https://docs.groupdocs.com/viewer/net/getting-used-fonts/).
