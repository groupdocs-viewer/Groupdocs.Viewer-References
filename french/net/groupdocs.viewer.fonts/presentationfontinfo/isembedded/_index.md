## PresentationFontInfo.IsEmbedded property

Indique si cette police est intégrée dans le document, chargé dans l'instance [`Viewer`](../../../groupdocs.viewer/viewer) (`true`), ou si c'est une police système (`false`). Les documents de feuille de calcul ne peuvent pas contenir de polices intégrées, donc pour eux cette propriété renvoie toujours `false`.

public bool IsEmbedded { get; }
