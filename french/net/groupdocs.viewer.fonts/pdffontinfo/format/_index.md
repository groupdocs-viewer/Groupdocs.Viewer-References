## PdfFontInfo.Format property

Format de cette police. Les documents peuvent utiliser des polices dans les formats suivants : TrueType, TrueType Collection, OpenType, Embedded OpenType. S'il n'existe que des métadonnées sur cette police, mais que son contenu binaire n'est pas disponible, cette propriété renvoie une valeur Unknown.
