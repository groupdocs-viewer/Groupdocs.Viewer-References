L'espace de noms fournit différentes classes d'exceptions.

## Classes

| Classe | Description |
| --- | --- |
| [GroupDocsViewerException](./groupdocsviewerexception) | Représente les erreurs génériques qui surviennent lors du traitement du document. |

| [InvalidFontFormatException](./invalidfontformatexception) | L'exception qui est levée lorsqu'on essaie d'ouvrir, charger, enregistrer ou traiter d'une quelconque manière un contenu qui est supposément une police d'un format pris en charge (connu), mais qui est en réalité une police d'un format inattendu et/ou non pris en charge ou qui n'est pas du tout une police. |

| [PasswordRequiredException](./passwordrequiredexception) | L'exception qui est levée lorsque le mot de passe est requis pour charger le document. |
