## License class

Gère la licence de GroupDocs.Viewer.

Les versions sous licence débloquent l'ensemble complet des fonctionnalités du wrapper à
temps d'exécution. Les versions non licenciées s'exécutent en mode d'évaluation avec la même API
surface mais avec des limites sur la taille de sortie et le contenu filigrané.

Le type License expose les membres suivants :
