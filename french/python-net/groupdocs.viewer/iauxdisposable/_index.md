## IAuxDisposable class

Étend l’interface standard `System.IDisposable`, permet d’obtenir l’état actuel d’un objet et de s’abonner à un événement de libération.

Le type IAuxDisposable expose les membres suivants :

### Propriétés
| Propriété | Description |
| :- | :- |
| [is_disposed](/viewer/python-net/groupdocs.viewer/iauxdisposable/is_disposed/) | La propriété indique si une ressource est déjà libérée (`True`) ou non (`False`). |
