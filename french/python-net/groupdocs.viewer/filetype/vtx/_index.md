## VTX field

Visio Template XML File (.vtx) est un modèle de dessin Microsoft Visio enregistré sur le disque au format XML. Ce modèle vise à fournir un fichier avec des paramètres de base pouvant être utilisés pour créer plusieurs fichiers Visio avec les mêmes paramètres. En savoir plus sur ce format de fichier ici.
