## GZIP field

Gnu Zipped File (.gzip) a été introduit comme un utilitaire gratuit pour remplacer le programme Compress utilisé dans les systèmes Unix. Ces fichiers peuvent être ouverts et extraits avec plusieurs applications telles que WinZip, disponible à la fois sur Windows et macOS. En savoir plus sur ce format de fichier ici.
