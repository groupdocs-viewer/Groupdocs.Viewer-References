## AZW3 field

Le ebook Amazon Kindle Format 8 (KF8) est le format de fichier numérique développé pour les appareils Amazon Kindle. Ce format est une amélioration des anciens fichiers AZW et est utilisé uniquement sur les appareils Kindle Fire avec une compatibilité descendante avec les formats de fichiers antérieurs, à savoir MOBI et AZW. En savoir plus sur ce format de fichier ici.
