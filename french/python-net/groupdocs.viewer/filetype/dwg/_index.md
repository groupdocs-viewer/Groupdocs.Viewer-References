## DWG field

AutoCAD Drawing Database File (.dwg) représente des fichiers binaires propriétaires utilisés pour contenir des données de conception 2D et 3D. Comme le DXF, qui sont des fichiers ASCII, le DWG représente le format de fichier binaire pour les dessins CAO (Conception Assistée par Ordinateur). En savoir plus sur ce format de fichier ici.
