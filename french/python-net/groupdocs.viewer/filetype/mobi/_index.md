## MOBI field

Le eBook Mobipocket (.mobi) est l'un des formats de fichier ebook les plus largement utilisés. Ce format est une amélioration du vieux format OEB (Open Ebook Format) et était utilisé comme format propriétaire pour le lecteur Mobipocket. En savoir plus sur ce format de fichier ici.
