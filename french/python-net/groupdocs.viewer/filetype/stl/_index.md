## STL field

Stereolithography File (.stl) est un format de fichier interchangeable qui représente la géométrie de surface tridimensionnelle. Ce format de fichier est utilisé dans plusieurs domaines tels que le prototypage rapide, l'impression 3D et la fabrication assistée par ordinateur. En savoir plus sur ce format de fichier ici.
