## PNG field

Le Portable Network Graphic (.png) est un type de format de fichier image matricielle qui utilise une compression sans perte. Ce format a été créé comme remplacement du Graphics Interchange Format (GIF) et ne comporte aucune limitation de droits d'auteur. En savoir plus sur ce format de fichier ici.
