## XLT field

Microsoft Excel Template (.xlt) sont des fichiers modèle créés avec Microsoft Excel, une application de tableur faisant partie de la suite Microsoft Office. Microsoft Office 97-2003 permettait de créer de nouveaux fichiers XLT ainsi que de les ouvrir. En savoir plus sur ce format de fichier ici.
