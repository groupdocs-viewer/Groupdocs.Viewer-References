## OST field

Le fichier Outlook Offline Data (.ost) représente les données de boîte aux lettres de l'utilisateur en mode hors ligne sur la machine locale après l'enregistrement auprès du serveur Exchange via Microsoft Outlook. En savoir plus sur ce format de fichier ici.
