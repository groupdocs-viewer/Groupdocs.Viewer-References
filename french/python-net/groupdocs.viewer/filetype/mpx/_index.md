## MPX field

Le fichier d’échange Microsoft Project (.mpx) est un format de fichier ASCII pour le transfert d’informations de projet entre Microsoft Project (MSP) et d’autres applications qui prennent en charge le format de fichier MPX telles que Primavera Project Planner, Sciforma et Timerline Precision Estimating.
