## TIFF field

Le format Tagged Image File (.tiff) représente des images matricielles destinées à être utilisées sur une variété d'appareils compatibles avec cette norme de format de fichier. Il peut décrire des données d'image binaire, en niveaux de gris, à palette de couleurs et en couleur pleine dans plusieurs espaces colorimétriques. En savoir plus sur ce format de fichier ici.
