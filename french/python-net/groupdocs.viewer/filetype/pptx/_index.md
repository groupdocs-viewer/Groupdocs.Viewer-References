## PPTX field

Les présentations PowerPoint Open XML (.pptx) sont des fichiers de présentation créés avec l'application Microsoft PowerPoint populaire. Contrairement à la version précédente du format de fichier de présentation PPT qui était binaire, le format PPTX est basé sur le format de fichier de présentation Open XML de Microsoft PowerPoint. En savoir plus sur ce format de fichier ici.
