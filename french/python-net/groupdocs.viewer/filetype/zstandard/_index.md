## ZSTANDARD field

Le fichier ZST est un fichier compressé généré avec l'algorithme de compression Zstandard (zstd). Il s'agit d'un fichier compressé créé avec une compression sans perte par cet algorithme. Les fichiers ZST peuvent être utilisés pour compresser différents types de fichiers tels que les bases de données, les systèmes de fichiers, les réseaux et les jeux. En savoir plus sur ce format de fichier ici.
