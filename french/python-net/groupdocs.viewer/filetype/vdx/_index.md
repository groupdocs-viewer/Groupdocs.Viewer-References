## VDX field

Visio Drawing XML File (.vdx) représente tout dessin ou graphique créé dans Microsoft Visio, mais enregistré au format XML avec l’extension .VDX. Un fichier XML de dessin Visio est créé dans le logiciel Visio, développé par Microsoft. En savoir plus sur ce format de fichier ici.
