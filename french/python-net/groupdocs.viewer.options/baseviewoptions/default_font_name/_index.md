## default_font_name property

La police par défaut pour un document utilisée lors du rendu lorsqu’une police requise est manquante.

Utilisez cette propriété pour définir la police par défaut d'un document. GroupDocs.Viewer utilise cette police lors du rendu à la place de toute police non installée.

Pour des exemples de code, consultez la documentation : https://docs.groupdocs.com/viewer/net/replace-missing-font/
