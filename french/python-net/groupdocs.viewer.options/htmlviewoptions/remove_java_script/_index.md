## remove_java_script property

La propriété détermine si le code source JavaScript est supprimé des liens dans les documents HTML générés lors du rendu de documents d'entrée contenant des scripts. Activée par défaut (`True`).

Pour plus de détails sur la suppression de JavaScript, consultez la documentation : https://docs.groupdocs.com/viewer/net/rendering-to-html/#preserving-or-disabling-javascript-when-rendering-to-html
