## exclude_fonts property

La propriété désactive l'ajout de toute police dans le document HTML.

Par défaut, GroupDocs.Viewer intègre les polices utilisées dans le document dans le balisage HTML, et cette propriété a la valeur `False`. Pour empêcher l'intégration des polices, définissez cette propriété sur `True`.
