## enable_font_hinting property

La propriété active le lissage des polices.

Le hinting de police ajuste la façon dont une police de contour est affichée. Applicable uniquement aux polices TTF utilisées dans le document source. Cette option est disponible pour le rendu aux formats PNG ou JPG. La valeur par défaut est False.
