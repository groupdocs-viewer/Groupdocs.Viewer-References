## EmailOptions class

Contient des options pour le rendu des messages électroniques.

GroupDocs.Viewer prend en charge la classe EmailOptions qui vous permet de spécifier différentes options pour le rendu des messages électroniques. Pour accéder à ces options, utilisez la propriété EmailOptions sur l'une des classes d'options de visualisation suivantes, en fonction du format de sortie souhaité :

- [`HtmlViewOptions`](/viewer/python-net/groupdocs.viewer.options/htmlviewoptions/)
- [`PdfViewOptions`](/viewer/python-net/groupdocs.viewer.options/pdfviewoptions/)
- [`PngViewOptions`](/viewer/python-net/groupdocs.viewer.options/pngviewoptions/)
- [`JpgViewOptions`](/viewer/python-net/groupdocs.viewer.options/jpgviewoptions/)

Le type EmailOptions expose les membres suivants :

| Propriété | Description |

| [field_text_map](/viewer/python-net/groupdocs.viewer.options/emailoptions/field_text_map/) | Le mappage entre le message électronique [`Field`](/viewer/python-net/groupdocs.viewer.options/field/) et la représentation du texte du champ. |

| [time_zone_offset](/viewer/python-net/groupdocs.viewer.options/emailoptions/time_zone_offset/) | Le décalage du fuseau horaire du message. |
