## max_width property

La largeur maximale d'une image de sortie en pixels (uniquement pour le rendu en PNG/JPG).

Utilisez cette propriété pour définir la largeur maximale de l'image de sortie (en pixels). Pour un exemple de code, consultez la documentation.

Si vous définissez la propriété [`ViewInfoOptions.Width`](/viewer/python-net/groupdocs.viewer.options/viewinfooptions/width/), cette propriété est ignorée.
