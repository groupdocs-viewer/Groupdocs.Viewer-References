### Exemple

```python
from groupdocs.viewer import Viewer
from groupdocs.viewer.options import JpgViewOptions

def render_to_jpg():
    # Chargez un document (p. ex., Excel, Numbers ou image)
    with Viewer("invoice.xlsx") as viewer:
        # Créez des options d'affichage JPG avec un modèle de fichier de sortie.
        # {0} sera remplacé par le numéro de page.
        view_options = JpgViewOptions("output_{0}.jpg")
        # Définissez la taille d'image de sortie souhaitée en pixels.
        view_options.width = 800
        view_options.height = 900
        # Rendre le document en fichiers JPEG.
        viewer.view(view_options)

if __name__ == "__main__":
    render_to_jpg()
```
