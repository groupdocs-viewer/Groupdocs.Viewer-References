## enable_performance_conversion_mode property

Le drapeau qui active un mode de conversion orienté performance pour tous les formats CAD, où le définir sur True accélère la conversion au prix d'une qualité de sortie réduite ; la valeur par défaut est False pour une qualité maximale.
