## render_to_pure_html property

La propriété active un nouveau mode de rendu HTML pour les documents Presentation — dans ce mode, les fichiers sont rendus en balisage HTML/CSS pur sans images SVG. Par défaut, il est désactivé (`False`), et le rendu HTML basé sur SVG existant est utilisé.

Pour un exemple de code, consultez la documentation à l'adresse https://docs.groupdocs.com/viewer/net/render-presentations/#generate-pure-htmlcss-markup.
