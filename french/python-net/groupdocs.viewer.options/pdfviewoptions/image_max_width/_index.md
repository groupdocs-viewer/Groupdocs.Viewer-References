## image_max_width property

La largeur maximale d'une image de sortie en pixels.

Utilisez cette propriété pour définir la largeur maximale de l'image de sortie (en pixels). GroupDocs.Viewer applique cette propriété lors du rendu d'une seule image en PDF. Pour plus de détails, consultez la documentation.

Si vous définissez la propriété [`PdfViewOptions.ImageWidth`](/viewer/python-net/groupdocs.viewer.options/pdfviewoptions/image_width/), cette propriété est ignorée.
