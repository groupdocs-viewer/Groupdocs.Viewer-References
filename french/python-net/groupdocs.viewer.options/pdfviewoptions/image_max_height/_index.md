## image_max_height property

La hauteur maximale d'une image de sortie en pixels.

Utilisez cette propriété pour définir la hauteur maximale de l'image de sortie (en pixels). GroupDocs.Viewer applique cette propriété lors du rendu d'une seule image en PDF. Pour plus de détails, consultez la documentation.

Si vous définissez la propriété [`PdfViewOptions.ImageHeight`](/viewer/python-net/groupdocs.viewer.options/pdfviewoptions/image_height/), cette propriété est ignorée.
