## image_width property

La largeur de l'image de sortie en pixels.

Utilisez cette propriété pour définir la largeur de l'image de sortie (en pixels). GroupDocs.Viewer applique cette propriété lors du rendu d'une seule image en PDF. Pour plus de détails, consultez la documentation.

Si vous définissez cette propriété, la propriété [`PdfViewOptions.ImageMaxWidth`](/viewer/python-net/groupdocs.viewer.options/pdfviewoptions/image_max_width/) est ignorée.
