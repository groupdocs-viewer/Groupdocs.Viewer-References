## update_fields property

La propriété détermine si les champs de certains types sont mis à jour avant d'enregistrer le document WordProcessing aux formats HTML, PDF, PNG ou JPEG. La valeur par défaut est True, ce qui signifie que les champs sont mis à jour.

Pour plus de détails, voir la documentation : https://docs.groupdocs.com/viewer/net/render-word-documents/#disable-updating-fields-when-saving
