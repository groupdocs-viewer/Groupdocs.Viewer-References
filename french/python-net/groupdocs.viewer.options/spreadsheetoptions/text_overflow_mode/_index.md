## text_overflow_mode property

Le mode de dépassement de texte pour le rendu des documents de feuille de calcul en HTML. La valeur par défaut est `TextOverflowMode.OverlayIfNextIsEmpty`, qui imite le comportement par défaut de MS Excel.
