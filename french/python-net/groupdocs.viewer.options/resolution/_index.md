## Resolution class

Contient une option pour définir la résolution des images dans le document de sortie.

Le type Resolution expose les membres suivants :

### Constructeurs
| Constructeur | Description |
| :- | :- |
| [__init__](/viewer/python-net/groupdocs.viewer.options/resolution/__init__/#value) | Initialise la résolution en DPI. |

### Propriétés
| Propriété | Description |
| :- | :- |
| [value](/viewer/python-net/groupdocs.viewer.options/resolution/value/) | Le DPI de qualité. |

### Champs
| Champ | Description |
| :- | :- |
| [DPI330](/viewer/python-net/groupdocs.viewer.options/resolution/dpi330/) | Bonne qualité pour les écrans haute définition (HD). |
| [DPI220](/viewer/python-net/groupdocs.viewer.options/resolution/dpi220/) | Qualité excellente sur la plupart des imprimantes et écrans. |
| [DPI150](/viewer/python-net/groupdocs.viewer.options/resolution/dpi150/) | Bon pour les pages web et les projecteurs. |
| [DPI96](/viewer/python-net/groupdocs.viewer.options/resolution/dpi96/) | Bon pour les pages web et les projecteurs. |
| [DPI72](/viewer/python-net/groupdocs.viewer.options/resolution/dpi72/) | Niveau de compression par défaut. |
| [DOCUMENT_RESOLUTION](/viewer/python-net/groupdocs.viewer.options/resolution/document_resolution/) | Niveau de compression par défaut - comme dans le document. |
