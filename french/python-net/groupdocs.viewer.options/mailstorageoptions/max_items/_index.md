## max_items property

Le nombre maximal de messages ou d'éléments à rendre.

Les fichiers de données de stockage de courrier peuvent être volumineux et la récupération de tous les messages peut prendre un temps considérable. Cette propriété limite le nombre maximal de messages ou d'éléments rendus. La valeur par défaut est 0 – tous les messages sont rendus.
