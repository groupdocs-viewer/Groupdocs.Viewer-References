## subset_fonts property

La propriété crée des sous‑ensembles de polices dans le fichier PDF de sortie.

Si le fichier utilise des polices intégrées, il contient toutes les données de police. GroupDocs.Viewer peut sous‑ensembliser les polices intégrées pour réduire la taille du fichier. Pour un exemple de code, consultez la documentation.
