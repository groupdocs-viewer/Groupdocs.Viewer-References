## resize_images property

La propriété permet de définir la résolution maximale dans le fichier PDF de sortie.

Pour activer cette option, définissez la propriété [`PdfOptimizationOptions.compress_images`](/viewer/python-net/groupdocs.viewer.options/pdfoptimizationoptions/compress_images/) sur `True`. Cette option permet de définir la propriété [`PdfOptimizationOptions.max_resolution`](/viewer/python-net/groupdocs.viewer.options/pdfoptimizationoptions/max_resolution/).
