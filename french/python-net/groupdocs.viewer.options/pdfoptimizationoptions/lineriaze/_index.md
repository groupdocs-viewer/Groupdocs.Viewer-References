## lineriaze property

La propriété permet d'optimiser le fichier PDF de sortie pour la visualisation en ligne avec un navigateur web.

Cette optimisation permet à un navigateur d’afficher les premières pages d’un fichier PDF lorsque vous ouvrez le document, au lieu d’attendre le téléchargement complet du fichier. Pour un exemple de code, consultez la documentation.
