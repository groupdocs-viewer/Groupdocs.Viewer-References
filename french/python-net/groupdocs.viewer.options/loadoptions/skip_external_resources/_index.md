## skip_external_resources property

La propriété désactive le chargement de toutes les ressources externes telles que les images, sauf celles répertoriées dans [`LoadOptions.whitelisted_resources`](/viewer/python-net/groupdocs.viewer.options/loadoptions/whitelisted_resources/).

Pour un exemple de code, consultez la documentation à l'adresse https://docs.groupdocs.com/viewer/net/loading-external-resources/#skip-loading-of-external-resources.
