## max_width property

La largeur maximale d'une image de sortie en pixels.

Utilisez cette propriété pour définir la largeur maximale de l'image de sortie (en pixels). Pour un exemple de code, voir la documentation : https://docs.groupdocs.com/viewer/net/set-image-size-limits-when-rendering-to-png-jpg/
