## CacheKeys class

Fournit des méthodes pour récupérer l'identifiant unique de l'entrée du cache.

Le type CacheKeys expose les membres suivants :

| Méthode | Description |
| :- | :- |
| [get_attachment_key](/viewer/python-net/groupdocs.viewer.caching/cachekeys/get_attachment_key/#attachment_id) | Renvoie un identifiant unique pour l'entrée du cache qui représente le fichier de pièce jointe. |
| [get_attachments_key](/viewer/python-net/groupdocs.viewer.caching/cachekeys/get_attachments_key/) | Renvoie un identifiant unique pour l'entrée du cache qui représente une collection d'objets [`Attachment`](/viewer/python-net/groupdocs.viewer.results/attachment/). |
| [get_file_info_key](/viewer/python-net/groupdocs.viewer.caching/cachekeys/get_file_info_key/) | Renvoie un identifiant unique pour l'entrée du cache qui représente l'objet [`ViewInfo`](/viewer/python-net/groupdocs.viewer.results/viewinfo/). |
| [get_file_key](/viewer/python-net/groupdocs.viewer.caching/cachekeys/get_file_key/#extension) | Renvoie un identifiant unique pour l'entrée du cache qui représente le fichier. |
| [get_page_key](/viewer/python-net/groupdocs.viewer.caching/cachekeys/get_page_key/#page_number-extension) | Renvoie un identifiant unique pour l'entrée du cache qui représente le fichier de page. |
| [get_resource_filter](/viewer/python-net/groupdocs.viewer.caching/cachekeys/get_resource_filter/#page_number) | Renvoie une chaîne de filtre pour rechercher les entrées du cache qui représentent des objets [`Resource`](/viewer/python-net/groupdocs.viewer.results/resource/). |
| [get_resource_key](/viewer/python-net/groupdocs.viewer.caching/cachekeys/get_resource_key/#page_number-resource) | Renvoie un identifiant unique pour l'entrée du cache qui représente l'objet [`Resource`](/viewer/python-net/groupdocs.viewer.results/resource/). |
| [get_view_info_key](/viewer/python-net/groupdocs.viewer.caching/cachekeys/get_view_info_key/) | Renvoie un identifiant unique pour l'entrée du cache qui représente l'objet [`ViewInfo`](/viewer/python-net/groupdocs.viewer.results/viewinfo/). |
