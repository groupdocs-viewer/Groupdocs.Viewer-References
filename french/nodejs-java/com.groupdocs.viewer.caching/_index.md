Le package fournit des classes pour personnaliser le comportement du cache.

Les principales classes et interfaces de ce package sont :

 *  [CacheKeys](../../com.groupdocs.viewer.caching/cachekeys) - Provides methods to retrieve unique identifiers for the cache entry.
 *  [FileCache](../../com.groupdocs.viewer.caching/filecache) - Represents a local on-disk cache.

L'interface [Cache](../../com.groupdocs.viewer.caching/cache) définit les méthodes requises pour stocker les documents rendus et les ressources de documents dans le cache.

Pour plus de détails sur la personnalisation du comportement du cache dans GroupDocs.Viewer, veuillez vous référer à la [GroupDocs.Viewer Documentation][].


[GroupDocs.Viewer Documentation]: https://docs.groupdocs.com/viewer/java/
