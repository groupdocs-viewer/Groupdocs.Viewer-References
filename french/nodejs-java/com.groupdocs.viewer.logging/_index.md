Le package fournit des classes pour configurer le système de journalisation dans GroupDocs.Viewer.

En utilisant ces classes, vous pouvez contrôler la façon dont les messages de journal sont gérés, par exemple en les écrivant dans un fichier ou en les dirigeant vers une implémentation de logger spécifique.

Les principales classes de ce package sont :

 *  [FileLogger](../../com.groupdocs.viewer.logging/filelogger) - Writes log messages to a file.
 *  [ViewerLogger](../../com.groupdocs.viewer.logging/viewerlogger) - Implements logging messages to an integrated or user-defined logger.

Pour plus de détails sur la configuration du système de journalisation dans GroupDocs.Viewer et la personnalisation du traitement des messages de journal, veuillez consulter la [GroupDocs.Viewer Documentation][].


[GroupDocs.Viewer Documentation]: https://docs.groupdocs.com/viewer/java/


## Classes

| Classe | Description |
| --- | --- |
| [FileLogger](../com.groupdocs.viewer.logging/filelogger) | Écrit les messages de journal dans un fichier. |
| [ViewerLogger](../com.groupdocs.viewer.logging/viewerlogger) | Journal global du visualiseur. |
