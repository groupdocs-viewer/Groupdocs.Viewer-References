Le package fournit des classes pour spécifier des options supplémentaires lors du rendu de documents.

Il comprend des options pour le rendu de différents formats de documents, la définition des autorisations et des paramètres de sécurité, la spécification des propriétés de filigrane, ainsi que la récupération d'informations sur les vues.

Les principales classes de ce package sont :

 *  [ArchiveOptions](../../com.groupdocs.viewer.options/archiveoptions) - Provides options for rendering archive files.
 *  [PdfOptions](../../com.groupdocs.viewer.options/pdfoptions) - Provides options for rendering PDF documents.
 *  [WordProcessingOptions](../../com.groupdocs.viewer.options/wordprocessingoptions) - Provides options for rendering word processing documents.

Pour plus de détails sur la configuration du système de journalisation dans GroupDocs.Viewer et la personnalisation du traitement des messages de journal, veuillez consulter la [GroupDocs.Viewer Documentation][].


[GroupDocs.Viewer Documentation]: https://docs.groupdocs.com/viewer/java/
