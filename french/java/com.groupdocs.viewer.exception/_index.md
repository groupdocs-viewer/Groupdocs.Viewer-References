Le package fournit des classes pour les exceptions pouvant survenir lors de la manipulation d'un document.

Les principales classes de ce package sont :

* com.groupdocs.viewer.exception.ArchiveSecurityException - Thrown when an archive being opened exceeds specified limits.
* [FileNotFoundException](../../com.groupdocs.viewer.exception/filenotfoundexception) - Represents an exception thrown when a file or directory is not found.
* [GroupDocsViewerException](../../com.groupdocs.viewer.exception/groupdocsviewerexception) - Represents generic errors that occur during document processing.


Pour plus de détails sur la gestion des exceptions dans GroupDocs.Viewer, veuillez vous référer au
[GroupDocs.Viewer Documentation](../https://docs.groupdocs.com/viewer/java/).



## Classes

| Classe | Description |
| --- | --- |
| [ArchiveSecurityException](../com.groupdocs.viewer.exception/archivesecurityexception) | Cette exception est levée lorsqu'une archive ouverte dépasse l'une des limites spécifiées dans ArchiveSecurityOptions. |
| [FileNotFoundException](../com.groupdocs.viewer.exception/filenotfoundexception) | Cette exception est levée lorsqu'un fichier ou un répertoire est introuvable. |
| [GroupDocsViewerException](../com.groupdocs.viewer.exception/groupdocsviewerexception) | Cette exception représente des erreurs génériques pouvant survenir lors du traitement de documents. |
| [IncorrectPasswordException](../com.groupdocs.viewer.exception/incorrectpasswordexception) | Cette exception est levée lorsque le mot de passe spécifié est incorrect. |
| [NotSupportedException](../com.groupdocs.viewer.exception/notsupportedexception) | Cette exception est levée lorsque l'opération demandée n'est pas prise en charge. |
| [PasswordRequiredException](../com.groupdocs.viewer.exception/passwordrequiredexception) | Cette exception est levée lorsqu'un mot de passe est requis pour charger le document. |
