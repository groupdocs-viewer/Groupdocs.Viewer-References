Contrôle si l’on doit appliquer de force la numérotation des pages au document WordProcessing chargé et, le cas échéant, où placer les numéros de page.

## Champs

| Champ | Description |
| --- | --- |
|  | [NOT_APPLY](#NOT-APPLY) | Laisser le document WordProcessing chargé intact. |
|
|  | [TOP_LEFT](#TOP-LEFT) | Placer le numéro de page dans le coin supérieur gauche de la page. |
|
|  | [TOP_CENTER](#TOP-CENTER) | Placer le numéro de page au centre supérieur de la page. |
|
|  | [TOP_RIGHT](#TOP-RIGHT) | Placer le numéro de page dans le coin supérieur droit de la page. |
|
|  | [BOTTOM_LEFT](#BOTTOM-LEFT) | Placer le numéro de page dans le coin inférieur gauche de la page. |
|
|  | [BOTTOM_CENTER](#BOTTOM-CENTER) | Placer le numéro de page au centre inférieur de la page. |
|
|  | [BOTTOM_RIGHT](#BOTTOM-RIGHT) | Placer le numéro de page dans le coin inférieur droit de la page. |
|
