## is_embedded property

Properti ini menunjukkan apakah font tersemat di dalam dokumen dan dimuat ke dalam instance [`Viewer`](/viewer/python-net/groupdocs.viewer/viewer/) (`True`), atau merupakan font sistem (`False`).

Dokumen Spreadsheet tidak dapat menyimpan font yang disematkan, sehingga properti ini selalu mengembalikan `False` untuk mereka.
