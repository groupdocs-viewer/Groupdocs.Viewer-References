## exclude_fonts property

Properti ini menonaktifkan penambahan font apa pun ke dalam dokumen HTML.

Secara default, GroupDocs.Viewer menyematkan font yang digunakan dalam dokumen ke dalam markup HTML, dan properti ini memiliki nilai `False`. Untuk mencegah penyematan font, setel properti ini ke `True`.
