## render_to_pure_html property

Properti ini mengaktifkan mode rendering HTML baru untuk dokumen Presentation — dalam mode ini file dirender menjadi markup HTML/CSS murni tanpa gambar SVG. Secara default mode ini dinonaktifkan (`False`), dan renderer HTML berbasis SVG yang ada digunakan.

Untuk contoh kode, lihat dokumentasi di https://docs.groupdocs.com/viewer/net/render-presentations/#generate-pure-htmlcss-markup.
