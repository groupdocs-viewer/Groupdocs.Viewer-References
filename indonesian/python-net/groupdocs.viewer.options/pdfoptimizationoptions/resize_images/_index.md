## resize_images property

Properti ini memungkinkan penetapan resolusi maksimum dalam file PDF keluaran.

Untuk mengaktifkan opsi ini, setel properti [`PdfOptimizationOptions.compress_images`](/viewer/python-net/groupdocs.viewer.options/pdfoptimizationoptions/compress_images/) menjadi `True`. Opsi ini memungkinkan pengaturan properti [`PdfOptimizationOptions.max_resolution`](/viewer/python-net/groupdocs.viewer.options/pdfoptimizationoptions/max_resolution/).
