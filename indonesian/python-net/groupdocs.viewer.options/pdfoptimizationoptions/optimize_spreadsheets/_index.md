## optimize_spreadsheets property

Properti yang memungkinkan optimasi spreadsheet dalam file PDF.

Optimisasi ini mengurangi ukuran file output dengan mengatur garis batas dan menghapus karakter Arial serta Times New Roman dengan kode 32‑127. Nilai default adalah `False`.
