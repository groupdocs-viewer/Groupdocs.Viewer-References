## max_items_in_folder property

Jumlah maksimum pesan atau item yang dapat dirender dari satu folder.

File data Outlook dapat berukuran besar dan mengambil semua pesan dapat memakan waktu yang signifikan. Properti ini membatasi jumlah maksimum pesan atau item yang dirender. Nilai default adalah `50`. Untuk merender semua pesan, setel nilai menjadi `0`.
