## for_rendering_by_width_and_height {#width-height}

Menginisialisasi sebuah instance dari kelas CadOptions untuk rendering berdasarkan lebar dan tinggi.

Untuk contoh kode, lihat dokumentasi.

```python
def for_rendering_by_width_and_height(cls, width, height):
    ...
```

| Parameter | Tipe | Deskripsi |
| :- | :- | :- |
| width | `int` | Lebar hasil output (dalam piksel). |
| height | `int` | Tinggi hasil output (dalam piksel). |

**Returns:** CadOptions: New instance of CadOptions class for rendering by width and height.

| Mengecualikan | Deskripsi |
| :- | :- |
| `ValueError` | Jika `height` kurang dari atau sama dengan nol. |
