## image_height property

Tinggi gambar output dalam piksel.

Gunakan properti ini untuk mengatur tinggi gambar output (dalam piksel). GroupDocs.Viewer menerapkan properti ini hanya saat merender satu gambar ke HTML. Untuk detail, lihat dokumentasi di https://docs.groupdocs.com/viewer/net/set-image-size-limits-when-rendering-to-pdf/.

Jika Anda mengatur properti ini, properti [`PdfViewOptions.ImageMaxHeight`](/viewer/python-net/groupdocs.viewer.options/pdfviewoptions/image_max_height/) diabaikan.
