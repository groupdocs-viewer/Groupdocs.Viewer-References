## render_text_as_image property

Opsi ini mengaktifkan perenderan teks dalam file PDF sebagai gambar dalam keluaran HTML.

Ketika opsi ini diatur ke True, GroupDocs.Viewer merender teks sebagai gambar dalam output HTML. Ini membuat teks tidak dapat dipilih dan meningkatkan rendering karakter, memastikan tampilan mirip PDF dalam HTML. Nilai default adalah False.

Opsi ini tersedia untuk merender ke HTML.
