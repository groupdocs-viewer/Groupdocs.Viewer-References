## enable_font_hinting property

Properti ini mengaktifkan petunjuk font.

Petunjuk font menyesuaikan cara font outline ditampilkan. Hanya berlaku untuk font TTF yang digunakan dalam dokumen sumber. Opsi ini tersedia untuk merender ke format PNG atau JPG. Nilai default adalah False.
