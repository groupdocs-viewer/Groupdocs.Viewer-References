## enable_layered_rendering property

Properti ini mengaktifkan perenderan teks dan grafik dalam urutan z dokumen PDF asli saat merender ke HTML.

Secara default, GroupDocs.Viewer merender teks dan grafik sebagai satu lapisan tunggal dalam HTML. Opsi ini memungkinkan Anda mengatur objek dalam urutan yang sama seperti pada file sumber. Nilai default adalah False.
