## GZ field

Gnu Zipped File (.gz) adalah file terkompresi yang dibuat dengan aplikasi kompresi gzip. File ini dapat berisi beberapa file terkompresi dan biasanya digunakan pada sistem UNIX dan Linux. Pelajari lebih lanjut tentang format file ini di sini.
