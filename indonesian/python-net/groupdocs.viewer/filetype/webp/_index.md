## WEBP field

WebP Image (.webp) adalah format file gambar raster web modern yang berbasis pada kompresi lossless dan lossy. Ini memberikan kualitas gambar yang sama sambil secara signifikan mengurangi ukuran gambar. Pelajari lebih lanjut tentang format file ini di sini.
