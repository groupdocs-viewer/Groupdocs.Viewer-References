## GZIP field

Gnu Zipped File (.gzip) diperkenalkan sebagai utilitas gratis untuk menggantikan program Compress yang digunakan pada sistem Unix. File semacam itu dapat dibuka dan diekstrak dengan beberapa aplikasi seperti WinZip yang tersedia di Windows maupun MacOS. Pelajari lebih lanjut tentang format file ini di sini.
