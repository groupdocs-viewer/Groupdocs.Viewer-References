## VST field

Visio Drawing Template (.vst) adalah file gambar vektor yang dibuat dengan Microsoft Visio dan berfungsi sebagai templat untuk membuat file selanjutnya. File templat ini berformat biner dan berisi tata letak serta pengaturan default yang digunakan untuk membuat gambar Visio baru. Pelajari lebih lanjut tentang format file ini di sini.
