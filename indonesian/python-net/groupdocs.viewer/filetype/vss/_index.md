## VSS field

Visio Stencil File(.vss) adalah file stensil yang dibuat dengan Microsoft Visio 2007 dan versi sebelumnya. File stensil menyediakan objek gambar yang dapat dimasukkan ke dalam gambar Visio .VSD. Pelajari lebih lanjut tentang format file ini di sini.
