## VCF field

vCard File (.vcf) adalah format file digital untuk menyimpan informasi kontak. Format ini banyak digunakan untuk pertukaran data di antara aplikasi pertukaran informasi yang populer. Pelajari lebih lanjut tentang format file ini di sini.
