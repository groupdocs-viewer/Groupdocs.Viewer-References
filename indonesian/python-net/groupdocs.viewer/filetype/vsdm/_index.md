## VSDM field

Visio Macro-Enabled Drawing (.vsdm) adalah file gambar yang dibuat dengan aplikasi Microsoft Visio yang mendukung makro. File VSDM adalah gambar OPC/XML yang mirip dengan VSDX, tetapi juga menyediakan kemampuan menjalankan makro saat file dibuka. Pelajari lebih lanjut tentang format file ini di sini.
