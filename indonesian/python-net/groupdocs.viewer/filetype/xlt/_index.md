## XLT field

Microsoft Excel Template (.xlt) adalah file templat yang dibuat dengan Microsoft Excel, yaitu aplikasi spreadsheet yang merupakan bagian dari paket Microsoft Office. Microsoft Office 97-2003 mendukung pembuatan file XLT baru serta membuka file tersebut. Pelajari lebih lanjut tentang format file ini di sini.
