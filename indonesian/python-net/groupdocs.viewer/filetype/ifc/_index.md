## IFC field

Industry Foundation Classes File (.ifc) adalah format file yang menetapkan standar internasional untuk mengimpor dan mengekspor objek bangunan serta propertinya. Format file ini menyediakan interoperabilitas antara berbagai aplikasi perangkat lunak. Pelajari lebih lanjut tentang format file ini di sini.
