## TIFF field

Tagged Image File Format (.tiff) mewakili gambar raster yang ditujukan untuk penggunaan pada berbagai perangkat yang mematuhi standar format file ini. Format ini mampu menggambarkan data gambar blevel, skala abu-abu, palet-warna, dan warna penuh dalam beberapa ruang warna. Pelajari lebih lanjut tentang format file ini di sini.
