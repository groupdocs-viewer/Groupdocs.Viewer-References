## MOBI field

Mobipocket eBook (.mobi) adalah salah satu format file ebook yang paling banyak digunakan. Format ini merupakan peningkatan dari format OEB (Open Ebook Format) lama dan digunakan sebagai format proprietari untuk Mobipocket Reader. Pelajari lebih lanjut tentang format file ini di sini.
