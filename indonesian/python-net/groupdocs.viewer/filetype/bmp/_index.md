## BMP field

File Gambar Bitmap (.bmp) digunakan untuk menyimpan gambar digital bitmap. Gambar ini independen dari adaptor grafis dan juga disebut format file bitmap independen perangkat (DIB). Pelajari lebih lanjut tentang format file ini di sini.
