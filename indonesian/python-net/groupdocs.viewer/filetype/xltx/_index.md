## XLTX field

Excel Open XML Spreadsheet Template (.xltx) mewakili Templat Microsoft Excel yang berbasis pada spesifikasi format file Office OpenXML. Templat ini digunakan untuk membuat file templat standar yang dapat digunakan untuk menghasilkan file XLSX yang memiliki pengaturan yang sama seperti yang ditentukan dalam file XLTX. Pelajari lebih lanjut tentang format file ini di sini.
