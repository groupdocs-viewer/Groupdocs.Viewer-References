## ISO field

ISO optical disc image adalah file gambar disk arsip yang tidak terkompresi yang mewakili seluruh isi data pada disc optik seperti CD atau DVD, berdasarkan standar ISO-9660. Pelajari lebih lanjut tentang format file ini di sini.
