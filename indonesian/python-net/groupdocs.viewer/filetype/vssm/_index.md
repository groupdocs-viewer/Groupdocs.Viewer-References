## VSSM field

Visio Macro-Enabled Stencil File (.vssm) adalah file Stencil Microsoft Visio yang mendukung makro. File VSSM ketika dibuka memungkinkan menjalankan makro untuk mencapai format dan penempatan bentuk yang diinginkan dalam diagram. Pelajari lebih lanjut tentang format file ini di sini.
