## STL field

Stereolithography File (.stl) adalah format file yang dapat dipertukarkan yang mewakili geometri permukaan tiga dimensi. Format file ini digunakan dalam beberapa bidang seperti prototyping cepat, pencetakan 3D, dan manufaktur berbantuan komputer. Pelajari lebih lanjut tentang format file ini di sini.
