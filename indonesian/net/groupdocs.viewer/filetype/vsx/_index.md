## FileType.VSX field

Visio Stencil XML File (.vsx) mengacu pada stensil yang terdiri dari gambar dan bentuk yang digunakan untuk membuat diagram di Microsoft Visio. File VSX disimpan dalam format file XML dan didukung hingga Visio 2013. Pelajari lebih lanjut tentang format file ini [di sini](https://wiki.fileformat.com/image/vsx).
