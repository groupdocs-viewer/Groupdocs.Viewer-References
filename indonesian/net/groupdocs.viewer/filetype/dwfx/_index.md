## FileType.DWFX field

File Design Web Format XPS (.dwfx) mewakili gambar 2D/3D sebagai dokumen XPS dalam format terkompres untuk melihat, meninjau, atau mencetak file desain. File ini berisi grafik dan teks sebagai bagian dari data desain dan mengurangi ukuran file karena formatnya yang terkompres.
