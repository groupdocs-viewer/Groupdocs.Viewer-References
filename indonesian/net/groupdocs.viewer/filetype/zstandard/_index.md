## FileType.Zstandard field

File ZST adalah file terkompresi yang dihasilkan dengan algoritma kompresi Zstandard (zstd). Ini adalah file terkompresi yang dibuat dengan kompresi lossless oleh algoritma tersebut. File ZST dapat digunakan untuk mengompresi berbagai jenis file seperti basis data, sistem file, jaringan, dan game. Pelajari lebih lanjut tentang format file ini [di sini](https://docs.fileformat.com/compression/zst/).
