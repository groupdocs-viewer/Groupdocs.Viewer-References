## FileType.VSTM field

Visio Macro-Enabled Drawing Template (.vstm) adalah file templat yang dibuat dengan Microsoft Visio dan mendukung makro. Tidak seperti file VSDX, file yang dibuat dari templat VSTM dapat menjalankan makro yang dikembangkan dalam kode Visual Basic for Applications (VBA).
