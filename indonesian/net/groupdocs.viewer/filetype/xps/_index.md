## FileType.XPS field

File XML Paper Specification (.xps) mewakili file tata letak halaman yang berbasis pada XML Paper Specification yang dibuat oleh Microsoft. Format ini dikembangkan oleh Microsoft sebagai pengganti format file EMF dan mirip dengan format file PDF, tetapi menggunakan XML dalam informasi tata letak, tampilan, dan pencetakan dokumen. Pelajari lebih lanjut tentang format file ini [di sini](https://wiki.fileformat.com/page-description-language/xps).
