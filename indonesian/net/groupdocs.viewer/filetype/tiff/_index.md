## FileType.TIFF field

Format File Gambar Bertanda (.tiff) mewakili gambar raster yang ditujukan untuk digunakan pada berbagai perangkat yang mematuhi standar format file ini. Ia dapat menggambarkan data gambar tingkat-biner, skala abu-abu, warna palet, dan warna penuh dalam beberapa ruang warna. Pelajari lebih lanjut tentang format file ini [di sini](https://wiki.fileformat.com/image/tiff).
