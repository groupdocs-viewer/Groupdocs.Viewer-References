## FileType.VTX field

Visio Template XML File (.vtx) adalah templat gambar Microsoft Visio yang disimpan di disk dalam format file XML. Templat ini bertujuan menyediakan file dengan pengaturan dasar yang dapat digunakan untuk membuat banyak file Visio dengan pengaturan yang sama.
