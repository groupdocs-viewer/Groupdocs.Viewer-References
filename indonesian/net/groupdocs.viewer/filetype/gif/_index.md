## FileType.GIF field

File Graphical Interchange Format (.gif) adalah jenis gambar yang sangat terkompresi. Untuk setiap gambar, GIF biasanya memungkinkan hingga 8 bit per piksel dan hingga 256 warna di seluruh gambar. Pelajari lebih lanjut tentang format file ini [di sini](https://wiki.fileformat.com/image/gif).
