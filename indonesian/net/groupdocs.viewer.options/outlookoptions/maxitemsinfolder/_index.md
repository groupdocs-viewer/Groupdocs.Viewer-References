## OutlookOptions.MaxItemsInFolder property

Jumlah maksimum pesan atau item yang dapat dirender dari satu folder.

```csharp
public int MaxItemsInFolder { get; set; }
```

### Catatan

File data Outlook dapat berukuran besar dan mengambil semua pesan dapat memakan waktu signifikan. Properti ini membatasi jumlah maksimum pesan atau item yang dirender. Nilai default adalah `50`. Untuk merender semua pesan, set nilai menjadi `0`.

Untuk contoh kode, lihat [documentation](https://docs.groupdocs.com/viewer/net/render-outlook-data-files/#limit-the-number-of-folder-items-to-render).
