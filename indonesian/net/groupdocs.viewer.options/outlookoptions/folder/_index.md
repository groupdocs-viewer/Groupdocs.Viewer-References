## OutlookOptions.Folder property

Mengatur nama folder (mis. Inbox, Sent Item, atau Deleted Items) yang akan dirender.

```csharp
public string Folder { get; set; }
```

### Catatan

Saat merender file data Outlook, GroupDocs.Viewer merender pesan dari semua folder yang terdapat dalam file (termasuk folder bersarang). Gunakan properti ini untuk merender item dari folder tertentu.

Untuk contoh kode, lihat [documentation](https://docs.groupdocs.com/viewer/net/render-outlook-data-files/#render-a-specific-folder).
