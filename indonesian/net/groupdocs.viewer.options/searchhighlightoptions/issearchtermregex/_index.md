## SearchHighlightOptions.IsSearchTermRegEx property

Mendapatkan atau mengatur nilai yang menunjukkan apakah istilah pencarian harus diperlakukan sebagai ekspresi reguler atau sebagai literal teks. Default adalah `false` — perlakukan sebagai literal teks.

```csharp
public bool IsSearchTermRegEx { get; set; }
```

### Catatan

Jika `true`, [`SearchTerm`](../searchterm) diinterpretasikan sebagai pola .NET Regex.

Jika `false`, [`SearchTerm`](../searchterm) dicari sebagai literal teks dalam dokumen.
