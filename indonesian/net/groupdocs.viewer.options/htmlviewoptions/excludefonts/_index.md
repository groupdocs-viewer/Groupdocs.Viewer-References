## HtmlViewOptions.ExcludeFonts property

Menonaktifkan penambahan font apa pun ke dokumen HTML.

```csharp
public bool ExcludeFonts { get; set; }
```

### Catatan

Secara default, GroupDocs.Viewer menyematkan font yang digunakan dalam dokumen ke dalam markup HTML, dan properti ini memiliki nilai `false`. Untuk mencegah penyematan font, setel properti ini ke `true`.

Untuk detail dan contoh kode, lihat [documentation](https://docs.groupdocs.com/viewer/net/exclude-fonts/).
