## HtmlViewOptions.FontsToExclude property

Daftar nama font yang akan dikecualikan dari dokumen HTML.

```csharp
public List<string> FontsToExclude { get; set; }
```

### Catatan

Font yang ditambahkan ke dalam dokumen HTML meningkatkan stabilitas tampilan output, sekaligus meningkatkan ukuran hasil rendering. Opsi ini memungkinkan Anda menyeimbangkan antara stabilitas dan ukuran output. Sertakan nama font yang populer dan terpasang di sebagian besar sistem.

Harap dicatat, properti ini aktif hanya ketika opsi [`ExcludeFonts`](../excludefonts) dinonaktifkan.

Untuk detail dan contoh kode, lihat [documentation](https://docs.groupdocs.com/viewer/net/exclude-fonts/).
