## BaseViewOptions.RenderNotes property

Mengaktifkan rendering catatan dan anotasi untuk beberapa format

```csharp
public bool RenderNotes { get; set; }
```

### Catatan

Beberapa format, seperti presentasi atau file Microsoft Project, mungkin berisi catatan. Selain itu, file PDF dapat memiliki anotasi popup (petunjuk balon), yang secara default tersembunyi dan hanya terlihat di penampil PDF ketika kursor mouse diarahkan ke mereka. Secara default, GroupDocs.Viewer tidak merender catatan dan anotasi tersebut (`false`). Untuk melakukannya, set properti ini ke `true`.

Untuk contoh kode, lihat [dokumentasi](https://docs.groupdocs.com/viewer/net/render-presentations/#render-speaker-notes).
