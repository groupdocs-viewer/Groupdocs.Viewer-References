## PdfOptions.EnableLayeredRendering property

Mengaktifkan perenderan teks dan grafik dalam urutan z dokumen PDF asli saat merender ke HTML.

```csharp
public bool EnableLayeredRendering { get; set; }
```

### Catatan

Secara default, GroupDocs.Veiewer merender teks dan grafik sebagai satu lapisan tunggal dalam HTML. Opsi ini memungkinkan Anda mengatur objek dalam urutan yang sama seperti pada file sumber. Nilai defaultnya adalah `false`.

Untuk contoh kode, lihat [dokumentasi](https://docs.groupdocs.com/viewer/net/render-pdf-documents/#enable-multi-layer-rendering).
