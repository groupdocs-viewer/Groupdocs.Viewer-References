## PdfOptions.FixedLayout property

Mengaktifkan perenderan dokumen PDF dan EPUB ke HTML dengan tata letak tetap.

```csharp
public bool FixedLayout { get; set; }
```

### Catatan

Dokumen PDF dan EPUB awalnya dirender ke HTML dengan tata letak tetap untuk mempertahankan tampilan dokumen sumber. Tata letak tetap ini berarti semua elemen HTML memiliki posisi yang tepat di dalam sebuah kontainer dengan ukuran yang ditetapkan. Mengubah ukuran jendela peramban tidak memengaruhi posisi dan ukuran elemen dalam dokumen.

Opsi ini hanya tersedia saat merender ke HTML. Nilai default adalah `true`. Untuk merender dengan tata letak cair, setel properti ini ke `false`.

Saat merender dengan tata letak cair, gambar akan dilewati. Gunakan tata letak cair saat merender dokumen PDF dengan konten teks.

For code example, lihat [dokumentasi](https://docs.groupdocs.com/viewer/net/render-pdf-documents/#create-html-with-fluid-layout).
