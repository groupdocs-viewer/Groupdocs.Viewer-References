## PdfOptions.RenderTextAsImage property

Mengaktifkan perenderan teks dalam file PDF sebagai gambar dalam output HTML.

```csharp
public bool RenderTextAsImage { get; set; }
```

### Catatan

Ketika opsi ini diatur ke `true`, GroupDocs.Viewer merender teks sebagai gambar dalam output HTML. Ini membuat teks tidak dapat dipilih dan meningkatkan rendering karakter, memastikan tampilan mirip PDF dalam HTML. Nilai default adalah `false`.

Opsi ini tersedia untuk merender ke HTML.

For code example, lihat [dokumentasi](https://docs.groupdocs.com/viewer/net/render-pdf-documents/#render-text-as-an-image).
