## PdfOptions.WrapImagesInSvg property

Mengaktifkan pembungkus setiap gambar dalam dokumen HTML output dengan tag SVG untuk meningkatkan kualitas output.

```csharp
public bool WrapImagesInSvg { get; set; }
```

### Catatan

Secara default, saat merender file PDF dan Page Layout ke HTML, semua gambar dirender sebagai satu gambar PNG. Gambar PNG yang dirender digunakan sebagai latar belakang untuk dokumen HTML output.

Opsi ini tersedia saat merender [format file PDF dan Page Layout](https://docs.groupdocs.com/viewer/net/supported-document-formats/#pdf-and-page-layout-file-formats) ke HTML dengan sumber daya tersemat dan eksternal. Ini memungkinkan membungkus setiap gambar dalam dokumen HTML output dengan tag SVG. Nilai defaultnya adalah `false`.

Untuk contoh kode, lihat [dokumentasi](https://docs.groupdocs.com/viewer/net/render-pdf-documents/#enclose-images-in-svg-when-rendering-pdf-and-page-layout-files).
