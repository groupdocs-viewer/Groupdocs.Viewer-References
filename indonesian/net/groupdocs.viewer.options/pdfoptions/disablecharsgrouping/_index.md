## PdfOptions.DisableCharsGrouping property

Menonaktifkan pengelompokan simbol untuk penempatan simbol yang tepat selama perenderan halaman.

```csharp
public bool DisableCharsGrouping { get; set; }
```

### Catatan

Saat mengonversi file PDF, GroupDocs.Viewer mengelompokkan karakter individual menjadi kata untuk meningkatkan kinerja rendering. Jika dokumen Anda berisi hieroglif atau simbol khusus, Anda mungkin ingin melarang pengelompokan karakter untuk memastikan tata letak yang lebih tepat. Nilai default adalah `false`.

For code example, lihat [dokumentasi](https://docs.groupdocs.com/viewer/net/render-pdf-documents/#disable-character-grouping).
