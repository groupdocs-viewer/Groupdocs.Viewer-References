## PdfOptions.EnableFontHinting property

Mengaktifkan hinting font.

```csharp
public bool EnableFontHinting { get; set; }
```

### Catatan

Petunjuk font menyesuaikan cara font outline ditampilkan. Hanya berlaku untuk font TTF yang digunakan dalam dokumen sumber. Opsi ini tersedia untuk merender ke format PNG atau JPG. Nilai defaultnya adalah `false`.

Untuk contoh kode, lihat [dokumentasi](https://docs.groupdocs.com/viewer/net/render-pdf-documents/#enable-font-hinting).
