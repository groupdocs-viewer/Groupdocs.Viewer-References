## PdfOptions.DisableCopyProtection property

Mematikan perlindungan penyalinan konten saat merender ke HTML.

```csharp
public bool DisableCopyProtection { get; set; }
```

### Catatan

Saat merender file PDF dengan perlindungan terhadap penyalinan teks dan gambar ke HTML, GroupDocs.Viewer menambahkan atribut HTML 'inert' ke tag BODY HTML. Nilai default opsi ini adalah `false`, yang menunjukkan bahwa atribut HTML 'intent' hanya ditambahkan jika dokumen PDF dilindungi.

For code example, lihat [dokumentasi](https://docs.groupdocs.com/viewer/net/render-pdf-documents/#disable-copy-protection).
