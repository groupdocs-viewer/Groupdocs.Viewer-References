## PdfOptions.RenderOriginalPageSize property

Mengatur ukuran halaman output sama dengan ukuran halaman dokumen PDF sumber.

```csharp
public bool RenderOriginalPageSize { get; set; }
```

### Catatan

Secara default, GroupDocs.Viewer menghitung ukuran halaman gambar output untuk kualitas render yang lebih baik. Aktifkan opsi ini untuk memastikan halaman output memiliki ukuran yang sama dengan ukuran halaman dokumen PDF sumber (dalam piksel). Nilai defaultnya adalah `false`.

Opsi ini tersedia untuk merender ke format PNG atau JPG.

Untuk contoh kode, lihat [dokumentasi](https://docs.groupdocs.com/viewer/net/render-pdf-documents/#preserve-the-size-of-document-pages).
