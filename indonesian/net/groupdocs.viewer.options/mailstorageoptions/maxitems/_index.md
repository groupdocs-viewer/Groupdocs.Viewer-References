## MailStorageOptions.MaxItems property

Mengatur jumlah maksimum pesan atau item yang akan dirender.

```csharp
public int MaxItems { get; set; }
```

### Catatan

File data penyimpanan email dapat berukuran besar dan mengambil semua pesan dapat memakan waktu yang signifikan. Properti ini membatasi jumlah maksimum pesan atau item yang dirender. Nilai default adalah 0 - semua pesan dirender.

Untuk contoh kode, lihat [dokumentasi](https://docs.groupdocs.com/viewer/net/render-lotus-notes-database-files/#limit-the-number-of-items-to-render).
