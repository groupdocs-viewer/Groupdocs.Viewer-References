## PdfOptimizationOptions.RemoveUnusedObjects property

Menghapus objek yang tidak terpakai (tertinggal) dari file PDF, yang ditempatkan dalam dokumen PDF, tetapi tidak direferensikan dari kamus sumber daya pada halaman mana pun sehingga tidak digunakan sama sekali. Mengaktifkan properti ini (`true`) akan mengurangi ukuran dokumen PDF output. Secara default dinonaktifkan (`false`).

public bool RemoveUnusedObjects { get; set; }
