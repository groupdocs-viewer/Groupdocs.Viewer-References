## PresentationOptions.RenderHeaderFooterPlaceholders property

Mengaktifkan rendering placeholder di header dan footer slide. Dinonaktifkan secara default (`false`). Opsi ini berlaku untuk semua 4 mode rendering presentasi: HTML, PDF, PNG, dan JPEG. Tidak berlaku saat merender presentasi ke markup HTML/CSS murni menggunakan [`RenderToPureHtml`](../rendertopurehtml).
