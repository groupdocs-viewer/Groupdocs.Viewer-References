## PresentationOptions.RenderToPureHtml property

Mengaktifkan mode rendering HTML baru untuk dokumen Presentation — dalam mode ini file Presentation dirender menjadi **pure HTML/CSS markup**, tanpa gambar SVG. Secara default dinonaktifkan (`false`) — renderer HTML berbasis SVG yang ada digunakan.
