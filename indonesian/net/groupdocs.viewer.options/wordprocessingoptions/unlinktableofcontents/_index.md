## WordProcessingOptions.UnlinkTableOfContents property

Saat merender ke HTML atau PDF, Anda dapat mengatur opsi ini ke `true` untuk menonaktifkan navigasi dari daftar isi. Untuk perenderan HTML, tag `a` dengan tautan relatif akan diganti dengan tag `span`, menghapus fungsionalitas tetapi mempertahankan tampilan visual. Untuk perenderan PDF, daftar isi akan dirender sebagai teks biasa tanpa tautan ke bagian dokumen.

```csharp
public bool UnlinkTableOfContents { get; set; }
```

### Catatan

Nilai default adalah `false`
