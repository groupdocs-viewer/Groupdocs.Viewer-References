## WordProcessingOptions.VerticalResolution property

Mendapatkan atau mengatur resolusi vertikal untuk gambar yang dihasilkan dalam dot per inci. Opsi ini digunakan saat merender dokumen WordProcessing ke format PNG atau JPEG saja.

```csharp
public int VerticalResolution { get; set; }
```

### Catatan

Nilai default adalah 96 DPI. Nilai minimum yang mungkin - 72 DPI, nilai maksimum yang mungkin - 600 DPI. Jika nilai yang ditentukan pengguna berada di luar batas ini, nilai minimum atau maksimum yang mungkin akan diterapkan.
