## WordProcessingOptions.PageSize property

Ukuran halaman output. Nilai default adalah Unspecified yang berarti ukuran halaman ditetapkan dalam pengaturan halaman (Page Setup) yang digunakan. Saat merender file HTM dan HTML, ukuran halaman default diatur ke Letter 792 x 612 poin. Akibatnya, sebagian konten mungkin tidak muat dalam bingkai halaman. Atur ukuran halaman yang lebih besar, misalnya A3, untuk menampung konten.
