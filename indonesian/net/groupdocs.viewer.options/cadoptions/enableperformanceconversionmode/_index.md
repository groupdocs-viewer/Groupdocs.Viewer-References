## CadOptions.EnablePerformanceConversionMode property

Mengatur flag ini ke `true` mengaktifkan mode konversi khusus yang berorientasi pada kinerja untuk semua format dalam keluarga CAD — dalam mode ini kecepatan konversi jauh lebih cepat, tetapi kualitas dokumen yang dihasilkan secara signifikan lebih buruk. Secara default dinonaktifkan (`false`) — kualitas dokumen yang dihasilkan adalah yang terbaik mungkin dengan mengorbankan kinerja.

public bool EnablePerformanceConversionMode { get; set; }
