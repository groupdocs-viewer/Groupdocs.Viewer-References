## SpreadsheetOptions.HorizontalResolution property

Mendapatkan atau mengatur resolusi horizontal untuk gambar yang dihasilkan dalam dot per inci. Opsi ini hanya digunakan saat merender spreadsheet ke format PNG atau JPEG.

```csharp
public int HorizontalResolution { get; set; }
```

### Catatan

Nilai default adalah 96 DPI. Nilai minimum yang mungkin - 72 DPI, nilai maksimum yang mungkin - 600 DPI. Jika nilai yang ditentukan pengguna berada di luar batas ini, nilai minimum atau maksimum yang mungkin akan diterapkan.
