## PdfViewOptions.ImageMaxWidth property

Mengatur lebar maksimum gambar output (dalam piksel).

### Catatan

Gunakan properti ini untuk mengatur lebar maksimum gambar output (dalam piksel). GroupDocs.Viewer menerapkan properti ini saat merender satu gambar ke PDF. Untuk detail, lihat [dokumentasi](https://docs.groupdocs.com/viewer/net/set-image-size-limits-when-rendering-to-pdf/).

Jika Anda mengatur properti [`ImageWidth`](../imagewidth), properti ini akan diabaikan.
