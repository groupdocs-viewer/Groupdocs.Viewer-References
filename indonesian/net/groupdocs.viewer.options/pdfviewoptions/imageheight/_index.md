## PdfViewOptions.ImageHeight property

Mengatur tinggi gambar output (dalam piksel).

```csharp
public int ImageHeight { get; set; }
```

### Catatan

Gunakan properti ini untuk mengatur tinggi gambar output (dalam piksel). GroupDocs.Viewer menerapkan properti ini saat merender satu gambar ke HTML saja. Untuk detail, lihat [dokumentasi](https://docs.groupdocs.com/viewer/net/set-image-size-limits-when-rendering-to-pdf/).

Jika Anda mengatur properti ini, properti [`ImageMaxHeight`](../imagemaxheight) akan diabaikan.
