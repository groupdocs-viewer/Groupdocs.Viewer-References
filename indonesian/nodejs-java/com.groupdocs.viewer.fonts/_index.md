Paket ini menyediakan kelas dan enumerasi untuk mengelola font yang digunakan selama proses rendering.

Kelas dan antarmuka utama dalam paket ini adalah:

 *  [FolderFontSource](../../com.groupdocs.viewer.fonts/folderfontsource) - Represents a folder that contains TrueType fonts.
 *  [FontSettings](../../com.groupdocs.viewer.fonts/fontsettings) - Provides methods for working with sources to look for TrueType fonts.
 *  [FontSource](../../com.groupdocs.viewer.fonts/fontsource) - Marker interface for the font sources.

Untuk detail lebih lanjut tentang cara bekerja dengan font di GroupDocs.Viewer, silakan lihat [GroupDocs.Viewer Documentation][].


[GroupDocs.Viewer Documentation]: https://docs.groupdocs.com/viewer/java/


## Kelas

| Kelas | Deskripsi |
| --- | --- |
| [FolderFontSource](../com.groupdocs.viewer.fonts/folderfontsource) | Mewakili folder yang berisi font TrueType. |
| [FontFormat](../com.groupdocs.viewer.fonts/fontformat) | Mewakili semua format font, yang mungkin ada dalam kelas UsedFontInfo. |
| [FontSettings](../com.groupdocs.viewer.fonts/fontsettings) | Menyediakan metode untuk bekerja dengan sumber guna mencari font TrueType. |
| [FontStyles](../com.groupdocs.viewer.fonts/fontstyles) | Mewakili 4 gaya font yang mungkin, digunakan dalam dokumen: Regular, Bold, Italic, atau Bold Italic. |
| [PdfFontInfo](../com.groupdocs.viewer.fonts/pdffontinfo) | Mengkapsulasi meta-informasi dan data biner dari satu font dalam dokumen PDF, yang dimuat ke dalam instance Viewer. |
| [PresentationFontInfo](../com.groupdocs.viewer.fonts/presentationfontinfo) | Mengkapsulasi metadata dan data biner dari font yang digunakan dalam dokumen Presentasi, yang dimuat ke dalam instance Viewer. |
| [SpreadsheetFontInfo](../com.groupdocs.viewer.fonts/spreadsheetfontinfo) | Mengkapsulasi metainfo dan data biner dari satu font dalam dokumen Spreadsheet, yang dimuat ke dalam instance Viewer. |
| [WordProcessingFontInfo](../com.groupdocs.viewer.fonts/wordprocessingfontinfo) | Mengkapsulasi metainfo dan data biner dari satu font dalam dokumen WordProcessing, yang dimuat ke dalam instance Viewer. |
| [WordProcessingSubstitutedFontInfo](../com.groupdocs.viewer.fonts/wordprocessingsubstitutedfontinfo) | Mengkapsulasi metadata dan data biner dari satu font pengganti yang digunakan dalam dokumen WordProcessing melalui GroupDocs.Viewer. |
