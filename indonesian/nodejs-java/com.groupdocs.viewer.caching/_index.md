Paket ini menyediakan kelas untuk menyesuaikan perilaku caching.

Kelas dan antarmuka utama dalam paket ini adalah:

 *  [CacheKeys](../../com.groupdocs.viewer.caching/cachekeys) - Provides methods to retrieve unique identifiers for the cache entry.
 *  [FileCache](../../com.groupdocs.viewer.caching/filecache) - Represents a local on-disk cache.

Antarmuka [Cache](../../com.groupdocs.viewer.caching/cache) mendefinisikan metode yang diperlukan untuk menyimpan dokumen yang dirender dan sumber daya dokumen dalam cache.

Untuk detail lebih lanjut tentang menyesuaikan perilaku caching di GroupDocs.Viewer, silakan merujuk ke [GroupDocs.Viewer Documentation][].


[GroupDocs.Viewer Documentation]: https://docs.groupdocs.com/viewer/java/
