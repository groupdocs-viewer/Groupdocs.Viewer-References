Paket ini menyediakan kelas untuk menentukan opsi tambahan saat merender dokumen.


Ini mencakup opsi untuk merender berbagai format dokumen, mendefinisikan izin dan pengaturan keamanan,
menentukan properti watermark, dan mengambil informasi tentang tampilan.

Kelas utama dalam paket ini adalah:

* [ArchiveOptions](../../com.groupdocs.viewer.options/archiveoptions) - Provides options for rendering archive files.
* [PdfOptions](../../com.groupdocs.viewer.options/pdfoptions) - Provides options for rendering PDF documents.
* [WordProcessingOptions](../../com.groupdocs.viewer.options/wordprocessingoptions) - Provides options for rendering word processing documents.


Untuk detail lebih lanjut tentang mengonfigurasi sistem logging di GroupDocs.Viewer dan menyesuaikan penanganan pesan log,
silakan merujuk ke [GroupDocs.Viewer Documentation](../https://docs.groupdocs.com/viewer/java/).
