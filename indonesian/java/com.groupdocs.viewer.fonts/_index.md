Paket ini menyediakan kelas dan enumerasi untuk mengelola font yang digunakan selama proses perenderan.

Kelas dan antarmuka utama dalam paket ini adalah:

* [FolderFontSource](../../com.groupdocs.viewer.fonts/folderfontsource) - Represents a folder that contains TrueType fonts.
* [FontSettings](../../com.groupdocs.viewer.fonts/fontsettings) - Provides methods for working with sources to look for TrueType fonts.
* [FontSource](../../com.groupdocs.viewer.fonts/fontsource) - Marker interface for the font sources.


Untuk detail lebih lanjut tentang bekerja dengan font di GroupDocs.Viewer, silakan merujuk ke
[GroupDocs.Viewer Documentation](../https://docs.groupdocs.com/viewer/java/).



## Kelas

| Kelas | Deskripsi |
| --- | --- |
| [FolderFontSource](../com.groupdocs.viewer.fonts/folderfontsource) | Mewakili folder yang berisi font TrueType. |
| [FontFormat](../com.groupdocs.viewer.fonts/fontformat) | Mewakili semua format font, yang mungkin ada dalam kelas UsedFontInfo. |
| [FontSettings](../com.groupdocs.viewer.fonts/fontsettings) | Menyediakan metode untuk bekerja dengan sumber yang mencari font TrueType. |
| [FontStyles](../com.groupdocs.viewer.fonts/fontstyles) | Mewakili 4 gaya font yang mungkin, digunakan dalam dokumen: Regular, Bold, Italic, atau Bold Italic. |
| [PdfFontInfo](../com.groupdocs.viewer.fonts/pdffontinfo) | Mengkapsulkan meta-informasi dan data biner dari satu font dalam dokumen PDF, yang dimuat ke dalam instance Viewer. |
| [PresentationFontInfo](../com.groupdocs.viewer.fonts/presentationfontinfo) | Mengkapsulkan metadata dan data biner dari font yang digunakan dalam dokumen Presentation, yang dimuat ke dalam instance Viewer. |
| [SpreadsheetFontInfo](../com.groupdocs.viewer.fonts/spreadsheetfontinfo) | Mengkapsulkan metainfo dan data biner dari satu font dalam dokumen Spreadsheet, yang dimuat ke dalam instance Viewer. |
| [WordProcessingFontInfo](../com.groupdocs.viewer.fonts/wordprocessingfontinfo) | Mengkapsulkan metainfo dan data biner dari satu font dalam dokumen WordProcessing, yang dimuat ke dalam instance Viewer. |
| [WordProcessingSubstitutedFontInfo](../com.groupdocs.viewer.fonts/wordprocessingsubstitutedfontinfo) | Mengkapsulkan metadata dan data biner dari satu font substitusi yang digunakan dalam dokumen WordProcessing melalui GroupDocs.Viewer. |

## Antarmuka

| Antarmuka | Deskripsi |
| --- | --- |
| [FontSource](../com.groupdocs.viewer.fonts/fontsource) | Antarmuka penanda untuk sumber font. |
| [IFontInfo](../com.groupdocs.viewer.fonts/ifontinfo) | Antarmuka umum untuk semua font yang dapat diekstrak dari format dokumen: PDF, WordProcessing, Spreadsheet, dan Presentation. |
