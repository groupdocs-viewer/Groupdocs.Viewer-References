Paket ini menyediakan kelas dan antarmuka yang merepresentasikan hasil perenderan dokumen.


Kelas-kelas ini mengenkapsulasi informasi tentang berbagai elemen dan komponen dokumen yang dirender,
seperti halaman, lampiran, tampilan, sumber daya, dan lainnya.

Kelas utama dalam paket ini adalah:

* [Page](../../com.groupdocs.viewer.results/page) - Represents a single page that can be viewed.
* [Attachment](../../com.groupdocs.viewer.results/attachment) - Represents an attachment file contained by an email message, archive, PDF document, or Outlook data file.
* [PdfViewInfo](../../com.groupdocs.viewer.results/pdfviewinfo) - Represents view information for a PDF document.


Untuk detail lebih lanjut tentang bekerja dengan hasil rendering dokumen menggunakan GroupDocs.Viewer,
silakan merujuk ke [GroupDocs.Viewer Documentation](../https://docs.groupdocs.com/viewer/java/).



## Kelas

| Kelas | Deskripsi |
| --- | --- |
| [Resource](../com.groupdocs.viewer.results/resource) | Mewakili sumber daya HTML seperti font, gaya, gambar, atau grafik. |
