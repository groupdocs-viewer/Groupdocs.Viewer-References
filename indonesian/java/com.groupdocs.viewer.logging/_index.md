Paket ini menyediakan kelas untuk mengkonfigurasi sistem logging di GroupDocs.Viewer.


Dengan menggunakan kelas-kelas ini, Anda dapat mengontrol cara pesan log ditangani, seperti menuliskannya ke
sebuah file atau mengarahkannya ke implementasi logger tertentu.

Kelas utama dalam paket ini adalah:

* [FileLogger](../../com.groupdocs.viewer.logging/filelogger) - Writes log messages to a file.
* [ViewerLogger](../../com.groupdocs.viewer.logging/viewerlogger) - Implements logging messages to an integrated or user-defined logger.


Untuk detail lebih lanjut tentang mengonfigurasi sistem logging di GroupDocs.Viewer dan menyesuaikan penanganan pesan log,
silakan merujuk ke [GroupDocs.Viewer Documentation](../https://docs.groupdocs.com/viewer/java/).



## Kelas

| Kelas | Deskripsi |
| --- | --- |
| [FileLogger](../com.groupdocs.viewer.logging/filelogger) | Menulis pesan log ke sebuah file. |
| [ViewerLogger](../com.groupdocs.viewer.logging/viewerlogger) | Logger penampil global. |
