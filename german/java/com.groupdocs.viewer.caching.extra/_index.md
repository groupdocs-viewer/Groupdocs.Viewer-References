Das Paket bietet Funktionalität zur Verwendung benutzerdefinierter Modelle in der Cache‑Implementierung.


Die Hauptklasse in diesem Paket ist [CacheableFactory](../../com.groupdocs.viewer.caching.extra/cacheablefactory),
die dabei hilft, den Cache durch Bereitstellung zusätzlicher Funktionalität anzupassen.


Weitere Details zur Verwendung benutzerdefinierter Modelle in der Cache-Implementierung in GroupDocs.Viewer finden Sie unter
[GroupDocs.Viewer Documentation](../https://docs.groupdocs.com/viewer/java/).
