Das Paket stellt Klassen zur Konfiguration des Protokollierungssystems in GroupDocs.Viewer bereit.


Durch die Verwendung dieser Klassen können Sie steuern, wie Protokollnachrichten verarbeitet werden, z. B. indem Sie sie in
eine Datei schreiben oder sie an eine bestimmte Logger‑Implementierung weiterleiten.

Die Hauptklassen in diesem Paket sind:

* [FileLogger](../../com.groupdocs.viewer.logging/filelogger) - Writes log messages to a file.
* [ViewerLogger](../../com.groupdocs.viewer.logging/viewerlogger) - Implements logging messages to an integrated or user-defined logger.


Weitere Details zur Konfiguration des Protokollierungssystems in GroupDocs.Viewer und zur Anpassung der Protokollnachrichtenverarbeitung finden Sie unter
Bitte beachten Sie die [GroupDocs.Viewer Dokumentation](../https://docs.groupdocs.com/viewer/java/).
