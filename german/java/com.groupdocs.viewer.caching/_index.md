Das Paket stellt Klassen zur Anpassung des Caching‑Verhaltens bereit.

Die wichtigsten Klassen und Schnittstellen in diesem Paket sind:

* [CacheKeys](../../com.groupdocs.viewer.caching/cachekeys) - Provides methods to retrieve unique identifiers for the cache entry.
* [FileCache](../../com.groupdocs.viewer.caching/filecache) - Represents a local on-disk cache.


Die [Cache](../../com.groupdocs.viewer.caching/cache)‑Schnittstelle definiert die für das Speichern gerenderter Dokumente erforderlichen Methoden
und Dokumentressourcen im Cache.


Weitere Details zur Anpassung des Caching-Verhaltens in GroupDocs.Viewer finden Sie unter
[GroupDocs.Viewer Documentation](../https://docs.groupdocs.com/viewer/java/).



## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [CacheKeys](../com.groupdocs.viewer.caching/cachekeys) | Stellt Methoden zum Abrufen der eindeutigen Kennung eines Cache-Eintrags bereit. |
| [FileCache](../com.groupdocs.viewer.caching/filecache) | Stellt einen lokalen Festplatten-Cache dar. |
