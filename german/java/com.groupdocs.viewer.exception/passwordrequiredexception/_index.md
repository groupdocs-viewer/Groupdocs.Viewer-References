Diese Ausnahme wird ausgelöst, wenn zum Laden des Dokuments ein Passwort erforderlich ist.
Diese Ausnahme tritt typischerweise auf, wenn versucht wird, ein Dokument zu laden oder zu öffnen, das verschlüsselt oder passwortgeschützt ist, ohne ein gültiges Passwort anzugeben.
