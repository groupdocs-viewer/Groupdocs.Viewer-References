Diese Ausnahme wird ausgelöst, wenn das angegebene Passwort inkorrekt ist.
Diese Ausnahme wird typischerweise ausgelöst, wenn versucht wird, auf ein geschütztes Dokument zuzugreifen oder es zu entschlüsseln, wobei ein ungültiges Passwort verwendet wird.
