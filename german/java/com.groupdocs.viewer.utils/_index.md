Das Paket stellt Hilfs‑ und Dienstprogrammk Klassen für verschiedene Funktionalitäten bereit.


Diese Klassen bieten praktische Methoden und Funktionalitäten, um bei verschiedenen Vorgängen zu unterstützen.

Die Hauptklassen in diesem Paket sind:

* [CancellationToken](../../com.groupdocs.viewer.utils/cancellationtoken) - Propagates a request to cancel rendering.
* [CancellationTokenSource](../../com.groupdocs.viewer.utils/cancellationtokensource) - Creates and signals a [CancellationToken](../../com.groupdocs.viewer.utils/cancellationtoken).
* [MemoryCleaner](../../com.groupdocs.viewer.utils/memorycleaner) - Provides methods to clean up resources and free memory.
* [PathUtils](../../com.groupdocs.viewer.utils/pathutils) - Represents the type for working with paths.


Weitere Details zur Verwendung der Dienstprogrammk Klassen im Paket com.groupdocs.viewer.utils,
Bitte beachten Sie die [GroupDocs.Viewer Dokumentation](../https://docs.groupdocs.com/viewer/java/).



## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [CancellationToken](../com.groupdocs.viewer.utils/cancellationtoken) | Übermittelt die Benachrichtigung, dass ein Vorgang abgebrochen werden sollte. |
| [CancellationTokenSource](../com.groupdocs.viewer.utils/cancellationtokensource) | Signalisiert einem [CancellationToken](../com.groupdocs.viewer.utils/cancellationtoken), dass ein Vorgang abgebrochen werden soll. |
| [MemoryCleaner](../com.groupdocs.viewer.utils/memorycleaner) | Bereinigt verschiedene Ressourcen, um Speicher freizugeben. |
| [PathUtils](../com.groupdocs.viewer.utils/pathutils) | Die Klasse PathUtils stellt Hilfsmethoden für die Arbeit mit Dateipfaden bereit. |
