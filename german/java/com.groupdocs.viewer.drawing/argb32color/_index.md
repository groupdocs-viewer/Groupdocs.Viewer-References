java.lang.Object
```
public class Argb32Color
```

Stellt 32-Bit-Farbe im ARGB-Format dar, mit 8 Bit pro Kanal (Alpha, Rot, Grün, Blau). Unterstützt Transparenz. Entwickelt, um (aber nicht ausschließlich) für CSS-Operationen nützlich zu sein. Weitere Informationen: https://developer.mozilla.org/en-US/docs/Web/CSS/color_value
