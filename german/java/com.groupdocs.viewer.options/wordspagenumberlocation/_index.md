Steuert, ob die Seitennummerierung zwingend auf das geladene WordProcessing-Dokument angewendet wird und, falls ja, wo die Seitenzahlen platziert werden.

## Felder

| Feld | Beschreibung |
| --- | --- |
|  | [NOT_APPLY](#NOT-APPLY) | Das geladene WordProcessing-Dokument unverändert lassen. |
|
|  | [TOP_LEFT](#TOP-LEFT) | Setze die Seitennummer in die obere linke Ecke der Seite. |
|
|  | [TOP_CENTER](#TOP-CENTER) | Setze die Seitennummer in die obere Mitte der Seite. |
|
|  | [TOP_RIGHT](#TOP-RIGHT) | Setze die Seitennummer in die obere rechte Ecke der Seite. |
|
|  | [BOTTOM_LEFT](#BOTTOM-LEFT) | Setze die Seitennummer in die untere linke Ecke der Seite. |
|
|  | [BOTTOM_CENTER](#BOTTOM-CENTER) | Setze die Seitennummer in die untere Mitte der Seite. |
|
|  | [BOTTOM_RIGHT](#BOTTOM-RIGHT) | Setzen Sie die Seitenzahl in die untere rechte Ecke der Seite. |
|
