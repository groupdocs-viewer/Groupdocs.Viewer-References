Das Paket stellt Klassen bereit, um zusätzliche Optionen beim Rendern von Dokumenten anzugeben.


Sie enthält Optionen zum Rendern verschiedener Dokumentformate, zum Definieren von Berechtigungen und Sicherheitseinstellungen,
Festlegen von Wasserzeichen-Eigenschaften und Abrufen von Informationen zu Ansichten.

Die Hauptklassen in diesem Paket sind:

* [ArchiveOptions](../../com.groupdocs.viewer.options/archiveoptions) - Provides options for rendering archive files.
* [PdfOptions](../../com.groupdocs.viewer.options/pdfoptions) - Provides options for rendering PDF documents.
* [WordProcessingOptions](../../com.groupdocs.viewer.options/wordprocessingoptions) - Provides options for rendering word processing documents.


Weitere Details zur Konfiguration des Protokollierungssystems in GroupDocs.Viewer und zur Anpassung der Protokollnachrichtenverarbeitung finden Sie unter
Bitte beachten Sie die [GroupDocs.Viewer Dokumentation](../https://docs.groupdocs.com/viewer/java/).
