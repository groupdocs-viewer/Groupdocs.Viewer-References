Warnprotokollnachrichten liefern Informationen über unerwartete und wiederherstellbare Ereignisse im Anwendungsablauf.

```python
def warning(self, message):
    ...
```

| Parameter | Typ | Beschreibung |
| :- | :- | :- |
| message | `str` | Die Warnmeldung. |

| Ausnahmen | Beschreibung |
| :- | :- |
| `ValueError` | Wenn `message` None ist. |
