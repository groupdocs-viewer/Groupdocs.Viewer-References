## FontStyles class

Stellt 4 mögliche Schriftstile der Schrift dar, die im Dokument verwendet werden: Regular, Bold, Italic oder Bold Italic.

Unveränderliche Struktur mit praktischer API und Kombinationsoperationen.

Der FontStyles-Typ stellt die folgenden Mitglieder bereit:
