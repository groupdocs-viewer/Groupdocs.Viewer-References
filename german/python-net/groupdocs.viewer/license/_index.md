## License class

Verwaltet die Lizenzierung von GroupDocs.Viewer.

Lizenzierte Builds schalten den vollen Funktionsumfang des Wrappers frei bei
Laufzeit. Nicht lizenzierte Builds laufen im Evaluierungsmodus mit derselben API
Oberfläche, jedoch mit Begrenzungen der Ausgabengröße und wassergezeichneten Inhalten.

Der Lizenztyp stellt die folgenden Mitglieder bereit:

### Methoden
| Methode | Beschreibung |
| :- | :- |
| [set_license](/viewer/python-net/groupdocs.viewer/license/set_license/#license_source) | Wendet eine Lizenz auf den aktuellen Prozess an. |
