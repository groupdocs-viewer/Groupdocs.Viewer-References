## Metered class

Verwaltet die nutzungsbasierte (Pay‑per‑Use) Lizenzierung.

Metered-Lizenzen werden nach tatsächlichem Verbrauch abgerechnet (typischerweise Seiten oder
verarbeitete Dokumente). Setzen Sie das öffentliche/privaten Schlüsselpaar einmal bei
Anwendungsstart; der Wrapper meldet die Nutzung zurück an die GroupDocs
Lizenz-Server im Hintergrund.

Der Metered Typ stellt die folgenden Mitglieder bereit:

### Methoden
| Methode | Beschreibung |
| :- | :- |
| [get_consumption_credit](/viewer/python-net/groupdocs.viewer/metered/get_consumption_credit/) | Gibt das verbleibende Metered-Guthaben für den aktuellen Schlüssel zurück. |
| [get_consumption_quantity](/viewer/python-net/groupdocs.viewer/metered/get_consumption_quantity/) | Gibt die bisher verbrauchte gesamte Metered-Menge zurück. |
| [set_metered_key](/viewer/python-net/groupdocs.viewer/metered/set_metered_key/#public_key-private_key) | Aktivieren Sie die Metered-Abrechnung mit dem angegebenen öffentlichen/privaten Schlüsselpaar. |
