## DWG field

AutoCAD Drawing Database File (.dwg) stellt proprietäre Binärdateien dar, die zur Speicherung von 2D‑ und 3D‑Designdaten verwendet werden. Wie DXF, das ASCII‑Dateien sind, repräsentiert DWG das binäre Dateiformat für CAD‑(Computer‑Aided‑Design‑)Zeichnungen. Erfahren Sie hier mehr über dieses Dateiformat.
