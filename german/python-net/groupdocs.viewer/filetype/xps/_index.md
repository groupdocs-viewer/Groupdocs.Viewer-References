## XPS field

XML Paper Specification Datei (.xps) stellt Seitenlayout‑Dateien dar, die auf von Microsoft erstellten XML Paper Specifications basieren. Dieses Format wurde von Microsoft als Ersatz für das EMF‑Dateiformat entwickelt und ist dem PDF‑Dateiformat ähnlich, verwendet jedoch XML für Layout, Aussehen und Druckinformationen eines Dokuments. Erfahren Sie hier mehr über dieses Dateiformat.
