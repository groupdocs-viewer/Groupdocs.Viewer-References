## VDX field

Visio‑Zeichnungs‑XML‑Datei (.vdx) steht für jede in Microsoft Visio erstellte Zeichnung oder Grafik, die im XML‑Format mit der Erweiterung .VDX gespeichert wird. Eine Visio‑Zeichnungs‑XML‑Datei wird in der Visio‑Software erstellt, die von Microsoft entwickelt wurde. Erfahren Sie mehr über dieses Dateiformat hier.
