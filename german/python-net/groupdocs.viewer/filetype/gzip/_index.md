## GZIP field

Gnu Zipped File (.gzip) wurde als kostenloses Dienstprogramm eingeführt, um das in Unix‑Systemen verwendete Compress‑Programm zu ersetzen. Solche Dateien können mit verschiedenen Anwendungen wie WinZip, das sowohl für Windows als auch für macOS verfügbar ist, geöffnet und extrahiert werden. Erfahren Sie hier mehr über dieses Dateiformat.
