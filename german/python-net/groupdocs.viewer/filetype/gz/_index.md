## GZ field

Gnu Zipped File (.gz) sind komprimierte Dateien, die mit der gzip‑Kompressionsanwendung erstellt werden. Sie können mehrere komprimierte Dateien enthalten und werden häufig auf UNIX‑ und Linux‑Systemen verwendet. Erfahren Sie hier mehr über dieses Dateiformat.
