## VSSM field

Visio-Makro‑aktivierte Stencil‑Datei (.vssm) sind Microsoft Visio‑Stencil‑Dateien, die Makros unterstützen. Wird eine VSSM‑Datei geöffnet, können die Makros ausgeführt werden, um die gewünschte Formatierung und Platzierung von Formen in einem Diagramm zu erreichen. Erfahren Sie mehr über dieses Dateiformat hier.
