## XLTX field

Excel Open‑XML‑Tabellenvorlage (.xltx) stellt eine Microsoft Excel‑Vorlage dar, die auf den Office‑OpenXML‑Dateiformatspezifikationen basiert. Sie wird verwendet, um eine Standardvorlagendatei zu erstellen, die zur Erzeugung von XLSX‑Dateien genutzt werden kann, die dieselben Einstellungen wie in der XLTX‑Datei aufweisen.
