## AZW3 field

Amazon Kindle Format 8 (KF8) eBook ist das digitale Dateiformat, das für Amazon Kindle‑Geräte entwickelt wurde. Das Format ist eine Weiterentwicklung älterer AZW‑Dateien und wird auf Kindle‑Fire‑Geräten ausschließlich mit Rückwärtskompatibilität zum Vorgängerformat, d. h. MOBI und AZW, verwendet. Erfahren Sie hier mehr über dieses Dateiformat.
