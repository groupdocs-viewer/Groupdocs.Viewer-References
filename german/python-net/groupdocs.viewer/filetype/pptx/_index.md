## PPTX field

PowerPoint Open XML Präsentation (.pptx) sind Präsentationsdateien, die mit der beliebten Microsoft PowerPoint‑Anwendung erstellt werden. Im Gegensatz zur vorherigen, binären PPT‑Version basiert das PPTX‑Format auf dem offenen XML‑Präsentationsdateiformat von Microsoft PowerPoint. Erfahren Sie hier mehr über dieses Dateiformat.
