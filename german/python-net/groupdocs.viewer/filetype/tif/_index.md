## TIF field

Tagged Image File (.tif) steht für Rasterbilder, die auf einer Vielzahl von Geräten verwendet werden können, die diesem Dateiformatstandard entsprechen. Es kann bilevel‑, Graustufen‑, Paletten‑ und Vollfarbbilddaten in mehreren Farbräumen beschreiben. Erfahren Sie hier mehr über dieses Dateiformat.
