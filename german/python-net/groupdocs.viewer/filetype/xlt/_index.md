## XLT field

Microsoft Excel Vorlage (.xlt) sind Vorlagendateien, die mit Microsoft Excel erstellt werden, einer Tabellenkalkulationsanwendung, die Teil der Microsoft Office‑Suite ist. Microsoft Office 97‑2003 unterstützte das Erstellen neuer XLT‑Dateien sowie das Öffnen dieser. Erfahren Sie hier mehr über dieses Dateiformat.
