## IAuxDisposable class

Erweitert die Standard‑Schnittstelle `System.IDisposable`, ermöglicht das Abrufen des aktuellen Zustands eines Objekts und das Abonnieren eines Dispose‑Ereignisses.

Der IAuxDisposable-Typ stellt die folgenden Mitglieder bereit:

### Eigenschaften
| Eigenschaft | Beschreibung |
| :- | :- |
| [is_disposed](/viewer/python-net/groupdocs.viewer/iauxdisposable/is_disposed/) | Die Eigenschaft gibt an, ob eine Ressource bereits entsorgt ist (`True`) oder nicht (`False`). |
