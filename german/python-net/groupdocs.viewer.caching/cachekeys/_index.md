## CacheKeys class

Stellt Methoden zum Abrufen einer eindeutigen Kennung für den Cache-Eintrag bereit.

Der Typ CacheKeys stellt die folgenden Mitglieder bereit:

### Methoden
| Methode | Beschreibung |
| :- | :- |
| [get_attachment_key](/viewer/python-net/groupdocs.viewer.caching/cachekeys/get_attachment_key/#attachment_id) | Gibt einen eindeutigen Bezeichner für den Cache‑Eintrag zurück, der die Anhangsdatei darstellt. |
| [get_attachments_key](/viewer/python-net/groupdocs.viewer.caching/cachekeys/get_attachments_key/) | Gibt einen eindeutigen Bezeichner für den Cache‑Eintrag zurück, der eine Sammlung von [`Attachment`](/viewer/python-net/groupdocs.viewer.results/attachment/) Objekten darstellt. |
| [get_file_info_key](/viewer/python-net/groupdocs.viewer.caching/cachekeys/get_file_info_key/) | Gibt einen eindeutigen Bezeichner für den Cache‑Eintrag zurück, der das [`ViewInfo`](/viewer/python-net/groupdocs.viewer.results/viewinfo/) Objekt darstellt. |
| [get_file_key](/viewer/python-net/groupdocs.viewer.caching/cachekeys/get_file_key/#extension) | Gibt einen eindeutigen Bezeichner für den Cache‑Eintrag zurück, der die Datei darstellt. |
| [get_page_key](/viewer/python-net/groupdocs.viewer.caching/cachekeys/get_page_key/#page_number-extension) | Gibt einen eindeutigen Bezeichner für den Cache‑Eintrag zurück, der die Seiten‑Datei darstellt. |
| [get_resource_filter](/viewer/python-net/groupdocs.viewer.caching/cachekeys/get_resource_filter/#page_number) | Gibt einen Filter‑String zurück, um nach Cache‑Einträgen zu suchen, die [`Resource`](/viewer/python-net/groupdocs.viewer.results/resource/) Objekte darstellen. |
| [get_resource_key](/viewer/python-net/groupdocs.viewer.caching/cachekeys/get_resource_key/#page_number-resource) | Gibt einen eindeutigen Bezeichner für den Cache‑Eintrag zurück, der das [`Resource`](/viewer/python-net/groupdocs.viewer.results/resource/) Objekt darstellt. |
| [get_view_info_key](/viewer/python-net/groupdocs.viewer.caching/cachekeys/get_view_info_key/) | Gibt einen eindeutigen Bezeichner für den Cache‑Eintrag zurück, der das [`ViewInfo`](/viewer/python-net/groupdocs.viewer.results/viewinfo/) Objekt darstellt. |
