## get_hue

Gibt die Farbtonkomponente der Farbe im HSL-Farbraum zurück, ausgedrückt in Grad. Ist die Farbe ein Graustufenwert (R == G == B), ist der Farbton undefiniert und die Methode gibt 0 zurück.

**Returns:** float: Hue value in degrees.
