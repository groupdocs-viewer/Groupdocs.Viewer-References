## to_argb

Gibt den ARGB-Wert dieser [`Argb32Color`](/viewer/python-net/groupdocs.viewer.drawing/argb32color/) Instanz zurück, kompatibel mit der Methode `System.Drawing.Color.ToArgb()`.

```python
def to_argb(self):
    ...
```

**Returns:** 32-bit ARGB value of this instance as int, identical to `System.Drawing.Color.ToArgb()` call for the same color. Never throws an exception.
