## folder property

Der Name des Ordners (z. B. Posteingang, Gesendete Elemente oder Gelöschte Elemente), der gerendert werden soll.

Beim Rendern einer Outlook‑Datendatei rendert GroupDocs.Viewer Nachrichten aus allen im Dateisystem enthaltenen Ordnern (einschließlich verschachtelter Ordner). Verwenden Sie diese Eigenschaft, um Elemente aus einem bestimmten Ordner zu rendern.
