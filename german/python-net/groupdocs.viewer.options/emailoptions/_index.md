## EmailOptions class

Enthält Optionen zum Rendern von E‑Mail‑Nachrichten.

GroupDocs.Viewer unterstützt die Klasse EmailOptions, mit der Sie verschiedene Optionen für die Darstellung von E‑Mail‑Nachrichten festlegen können. Um auf diese Optionen zuzugreifen, verwenden Sie die Eigenschaft EmailOptions in einer der folgenden Ansichtoption‑Klassen, abhängig vom gewünschten Ausgabeformat:

- [`HtmlViewOptions`](/viewer/python-net/groupdocs.viewer.options/htmlviewoptions/)
- [`PdfViewOptions`](/viewer/python-net/groupdocs.viewer.options/pdfviewoptions/)
- [`PngViewOptions`](/viewer/python-net/groupdocs.viewer.options/pngviewoptions/)
- [`JpgViewOptions`](/viewer/python-net/groupdocs.viewer.options/jpgviewoptions/)
