## render_to_pure_html property

Die Eigenschaft aktiviert einen neuen HTML-Rendermodus für Präsentationsdokumente — in diesem Modus werden die Dateien in reines HTML/CSS-Markup ohne SVG‑Bilder gerendert. Standardmäßig ist er deaktiviert (`False`) und der vorhandene SVG‑basierte HTML‑Renderer wird verwendet.

Für ein Codebeispiel siehe die Dokumentation unter https://docs.groupdocs.com/viewer/net/render-presentations/#generate-pure-htmlcss-markup.
