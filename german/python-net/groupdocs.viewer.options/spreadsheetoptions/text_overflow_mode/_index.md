## text_overflow_mode property

Der Textüberlaufmodus für das Rendern von Tabellenkalkulationsdokumenten in HTML. Der Standard ist `TextOverflowMode.OverlayIfNextIsEmpty`, der das Standardverhalten von MS Excel nachahmt.
