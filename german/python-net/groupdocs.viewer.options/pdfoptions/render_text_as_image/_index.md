## render_text_as_image property

Die Option ermöglicht das Rendern von Texten in PDF‑Dateien als Bild in der HTML‑Ausgabe.

Wenn diese Option auf True gesetzt ist, rendert GroupDocs.Viewer Text als Bild in der HTML‑Ausgabe. Dadurch wird der Text nicht auswählbar und die Zeichen­darstellung verbessert, was ein PDF‑ähnliches Erscheinungsbild in HTML gewährleistet. Der Standardwert ist False.

Diese Option ist für das Rendern nach HTML verfügbar.
