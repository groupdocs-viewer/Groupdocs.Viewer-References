## enable_font_hinting property

Die Eigenschaft aktiviert Font-Hinting.

Font-Hinting passt an, wie eine Kontur-Schriftart angezeigt wird. Nur anwendbar auf TTF-Schriftarten, die im Quelldokument verwendet werden. Diese Option ist für die Darstellung in PNG- oder JPG-Formaten verfügbar. Der Standardwert ist False.
