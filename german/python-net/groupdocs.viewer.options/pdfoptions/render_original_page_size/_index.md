## render_original_page_size property

Die Ausgabe‑Seitengröße wird so eingestellt, dass sie der Seitengröße des Quell‑PDF‑Dokuments entspricht.

Standardmäßig berechnet GroupDocs.Viewer die Seitengröße des Ausgabebildes für eine bessere Renderqualität. Aktiviere diese Option, um sicherzustellen, dass die Ausgabeseiten dieselbe Größe wie die Seitengröße des Quell‑PDF‑Dokuments (in Pixeln) haben. Der Standardwert ist False.

Diese Option ist für das Rendern zu PNG‑ oder JPG‑Formaten verfügbar.
