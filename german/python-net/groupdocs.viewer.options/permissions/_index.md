## Permissions class

Der Permissions-Typ stellt die folgenden Mitglieder bereit:

### Felder
| Feld | Beschreibung |
| :- | :- |
| [ALLOW_ALL](/viewer/python-net/groupdocs.viewer.options/permissions/allow_all/) | Drucken, Ändern und Datenextraktion zulassen. |
| [DENY_PRINTING](/viewer/python-net/groupdocs.viewer.options/permissions/deny_printing/) | Drucken verweigern. |
| [DENY_MODIFICATION](/viewer/python-net/groupdocs.viewer.options/permissions/deny_modification/) | Inhaltsänderungen, Ausfüllen von Formularen, Hinzufügen oder Ändern von Anmerkungen verweigern. |
| [DENY_DATA_EXTRACTION](/viewer/python-net/groupdocs.viewer.options/permissions/deny_data_extraction/) | Verweigern Sie das Extrahieren von Text und Grafiken. |
| [DENY_ALL](/viewer/python-net/groupdocs.viewer.options/permissions/deny_all/) | Verweigern Sie das Drucken, die Inhaltsänderung und das Extrahieren von Daten. |
