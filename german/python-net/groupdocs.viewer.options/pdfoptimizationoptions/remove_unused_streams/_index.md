## remove_unused_streams property

Die Eigenschaft entfernt ungenutzte (verwaiste) Streams aus einer PDF-Datei, die im Seitenressourcen‑Wörterbuch referenziert, aber nie im Seiteninhalt verwendet werden. Standardmäßig deaktiviert (`False`); wird sie auf `True` gesetzt, reduziert dies die Größe der Ausgabe‑PDF.
