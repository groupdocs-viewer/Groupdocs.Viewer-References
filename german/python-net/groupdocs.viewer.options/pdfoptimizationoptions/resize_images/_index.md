## resize_images property

Die Eigenschaft ermöglicht das Festlegen der maximalen Auflösung in der Ausgabe‑PDF.

Um diese Option zu aktivieren, setzen Sie die Eigenschaft [`PdfOptimizationOptions.compress_images`](/viewer/python-net/groupdocs.viewer.options/pdfoptimizationoptions/compress_images/) auf `True`. Diese Option ermöglicht das Festlegen der Eigenschaft [`PdfOptimizationOptions.max_resolution`](/viewer/python-net/groupdocs.viewer.options/pdfoptimizationoptions/max_resolution/).
