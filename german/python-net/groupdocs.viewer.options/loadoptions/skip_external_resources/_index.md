## skip_external_resources property

Die Eigenschaft deaktiviert das Laden aller externen Ressourcen wie Bilder, außer denen, die in [`LoadOptions.whitelisted_resources`](/viewer/python-net/groupdocs.viewer.options/loadoptions/whitelisted_resources/) aufgeführt sind.

Ein Codebeispiel finden Sie in der Dokumentation unter https://docs.groupdocs.com/viewer/net/loading-external-resources/#skip-loading-of-external-resources.
