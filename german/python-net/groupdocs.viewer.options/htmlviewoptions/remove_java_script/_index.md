## remove_java_script property

Die Eigenschaft bestimmt, ob JavaScript-Quellcode aus Links in den generierten HTML-Dokumenten entfernt wird, wenn Eingabedokumente mit Skripten gerendert werden. Standardmäßig aktiviert (`True`).

Weitere Details zum Entfernen von JavaScript finden Sie in der Dokumentation: https://docs.groupdocs.com/viewer/net/rendering-to-html/#preserving-or-disabling-javascript-when-rendering-to-html
