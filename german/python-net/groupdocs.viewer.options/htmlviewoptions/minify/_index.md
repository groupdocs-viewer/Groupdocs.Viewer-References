## minify property

Die Eigenschaft aktiviert die Minimierung von HTML-Inhalten und HTML-Ressourcen.

Die Komprimierung des Ausgabecodes (HTML, CSS und SVG) ist eine Möglichkeit, die HTML-Datei zu optimieren. Dafür setzen Sie diese Eigenschaft auf `True`.
