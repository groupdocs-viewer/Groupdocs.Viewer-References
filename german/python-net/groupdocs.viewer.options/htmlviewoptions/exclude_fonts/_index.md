## exclude_fonts property

Die Eigenschaft deaktiviert das Hinzufügen von Schriftarten in das HTML-Dokument.

Standardmäßig bettet GroupDocs.Viewer die im Dokument verwendeten Schriftarten in das HTML-Markup ein, und diese Eigenschaft hat den Wert `False`. Um das Einbetten von Schriftarten zu verhindern, setzen Sie diese Eigenschaft auf `True`.
