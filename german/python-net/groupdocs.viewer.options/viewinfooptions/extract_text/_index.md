## extract_text property

Die Eigenschaft ermöglicht die Textextraktion.

Verwenden Sie diese Eigenschaft, um den im Quelldokument enthaltenen Text und dessen Koordinaten zu erhalten. Anschließend können Sie diese Daten nutzen, um einen auswählbaren Text über das Bild zu legen oder eine Textsuche bei bildbasiertem Rendering zu implementieren.
