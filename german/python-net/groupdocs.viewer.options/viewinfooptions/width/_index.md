## width property

Die Breite des Ausgabebildes (in Pixeln, nur für die Darstellung als PNG/JPG).

Verwenden Sie diese Eigenschaft, um die Breite des Ausgabebildes (in Pixeln) festzulegen. Für ein Codebeispiel siehe die Dokumentation.

Wenn Sie diese Eigenschaft festlegen, wird die [`ViewInfoOptions.MaxWidth`](/viewer/python-net/groupdocs.viewer.options/viewinfooptions/max_width/)‑Eigenschaft ignoriert.
