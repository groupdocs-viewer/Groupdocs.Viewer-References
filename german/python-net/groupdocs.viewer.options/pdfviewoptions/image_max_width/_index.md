## image_max_width property

Die maximale Breite eines Ausgabebildes in Pixeln.

Verwenden Sie diese Eigenschaft, um die maximale Ausgabe-Bildbreite (in Pixeln) festzulegen. GroupDocs.Viewer wendet diese Eigenschaft beim Rendern eines einzelnen Bildes zu PDF an. Weitere Details finden Sie in der Dokumentation.

Wenn Sie die [`PdfViewOptions.ImageWidth`](/viewer/python-net/groupdocs.viewer.options/pdfviewoptions/image_width/) Eigenschaft festlegen, wird diese Eigenschaft ignoriert.
