## max_items property

Die maximale Anzahl von Nachrichten oder Elementen, die gerendert werden sollen.

Mail-Storage-Datendateien können groß sein und das Abrufen aller Nachrichten kann erheblich Zeit in Anspruch nehmen. Diese Eigenschaft begrenzt die maximale Anzahl von Nachrichten oder Elementen, die gerendert werden. Der Standardwert ist 0 – alle Nachrichten werden gerendert.
