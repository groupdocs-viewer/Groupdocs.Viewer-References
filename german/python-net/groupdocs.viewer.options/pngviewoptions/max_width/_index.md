## max_width property

Die maximale Breite eines Ausgabebildes in Pixeln.

Verwenden Sie diese Eigenschaft, um die maximale Ausgabe‑Bildbreite (in Pixeln) festzulegen. Für ein Code‑Beispiel siehe die Dokumentation: https://docs.groupdocs.com/viewer/net/set-image-size-limits-when-rendering-to-png-jpg/

Wenn Sie die [`PngViewOptions.width`](/viewer/python-net/groupdocs.viewer.options/pngviewoptions/width/) Eigenschaft festlegen, wird diese Eigenschaft ignoriert.
