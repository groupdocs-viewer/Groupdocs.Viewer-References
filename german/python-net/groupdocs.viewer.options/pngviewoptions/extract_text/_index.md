## extract_text property

Die Eigenschaft ermöglicht die Textextraktion.

Verwenden Sie diese Eigenschaft, um den im Quelldokument enthaltenen Text und dessen Koordinaten zu erhalten. Anschließend können Sie diese Daten nutzen, um einen auswählbaren Text über dem Bild hinzuzufügen oder eine Textsuche in bildbasierter Darstellung zu implementieren.

Für ein Codebeispiel siehe die Dokumentation: https://docs.groupdocs.com/viewer/net/image-viewer-get-text-coordinates/
