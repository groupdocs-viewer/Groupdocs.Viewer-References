## max_height property

Die maximale Höhe eines Ausgabebildes in Pixeln.

Verwenden Sie diese Eigenschaft, um die maximale Ausgabe‑Bildhöhe (in Pixeln) festzulegen. Für ein Codebeispiel siehe die Dokumentation unter https://docs.groupdocs.com/viewer/net/set-image-size-limits-when-rendering-to-png-jpg/.

Wenn Sie die [`JpgViewOptions.height`](/viewer/python-net/groupdocs.viewer.options/jpgviewoptions/height/) Eigenschaft setzen, wird diese Eigenschaft ignoriert.
