## max_width property

Die maximale Breite eines Ausgabebildes in Pixeln.

Verwenden Sie diese Eigenschaft, um die maximale Breite des Ausgabebildes (in Pixeln) festzulegen. Für ein Codebeispiel siehe die Dokumentation unter https://docs.groupdocs.com/viewer/net/set-image-size-limits-when-rendering-to-png-jpg/.

Wenn die `Width`‑Eigenschaft gesetzt ist, wird diese Eigenschaft ignoriert.
