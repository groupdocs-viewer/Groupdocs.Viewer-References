### Beispiel

```python
from groupdocs.viewer import Viewer
from groupdocs.viewer.options import JpgViewOptions

def render_to_jpg():
    # Laden Sie ein Dokument (z. B. Excel, Numbers oder Bild)
    with Viewer("invoice.xlsx") as viewer:
        # Erstellen Sie JPG-Ansichtsoptionen mit einem Ausgabedateimuster.
        # {0} wird durch die Seitenzahl ersetzt.
        view_options = JpgViewOptions("output_{0}.jpg")
        # Legen Sie die gewünschte Ausgabebildgröße in Pixeln fest.
        view_options.width = 800
        view_options.height = 900
        # Rendern Sie das Dokument zu JPEG-Dateien.
        viewer.view(view_options)

if __name__ == "__main__":
    render_to_jpg()
```
