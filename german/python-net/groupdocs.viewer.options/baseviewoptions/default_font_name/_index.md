## default_font_name property

Die Standardschriftart für ein Dokument, die beim Rendern verwendet wird, wenn eine erforderliche Schriftart fehlt.

Verwenden Sie diese Eigenschaft, um die Standardschriftart für ein Dokument festzulegen. GroupDocs.Viewer verwendet diese Schriftart beim Rendern anstelle von nicht installierten Schriftarten.

Codebeispiele finden Sie in der Dokumentation: https://docs.groupdocs.com/viewer/net/replace-missing-font/
