## render_comments property

Die Eigenschaft aktiviert oder deaktiviert das Rendern von Kommentaren.

Standardmäßig rendert GroupDocs.Viewer Kommentare. Um das Rendern von Kommentaren zu deaktivieren, setzen Sie diese Eigenschaft auf `False`.
