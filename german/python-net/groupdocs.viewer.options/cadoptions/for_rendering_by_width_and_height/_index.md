## for_rendering_by_width_and_height {#width-height}

Initialisiert eine Instanz der CadOptions-Klasse für die Darstellung nach Breite und Höhe.

Für ein Code‑Beispiel siehe die Dokumentation.

```python
def for_rendering_by_width_and_height(cls, width, height):
    ...
```

| Parameter | Typ | Beschreibung |
| :- | :- | :- |
| width | `int` | Die Breite des Ausgaberesultats (in Pixeln). |
| height | `int` | Die Höhe des Ausgabeergebnisses (in Pixeln). |

**Returns:** CadOptions: New instance of CadOptions class for rendering by width and height.

| Ausnahmen | Beschreibung |
| :- | :- |
| `ValueError` | Wenn `height` kleiner oder gleich null ist. |
