## enable_performance_conversion_mode property

Das Flag, das einen leistungsorientierten Konvertierungsmodus für alle CAD-Formate aktiviert, wobei das Setzen auf True die Konvertierung beschleunigt, jedoch die Ausgabequalität reduziert; standardmäßig ist es auf False eingestellt für maximale Qualität.
