| Parameter | Typ | Beschreibung |
| :- | :- | :- |
| character | `str` | Das Zeichen. |
| x | `float` | Die X‑Koordinate des höchsten linken Punktes im Seitenlayout, an dem das Rechteck, das das Zeichen enthält, beginnt. |
