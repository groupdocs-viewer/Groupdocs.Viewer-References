## FileType.TIFF field

Das Tagged Image File Format (.tiff) stellt Rasterbilder dar, die für die Verwendung auf einer Vielzahl von Geräten gedacht sind, die diesem Dateiformatstandard entsprechen. Es ist in der Lage, Bilevel-, Graustufen-, Palettenfarb- und Vollfarbbilddaten in mehreren Farbräumen zu beschreiben. Erfahren Sie mehr über dieses Dateiformat [hier](https://wiki.fileformat.com/image/tiff).
