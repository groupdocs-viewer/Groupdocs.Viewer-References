## FileType.XPS field

XML Paper Specification‑Datei (.xps) stellt Seitenlayout‑Dateien dar, die auf den von Microsoft erstellten XML Paper Specifications basieren. Dieses Format wurde von Microsoft als Ersatz für das EMF‑Dateiformat entwickelt und ist dem PDF‑Dateiformat ähnlich, verwendet jedoch XML für Layout-, Erscheinungs‑ und Druckinformationen eines Dokuments. Erfahren Sie mehr über dieses Dateiformat [hier](https://wiki.fileformat.com/page-description-language/xps).
