## FileType.PPT field

PowerPoint Presentation (.ppt) stellt eine PowerPoint‑Datei dar, die aus einer Sammlung von Folien für die Anzeige als Diashow besteht. Sie definiert das binäre Dateiformat, das von Microsoft PowerPoint 97‑2003 verwendet wird. Erfahren Sie mehr über dieses Dateiformat [hier](https://wiki.fileformat.com/presentation/ppt).
