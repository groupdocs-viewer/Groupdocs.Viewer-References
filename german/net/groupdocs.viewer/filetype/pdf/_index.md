## FileType.PDF field

Portable Document Format File (.pdf) ist ein Dokumenttyp, der in den 1990er‑Jahren von Adobe erstellt wurde. Der Zweck dieses Dateiformats bestand darin, einen Standard für die Darstellung von Dokumenten und anderem Referenzmaterial in einem Format einzuführen, das unabhängig von Anwendungssoftware, Hardware sowie Betriebssystem ist. Weitere Informationen zu diesem Dateiformat finden Sie [hier](https://wiki.fileformat.com/view/pdf).
