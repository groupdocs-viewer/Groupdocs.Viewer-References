## FileType.EPUB field

Open eBook File (.epub) ist ein eBook-Dateiformat, das ein standardisiertes digitales Veröffentlichungsformat für Verlage und Verbraucher bereitstellt. Das Format ist inzwischen so verbreitet, dass es von vielen E-Readern und Softwareanwendungen unterstützt wird.
