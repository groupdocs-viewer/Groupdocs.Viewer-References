## FileType.DWG field

AutoCAD Drawing Database File (.dwg) stellt proprietäre Binärdateien dar, die 2D‑ und 3D‑Designdaten enthalten. Wie DXF, das ASCII‑Dateien sind, repräsentiert DWG das Binärdateiformat für CAD (Computer Aided Design)‑Zeichnungen. Erfahren Sie mehr über dieses Dateiformat [hier](https://wiki.fileformat.com/cad/dwg).
