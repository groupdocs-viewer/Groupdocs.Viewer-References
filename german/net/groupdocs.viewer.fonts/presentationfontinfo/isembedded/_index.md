## PresentationFontInfo.IsEmbedded property

Gibt an, ob diese Schriftart im Dokument eingebettet ist, in die [`Viewer`](../../../groupdocs.viewer/viewer)-Instanz geladen wird (`true`), oder ob es eine Systemschriftart ist (`false`). Tabellenkalkulationsdokumente können keine eingebetteten Schriftarten enthalten, daher gibt diese Eigenschaft für sie stets `false` zurück.

public bool IsEmbedded { get; }
