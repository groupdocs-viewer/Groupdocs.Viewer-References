## WordsPageNumberLocation enumeration

Steuert, ob die Seitennummerierung zwingend auf das geladene WordProcessing-Dokument angewendet wird und, falls ja, wo die Seitenzahlen platziert werden.

```csharp
public enum WordsPageNumberLocation : byte
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| NotApply | `0` | Lässt das geladene WordProcessing-Dokument unverändert. Standardwert. |
| TopLeft | `1` | Platziere die Seitennummer in der oberen linken Ecke der Seite. |
| TopCenter | `2` | Platziere die Seitennummer in der oberen mittleren Ecke der Seite. |
| TopRight | `3` | Platziere die Seitennummer in der oberen rechten Ecke der Seite. |
| BottomLeft | `4` | Platziere die Seitennummer in der unteren linken Ecke der Seite. |
| BottomCenter | `5` | Platziere die Seitennummer in der unteren mittleren Ecke der Seite. |
| BottomRight | `6` | Platziere die Seitennummer in der unteren rechten Ecke der Seite. |
