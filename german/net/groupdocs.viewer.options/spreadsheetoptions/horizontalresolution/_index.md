## SpreadsheetOptions.HorizontalResolution property

Liest oder setzt die horizontale Auflösung für erzeugte Bilder in Punkten pro Zoll. Diese Option wird nur beim Rendern von Tabellenkalkulationen in PNG- oder JPEG-Formate verwendet.

```csharp
public int HorizontalResolution { get; set; }
```

### Bemerkungen

Der Standardwert beträgt 96 DPI. Der minimal mögliche Wert beträgt 72 DPI, der maximal mögliche Wert 600 DPI. Wenn der vom Benutzer angegebene Wert außerhalb dieser Grenzen liegt, wird der minimale bzw. maximale mögliche Wert verwendet.
