## PdfViewOptions.ImageMaxHeight property

Legt die maximale Höhe eines Ausgabebildes fest (in Pixeln).

```csharp
public int ImageMaxHeight { get; set; }
```

### Bemerkungen

Verwenden Sie diese Eigenschaft, um die maximale Höhe des Ausgabebildes (in Pixeln) festzulegen. GroupDocs.Viewer wendet diese Eigenschaft beim Rendern eines einzelnen Bildes zu PDF an. Weitere Details finden Sie in der [Dokumentation](https://docs.groupdocs.com/viewer/net/set-image-size-limits-when-rendering-to-pdf/).

Wenn Sie die [`ImageHeight`](../imageheight)-Eigenschaft festlegen, wird diese Eigenschaft ignoriert.
