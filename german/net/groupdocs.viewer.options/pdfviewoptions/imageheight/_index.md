## PdfViewOptions.ImageHeight property

Legt die Höhe eines Ausgabebildes fest (in Pixeln).

```csharp
public int ImageHeight { get; set; }
```

### Bemerkungen

Verwenden Sie diese Eigenschaft, um die Höhe des Ausgabebildes (in Pixeln) festzulegen. GroupDocs.Viewer wendet diese Eigenschaft ausschließlich beim Rendern eines einzelnen Bildes zu HTML an. Weitere Details finden Sie in der [Dokumentation](https://docs.groupdocs.com/viewer/net/set-image-size-limits-when-rendering-to-pdf/).

Wenn Sie diese Eigenschaft festlegen, wird die [`ImageMaxHeight`](../imagemaxheight)-Eigenschaft ignoriert.
