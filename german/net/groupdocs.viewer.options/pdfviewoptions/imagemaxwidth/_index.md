## PdfViewOptions.ImageMaxWidth property

Legt die maximale Breite eines Ausgabebildes fest (in Pixeln).

```csharp
public int ImageMaxWidth { get; set; }
```

### Bemerkungen

Verwenden Sie diese Eigenschaft, um die maximale Breite des Ausgabebildes (in Pixeln) festzulegen. GroupDocs.Viewer wendet diese Eigenschaft beim Rendern eines einzelnen Bildes zu PDF an. Weitere Details finden Sie in der [Dokumentation](https://docs.groupdocs.com/viewer/net/set-image-size-limits-when-rendering-to-pdf/).

Wenn Sie die [`ImageWidth`](../imagewidth)-Eigenschaft festlegen, wird diese Eigenschaft ignoriert.
