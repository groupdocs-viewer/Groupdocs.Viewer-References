## PdfViewOptions.ImageWidth property

Legt die Breite eines Ausgabebildes fest (in Pixeln).

```csharp
public int ImageWidth { get; set; }
```

### Bemerkungen

Verwenden Sie diese Eigenschaft, um die Breite des Ausgabebildes (in Pixeln) festzulegen. GroupDocs.Viewer wendet diese Eigenschaft beim Rendern eines einzelnen Bildes zu PDF an. Weitere Details finden Sie in der [Dokumentation](https://docs.groupdocs.com/viewer/net/set-image-size-limits-when-rendering-to-pdf/).

Wenn Sie diese Eigenschaft festlegen, wird die [`ImageMaxWidth`](../imagemaxwidth)-Eigenschaft ignoriert.
