## HtmlViewOptions.RemoveJavaScript property

Ermöglicht das Entfernen des JavaScript-Quellcodes aus den Links in resultierenden HTML-Dokumenten, wenn Eingabedokumente gerendert werden, die Skripte enthalten. Standardmäßig ist dies aktiviert (`true`).

```csharp
public bool RemoveJavaScript { get; set; }
```
