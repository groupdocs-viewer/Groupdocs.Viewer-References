## HtmlViewOptions.ExcludeFonts property

Deaktiviert das Hinzufügen von Schriftarten zum HTML-Dokument.

```csharp
public bool ExcludeFonts { get; set; }
```

### Bemerkungen

Standardmäßig bettet GroupDocs.Viewer die im Dokument verwendeten Schriftarten in das HTML-Markup ein, und diese Eigenschaft hat den Wert `false`. Um das Einbetten von Schriftarten zu verhindern, setzen Sie diese Eigenschaft auf `true`.

Für Details und ein Codebeispiel siehe die [Dokumentation](https://docs.groupdocs.com/viewer/net/exclude-fonts/).
