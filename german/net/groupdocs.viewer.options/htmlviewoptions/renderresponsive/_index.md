## HtmlViewOptions.RenderResponsive property

Aktiviert responsives Rendering.

### Bemerkungen

Responsive Design zielt darauf ab, Webpages auf einer Vielzahl von Geräten gut darzustellen. Um mit einem responsiven Layout zu rendern, setzen Sie diese Eigenschaft auf `true`.

Für ein Codebeispiel siehe die [Dokumentation](https://docs.groupdocs.com/viewer/net/render-with-responsive-layout/).
