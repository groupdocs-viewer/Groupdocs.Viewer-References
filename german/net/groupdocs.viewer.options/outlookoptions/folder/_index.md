## OutlookOptions.Folder property

Legt den Namen des Ordners (z. B. Inbox, Sent Item oder Deleted Items) fest, der gerendert werden soll.

```csharp
public string Folder { get; set; }
```

### Bemerkungen

Beim Rendern einer Outlook-Datendatei rendert GroupDocs.Viewer Nachrichten aus allen im Datei enthaltenen Ordnern (einschließlich verschachtelter Ordner). Verwenden Sie diese Eigenschaft, um Elemente aus einem bestimmten Ordner zu rendern.

Für ein Codebeispiel siehe diese [Dokumentation](https://docs.groupdocs.com/viewer/net/render-outlook-data-files/#render-a-specific-folder).
