## JpgViewOptions.Quality property

Legt die Qualität des Ausgabebildes fest.

```csharp
public byte Quality { get; set; }
```

### Bemerkungen

Verwenden Sie diese Eigenschaft, um die Bildqualität anzupassen. Der Wert muss zwischen 1 ( minimale Qualität) und 100 liegen. Der Standardwert ist 90.

Für ein Codebeispiel siehe die [Dokumentation](https://docs.groupdocs.com/viewer/net/image-viewer-adjust-quality-for-jpg/).
