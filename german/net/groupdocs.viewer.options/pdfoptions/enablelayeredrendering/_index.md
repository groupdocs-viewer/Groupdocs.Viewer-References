## PdfOptions.EnableLayeredRendering property

Ermöglicht das Rendern von Text und Grafiken in der ursprünglichen Z‑Reihenfolge des PDF‑Dokuments beim Rendern zu HTML.

```csharp
public bool EnableLayeredRendering { get; set; }
```

### Bemerkungen

Standardmäßig rendert GroupDocs.Veiewer Text und Grafiken als eine einzelne Ebene in HTML. Diese Option ermöglicht es Ihnen, Objekte in derselben Reihenfolge wie in der Quelldatei anzuordnen. Der Standardwert ist `false`.

Für ein Code‑Beispiel siehe die [Dokumentation](https://docs.groupdocs.com/viewer/net/render-pdf-documents/#enable-multi-layer-rendering).
