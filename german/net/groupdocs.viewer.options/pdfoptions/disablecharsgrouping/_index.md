## PdfOptions.DisableCharsGrouping property

Deaktiviert die Symbolgruppierung für präzise Symbolpositionierung während des Seitenrenderings.

```csharp
public bool DisableCharsGrouping { get; set; }
```

### Bemerkungen

Beim Konvertieren von PDF‑Dateien gruppiert GroupDocs.Viewer einzelne Zeichen zu Wörtern, um die Rendering‑Leistung zu verbessern. Wenn Ihr Dokument Hieroglyphen oder Sonderzeichen enthält, möchten Sie möglicherweise die Zeichen­gruppierung verbieten, um ein genaueres Layout zu gewährleisten. Der Standardwert ist `false`.

Für ein Code‑Beispiel siehe die [Dokumentation](https://docs.groupdocs.com/viewer/net/render-pdf-documents/#disable-character-grouping).
