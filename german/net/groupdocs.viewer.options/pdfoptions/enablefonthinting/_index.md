## PdfOptions.EnableFontHinting property

Aktiviert Font-Hinting.

```csharp
public bool EnableFontHinting { get; set; }
```

### Bemerkungen

Font‑Hinting passt an, wie eine Kontur‑Schrift dargestellt wird. Nur anwendbar auf TTF‑Schriften, die im Quelldokument verwendet werden. Diese Option ist für das Rendern in PNG- oder JPG-Formate verfügbar. Der Standardwert ist `false`.

Für ein Code‑Beispiel siehe die [Dokumentation](https://docs.groupdocs.com/viewer/net/render-pdf-documents/#enable-font-hinting).
