## PdfOptions.RenderOriginalPageSize property

Setzt die Ausgabe‑Seitengröße gleich der Seitengröße des Quell‑PDF‑Dokuments.

```csharp
public bool RenderOriginalPageSize { get; set; }
```

### Bemerkungen

Standardmäßig berechnet GroupDocs.Viewer die Seitengröße des Ausgabebildes für eine bessere Rendering‑Qualität. Aktivieren Sie diese Option, um sicherzustellen, dass die Ausgabeseiten dieselbe Größe wie die Seitengröße des Quell‑PDF‑Dokuments (in Pixeln) haben. Der Standardwert ist `false`.

Diese Option ist für das Rendern in PNG- oder JPG-Formate verfügbar.

Für ein Code‑Beispiel siehe die [Dokumentation](https://docs.groupdocs.com/viewer/net/render-pdf-documents/#preserve-the-size-of-document-pages).
