## PdfOptions.RenderTextAsImage property

Ermöglicht das Rendern von Texten in PDF-Dateien als Bild in der HTML‑Ausgabe.

```csharp
public bool RenderTextAsImage { get; set; }
```

### Bemerkungen

Wenn diese Option auf `true` gesetzt ist, rendert GroupDocs.Viewer Text im HTML‑Ausgabe als Bild. Dadurch wird der Text nicht auswählbar und die Zeichen­darstellung wird verbessert, wodurch ein PDF‑ähnliches Erscheinungsbild im HTML gewährleistet wird. Der Standardwert ist `false`.

Diese Option ist für das Rendern nach HTML verfügbar.

Für ein Code‑Beispiel siehe die [Dokumentation](https://docs.groupdocs.com/viewer/net/render-pdf-documents/#render-text-as-an-image).
