## MailStorageOptions.MaxItems property

Legt die maximale Anzahl von Nachrichten oder Elementen fest, die gerendert werden sollen.

```csharp
public int MaxItems { get; set; }
```

### Bemerkungen

Mail‑Speicherdateien können groß sein und das Abrufen aller Nachrichten kann erhebliche Zeit in Anspruch nehmen. Diese Eigenschaft begrenzt die maximale Anzahl von Nachrichten oder Elementen, die gerendert werden. Der Standardwert ist 0 – alle Nachrichten werden gerendert.

Für ein Code‑Beispiel siehe die [Dokumentation](https://docs.groupdocs.com/viewer/net/render-lotus-notes-database-files/#limit-the-number-of-items-to-render).
