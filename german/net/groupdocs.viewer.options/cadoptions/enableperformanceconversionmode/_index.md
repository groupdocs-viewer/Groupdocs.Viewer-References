## CadOptions.EnablePerformanceConversionMode property

Das Setzen dieses Flags auf `true` aktiviert einen speziellen, leistungsorientierten Konvertierungsmodus für alle Formate der CAD‑Familie — in diesem Modus ist die Konvertierungsgeschwindigkeit deutlich höher, jedoch ist die Qualität der resultierenden Dokumente signifikant schlechter. Standardmäßig ist er deaktiviert (`false`) — die Qualität der resultierenden Dokumente ist dann bestmöglich, jedoch zulasten der Leistung.

public bool EnablePerformanceConversionMode { get; set; }
