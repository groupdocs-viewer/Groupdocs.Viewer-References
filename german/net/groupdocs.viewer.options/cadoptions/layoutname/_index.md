## CadOptions.LayoutName property

Der Name des zu rendernden Layouts. Der Layout‑Name ist groß-/kleinschreibungssensitiv.

```csharp
public string LayoutName { get; set; }
```

### Bemerkungen

Diese Option ist nur für CAD‑Zeichnungen verfügbar, die Layouts unterstützen: [`DXF`](../../../groupdocs.viewer/filetype/dxf), [`DWG`](../../../groupdocs.viewer/filetype/dwg), [`DWT`](../../../groupdocs.viewer/filetype/dwt), [`DWF`](../../../groupdocs.viewer/filetype/dwf), und [`DWFX`](../../../groupdocs.viewer/filetype/dwfx); Standardmäßig wird nur das Modell gerendert.
