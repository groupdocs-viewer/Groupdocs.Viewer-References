## CadOptions.RenderLayouts property

Flag, ob Layouts aus dem CAD‑Dokument gerendert werden sollen.

```csharp
public bool RenderLayouts { get; set; }
```

### Bemerkungen

Diese Option ist nur für CAD‑Zeichnungen verfügbar, die Layouts unterstützen [`DXF`](../../../groupdocs.viewer/filetype/dxf), [`DWG`](../../../groupdocs.viewer/filetype/dwg), [`DWT`](../../../groupdocs.viewer/filetype/dwt), und [`DWF`](../../../groupdocs.viewer/filetype/dwf), sowie [`DWFX`](../../../groupdocs.viewer/filetype/dwfx). Standardmäßig wird nur das Modell gerendert.
