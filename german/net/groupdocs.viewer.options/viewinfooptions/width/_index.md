## ViewInfoOptions.Width property

Die Breite des Ausgabebildes (in Pixeln, nur für die Darstellung als PNG/JPG).

```csharp
public int Width { get; set; }
```

### Bemerkungen

Verwenden Sie diese Eigenschaft, um die Breite des Ausgabebildes (in Pixeln) festzulegen. Für ein Codebeispiel siehe die [Dokumentation](https://docs.groupdocs.com/viewer/net/image-viewer-adjust-image-size/).

Wenn Sie diese Eigenschaft setzen, wird die [`MaxWidth`](../maxwidth)-Eigenschaft ignoriert.
