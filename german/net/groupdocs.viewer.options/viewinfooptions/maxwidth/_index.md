## ViewInfoOptions.MaxWidth property

Legt die maximale Breite eines Ausgabebildes fest (in Pixeln, nur für die Darstellung als PNG/JPG).

```csharp
public int MaxWidth { get; set; }
```

### Bemerkungen

Verwenden Sie diese Eigenschaft, um die maximale Breite des Ausgabebildes (in Pixeln) festzulegen. Für das Codebeispiel siehe die [Dokumentation](https://docs.groupdocs.com/viewer/net/set-image-size-limits-when-rendering-to-png-jpg/).

Wenn Sie die [`Width`](../width)-Eigenschaft setzen, wird diese Eigenschaft ignoriert.
