## ViewInfoOptions.ExtractText property

Aktiviert die Textextraktion.

```csharp
public bool ExtractText { get; set; }
```

### Bemerkungen

Verwenden Sie diese Eigenschaft, um den im Quelldokument enthaltenen Text und seine Koordinaten zu erhalten. Anschließend können Sie diese Daten verwenden, um einen auswählbaren Text über dem Bild hinzuzufügen oder eine Textsuche in bildbasierter Darstellung zu implementieren.

Für ein Codebeispiel siehe die [Dokumentation](https://docs.groupdocs.com/viewer/net/image-viewer-get-text-coordinates/).
