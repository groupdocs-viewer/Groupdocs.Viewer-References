## ViewInfoOptions.Height property

Die Höhe des Ausgabebildes (in Pixeln, nur für die Darstellung als PNG/JPG).

```csharp
public int Height { get; set; }
```

### Bemerkungen

Verwenden Sie diese Eigenschaft, um die Höhe des Ausgabebildes (in Pixeln) festzulegen. Für ein Codebeispiel siehe die [Dokumentation](https://docs.groupdocs.com/viewer/net/image-viewer-adjust-image-size/).

Wenn Sie diese Eigenschaft setzen, wird die [`MaxHeight`](../maxheight)-Eigenschaft ignoriert.
