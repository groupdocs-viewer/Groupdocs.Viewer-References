## PresentationOptions.RenderHeaderFooterPlaceholders property

Aktiviert das Rendern von Platzhaltern in Kopf‑ und Fußzeilen einer Folie. Standardmäßig deaktiviert (`false`). Diese Option gilt für alle 4 Rendermodi von Präsentationen: HTML, PDF, PNG und JPEG. Nicht anwendbar, wenn die Präsentation in reines HTML/CSS‑Markup mit [`RenderToPureHtml`](../rendertopurehtml) gerendert wird.

```csharp
public bool RenderHeaderFooterPlaceholders { get; set; }
```
