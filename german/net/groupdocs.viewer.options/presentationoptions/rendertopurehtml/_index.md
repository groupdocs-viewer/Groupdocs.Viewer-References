## PresentationOptions.RenderToPureHtml property

Aktiviert einen neuen HTML-Rendermodus für die Präsentationsdokumente — in diesem Modus werden die Präsentationsdateien zu **pure HTML/CSS markup** gerendert, ohne SVG‑Bilder. Standardmäßig ist er deaktiviert (`false`) — der vorhandene SVG‑basierte HTML‑Renderer wird verwendet.

```csharp
public bool RenderToPureHtml { get; set; }
```
