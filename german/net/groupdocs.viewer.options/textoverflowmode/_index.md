## TextOverflowMode enumeration

Legt den Textüberlaufmodus für das Rendern von Tabellenkalkulationsdokumenten in HTML fest.

```csharp
public enum TextOverflowMode
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| Overlay | `0` | Überlagert die nächsten Zellen, selbst wenn sie nicht leer sind. |
| OverlayIfNextIsEmpty | `1` | Überlagert die nächsten Zellen nur, wenn sie leer sind. Standardwert. |
| AutoFitColumn | `2` | Spalten erweitern, um den Text anzupassen. |
| HideText | `3` | Überlaufenden Text ausblenden. |
