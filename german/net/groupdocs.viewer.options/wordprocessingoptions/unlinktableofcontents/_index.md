## WordProcessingOptions.UnlinkTableOfContents property

Beim Rendern zu HTML oder PDF können Sie diese Option auf `true` setzen, um die Navigation im Inhaltsverzeichnis zu deaktivieren. Beim HTML-Rendering werden `a`‑Tags mit relativen Links durch `span`‑Tags ersetzt, wodurch die Funktionalität entfernt, aber das visuelle Erscheinungsbild erhalten bleibt. Beim PDF-Rendering wird das Inhaltsverzeichnis als reiner Text ohne Links zu Dokumentabschnitten gerendert.

```csharp
public bool UnlinkTableOfContents { get; set; }
```

### Bemerkungen

Standardwert ist `false`.

Weitere Details finden Sie in der [Dokumentation](https://docs.groupdocs.com/viewer/net/render-word-documents/#unlink-table-of-contents).
