## WordProcessingOptions.UpdateFields property

Liest oder setzt einen Wert, der bestimmt, ob Felder bestimmter Typen vor dem Speichern des Eingabe‑WordProcessing‑Dokuments in die Formate HTML, PDF, PNG oder JPEG aktualisiert werden sollen. Der Standardwert für diese Eigenschaft ist `true` — Felder werden vor dem Speichern aktualisiert.

```csharp
public bool UpdateFields { get; set; }
```
