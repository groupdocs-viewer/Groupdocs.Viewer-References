## PdfOptimizationOptions.RemoveUnusedStreams property

Entfernt ungenutzte (verwaiste) Streams aus einer PDF-Datei, die noch von den Ressourcen‑Dictionaries der Seite referenziert werden, aber tatsächlich nie im Seiteninhalt verwendet werden. Standardmäßig ist dies deaktiviert (`false`), das Aktivieren (`true`) verringert die Größe des Ausgabedokuments.

```csharp
public bool RemoveUnusedStreams { get; set; }
```
