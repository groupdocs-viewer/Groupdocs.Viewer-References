## PdfOptimizationOptions.RemoveUnusedObjects property

Entfernt ungenutzte (verwaiste) Objekte aus einer PDF-Datei, die im PDF‑Dokument platziert, aber von keinen Ressourcen‑Dictionaries einer Seite referenziert werden und daher überhaupt nicht verwendet werden. Das Aktivieren dieser Eigenschaft (`true`) verringert die Größe des Ausgabedokuments. Standardmäßig ist sie deaktiviert (`false`).

```csharp
public bool RemoveUnusedObjects { get; set; }
```
