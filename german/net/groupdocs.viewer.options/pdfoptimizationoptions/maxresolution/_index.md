## PdfOptimizationOptions.MaxResolution property

Legt die maximale Auflösung in der Ausgabedatei fest.

```csharp
public int MaxResolution { get; set; }
```

### Bemerkungen

Um diese Option zu ermöglichen, setzen Sie die [`CompressImages`](../compressimages) und `MaxResolution` Eigenschaften auf `true`.

Der Standardwert ist `300`.

Siehe für ein Code‑Beispiel diese [Dokumentation](https://docs.groupdocs.com/viewer/net/optimization-pdf-set-max-resolution/).
