## PdfOptimizationOptions.OptimizeSpreadsheets property

Ermöglicht die Optimierung von Tabellenkalkulationen in PDF-Dateien.

```csharp
public bool OptimizeSpreadsheets { get; set; }
```

### Bemerkungen

Diese Optimierung ermöglicht es, die Größe der Ausgabedatei zu reduzieren, indem Rahmenlinien gesetzt werden. Darüber hinaus entfernt sie die Zeichen von Arial und Times New Roman im Code‑Bereich 32‑127.
