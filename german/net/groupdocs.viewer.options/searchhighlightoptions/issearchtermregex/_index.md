## SearchHighlightOptions.IsSearchTermRegEx property

Liest oder setzt einen Wert, der angibt, ob der Suchbegriff als regulärer Ausdruck oder als Textliteral behandelt werden soll. Standard ist `false` — als Textliteral behandeln.

```csharp
public bool IsSearchTermRegEx { get; set; }
```

### Bemerkungen

Wenn `true`, wird [`SearchTerm`](../searchterm) als .NET‑Regex‑Muster interpretiert.

Wenn `false`, wird [`SearchTerm`](../searchterm) als Textliteral im Dokument gesucht.
