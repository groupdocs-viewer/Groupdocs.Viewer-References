Das Paket stellt Klassen zur Angabe zusätzlicher Optionen beim Rendern von Dokumenten bereit.

Sie enthält Optionen zum Rendern verschiedener Dokumentformate, zum Definieren von Berechtigungen und Sicherheitseinstellungen, zum Festlegen von Wasserzeichen‑Eigenschaften und zum Abrufen von Informationen zu Ansichten.

Die Hauptklassen in diesem Paket sind:

 *  [ArchiveOptions](../../com.groupdocs.viewer.options/archiveoptions) - Provides options for rendering archive files.
 *  [PdfOptions](../../com.groupdocs.viewer.options/pdfoptions) - Provides options for rendering PDF documents.
 *  [WordProcessingOptions](../../com.groupdocs.viewer.options/wordprocessingoptions) - Provides options for rendering word processing documents.

Weitere Details zur Konfiguration des Protokollierungssystems in GroupDocs.Viewer und zur Anpassung der Behandlung von Protokollnachrichten finden Sie in der [GroupDocs.Viewer Documentation][].


[GroupDocs.Viewer Documentation]: https://docs.groupdocs.com/viewer/java/
