Das Paket bietet Funktionalität zur Verwendung benutzerdefinierter Modelle in der Cache‑Implementierung.

Die Hauptklasse in diesem Paket ist [CacheableFactory](../../com.groupdocs.viewer.caching.extra/cacheablefactory), die bei der Anpassung des Caches hilft, indem sie zusätzliche Funktionalität bereitstellt.

Weitere Details zur Verwendung benutzerdefinierter Modelle in der Cache-Implementierung in GroupDocs.Viewer finden Sie in der [GroupDocs.Viewer Documentation][].
