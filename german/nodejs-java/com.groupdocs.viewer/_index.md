Das Paket stellt Klassen zum Rendern von Dokumenten im HTML5-, Bild- oder PDF‑Modus mit schnellen und hochwertigen Ergebnissen bereit.

Die Hauptklassen in diesem Paket sind:

 *  [License](../../com.groupdocs.viewer/license) - Provides methods for licensing Viewer.
 *  [Viewer](../../com.groupdocs.viewer/viewer) - Represents the main class that controls the document rendering process.
 *  [ViewerSettings](../../com.groupdocs.viewer/viewersettings) - Defines settings for customizing the behavior of the Viewer.

Weitere Details zur Arbeit mit dem Dokument-Renderprozess unter Verwendung von GroupDocs.Viewer für Java finden Sie in der [GroupDocs.Viewer Documentation][].


[GroupDocs.Viewer Documentation]: https://docs.groupdocs.com/viewer/java/


## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [License](../com.groupdocs.viewer/license) | Stellt Methoden zum Lizenzieren der Komponente und zum Freischalten ihrer vollen Funktionalität bereit. |
| [Metered](../com.groupdocs.viewer/metered) | Stellt Methoden zum Anwenden einer nutzungsbasierten Lizenz auf die GroupDocs.Viewer-Komponente bereit. |
| [Viewer](../com.groupdocs.viewer/viewer) | Stellt die Hauptklasse dar, die den Dokument-Renderprozess steuert. |
| [ViewerSettings](../com.groupdocs.viewer/viewersettings) | Definiert Einstellungen zur Anpassung des Verhaltens der Viewer-Komponente. |
