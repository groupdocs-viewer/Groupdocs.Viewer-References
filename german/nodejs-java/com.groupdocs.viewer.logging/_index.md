Das Paket stellt Klassen zur Konfiguration des Protokollierungssystems in GroupDocs.Viewer bereit.

Durch die Verwendung dieser Klassen können Sie steuern, wie Protokollnachrichten verarbeitet werden, zum Beispiel indem Sie sie in eine Datei schreiben oder an eine bestimmte Logger‑Implementierung weiterleiten.

Die Hauptklassen in diesem Paket sind:

 *  [FileLogger](../../com.groupdocs.viewer.logging/filelogger) - Writes log messages to a file.
 *  [ViewerLogger](../../com.groupdocs.viewer.logging/viewerlogger) - Implements logging messages to an integrated or user-defined logger.

Weitere Details zur Konfiguration des Protokollierungssystems in GroupDocs.Viewer und zur Anpassung der Behandlung von Protokollnachrichten finden Sie in der [GroupDocs.Viewer Documentation][].


[GroupDocs.Viewer Documentation]: https://docs.groupdocs.com/viewer/java/
