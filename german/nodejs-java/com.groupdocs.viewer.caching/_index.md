Das Paket stellt Klassen zur Anpassung des Caching‑Verhaltens bereit.

Die Hauptklassen und -schnittstellen in diesem Paket sind:

 *  [CacheKeys](../../com.groupdocs.viewer.caching/cachekeys) - Provides methods to retrieve unique identifiers for the cache entry.
 *  [FileCache](../../com.groupdocs.viewer.caching/filecache) - Represents a local on-disk cache.

Die [Cache](../../com.groupdocs.viewer.caching/cache)‑Schnittstelle definiert die für das Speichern von gerenderten Dokumenten und Dokumentressourcen im Cache erforderlichen Methoden.

Weitere Details zur Anpassung des Caching‑Verhaltens in GroupDocs.Viewer finden Sie in der [GroupDocs.Viewer Documentation][].


[GroupDocs.Viewer Documentation]: https://docs.groupdocs.com/viewer/java/

| --- | --- |

| [FileCache](../com.groupdocs.viewer.caching/filecache) | Stellt einen lokalen Festplattencache dar. |
