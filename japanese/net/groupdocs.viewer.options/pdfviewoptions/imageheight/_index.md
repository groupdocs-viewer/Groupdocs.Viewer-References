## PdfViewOptions.ImageHeight property

出力画像の高さ（ピクセル単位）を設定します。

```csharp
public int ImageHeight { get; set; }
```

### 備考

このプロパティを使用して、出力画像の高さ（ピクセル単位）を設定します。GroupDocs.Viewer は単一画像を HTML にレンダリングする際にのみこのプロパティを適用します。詳細については、[documentation](https://docs.groupdocs.com/viewer/net/set-image-size-limits-when-rendering-to-pdf/) を参照してください。

このプロパティを設定した場合、[`ImageMaxHeight`](../imagemaxheight) プロパティは無視されます。
