## PdfViewOptions.ImageWidth property

出力画像の幅（ピクセル単位）を設定します。

```csharp
public int ImageWidth { get; set; }
```

### 備考

このプロパティを使用して、出力画像の幅（ピクセル単位）を設定します。GroupDocs.Viewer は単一画像を PDF にレンダリングする際にこのプロパティを適用します。詳細については、[documentation](https://docs.groupdocs.com/viewer/net/set-image-size-limits-when-rendering-to-pdf/) を参照してください。

このプロパティを設定した場合、[`ImageMaxWidth`](../imagemaxwidth) プロパティは無視されます。
