## PdfOptimizationOptions.RemoveUnusedStreams property

PDF ファイルから未使用（孤立）ストリームを削除します。これらはページのリソース辞書から参照されていますが、実際にはページ内容で使用されていません。デフォルトでは無効（`false`）で、有効にすると（`true`）出力 PDF ドキュメントのサイズが縮小します。

```csharp
public bool RemoveUnusedStreams { get; set; }
```
