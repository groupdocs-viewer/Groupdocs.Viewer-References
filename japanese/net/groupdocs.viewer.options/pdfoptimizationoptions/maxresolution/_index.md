## PdfOptimizationOptions.MaxResolution property

出力 PDF ファイルの最大解像度を設定します。

```csharp
public int MaxResolution { get; set; }
```

### 備考

このオプションを有効にするには、[`CompressImages`](../compressimages) と `MaxResolution` プロパティを `true` に設定します。

デフォルト値は `300` です。

コード例については、この[ドキュメント](https://docs.groupdocs.com/viewer/net/optimization-pdf-set-max-resolution/) を参照してください。
