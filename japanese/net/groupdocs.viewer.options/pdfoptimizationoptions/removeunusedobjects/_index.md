## PdfOptimizationOptions.RemoveUnusedObjects property

PDF ファイルから未使用（孤立）オブジェクトを削除します。これらは PDF ドキュメントに配置されていますが、任意のページのリソース辞書から参照されておらず、全く使用されていません。このプロパティを有効にすると（`true`）、出力 PDF ドキュメントのサイズが縮小します。デフォルトでは無効（`false`）です。

```csharp
public bool RemoveUnusedObjects { get; set; }
```
