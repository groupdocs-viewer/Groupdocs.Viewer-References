## PdfOptimizationOptions.OptimizeSpreadsheets property

PDF ファイル内のスプレッドシートの最適化を有効にします。

```csharp
public bool OptimizeSpreadsheets { get; set; }
```

### 備考

この最適化は、罫線を設定することで出力ファイルサイズを削減できます。さらに、32〜127 のコードの Arial と Times New Roman の文字を削除します。

コード例については、こちらの[documentation](https://docs.groupdocs.com/viewer/net/optimization-pdf-spreadsheets/)をご覧ください。
