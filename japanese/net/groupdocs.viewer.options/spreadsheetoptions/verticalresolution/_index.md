## SpreadsheetOptions.VerticalResolution property

生成された画像の垂直解像度（dpi）を取得または設定します。このオプションはスプレッドシートを PNG または JPEG 形式でレンダリングする場合にのみ使用されます。

```csharp
public int VerticalResolution { get; set; }
```

### 備考

デフォルト値は 96 DPI です。最小可能値は 72 DPI、最大可能値は 600 DPI です。ユーザー指定の値がこれらの範囲外の場合、最小または最大の可能な値が適用されます。
