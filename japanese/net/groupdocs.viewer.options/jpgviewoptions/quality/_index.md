## JpgViewOptions.Quality property

出力画像の品質を設定します。

```csharp
public byte Quality { get; set; }
```

### 備考

このプロパティを使用して画像の品質を調整します。値は 1（最低品質）から 100 の間で指定してください。デフォルト値は 90 です。

コード例については、[ドキュメント](https://docs.groupdocs.com/viewer/net/image-viewer-adjust-quality-for-jpg/) を参照してください。
