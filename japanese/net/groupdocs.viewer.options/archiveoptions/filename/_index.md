## ArchiveOptions.FileName property

表示されるアーカイブファイル名を設定します。

```csharp
public FileName FileName { get; set; }
```

### 備考

既定では、GroupDocs.Viewer は各ページのヘッダーにアーカイブファイル名を表示します。この名前を変更または非表示にするには、このプロパティを設定します。

詳細情報とコード例については、[ドキュメント](https://docs.groupdocs.com/viewer/net/render-archive-files/#specify-the-archive-document-name) を参照してください。
