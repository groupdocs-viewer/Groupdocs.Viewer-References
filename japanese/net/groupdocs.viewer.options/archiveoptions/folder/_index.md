## ArchiveOptions.Folder property

レンダリング対象のフォルダーを設定します。

```csharp
public string Folder { get; set; }
```

### 備考

既定では、GroupDocs.Viewer はアーカイブに含まれるすべてのフォルダーの項目をレンダリングします。特定のフォルダーの項目だけをレンダリングするには、このプロパティを設定します。

コード例については、[ドキュメント](https://docs.groupdocs.com/viewer/net/render-archive-files/#render-a-specific-folder) を参照してください。
