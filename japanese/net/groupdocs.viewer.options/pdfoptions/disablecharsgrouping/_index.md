## PdfOptions.DisableCharsGrouping property

ページレンダリング中の正確なシンボル位置決めのために、シンボルのグルーピングを無効にします。

```csharp
public bool DisableCharsGrouping { get; set; }
```

### 備考

PDF ファイルを変換する際、GroupDocs.Viewer は個々の文字を単語にグループ化して、レンダリング性能を向上させます。文書に象形文字や特殊記号が含まれる場合、より正確なレイアウトを確保するために文字のグループ化を無効にしたいかもしれません。デフォルト値は `false` です。

コード例については、[documentation](https://docs.groupdocs.com/viewer/net/render-pdf-documents/#disable-character-grouping) を参照してください。
