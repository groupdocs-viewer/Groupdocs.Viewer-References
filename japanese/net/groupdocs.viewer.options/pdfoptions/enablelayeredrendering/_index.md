## PdfOptions.EnableLayeredRendering property

HTML へのレンダリング時に、元の PDF ドキュメントの Z オーダーでテキストとグラフィックのレンダリングを有効にします。

```csharp
public bool EnableLayeredRendering { get; set; }
```

### 備考

デフォルトでは、GroupDocs.Veiewer はテキストとグラフィックを HTML で単一レイヤーとしてレンダリングします。このオプションを使用すると、オブジェクトをソースファイルと同じ順序で配置できます。デフォルト値は `false` です。

コード例については、[documentation](https://docs.groupdocs.com/viewer/net/render-pdf-documents/#enable-multi-layer-rendering) を参照してください。
