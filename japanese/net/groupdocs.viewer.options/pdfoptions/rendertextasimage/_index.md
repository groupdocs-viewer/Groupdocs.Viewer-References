## PdfOptions.RenderTextAsImage property

PDF ファイル内のテキストを HTML 出力で画像としてレンダリングすることを有効にします。

```csharp
public bool RenderTextAsImage { get; set; }
```

### 備考

このオプションを `true` に設定すると、GroupDocs.Viewer は HTML 出力でテキストを画像としてレンダリングします。これによりテキストは選択できなくなり、文字のレンダリングが強化され、HTML で PDF のような外観が実現します。デフォルト値は `false` です。

このオプションは HTML へのレンダリングで利用可能です。

コード例については、[documentation](https://docs.groupdocs.com/viewer/net/render-pdf-documents/#render-text-as-an-image) を参照してください。
