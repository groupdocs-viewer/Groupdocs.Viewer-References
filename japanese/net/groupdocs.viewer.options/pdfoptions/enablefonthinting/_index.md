## PdfOptions.EnableFontHinting property

フォントヒンティングを有効にします。

```csharp
public bool EnableFontHinting { get; set; }
```

### 備考

フォントヒンティングはアウトラインフォントの表示方法を調整します。ソースドキュメントで使用されている TTF フォントにのみ適用可能です。このオプションは PNG または JPG 形式へのレンダリングで利用できます。デフォルト値は `false` です。

コード例については、[documentation](https://docs.groupdocs.com/viewer/net/render-pdf-documents/#enable-font-hinting) を参照してください。
