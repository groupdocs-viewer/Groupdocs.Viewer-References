## MailStorageOptions.MaxItems property

レンダリングするメッセージまたはアイテムの最大数を設定します。

```csharp
public int MaxItems { get; set; }
```

### 備考

メールストレージのデータファイルは大きくなることがあり、すべてのメッセージを取得するのにかなりの時間がかかる場合があります。このプロパティは、レンダリングされるメッセージまたはアイテムの最大数を制限します。デフォルト値は 0 で、すべてのメッセージがレンダリングされます。

コード例については、[documentation](https://docs.groupdocs.com/viewer/net/render-lotus-notes-database-files/#limit-the-number-of-items-to-render) を参照してください。
