## OutlookOptions.Folder property

レンダリングするフォルダーの名前を設定します（例: Inbox、Sent Item、Deleted Items）。

```csharp
public string Folder { get; set; }
```

### 備考

Outlook データ ファイルをレンダリングする際、GroupDocs.Viewer はファイルに含まれるすべてのフォルダー（ネストされたフォルダーを含む）からメッセージをレンダリングします。このプロパティを使用して、特定のフォルダーからアイテムをレンダリングします。

コード例については、[ドキュメント](https://docs.groupdocs.com/viewer/net/render-outlook-data-files/#render-a-specific-folder) を参照してください。
