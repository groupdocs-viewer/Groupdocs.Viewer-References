## PresentationOptions.RenderHeaderFooterPlaceholders property

スライドのヘッダーとフッターにプレースホルダーのレンダリングを有効にします。デフォルトでは無効（`false`）です。このオプションは、プレゼンテーションの 4 つのレンダリングモード（HTML、PDF、PNG、JPEG）すべてに適用されます。[`RenderToPureHtml`](../rendertopurehtml) を使用してプレゼンテーションを純粋な HTML/CSS マークアップにレンダリングする場合は適用されません。

```csharp
public bool RenderHeaderFooterPlaceholders { get; set; }
```
