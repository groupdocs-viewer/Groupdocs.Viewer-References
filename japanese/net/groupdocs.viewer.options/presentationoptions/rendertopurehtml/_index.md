## PresentationOptions.RenderToPureHtml property

プレゼンテーションドキュメント用の新しい HTML レンダリングモードを有効にします — このモードでは、プレゼンテーションファイルが **pure HTML/CSS markup** にレンダリングされ、SVG 画像は使用されません。デフォルトでは無効 (`false`) で、既存の SVG ベースの HTML レンダラーが使用されます。

```csharp
public bool RenderToPureHtml { get; set; }
```
