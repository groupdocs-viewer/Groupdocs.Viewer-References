## WordProcessingOptions.PageSize property

出力ページのサイズです。デフォルト値は Unspecified で、これはページ設定（ページ設定）でページサイズが指定されていることを意味します。HTM および HTML ファイルをレンダリングする場合、デフォルトのページサイズは Letter（792 x 612 ポイント）に設定されます。その結果、コンテンツの一部がページ枠に収まらないことがあります。コンテンツを収めるために、例えば A3 などの大きなページサイズを設定してください。

```csharp
public PageSize PageSize { get; set; }
```
