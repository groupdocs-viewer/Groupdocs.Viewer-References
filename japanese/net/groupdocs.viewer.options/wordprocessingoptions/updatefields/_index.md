## WordProcessingOptions.UpdateFields property

入力の WordProcessing ドキュメントを HTML、PDF、PNG、または JPEG の出力形式で保存する前に、特定のタイプのフィールドを更新するかどうかを決定する値を取得または設定します。このプロパティのデフォルト値は `true` で、保存前にフィールドが更新されます。

```csharp
public bool UpdateFields { get; set; }
```
