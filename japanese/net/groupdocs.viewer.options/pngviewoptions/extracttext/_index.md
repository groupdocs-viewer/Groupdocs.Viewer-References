## PngViewOptions.ExtractText property

テキスト抽出を有効にします。

```csharp
public bool ExtractText { get; set; }
```

### 備考

このプロパティを使用して、ソースドキュメントに含まれるテキストとその座標を取得します。そのデータを使用して、画像上に選択可能なテキストを追加したり、画像ベースのレンダリングでテキスト検索を実装したりできます。

コード例については、[ドキュメント](https://docs.groupdocs.com/viewer/net/image-viewer-get-text-coordinates/) を参照してください。
