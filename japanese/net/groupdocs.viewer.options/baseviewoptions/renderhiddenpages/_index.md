## BaseViewOptions.RenderHiddenPages property

非表示ページの描画を有効にします。

```csharp
public bool RenderHiddenPages { get; set; }
```

### 備考

プレゼンテーションやスプレッドシートなどの一部のファイルには非表示ページが含まれることがあります。デフォルトでは、GroupDocs.Viewer はこれらのページをレンダリングしません。これらをレンダリングするには、このプロパティを `true` に設定してください。

コード例については、[documentation](https://docs.groupdocs.com/viewer/net/render-presentations/#render-hidden-slides) を参照してください。
