## CadOptions.EnablePerformanceConversionMode property

`true` に設定すると、CAD ファミリ内のすべての形式に対して、パフォーマンス重視の特別な変換モードが有効になります。このモードでは変換速度が大幅に速くなりますが、生成されるドキュメントの品質は著しく低下します。デフォルトでは無効 (`false`) で、生成されるドキュメントの品質はパフォーマンスを犠牲にして可能な限り最高になります。

```csharp
public bool EnablePerformanceConversionMode { get; set; }
```
