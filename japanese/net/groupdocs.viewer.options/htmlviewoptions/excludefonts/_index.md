## HtmlViewOptions.ExcludeFonts property

HTMLドキュメントへのフォント追加を無効にします。

```csharp
public bool ExcludeFonts { get; set; }
```

### 備考

デフォルトでは、GroupDocs.Viewer はドキュメントで使用されているフォントを HTML マークアップに埋め込みます。このプロパティは `false` が設定されています。フォントの埋め込みを防止するには、このプロパティを `true` に設定します。

詳細とコード例については、[documentation](https://docs.groupdocs.com/viewer/net/exclude-fonts/) を参照してください。
