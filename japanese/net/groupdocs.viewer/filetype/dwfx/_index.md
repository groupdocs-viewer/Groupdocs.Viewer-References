## FileType.DWFX field

Design Web Format File XPS (.dwfx) は、閲覧、レビュー、印刷用の圧縮形式で XPS ドキュメントとして 2D/3D 図面を表します。設計データの一部としてグラフィックとテキストを含み、圧縮形式によりファイルサイズが削減されます。このファイル形式の詳細は、[here](https://wiki.fileformat.com/cad/dwfx) で確認できます。

```csharp
public static readonly FileType DWFX;
```
