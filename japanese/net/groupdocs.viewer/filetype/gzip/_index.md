## FileType.GZIP field

Gnu Zipped File (.gzip) は、Unix 系システムで使用されていた Compress プログラムの代替として導入されたフリーユーティリティです。このようなファイルは、Windows と macOS の両方で利用できる WinZip などの多数のアプリケーションで開いたり展開したりできます。詳細はこのファイル形式について [here](https://wiki.fileformat.com/compression/gz) をご覧ください。

public static readonly FileType GZIP;
