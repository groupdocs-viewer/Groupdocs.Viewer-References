## FileType.TIF field

Tagged Image File (.tif) は、このファイル形式標準に準拠したさまざまなデバイスで使用されるラスタ画像を表します。二値、グレースケール、パレットカラー、フルカラーの画像データを複数のカラースペースで記述できます。このファイル形式の詳細は[こちら](https://wiki.fileformat.com/image/tiff)をご覧ください。

public static readonly FileType TIF;
