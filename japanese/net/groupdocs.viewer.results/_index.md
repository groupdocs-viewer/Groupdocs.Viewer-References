| [CadViewInfo](./cadviewinfo) | CAD 図面のビュー情報を表します。 |

| [LotusNotesViewInfo](./lotusnotesviewinfo) | Lotus Notes データベース ストレージのビュー情報を表します。 |
| [MailMessageViewInfo](./mailmessageviewinfo) | 単一のメール メッセージに関するビュー情報を表します。 |
| [MboxViewInfo](./mboxviewinfo) | Mbox ファイル ストレージのビュー情報を表します。 |
| [OutlookViewInfo](./outlookviewinfo) | Outlook データ ファイルのビュー情報を表します。 |
| [Page](./page) | 表示可能な単一ページを表します。 |

| [Resource](./resource) | フォント、スタイル、画像、またはグラフィックなどの HTML リソースを表します。 |

| [Word](./word) | 単一単語を含む相対位置の矩形を表します。 |
