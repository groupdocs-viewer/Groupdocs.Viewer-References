## Resource class

フォント、スタイル、画像、またはグラフィックなどの HTML リソースを表します。

Resource 型は次のメンバーを公開します:

### コンストラクタ
| コンストラクタ | 説明 |
| :- | :- |
| [__init__](/viewer/python-net/groupdocs.viewer.results/resource/__init__/) | 新しい Resource インスタンスを初期化します。 |
| [__init__](/viewer/python-net/groupdocs.viewer.results/resource/__init__/#file_name-nested) | 新しい Resource インスタンスを初期化します。 |

### メソッド
| メソッド | 説明 |
| :- | :- |
| [to_string](/viewer/python-net/groupdocs.viewer.results/resource/to_string/) | 現在のオブジェクトを表す文字列を返します。 |

### プロパティ
| プロパティ | 説明 |
| :- | :- |
| [file_name](/viewer/python-net/groupdocs.viewer.results/resource/file_name/) | リソースファイル名です。 |
| [nested](/viewer/python-net/groupdocs.viewer.results/resource/nested/) | このプロパティは、リソースが別のリソース内に存在するかどうかを示します。例: CSS または SVG リソース内にあるフォントリソース。 |
