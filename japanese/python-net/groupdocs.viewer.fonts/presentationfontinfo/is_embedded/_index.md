## is_embedded property

このプロパティは、フォントがドキュメントに埋め込まれ、[`Viewer`](/viewer/python-net/groupdocs.viewer/viewer/) インスタンスにロードされているか (`True`)、あるいはシステムフォントであるか (`False`) を示します。

スプレッドシート ドキュメントは埋め込みフォントを保持できないため、このプロパティは常に `False` を返します。
