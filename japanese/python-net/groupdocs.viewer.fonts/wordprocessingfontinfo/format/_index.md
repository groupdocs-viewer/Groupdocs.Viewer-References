## format property

このフォントの形式を取得します。

ドキュメントは次の形式のフォントを使用できる場合があります: TrueType、TrueType Collection、OpenType、Embedded OpenType。フォントに関するメタデータのみが利用可能でバイナリ内容が欠落している場合、このプロパティは `FontFormat.unknown` を返します。
