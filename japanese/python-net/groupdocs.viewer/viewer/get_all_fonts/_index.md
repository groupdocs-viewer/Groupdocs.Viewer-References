## get_all_fonts

ロードされたドキュメントで使用されているすべてのフォントを返します。埋め込みフォントと OS にインストールされているシステムフォントを含みます。

詳細については、https://docs.groupdocs.com/viewer/net/getting-used-fonts/ のドキュメントをご覧ください。

```python
def get_all_fonts(self):
    ...
```

**Returns:** list[str]: Non-null list of all fonts used in the document loaded into this Viewer instance.
