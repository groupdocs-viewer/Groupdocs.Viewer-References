## License class

ライセンスされたビルドは、ラッパーのフル機能セットを at でアンロックします
ランタイム。未ライセンスのビルドは、同じ API で評価モードで実行されます
表面上は同じですが、出力サイズと透かし付きコンテンツに制限があります。
