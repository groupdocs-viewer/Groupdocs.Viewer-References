トップレベルの API クラスを含むメインの GroupDocs.Viewer 名前空間。

### クラス
| クラス | 説明 |
| :- | :- |
| [`FileType`](/viewer/python-net/groupdocs.viewer/filetype/) | ファイルタイプを表し、GroupDocs.Viewer がサポートするすべてのファイルタイプのリストを取得するメソッドを提供します。 |
| [`IAuxDisposable`](/viewer/python-net/groupdocs.viewer/iauxdisposable/) | 標準の `System.IDisposable` インターフェイスを拡張し、オブジェクトの現在の状態を取得し、破棄イベントに購読できるようにします。 |
| [`License`](/viewer/python-net/groupdocs.viewer/license/) | GroupDocs.Viewer のライセンスを管理します。 |
| [`Metered`](/viewer/python-net/groupdocs.viewer/metered/) | 従量課金（使用量に応じた支払い）ライセンスを管理します。 |
| [`Viewer`](/viewer/python-net/groupdocs.viewer/viewer/) | ドキュメントのレンダリングプロセスを制御するメインクラスを表します。 |
| [`ViewerSettings`](/viewer/python-net/groupdocs.viewer/viewersettings/) | [`Viewer`](/viewer/python-net/groupdocs.viewer/viewer/) の動作をカスタマイズする設定を定義します。 |

### 例外
| 例外 | 説明 |
| :- | :- |
| [`GroupDocsViewerException`](/viewer/python-net/groupdocs.viewer/groupdocsviewerexception/) | ドキュメント処理中に発生する汎用エラーを表します。 |
| [`IncorrectPasswordException`](/viewer/python-net/groupdocs.viewer/incorrectpasswordexception/) | 指定されたパスワードが正しくない場合にスローされる例外です。 |
| [`InvalidFontFormatException`](/viewer/python-net/groupdocs.viewer/invalidfontformatexception/) | サポートされている（既知の）形式のフォントであると想定されるコンテンツを開く、ロードする、保存する、または処理しようとした際に、実際には予期しない、またはサポートされていない形式のフォント、あるいはフォントではない場合にスローされる例外です。 |
| [`InvalidImageFormatException`](/viewer/python-net/groupdocs.viewer/invalidimageformatexception/) | 画像（ラスタまたはベクタ）であると想定されるコンテンツを開く、ロードする、保存する、または処理しようとした際に、実際には予期しない、またはサポートされていない形式の画像、あるいは画像ではない場合にスローされる例外です。 |
| [`PasswordRequiredException`](/viewer/python-net/groupdocs.viewer/passwordrequiredexception/) | ドキュメントのロードにパスワードが必要な場合にスローされる例外です。 |
