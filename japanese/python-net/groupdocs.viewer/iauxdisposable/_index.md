## IAuxDisposable class

IAuxDisposable 型は以下のメンバーを公開します：

### プロパティ
| プロパティ | 説明 |
| :- | :- |
| [is_disposed](/viewer/python-net/groupdocs.viewer/iauxdisposable/is_disposed/) | このプロパティは、リソースが既に破棄されているか（`True`）どうか（`False`）を示します。 |
