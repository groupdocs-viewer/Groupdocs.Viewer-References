## PPTX field

PowerPoint Open XML プレゼンテーション (.pptx) は、人気のある Microsoft PowerPoint アプリケーションで作成されたプレゼンテーション ファイルです。以前のバイナリ形式の PPT と異なり、PPTX 形式は Microsoft PowerPoint のオープン XML プレゼンテーション ファイル形式に基づいています。このファイル形式の詳細については、こちらをご覧ください。
