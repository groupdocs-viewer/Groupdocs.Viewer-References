## IFC field

Industry Foundation Classes File (.ifc) は、建築オブジェクトとそのプロパティのインポート・エクスポートのための国際標準を確立するファイル形式です。このファイル形式は、異なるソフトウェア間の相互運用性を提供します。このファイル形式の詳細については、こちらをご覧ください。
