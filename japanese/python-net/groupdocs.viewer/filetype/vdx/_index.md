## VDX field

Visio Drawing XML File (.vdx) は、Microsoft Visio で作成された任意の図面やチャートを表し、XML 形式で保存されたものは .VDX 拡張子を持ちます。Visio の XML 図面ファイルは、Microsoft が開発した Visio ソフトウェアで作成されます。このファイル形式の詳細については、こちらをご覧ください。
