## GIF field

Graphical Interchange Format File (.gif) は、高度に圧縮された画像の一種です。GIF は通常、1 ピクセルあたり最大 8 ビット、画像全体で最大 256 色を許容します。このファイル形式の詳細はここで確認できます。
