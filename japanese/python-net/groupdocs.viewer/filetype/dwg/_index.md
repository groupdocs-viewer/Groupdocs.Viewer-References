## DWG field

AutoCAD Drawing Database File (.dwg) は、2D および 3D 設計データを格納するために使用される独自のバイナリファイルを表します。ASCII ファイルである DXF と同様に、DWG は CAD (Computer Aided Design) 図面のバイナリファイル形式です。このファイル形式の詳細については、こちらをご覧ください。
