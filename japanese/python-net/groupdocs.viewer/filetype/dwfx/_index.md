## DWFX field

Design Web Format File XPS (.dwfx) は、閲覧、レビュー、印刷用に圧縮形式の XPS ドキュメントとして表現された 2D/3D 図面です。デザインデータの一部としてグラフィックとテキストを含み、圧縮形式によりファイルサイズを削減します。このファイル形式の詳細については、こちらをご覧ください。
