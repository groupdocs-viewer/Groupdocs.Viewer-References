## VSSM field

Visio Macro-Enabled Stencil File (.vssm) は、マクロをサポートする Microsoft Visio ステンシルファイルです。VSSM ファイルを開くと、マクロを実行して図中の形状の書式設定や配置を行うことができます。このファイル形式の詳細については、こちらをご覧ください。
