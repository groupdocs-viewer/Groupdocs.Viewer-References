## DWF field

Design Web Format File (.dwf) は、設計ファイルの閲覧、レビュー、印刷のために圧縮形式で表現された 2D/3D 図面です。デザインデータの一部としてグラフィックとテキストを含み、圧縮形式によりファイルサイズを削減します。このファイル形式の詳細については、こちらをご覧ください。
