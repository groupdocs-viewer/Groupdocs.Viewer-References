## EPUB field

Open eBook File (.epub) は、出版社と読者向けに標準的なデジタル出版フォーマットを提供する電子書籍ファイル形式です。このフォーマットは現在非常に一般的で、多くの電子書籍リーダーやソフトウェアアプリケーションでサポートされています。このファイル形式の詳細については、こちらをご覧ください。
