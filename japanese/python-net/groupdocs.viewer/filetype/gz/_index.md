## GZ field

Gnu Zipped File (.gz) は、gzip 圧縮アプリケーションで作成された圧縮ファイルです。複数の圧縮ファイルを含むことができ、UNIX や Linux システムで一般的に使用されます。このファイル形式の詳細については、こちらをご覧ください。
