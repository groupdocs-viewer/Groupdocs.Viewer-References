## GZIP field

Gnu Zipped File (.gzip) は、Unix システムで使用されていた Compress プログラムの代替として導入されたフリーユーティリティです。このようなファイルは、Windows と macOS の両方で利用できる WinZip などの複数のアプリケーションで開いたり展開したりできます。このファイル形式の詳細については、こちらをご覧ください。
