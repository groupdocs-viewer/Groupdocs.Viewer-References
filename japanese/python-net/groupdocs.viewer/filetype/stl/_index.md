## STL field

Stereolithography File (.stl) は、3 次元表面ジオメトリを表す汎用ファイル形式です。このファイル形式は、ラピッドプロトタイピング、3D プリント、コンピュータ支援製造など、さまざまな分野で利用されています。このファイル形式の詳細については、こちらをご覧ください。
