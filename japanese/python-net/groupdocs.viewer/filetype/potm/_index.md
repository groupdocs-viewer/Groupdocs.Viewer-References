## POTM field

PowerPoint Open XML マクロ有効プレゼンテーション テンプレート (.potm) は、マクロをサポートする Microsoft PowerPoint テンプレート ファイルです。POTM ファイルは PowerPoint 2007 以降で作成され、さらにプレゼンテーション ファイルを作成するために使用できる既定設定が含まれています。このファイル形式の詳細については、こちらをご覧ください。
