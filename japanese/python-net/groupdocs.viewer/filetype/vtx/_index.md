## VTX field

Visio Template XML File (.vtx) は、XML 形式でディスクに保存される Microsoft Visio の描画テンプレートです。このテンプレートは、同一の設定を持つ複数の Visio ファイルを作成するための基本設定を提供することを目的としています。このファイル形式の詳細については、こちらをご覧ください。
