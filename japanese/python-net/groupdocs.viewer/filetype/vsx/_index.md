## VSX field

Visio Stencil XML File (.vsx) は、Microsoft Visio で図表作成に使用される描画や形状からなるステンシルを指します。VSX ファイルは XML 形式で保存され、Visio 2013 までサポートされていました。このファイル形式の詳細については、こちらをご覧ください。
