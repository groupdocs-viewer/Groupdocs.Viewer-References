## DOCX field

Microsoft Word Open XML ドキュメント (.docx) は、Microsoft Word 文書のよく知られた形式です。2007 年に Microsoft Office 2007 がリリースされた際に導入され、この新しいドキュメント形式の構造は、従来のバイナリ形式から XML とバイナリファイルの組み合わせに変更されました。こちらでこのファイル形式の詳細をご覧ください。
