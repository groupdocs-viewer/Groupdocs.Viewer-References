## BMP field

Bitmap Image File (.bmp) は、ビットマップデジタル画像を保存するために使用されます。これらの画像はグラフィックアダプタに依存せず、デバイス非依存ビットマップ (DIB) ファイルフォーマットとも呼ばれます。このファイル形式の詳細はここで確認できます。
