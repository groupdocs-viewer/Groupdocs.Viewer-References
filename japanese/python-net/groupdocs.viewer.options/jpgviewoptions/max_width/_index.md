## max_width property

出力画像の最大幅（ピクセル単位）。

このプロパティを使用して、最大出力画像幅（ピクセル単位）を設定します。コード例については、ドキュメント https://docs.groupdocs.com/viewer/net/set-image-size-limits-when-rendering-to-png-jpg/ を参照してください。

`Width` プロパティが設定されている場合、このプロパティは無視されます。
