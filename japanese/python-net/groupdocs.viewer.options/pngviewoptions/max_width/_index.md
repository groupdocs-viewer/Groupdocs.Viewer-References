## max_width property

出力画像の最大幅（ピクセル単位）。

このプロパティを使用して、出力画像の最大幅（ピクセル単位）を設定します。コード例については、ドキュメントをご参照ください: https://docs.groupdocs.com/viewer/net/set-image-size-limits-when-rendering-to-png-jpg/

[`PngViewOptions.width`](/viewer/python-net/groupdocs.viewer.options/pngviewoptions/width/) プロパティを設定した場合、このプロパティは無視されます。
