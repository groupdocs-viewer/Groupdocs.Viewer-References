## Field class

メールメッセージのフィールド（例: From、To、Subject など）を表します。

詳細については、ドキュメントをご覧ください。

Field 型は次のメンバーを公開します：

### メソッド
| メソッド | 説明 |
| :- | :- |
| [to_string](/viewer/python-net/groupdocs.viewer.options/field/to_string/) | 現在のオブジェクトを表す文字列を返します。 |

### プロパティ
| プロパティ | 説明 |
| :- | :- |
| [name](/viewer/python-net/groupdocs.viewer.options/field/name/) | フィールド名。 |
