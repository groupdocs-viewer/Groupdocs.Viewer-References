## Permissions class

Permissions 型は次のメンバーを公開します。

### フィールド
| フィールド | 説明 |
| :- | :- |
| [ALLOW_ALL](/viewer/python-net/groupdocs.viewer.options/permissions/allow_all/) | 印刷、変更、データ抽出を許可します。 |
| [DENY_PRINTING](/viewer/python-net/groupdocs.viewer.options/permissions/deny_printing/) | 印刷を拒否します。 |
| [DENY_MODIFICATION](/viewer/python-net/groupdocs.viewer.options/permissions/deny_modification/) | コンテンツの変更、フォームへの入力、注釈の追加または変更を拒否します。 |
| [DENY_DATA_EXTRACTION](/viewer/python-net/groupdocs.viewer.options/permissions/deny_data_extraction/) | テキストとグラフィックの抽出を拒否します。 |
| [DENY_ALL](/viewer/python-net/groupdocs.viewer.options/permissions/deny_all/) | 印刷、コンテンツの変更、データ抽出を拒否します。 |
