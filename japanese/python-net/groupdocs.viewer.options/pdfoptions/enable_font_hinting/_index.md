## enable_font_hinting property

このプロパティはフォントヒンティングを有効にします。

フォントヒンティングはアウトラインフォントの表示方法を調整します。元のドキュメントで使用されている TTF フォントにのみ適用されます。このオプションは PNG または JPG 形式へのレンダリングで利用可能です。デフォルト値は False です。
