## width property

出力画像の幅（ピクセル単位、PNG/JPG のレンダリング時のみ）。

このプロパティを使用して、出力画像の幅（ピクセル単位）を設定します。コード例については、ドキュメントをご参照ください。

このプロパティを設定すると、[`ViewInfoOptions.MaxWidth`](/viewer/python-net/groupdocs.viewer.options/viewinfooptions/max_width/) プロパティは無視されます。
