Resolution 型は次のメンバーを公開します：

### コンストラクタ
| コンストラクタ | 説明 |
| :- | :- |
| [__init__](/viewer/python-net/groupdocs.viewer.options/resolution/__init__/#value) | DPI で解像度を初期化します。 |

### プロパティ
| プロパティ | 説明 |
| :- | :- |
| [value](/viewer/python-net/groupdocs.viewer.options/resolution/value/) | 品質 DPI。 |

| フィールド | 説明 |
| :- | :- |
