## update_fields property

このプロパティは、WordProcessing 文書を HTML、PDF、PNG、または JPEG 形式で保存する前に、特定のタイプのフィールドが更新されるかどうかを決定します。デフォルトは True で、フィールドが更新されることを意味します。

詳細については、ドキュメントをご覧ください: https://docs.groupdocs.com/viewer/net/render-word-documents/#disable-updating-fields-when-saving
