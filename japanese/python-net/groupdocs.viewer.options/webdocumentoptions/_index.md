## WebDocumentOptions class

Web ドキュメントのレンダリングオプションを表します。

詳細については、ドキュメントをご覧ください。

WebDocumentOptions 型は次のメンバーを公開します：

### コンストラクタ
| コンストラクタ | 説明 |
| :- | :- |
| [__init__](/viewer/python-net/groupdocs.viewer.options/webdocumentoptions/__init__/) | [`WebDocumentOptions`](/viewer/python-net/groupdocs.viewer.options/webdocumentoptions/) クラスのインスタンスを初期化します。 |

### プロパティ
| プロパティ | 説明 |
| :- | :- |
| [bottom_margin](/viewer/python-net/groupdocs.viewer.options/webdocumentoptions/bottom_margin/) | ページの下余白です。デフォルト値は 72 ポイントです。 |
| [left_margin](/viewer/python-net/groupdocs.viewer.options/webdocumentoptions/left_margin/) | ページの左余白（デフォルトは 5 ポイント）。 |
| [page_size](/viewer/python-net/groupdocs.viewer.options/webdocumentoptions/page_size/) | 出力ページのサイズ。 |
| [right_margin](/viewer/python-net/groupdocs.viewer.options/webdocumentoptions/right_margin/) | ページの右余白です。デフォルト値は 5 ポイントです。 |
| [top_margin](/viewer/python-net/groupdocs.viewer.options/webdocumentoptions/top_margin/) | ページの上余白（デフォルトは 72 ポイント）。 |
