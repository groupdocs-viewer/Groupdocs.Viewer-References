## IMaxSizeOptions class

画像サイズオプションの上限を表します。

IMaxSizeOptions 型は次のメンバーを公開します：

### プロパティ
| プロパティ | 説明 |
| :- | :- |
| [max_height](/viewer/python-net/groupdocs.viewer.options/imaxsizeoptions/max_height/) | 出力画像の最大高さ（ピクセル単位）。 |
| [max_width](/viewer/python-net/groupdocs.viewer.options/imaxsizeoptions/max_width/) | 出力画像の最大幅（ピクセル単位）。 |
