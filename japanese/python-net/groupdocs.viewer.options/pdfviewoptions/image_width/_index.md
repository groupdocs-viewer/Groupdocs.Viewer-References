## image_width property

出力画像の幅（ピクセル単位）。

このプロパティを使用して、出力画像の幅（ピクセル単位）を設定します。GroupDocs.Viewer は単一画像を PDF にレンダリングする際にこのプロパティを適用します。詳細については、ドキュメントをご覧ください。

このプロパティを設定した場合、[`PdfViewOptions.ImageMaxWidth`](/viewer/python-net/groupdocs.viewer.options/pdfviewoptions/image_max_width/) プロパティは無視されます。
