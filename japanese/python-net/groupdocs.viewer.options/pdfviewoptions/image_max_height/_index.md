## image_max_height property

出力画像の最大高さ（ピクセル単位）。

このプロパティを使用して、出力画像の最大高さ（ピクセル単位）を設定します。GroupDocs.Viewer は単一画像を PDF にレンダリングする際にこのプロパティを適用します。詳細については、ドキュメントをご覧ください。

[`PdfViewOptions.ImageHeight`](/viewer/python-net/groupdocs.viewer.options/pdfviewoptions/image_height/) プロパティを設定した場合、このプロパティは無視されます。
