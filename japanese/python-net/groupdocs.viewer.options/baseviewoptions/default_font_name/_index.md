## default_font_name property

必要なフォントが見つからない場合に、レンダリング中に使用されるドキュメントのデフォルトフォントです。

このプロパティを使用して、ドキュメントのデフォルトフォントを設定します。GroupDocs.Viewer は、インストールされていないフォントの代わりにこのフォントを描画時に使用します。

コード例については、https://docs.groupdocs.com/viewer/net/replace-missing-font/ のドキュメントをご覧ください。
