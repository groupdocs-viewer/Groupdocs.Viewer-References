## SearchHighlightOptions class

[`Viewer`](/viewer/python-net/groupdocs.viewer/viewer/) クラスにロードされたドキュメント内のテキスト検索およびハイライト用オプションを提供します。

### プロパティ
| プロパティ | 説明 |
| :- | :- |
| [background_color](/viewer/python-net/groupdocs.viewer.options/searchhighlightoptions/background_color/) | ハイライト用の背景色です。 |
| [foreground_color](/viewer/python-net/groupdocs.viewer.options/searchhighlightoptions/foreground_color/) | ハイライト用の前景（テキスト）色です。 |
| [is_search_term_reg_ex](/viewer/python-net/groupdocs.viewer.options/searchhighlightoptions/is_search_term_reg_ex/) | このプロパティは、検索語句を正規表現として扱うかテキストリテラルとして扱うかを示します。デフォルトは False で、テキストリテラルとして扱います。 |
