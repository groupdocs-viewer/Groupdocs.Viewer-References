## minify property

このプロパティは HTML コンテンツと HTML リソースの縮小を有効にします。

出力コンテンツ（HTML、CSS、SVG）の圧縮は、HTML ファイルを最適化する方法の一つです。これを行うには、このプロパティを `True` に設定してください。
