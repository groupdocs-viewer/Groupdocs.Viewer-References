## trace {#message}

トレースメッセージを書き込みます。

トレース ログ メッセージは、アプリケーションのフローに関する一般的に有用な情報を提供します。

```python
def trace(self, message):
    ...
```

| パラメータ | 型 | 説明 |
| :- | :- | :- |
| message | `str` | トレース メッセージです。 |

| 例外 | 説明 |
| :- | :- |
| `ValueError` | `message` が None のときに発生します。 |
