このパッケージは、文書の操作中に発生し得る例外のためのクラスを提供します。

このパッケージの主なクラスは次のとおりです：

* com.groupdocs.viewer.exception.ArchiveSecurityException - Thrown when an archive being opened exceeds specified limits.
* [FileNotFoundException](../../com.groupdocs.viewer.exception/filenotfoundexception) - Represents an exception thrown when a file or directory is not found.
* [GroupDocsViewerException](../../com.groupdocs.viewer.exception/groupdocsviewerexception) - Represents generic errors that occur during document processing.


GroupDocs.Viewer の例外処理に関する詳細は、以下をご参照ください
[GroupDocs.Viewer Documentation](../https://docs.groupdocs.com/viewer/java/).



## クラス

| クラス | 説明 |
| --- | --- |
| [ArchiveSecurityException](../com.groupdocs.viewer.exception/archivesecurityexception) | この例外は、開こうとしているアーカイブが ArchiveSecurityOptions で指定された制限を超えた場合にスローされます。 |
| [FileNotFoundException](../com.groupdocs.viewer.exception/filenotfoundexception) | この例外は、ファイルまたはディレクトリが見つからない場合にスローされます。 |
| [GroupDocsViewerException](../com.groupdocs.viewer.exception/groupdocsviewerexception) | この例外は、ドキュメント処理中に発生し得る汎用エラーを表します。 |
| [IncorrectPasswordException](../com.groupdocs.viewer.exception/incorrectpasswordexception) | この例外は、指定されたパスワードが正しくない場合にスローされます。 |
| [NotSupportedException](../com.groupdocs.viewer.exception/notsupportedexception) | この例外は、要求された操作がサポートされていない場合にスローされます。 |
| [PasswordRequiredException](../com.groupdocs.viewer.exception/passwordrequiredexception) | この例外は、ドキュメントの読み込みにパスワードが必要な場合にスローされます。 |
