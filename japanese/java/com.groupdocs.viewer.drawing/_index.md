このパッケージは、Color のようなプラットフォーム固有のグラフィック型を置き換える型を提供します。

このパッケージの主なクラスとインターフェイスは次のとおりです：

* [Argb32Color](../../com.groupdocs.viewer.drawing/argb32color) - Represents 32-bit color in ARGB format, with 8 bits per channel (Alpha, Red, Green, Blue).
* [Image2DFormat](../../com.groupdocs.viewer.drawing/image2dformat) - Represents a 2D image format \\u2014 raster or vector.
* [Rgb24Color](../../com.groupdocs.viewer.drawing/rgb24color) - Represents 24-bit color in RGB format, with 8 bits per every channel (Red, Green, Blue). Does not support transparency.


GroupDocs.Viewer のキャッシュ動作のカスタマイズに関する詳細は、以下をご参照ください
[GroupDocs.Viewer Documentation](../https://docs.groupdocs.com/viewer/java/).

| クラス | 説明 |

| [Argb32Color](../com.groupdocs.viewer.drawing/argb32color) | ARGB 形式の 32 ビットカラーを表し、各チャンネル（アルファ、赤、緑、青）は 8 ビットです。 |
| [Image2DFormat](../com.groupdocs.viewer.drawing/image2dformat) | 2D 画像フォーマットを表します \\u2014 ラスターまたはベクター。 |
| [Rgb24Color](../com.groupdocs.viewer.drawing/rgb24color) | RGB 形式の 24 ビットカラーを表し、各チャンネル（赤、緑、青）は 8 ビットです。 |
