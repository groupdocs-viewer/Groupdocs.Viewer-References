このパッケージは、文書レンダリング結果を表すクラスとインターフェイスを提供します。


これらのクラスは、レンダリングされたドキュメントのさまざまな要素やコンポーネントに関する情報をカプセル化します、
ページ、添付ファイル、ビュー、リソースなどが含まれます。

このパッケージの主なクラスは次のとおりです：

* [Page](../../com.groupdocs.viewer.results/page) - Represents a single page that can be viewed.
* [Attachment](../../com.groupdocs.viewer.results/attachment) - Represents an attachment file contained by an email message, archive, PDF document, or Outlook data file.
* [PdfViewInfo](../../com.groupdocs.viewer.results/pdfviewinfo) - Represents view information for a PDF document.


GroupDocs.Viewer を使用したドキュメントレンダリング結果の操作に関する詳細は、
こちらの [GroupDocs.Viewer Documentation](../https://docs.groupdocs.com/viewer/java/) を参照してください。



## クラス

| クラス | 説明 |
| --- | --- |
| [Resource](../com.groupdocs.viewer.results/resource) | フォント、スタイル、画像、またはグラフィックなどの HTML リソースを表します。 |
