このパッケージは、さまざまな機能のためのヘルパーおよびユーティリティクラスを提供します。


これらのクラスは、さまざまな操作を支援する便利なメソッドと機能を提供します。

このパッケージの主なクラスは次のとおりです：

* [CancellationToken](../../com.groupdocs.viewer.utils/cancellationtoken) - Propagates a request to cancel rendering.
* [CancellationTokenSource](../../com.groupdocs.viewer.utils/cancellationtokensource) - Creates and signals a [CancellationToken](../../com.groupdocs.viewer.utils/cancellationtoken).
* [MemoryCleaner](../../com.groupdocs.viewer.utils/memorycleaner) - Provides methods to clean up resources and free memory.
* [PathUtils](../../com.groupdocs.viewer.utils/pathutils) - Represents the type for working with paths.


com.groupdocs.viewer.utils パッケージのユーティリティクラスの使用に関する詳細は、
こちらの [GroupDocs.Viewer Documentation](../https://docs.groupdocs.com/viewer/java/) を参照してください。



## クラス

| クラス | 説明 |
| --- | --- |
| [CancellationToken](../com.groupdocs.viewer.utils/cancellationtoken) | 操作がキャンセルされるべきであることを通知します。 |
| [CancellationTokenSource](../com.groupdocs.viewer.utils/cancellationtokensource) | 操作がキャンセルされるべきであることを [CancellationToken](../com.groupdocs.viewer.utils/cancellationtoken) にシグナルします。 |
| [MemoryCleaner](../com.groupdocs.viewer.utils/memorycleaner) | メモリを解放するためにさまざまなリソースをクリーンアップします。 |
| [PathUtils](../com.groupdocs.viewer.utils/pathutils) | PathUtils クラスはファイルパスを扱うためのユーティリティメソッドを提供します。 |
