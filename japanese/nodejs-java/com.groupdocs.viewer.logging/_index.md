このパッケージは、GroupDocs.Viewer のロギングシステムを構成するためのクラスを提供します。

これらのクラスを使用することで、ログメッセージの処理方法（ファイルへの書き込みや特定のロガー実装への転送など）を制御できます。

このパッケージの主なクラスは次のとおりです：

 *  [FileLogger](../../com.groupdocs.viewer.logging/filelogger) - Writes log messages to a file.
 *  [ViewerLogger](../../com.groupdocs.viewer.logging/viewerlogger) - Implements logging messages to an integrated or user-defined logger.

GroupDocs.Viewer のロギングシステムの構成およびログメッセージ処理のカスタマイズの詳細については、[GroupDocs.Viewer ドキュメント][] を参照してください。


[GroupDocs.Viewer Documentation]: https://docs.groupdocs.com/viewer/java/


## クラス

| クラス | 説明 |
| --- | --- |
| [FileLogger](../com.groupdocs.viewer.logging/filelogger) | ログメッセージをファイルに書き込みます。 |
| [ViewerLogger](../com.groupdocs.viewer.logging/viewerlogger) | グローバル ビューア ロガー。 |
