このパッケージは、HTML5、画像、または PDF モードで文書を高速かつ高品質にレンダリングするためのクラスを提供します。

このパッケージの主なクラスは次のとおりです：

 *  [License](../../com.groupdocs.viewer/license) - Provides methods for licensing Viewer.
 *  [Viewer](../../com.groupdocs.viewer/viewer) - Represents the main class that controls the document rendering process.
 *  [ViewerSettings](../../com.groupdocs.viewer/viewersettings) - Defines settings for customizing the behavior of the Viewer.

Java 用 GroupDocs.Viewer を使用したドキュメントレンダリングプロセスの詳細については、[GroupDocs.Viewer ドキュメント][] を参照してください。


[GroupDocs.Viewer Documentation]: https://docs.groupdocs.com/viewer/java/


## クラス

| クラス | 説明 |
| --- | --- |
| [License](../com.groupdocs.viewer/license) | コンポーネントにライセンスを付与し、完全な機能を有効にするためのメソッドを提供します。 |
| [Metered](../com.groupdocs.viewer/metered) | GroupDocs.Viewer コンポーネントに従量制ライセンスを適用するためのメソッドを提供します。 |
| [Viewer](../com.groupdocs.viewer/viewer) | ドキュメントレンダリングプロセスを制御するメインクラスを表します。 |
| [ViewerSettings](../com.groupdocs.viewer/viewersettings) | Viewer コンポーネントの動作をカスタマイズするための設定を定義します。 |
