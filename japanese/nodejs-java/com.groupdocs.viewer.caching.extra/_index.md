このパッケージは、キャッシュ実装でカスタムモデルを使用する機能を提供します。

このパッケージのメインクラスは[CacheableFactory](../../com.groupdocs.viewer.caching.extra/cacheablefactory)で、追加機能を提供してキャッシュのカスタマイズを支援します。

GroupDocs.Viewer のキャッシュ実装でカスタムモデルを使用する詳細については、[GroupDocs.Viewer Documentation][]. を参照してください。


[GroupDocs.Viewer Documentation]: https://docs.groupdocs.com/viewer/java/
