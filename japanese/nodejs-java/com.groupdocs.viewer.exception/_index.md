このパッケージは、文書を操作中に発生し得る例外のためのクラスを提供します。

このパッケージの主なクラスは次のとおりです：

 *  com.groupdocs.viewer.exception.ArchiveSecurityException - Thrown when an archive being opened exceeds specified limits.
 *  [FileNotFoundException](../../com.groupdocs.viewer.exception/filenotfoundexception) - Represents an exception thrown when a file or directory is not found.
 *  [GroupDocsViewerException](../../com.groupdocs.viewer.exception/groupdocsviewerexception) - Represents generic errors that occur during document processing.

GroupDocs.Viewer の例外処理に関する詳細については、[GroupDocs.Viewer Documentation][] を参照してください。


[GroupDocs.Viewer Documentation]: https://docs.groupdocs.com/viewer/java/


## クラス

| クラス | 説明 |
| --- | --- |
| [ArchiveSecurityException](../com.groupdocs.viewer.exception/archivesecurityexception) | 開こうとしているアーカイブが ArchiveSecurityOptions で指定された制限を超える場合に、この例外がスローされます。 |
| [FileNotFoundException](../com.groupdocs.viewer.exception/filenotfoundexception) | ファイルまたはディレクトリが見つからない場合にこの例外がスローされます。 |
| [GroupDocsViewerException](../com.groupdocs.viewer.exception/groupdocsviewerexception) | この例外は、ドキュメント処理中に発生する可能性のある汎用エラーを表します。 |
| [IncorrectPasswordException](../com.groupdocs.viewer.exception/incorrectpasswordexception) | 指定されたパスワードが正しくない場合にこの例外がスローされます。 |
| [NotSupportedException](../com.groupdocs.viewer.exception/notsupportedexception) | 要求された操作がサポートされていない場合にこの例外がスローされます。 |
| [PasswordRequiredException](../com.groupdocs.viewer.exception/passwordrequiredexception) | ドキュメントを読み込む際にパスワードが必要な場合にこの例外がスローされます。 |
