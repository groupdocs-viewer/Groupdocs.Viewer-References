このパッケージは、キャッシュ動作をカスタマイズするためのクラスを提供します。

このパッケージの主なクラスとインターフェイスは次のとおりです：

 *  [CacheKeys](../../com.groupdocs.viewer.caching/cachekeys) - Provides methods to retrieve unique identifiers for the cache entry.
 *  [FileCache](../../com.groupdocs.viewer.caching/filecache) - Represents a local on-disk cache.

この [Cache](../../com.groupdocs.viewer.caching/cache) インターフェイスは、レンダリングされたドキュメントとドキュメントリソースをキャッシュに保存するために必要なメソッドを定義します。

GroupDocs.Viewer におけるキャッシュ動作のカスタマイズの詳細については、[GroupDocs.Viewer Documentation][] を参照してください。


[GroupDocs.Viewer Documentation]: https://docs.groupdocs.com/viewer/java/


## クラス

| クラス | 説明 |
| --- | --- |
| [CacheKeys](../com.groupdocs.viewer.caching/cachekeys) | キャッシュエントリの一意の識別子を取得するメソッドを提供します。 |
| [FileCache](../com.groupdocs.viewer.caching/filecache) | ローカルのディスク上キャッシュを表します。 |
