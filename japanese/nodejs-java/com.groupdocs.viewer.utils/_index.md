このパッケージは、さまざまな機能のためのヘルパーおよびユーティリティクラスを提供します。

これらのクラスは、さまざまな操作を支援する便利なメソッドと機能を提供します。

このパッケージの主なクラスは次のとおりです：

 *  [MemoryCleaner](../../com.groupdocs.viewer.utils/memorycleaner) - Provides methods to clean up resources and free memory.
 *  [PathUtils](../../com.groupdocs.viewer.utils/pathutils) - Represents the type for working with paths.

com.groupdocs.viewer.utils パッケージのユーティリティクラスの使用に関する詳細は、[GroupDocs.Viewer Documentation][] を参照してください。


[GroupDocs.Viewer Documentation]: https://docs.groupdocs.com/viewer/java/


## クラス

| クラス | 説明 |
| --- | --- |
| [MemoryCleaner](../com.groupdocs.viewer.utils/memorycleaner) | さまざまなリソースをクリーンアップしてメモリを解放します。 |
| [PathUtils](../com.groupdocs.viewer.utils/pathutils) | PathUtils クラスは、ファイルパスを扱うためのユーティリティメソッドを提供します。 |
