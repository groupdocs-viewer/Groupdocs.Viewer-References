Το πακέτο παρέχει λειτουργικότητα για τη χρήση προσαρμοσμένων μοντέλων στην υλοποίηση της προσωρινής αποθήκευσης.

Η κύρια κλάση σε αυτό το πακέτο είναι η [CacheableFactory](../../com.groupdocs.viewer.caching.extra/cacheablefactory), η οποία βοηθά στην προσαρμογή της προσωρινής μνήμης παρέχοντας πρόσθετη λειτουργικότητα.

Για περισσότερες λεπτομέρειες σχετικά με τη χρήση προσαρμοσμένων μοντέλων στην υλοποίηση της προσωρινής μνήμης στο GroupDocs.Viewer, παρακαλούμε ανατρέξτε στην [GroupDocs.Viewer Documentation][].
