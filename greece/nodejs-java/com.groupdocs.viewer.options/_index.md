Το πακέτο παρέχει κλάσεις για τον καθορισμό πρόσθετων επιλογών κατά την απόδοση εγγράφων.

Περιλαμβάνει επιλογές για την απόδοση διαφόρων μορφών εγγράφων, τον ορισμό δικαιωμάτων και ρυθμίσεων ασφαλείας, τον καθορισμό ιδιοτήτων υδατογραφήματος και την ανάκτηση πληροφοριών σχετικά με τις προβολές.

Οι κύριες κλάσεις σε αυτό το πακέτο είναι:

 *  [ArchiveOptions](../../com.groupdocs.viewer.options/archiveoptions) - Provides options for rendering archive files.
 *  [PdfOptions](../../com.groupdocs.viewer.options/pdfoptions) - Provides options for rendering PDF documents.
 *  [WordProcessingOptions](../../com.groupdocs.viewer.options/wordprocessingoptions) - Provides options for rendering word processing documents.

Για περισσότερες λεπτομέρειες σχετικά με τη διαμόρφωση του συστήματος καταγραφής στο GroupDocs.Viewer και την προσαρμογή του χειρισμού των μηνυμάτων καταγραφής, παρακαλούμε ανατρέξτε στην [GroupDocs.Viewer Documentation][].


[GroupDocs.Viewer Documentation]: https://docs.groupdocs.com/viewer/java/
