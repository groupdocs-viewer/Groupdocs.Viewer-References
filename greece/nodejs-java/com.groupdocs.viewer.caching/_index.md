Το πακέτο παρέχει κλάσεις για την προσαρμογή της συμπεριφοράς της προσωρινής αποθήκευσης.

Οι κύριες κλάσεις και διεπαφές σε αυτό το πακέτο είναι:

 *  [CacheKeys](../../com.groupdocs.viewer.caching/cachekeys) - Provides methods to retrieve unique identifiers for the cache entry.
 *  [FileCache](../../com.groupdocs.viewer.caching/filecache) - Represents a local on-disk cache.

Η διεπαφή [Cache](../../com.groupdocs.viewer.caching/cache) ορίζει τις μεθόδους που απαιτούνται για την αποθήκευση των αποδομένων εγγράφων και των πόρων εγγράφων στην κρυφή μνήμη.

Για περισσότερες λεπτομέρειες σχετικά με την προσαρμογή της συμπεριφοράς της κρυφής μνήμης στο GroupDocs.Viewer, παρακαλούμε ανατρέξτε στην [GroupDocs.Viewer Documentation][].


[GroupDocs.Viewer Documentation]: https://docs.groupdocs.com/viewer/java/


## Κλάσεις

| Κλάση | Περιγραφή |

| [CacheKeys](../com.groupdocs.viewer.caching/cachekeys) | Παρέχει μεθόδους για την ανάκτηση του μοναδικού αναγνωριστικού μιας καταχώρησης κρυφής μνήμης. |
| [FileCache](../com.groupdocs.viewer.caching/filecache) | Αντιπροσωπεύει μια τοπική κρυφή μνήμη στο δίσκο. |
