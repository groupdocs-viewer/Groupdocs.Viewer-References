Το πακέτο παρέχει κλάσεις και απαριθμήσεις για τη διαχείριση των γραμματοσειρών που χρησιμοποιούνται κατά τη διαδικασία απόδοσης.

Οι κύριες κλάσεις και διεπαφές σε αυτό το πακέτο είναι:

 *  [FolderFontSource](../../com.groupdocs.viewer.fonts/folderfontsource) - Represents a folder that contains TrueType fonts.
 *  [FontSettings](../../com.groupdocs.viewer.fonts/fontsettings) - Provides methods for working with sources to look for TrueType fonts.
 *  [FontSource](../../com.groupdocs.viewer.fonts/fontsource) - Marker interface for the font sources.

Για περισσότερες λεπτομέρειες σχετικά με τη δουλειά με γραμματοσειρές στο GroupDocs.Viewer, παρακαλούμε ανατρέξτε στην [GroupDocs.Viewer Τεκμηρίωση][].


[GroupDocs.Viewer Documentation]: https://docs.groupdocs.com/viewer/java/


## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [FolderFontSource](../com.groupdocs.viewer.fonts/folderfontsource) | Αναπαριστά έναν φάκελο που περιέχει γραμματοσειρές TrueType. |
| [FontFormat](../com.groupdocs.viewer.fonts/fontformat) | Αναπαριστά όλες τις μορφές γραμματοσειρών, που μπορεί να υπάρχουν στην κλάση UsedFontInfo. |
| [FontSettings](../com.groupdocs.viewer.fonts/fontsettings) | Παρέχει μεθόδους για τη δουλειά με πηγές ώστε να εντοπίζει γραμματοσειρές TrueType. |
| [FontStyles](../com.groupdocs.viewer.fonts/fontstyles) | Αναπαριστά 4 πιθανά στυλ της γραμματοσειράς, που χρησιμοποιούνται στο έγγραφο: Κανονικό, Έντονο, Πλάγιο ή Έντονο Πλάγιο. |
| [PdfFontInfo](../com.groupdocs.viewer.fonts/pdffontinfo) | Περιλαμβάνει μετα-πληροφορίες και δυαδικά δεδομένα μιας γραμματοσειράς από έγγραφο PDF, που φορτώθηκε στην παρουσία Viewer instance. |
| [PresentationFontInfo](../com.groupdocs.viewer.fonts/presentationfontinfo) | Περιλαμβάνει μεταδεδομένα και δυαδικά δεδομένα μιας γραμματοσειράς που χρησιμοποιείται σε έγγραφο Παρουσίασης, που φορτώθηκε στην παρουσία Viewer instance. |
| [SpreadsheetFontInfo](../com.groupdocs.viewer.fonts/spreadsheetfontinfo) | Περιλαμβάνει μεταπληροφορίες και δυαδικά δεδομένα μιας γραμματοσειράς από το έγγραφο Υπολογιστικού Φύλλου, που φορτώθηκε στην παρουσία Viewer instance. |
| [WordProcessingFontInfo](../com.groupdocs.viewer.fonts/wordprocessingfontinfo) | Περιλαμβάνει μεταπληροφορίες και δυαδικά δεδομένα μιας γραμματοσειράς από το έγγραφο Επεξεργασίας Κειμένου, που φορτώθηκε στην παρουσία Viewer instance. |
| [WordProcessingSubstitutedFontInfo](../com.groupdocs.viewer.fonts/wordprocessingsubstitutedfontinfo) | Περιλαμβάνει μεταδεδομένα και δυαδικά δεδομένα μιας αντικατεστημένης γραμματοσειράς που χρησιμοποιείται σε έγγραφο Επεξεργασίας Κειμένου μέσω του GroupDocs.Viewer. |
