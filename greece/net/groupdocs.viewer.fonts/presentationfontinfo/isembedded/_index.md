## PresentationFontInfo.IsEmbedded property

Δείχνει εάν αυτή η γραμματοσειρά είναι ενσωματωμένη μέσα στο έγγραφο, που φορτώθηκε στην παρουσία [`Viewer`](../../../groupdocs.viewer/viewer) (`true`), ή είναι γραμματοσειρά συστήματος (`false`). Τα έγγραφα υπολογιστικών φύλλων δεν μπορούν να περιέχουν ενσωματωμένες γραμματοσειρές, επομένως για αυτά η ιδιότητα πάντα επιστρέφει `false`.

```csharp
public bool IsEmbedded { get; }
```
