## FileType.VSSM field

Τα Visio Macro-Enabled Stencil File (.vssm) είναι αρχεία στενσίλ του Microsoft Visio που υποστηρίζουν μακροεντολές. Ένα αρχείο VSSM όταν ανοίγεται επιτρέπει την εκτέλεση των μακροεντολών για την επίτευξη της επιθυμητής μορφοποίησης και τοποθέτησης των σχημάτων σε ένα διάγραμμα. Μάθετε περισσότερα για αυτή τη μορφή αρχείου [εδώ](https://wiki.fileformat.com/image/vssm).

```csharp
public static readonly FileType VSSM;
```
