## FileType.PPTX field

PowerPoint Open XML Presentation (.pptx) είναι αρχεία παρουσίασης που δημιουργούνται με τη δημοφιλή εφαρμογή Microsoft PowerPoint. Σε αντίθεση με την προηγούμενη έκδοση του μορφότυπου αρχείου παρουσίασης PPT που ήταν δυαδική, η μορφή PPTX βασίζεται στον ανοιχτό XML μορφότυπο παρουσίασης του Microsoft PowerPoint. Μάθετε περισσότερα για αυτόν τον μορφότυπο αρχείου [εδώ](https://wiki.fileformat.com/presentation/pptx).

```csharp
public static readonly FileType PPTX;
```
