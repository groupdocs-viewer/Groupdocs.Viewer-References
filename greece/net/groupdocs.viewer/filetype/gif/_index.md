## FileType.GIF field

Το αρχείο Graphical Interchange Format (.gif) είναι ένας τύπος πολύ συμπιεσμένης εικόνας. Για κάθε εικόνα, το GIF επιτρέπει συνήθως έως 8 bit ανά pixel και έως 256 χρώματα σε όλη την εικόνα. Μάθετε περισσότερα για αυτή τη μορφή αρχείου [εδώ](https://wiki.fileformat.com/image/gif).

```csharp
public static readonly FileType GIF;
```
