## FileType.XLT field

Τα Microsoft Excel Template (.xlt) είναι αρχεία προτύπων που δημιουργήθηκαν με το Microsoft Excel, μια εφαρμογή λογιστικού φύλλου που αποτελεί μέρος της σουίτας Microsoft Office. Το Microsoft Office 97-2003 υποστήριζε τη δημιουργία νέων αρχείων XLT καθώς και το άνοιγμά τους. Μάθετε περισσότερα για αυτή τη μορφή αρχείου [εδώ](https://wiki.fileformat.com/spreadsheet/xlt).

public static readonly FileType XLT;
