## FileType.VTX field

Το Visio Template XML File (.vtx) είναι ένα πρότυπο σχεδίου Microsoft Visio που αποθηκεύεται στο δίσκο σε μορφή XML. Το πρότυπο στοχεύει στην παροχή ενός αρχείου με βασικές ρυθμίσεις που μπορούν να χρησιμοποιηθούν για τη δημιουργία πολλαπλών αρχείων Visio με τις ίδιες ρυθμίσεις. Μάθετε περισσότερα για αυτή τη μορφή αρχείου [εδώ](https://wiki.fileformat.com/image/vtx).

public static readonly FileType VTX;
