## FileType.XLTX field

Το Excel Open XML Spreadsheet Template (.xltx) αντιπροσωπεύει πρότυπα Microsoft Excel που βασίζονται στις προδιαγραφές μορφής αρχείου Office OpenXML. Χρησιμοποιείται για τη δημιουργία ενός τυπικού αρχείου προτύπου που μπορεί να χρησιμοποιηθεί για τη δημιουργία αρχείων XLSX με τις ίδιες ρυθμίσεις όπως ορίζονται στο αρχείο XLTX. Μάθετε περισσότερα για αυτή τη μορφή αρχείου [εδώ](https://wiki.fileformat.com/spreadsheet/xltx).

```csharp
public static readonly FileType XLTX;
```
