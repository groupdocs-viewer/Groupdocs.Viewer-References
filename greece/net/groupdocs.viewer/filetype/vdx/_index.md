## FileType.VDX field

Το Αρχείο XML Σχεδίου Visio (.vdx) αντιπροσωπεύει οποιοδήποτε σχέδιο ή διάγραμμα που δημιουργείται στο Microsoft Visio, αλλά αποθηκεύεται σε μορφή XML με επέκταση .VDX. Ένα αρχείο XML σχεδίου Visio δημιουργείται στο λογισμικό Visio, το οποίο αναπτύσσεται από τη Microsoft. Μάθετε περισσότερα για αυτό το μορφότυπο αρχείου [εδώ](https://wiki.fileformat.com/image/vdx).

```csharp
public static readonly FileType VDX;
```
