## FileType.EMF field

Το Enhanced Windows Metafile (.emf) αντιπροσωπεύει γραφικές εικόνες ανεξάρτητα από τη συσκευή. Τα μετααρχεία EMF αποτελούνται από εγγραφές μεταβλητού μήκους σε χρονολογική σειρά που μπορούν να αποδώσουν την αποθηκευμένη εικόνα μετά την ανάλυση σε οποιαδήποτε έξοδο. Μάθετε περισσότερα για αυτή τη μορφή αρχείου [εδώ](https://wiki.fileformat.com/image/emf).

```csharp
public static readonly FileType EMF;
```
