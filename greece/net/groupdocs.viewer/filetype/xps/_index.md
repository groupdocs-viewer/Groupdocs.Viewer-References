## FileType.XPS field

Το XML Paper Specification File (.xps) αντιπροσωπεύει αρχεία διάταξης σελίδας που βασίζονται στις XML Paper Specifications που δημιουργήθηκαν από τη Microsoft. Αυτή η μορφή αναπτύχθηκε από τη Microsoft ως αντικατάσταση της μορφής αρχείου EMF και είναι παρόμοια με τη μορφή αρχείου PDF, αλλά χρησιμοποιεί XML για τη διάταξη, την εμφάνιση και τις πληροφορίες εκτύπωσης ενός εγγράφου. Μάθετε περισσότερα για αυτή τη μορφή αρχείου [εδώ](https://wiki.fileformat.com/page-description-language/xps).

public static readonly FileType XPS;
