Ο ονοματοχώρος παρέχει τύπους που αντικαθιστούν τύπους γραφικών ειδικών για την πλατφόρμα, όπως το Color.

## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [Rgb24Color.KnownColors](./rgb24color.knowncolors) | Περιέχει όλα τα "γνωστά χρώματα", που έχουν σταθερό μοναδικό όνομα και τιμή στο πρότυπο CSS |
## Structures

| Δομή | Περιγραφή |
| --- | --- |
| [Argb32Color](./argb32color) | Αναπαριστά χρώμα 32-bit σε μορφή ARGB, με 8 bits για κάθε κανάλι (Alpha, Red, Green, Blue). Υποστηρίζει διαφάνεια. |
| [Image2DFormat](./image2dformat) | Αναπαριστά τις πιο κοινές μορφές 2D εικόνων, υποστηρίζει τόσο raster όσο και vector μορφές. |
| [Rgb24Color](./rgb24color) | Αναπαριστά χρώμα 24-bit σε μορφή RGB, με 8 bits για κάθε κανάλι (Red, Green, Blue). Δεν υποστηρίζει διαφάνεια. |
