## InvalidFontFormatException class

Η εξαίρεση που ρίχνεται όταν προσπαθείτε να ανοίξετε, φορτώσετε, αποθηκεύσετε ή επεξεργαστείτε με κάποιον τρόπο άλλο κάποιο περιεχόμενο, που υποτίθεται ότι είναι γραμματοσειρά υποστηριζόμενης (γνωστής) μορφής, αλλά στην πραγματικότητα είναι γραμματοσειρά απροσδόκητης και/ή μη υποστηριζόμενης μορφής ή καθόλου δεν είναι γραμματοσειρά.

```csharp
public class InvalidFontFormatException : Exception
```
