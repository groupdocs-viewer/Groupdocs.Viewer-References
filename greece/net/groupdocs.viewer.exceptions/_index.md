Ο ονοματοχώρος παρέχει διαφορετικές κλάσεις εξαιρέσεων.

## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [GroupDocsViewerException](./groupdocsviewerexception) | Αντιπροσωπεύει τα γενικά σφάλματα που προκύπτουν κατά την επεξεργασία εγγράφων. |
| [IncorrectPasswordException](./incorrectpasswordexception) | Η εξαίρεση που δημιουργείται όταν ο καθορισμένος κωδικός πρόσβασης είναι λανθασμένος. |
| [InvalidFontFormatException](./invalidfontformatexception) | Η εξαίρεση που ρίχνεται όταν προσπαθείτε να ανοίξετε, φορτώσετε, αποθηκεύσετε ή επεξεργαστείτε με κάποιον τρόπο άλλο κάποιο περιεχόμενο, που υποτίθεται ότι είναι γραμματοσειρά υποστηριζόμενης (γνωστής) μορφής, αλλά στην πραγματικότητα είναι γραμματοσειρά απροσδόκητης και/ή μη υποστηριζόμενης μορφής ή καθόλου δεν είναι γραμματοσειρά. |
| [InvalidImageFormatException](./invalidimageformatexception) | Η εξαίρεση που ρίχνεται όταν προσπαθείτε να ανοίξετε, φορτώσετε, αποθηκεύσετε ή επεξεργαστείτε με κάποιον τρόπο άλλο κάποιο περιεχόμενο, που υποτίθεται ότι είναι εικόνα (ραστερ ή διανυσματική), αλλά στην πραγματικότητα είναι εικόνα απροσδόκητης και/ή μη υποστηριζόμενης μορφής ή καθόλου δεν είναι εικόνα. |
| [PasswordRequiredException](./passwordrequiredexception) | Η εξαίρεση που ρίχνεται όταν απαιτείται κωδικός πρόσβασης για τη φόρτωση του εγγράφου. |
