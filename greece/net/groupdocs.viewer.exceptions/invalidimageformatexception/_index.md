## InvalidImageFormatException class

Η εξαίρεση που ρίχνεται όταν προσπαθείτε να ανοίξετε, φορτώσετε, αποθηκεύσετε ή επεξεργαστείτε με κάποιον τρόπο άλλο κάποιο περιεχόμενο, που υποτίθεται ότι είναι εικόνα (ραστερ ή διανυσματική), αλλά στην πραγματικότητα είναι εικόνα απροσδόκητης και/ή μη υποστηριζόμενης μορφής ή καθόλου δεν είναι εικόνα.

```csharp
public class InvalidImageFormatException : Exception
```
