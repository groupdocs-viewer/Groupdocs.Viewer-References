Ο ονοματοχώρος παρέχει κλάσεις για τον καθορισμό πρόσθετων επιλογών κατά την απόδοση εγγράφων.

## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [ArchiveOptions](./archiveoptions) | Περιέχει επιλογές για την απόδοση των αρχείων αρχειοθέτησης. Για λεπτομέρειες, δείτε την [τεκμηρίωση](https://docs.groupdocs.com/viewer/net/render-archive-files/). |
| [BaseViewOptions](./baseviewoptions) | Περιέχει τις βασικές επιλογές απόδοσης. |
| [CadOptions](./cadoptions) | Περιέχει επιλογές για την απόδοση σχεδίων CAD. Για περισσότερες πληροφορίες και παραδείγματα κώδικα, δείτε το [Απόδοση σχεδίων CAD και μοντέλων ως HTML, PDF και αρχεία εικόνας](https://docs.groupdocs.com/viewer/net/render-cad-drawings-and-models/) και το [Καθορισμός επιλογών απόδοσης για αρχεία CAD](https://docs.groupdocs.com/viewer/net/specify-cad-rendering-options/). |
| [EmailOptions](./emailoptions) | Περιέχει επιλογές για την απόδοση μηνυμάτων email. Για λεπτομέρειες, δείτε την [τεκμηρίωση](https://docs.groupdocs.com/viewer/net/render-email-messages/). |
| [Field](./field) | Αναπαριστά πεδίο μηνύματος email π.χ. Από, Προς, Θέμα κ.λπ. Για λεπτομέρειες, δείτε την [τεκμηρίωση](https://docs.groupdocs.com/viewer/net/render-email-messages/#rename-fields-in-the-message-header). |
| [FileName](./filename) | Το όνομα αρχείου. |
| [HtmlViewOptions](./htmlviewoptions) | Περιέχει επιλογές για την απόδοση εγγράφων σε μορφή HTML. Για λεπτομέρειες, δείτε το [θέμα](https://docs.groupdocs.com/viewer/net/rendering-to-html/) και τα υπο-στοιχεία του. |
| [JpgViewOptions](./jpgviewoptions) | Παρέχει επιλογές για την απόδοση εγγράφων σε μορφή JPG. Για λεπτομέρειες, δείτε αυτή τη [σελίδα](https://docs.groupdocs.com/viewer/net/rendering-to-png-or-jpeg/) και τα υπο-στοιχεία της. |
| [LoadOptions](./loadoptions) | Περιέχει επιλογές που χρησιμοποιούνται για το άνοιγμα του αρχείου. Για λεπτομέρειες, δείτε αυτή τη [σελίδα](https://docs.groupdocs.com/viewer/net/loading/) και τα υπο-στοιχεία της. |
| [MailStorageOptions](./mailstorageoptions) | Περιέχει επιλογές για την απόδοση αρχείων δεδομένων αποθήκευσης αλληλογραφίας (Lotus Notes, MBox). Για λεπτομέρειες, δείτε την [τεκμηρίωση](https://docs.groupdocs.com/viewer/net/render-lotus-notes-database-files/#specify-rendering-options). |
| [OutlookOptions](./outlookoptions) | Περιέχει επιλογές για την απόδοση αρχείων δεδομένων Outlook. Για λεπτομέρειες, δείτε την [τεκμηρίωση](https://docs.groupdocs.com/viewer/net/render-lotus-notes-database-files/#specify-rendering-options). |
| [PdfOptimizationOptions](./pdfoptimizationoptions) | Περιέχει τις επιλογές βελτιστοποίησης PDF που εφαρμόζονται στο αρχείο PDF εξόδου. Για λεπτομέρειες και παραδείγματα κώδικα, δείτε αυτή τη [σελίδα](https://docs.groupdocs.com/viewer/net/optimization-pdf-options/) και τα υπο-στοιχεία της. |
| [PdfOptions](./pdfoptions) | Περιέχει επιλογές για την απόδοση σε έγγραφα PDF. Για λεπτομέρειες, δείτε την [τεκμηρίωση](https://docs.groupdocs.com/viewer/net/render-pdf-documents/). |
| [PdfViewOptions](./pdfviewoptions) | Περιέχει επιλογές για την απόδοση εγγράφων σε μορφή PDF. Για λεπτομέρειες, δείτε την [τεκμηρίωση](https://docs.groupdocs.com/viewer/net/rendering-to-pdf/). |
| [PngViewOptions](./pngviewoptions) | Περιέχει επιλογές για την απόδοση εγγράφων σε μορφή PNG. Για λεπτομέρειες, δείτε αυτή τη [σελίδα](https://docs.groupdocs.com/viewer/net/rendering-to-png-or-jpeg/) και τα υπο-στοιχεία της. |
| [PresentationOptions](./presentationoptions) | Περιέχει επιλογές για την απόδοση παρουσιάσεων. Για λεπτομέρειες, δείτε την [τεκμηρίωση](https://docs.groupdocs.com/viewer/net/render-presentations/). |
| [ProjectManagementOptions](./projectmanagementoptions) | Περιέχει επιλογές για την απόδοση αρχείων διαχείρισης έργων. Για λεπτομέρειες, δείτε την [τεκμηρίωση](https://docs.groupdocs.com/viewer/net/render-ms-project-files/). |
| [Resolution](./resolution) | Περιέχει επιλογή για τον καθορισμό της ανάλυσης των εικόνων στο έγγραφο εξόδου. |
| [SearchHighlightOptions](./searchhighlightoptions) | Παρέχει επιλογές για αναζήτηση και επισήμανση κειμένου στα έγγραφα, φορτωμένα στην κλάση [`Viewer`](../groupdocs.viewer/viewer). |
| [Security](./security) | Περιέχει τις επιλογές ασφαλείας εγγράφου PDF. Για λεπτομέρειες, δείτε την [τεκμηρίωση](https://docs.groupdocs.com/viewer/net/protect-pdf-documents/). |
| [Size](./size) | Περιέχει το μέγεθος του υδατογραφήματος. |
| [SpreadsheetOptions](./spreadsheetoptions) | Περιέχει επιλογές για την απόδοση λογιστικών φύλλων. Για λεπτομέρειες, δείτε τα υπο-στοιχεία του [Απόδοση αρχείων λογιστικών φύλλων](https://docs.groupdocs.com/viewer/net/render-spreadsheets/) θέματος. |
| [TextOptions](./textoptions) | Επιλογές διαίρεσης αρχείων κειμένου σε σελίδες. |
| [Tile](./tile) | Αναπαριστά την περιοχή σχεδίασης. |
| [ViewInfoOptions](./viewinfooptions) | Περιέχει επιλογές για την ανάκτηση πληροφοριών σχετικά με την προβολή. |
| [ViewOptions](./viewoptions) | Περιέχει τις επιλογές απόδοσης. |
| [VisioRenderingOptions](./visiorenderingoptions) | Περιέχει επιλογές για την απόδοση εγγράφων Visio. Για λεπτομέρειες, δείτε την [τεκμηρίωση](https://docs.groupdocs.com/viewer/net/render-visio-documents/). |
| [Watermark](./watermark) | Αντιπροσωπεύει ένα υδατογράφημα κειμένου. Για λεπτομέρειες, δείτε την [τεκμηρίωση](https://docs.groupdocs.com/viewer/net/add-text-watermark/). |
| [WebDocumentOptions](./webdocumentoptions) | Περιέχει επιλογές για την απόδοση εγγράφων web. Για λεπτομέρειες, δείτε την [τεκμηρίωση](https://docs.groupdocs.com/viewer/net/render-web-documents/). |
| [WordProcessingOptions](./wordprocessingoptions) | Περιέχει επιλογές για την απόδοση εγγράφων Word. Για λεπτομέρειες, δείτε την [τεκμηρίωση](https://docs.groupdocs.com/viewer/net/render-word-documents/). |
## Διεπαφές

| Διεπαφή | Περιγραφή |

## Απαρίθμηση

| Απαρίθμηση | Περιγραφή |
| --- | --- |
| [ImageQuality](./imagequality) | Η ποιότητα των εικόνων στο παραγόμενο HTML που περιέχεται στα έγγραφα PDF. |
| [PageSize](./pagesize) | Το μέγεθος της σελίδας. |
| [Permissions](./permissions) | Ορίζει τα δικαιώματα εγγράφου PDF. |
| [Position](./position) | Ορίζει τη θέση του υδατογραφήματος. |
| [Rotation](./rotation) | Περιέχει την περιστροφή της σελίδας σε μοίρες (δεξιόστροφα). |
| [TextOverflowMode](./textoverflowmode) | Ορίζει τη λειτουργία υπερχείλισης κειμένου για την απόδοση εγγράφων λογιστικού φύλλου σε HTML. |
| [TimeUnit](./timeunit) | Μονάδα χρόνου της διάρκειας του έργου. |
| [WordsPageNumberLocation](./wordspagenumberlocation) | Ελέγχει αν θα εφαρμοστεί εξαναγκαστικά η αρίθμηση σελίδων στο φορτωμένο έγγραφο WordProcessing και, εάν ναι, πού θα τοποθετηθούν οι αριθμοί σελίδων. |
