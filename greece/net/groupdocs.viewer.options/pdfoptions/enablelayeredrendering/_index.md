## PdfOptions.EnableLayeredRendering property

Ενεργοποιεί την απόδοση κειμένου και γραφικών στη ζ-τάξη του αρχικού εγγράφου PDF κατά την απόδοση σε HTML.

```csharp
public bool EnableLayeredRendering { get; set; }
```

### Παρατηρήσεις

Από προεπιλογή, το GroupDocs.Veiewer αποδίδει κείμενο και γραφικά ως ένα ενιαίο στρώμα σε HTML. Αυτή η επιλογή σας επιτρέπει να διατάξετε τα αντικείμενα με την ίδια σειρά όπως στο πηγαίο αρχείο. Η προεπιλεγμένη τιμή είναι `false`.

Για παράδειγμα κώδικα, δείτε την [τεκμηρίωση](https://docs.groupdocs.com/viewer/net/render-pdf-documents/#enable-multi-layer-rendering).
