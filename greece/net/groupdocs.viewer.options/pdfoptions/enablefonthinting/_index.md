## PdfOptions.EnableFontHinting property

Ενεργοποιεί την υποδείξη γραμματοσειράς.

```csharp
public bool EnableFontHinting { get; set; }
```

### Παρατηρήσεις

Η υποδείξη γραμματοσειράς (font hinting) προσαρμόζει τον τρόπο εμφάνισης μιας γραμματοσειράς περιγράμματος. Ισχύει μόνο για γραμματοσειρές TTF που χρησιμοποιούνται στο πηγαίο έγγραφο. Αυτή η επιλογή είναι διαθέσιμη για απόδοση σε μορφές PNG ή JPG. Η προεπιλεγμένη τιμή είναι `false`.

Για παράδειγμα κώδικα, δείτε την [τεκμηρίωση](https://docs.groupdocs.com/viewer/net/render-pdf-documents/#enable-font-hinting).
