## PdfOptions.DisableCharsGrouping property

Απενεργοποιεί την ομαδοποίηση συμβόλων για ακριβή τοποθέτηση συμβόλων κατά την απόδοση της σελίδας.

```csharp
public bool DisableCharsGrouping { get; set; }
```

### Παρατηρήσεις

Κατά τη μετατροπή αρχείων PDF, το GroupDocs.Viewer ομαδοποιεί μεμονωμένους χαρακτήρες σε λέξεις για βελτιωμένη απόδοση απόδοσης. Εάν το έγγραφό σας περιλαμβάνει ιερογλυφικά ή ειδικά σύμβολα, ίσως θελήσετε να απαγορεύσετε την ομαδοποίηση χαρακτήρων ώστε να εξασφαλίσετε πιο ακριβή διάταξη. Η προεπιλεγμένη τιμή είναι `false`.

Για παράδειγμα κώδικα, δείτε την [τεκμηρίωση](https://docs.groupdocs.com/viewer/net/render-pdf-documents/#disable-character-grouping).
