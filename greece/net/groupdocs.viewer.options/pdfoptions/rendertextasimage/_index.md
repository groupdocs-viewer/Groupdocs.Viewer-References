## PdfOptions.RenderTextAsImage property

Ενεργοποιεί την απόδοση κειμένων στα αρχεία PDF ως εικόνα στην έξοδο HTML.

```csharp
public bool RenderTextAsImage { get; set; }
```

### Παρατηρήσεις

Όταν αυτή η επιλογή ορίζεται σε `true`, το GroupDocs.Viewer αποδίδει το κείμενο ως εικόνα στην έξοδο HTML. Αυτό καθιστά το κείμενο μη επιλέξιμο και βελτιώνει την απόδοση των χαρακτήρων, εξασφαλίζοντας εμφάνιση παρόμοια με PDF στο HTML. Η προεπιλεγμένη τιμή είναι `false`.

Αυτή η επιλογή είναι διαθέσιμη για απόδοση σε HTML.

Για παράδειγμα κώδικα, δείτε την [τεκμηρίωση](https://docs.groupdocs.com/viewer/net/render-pdf-documents/#render-text-as-an-image).
