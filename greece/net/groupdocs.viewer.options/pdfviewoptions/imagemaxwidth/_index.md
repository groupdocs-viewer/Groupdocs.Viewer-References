## PdfViewOptions.ImageMaxWidth property

Ορίζει το μέγιστο πλάτος μιας εικόνας εξόδου (σε εικονοστοιχεία).

```csharp
public int ImageMaxWidth { get; set; }
```

### Παρατηρήσεις

Χρησιμοποιήστε αυτήν την ιδιότητα για να ορίσετε το μέγιστο πλάτος της εικόνας εξόδου (σε εικονοστοιχεία). Το GroupDocs.Viewer εφαρμόζει αυτήν την ιδιότητα κατά την απόδοση μιας μόνο εικόνας σε PDF. Για λεπτομέρειες, δείτε την [documentation](https://docs.groupdocs.com/viewer/net/set-image-size-limits-when-rendering-to-pdf/).

Εάν ορίσετε την ιδιότητα [`ImageWidth`](../imagewidth), αυτή η ιδιότητα αγνοείται.
