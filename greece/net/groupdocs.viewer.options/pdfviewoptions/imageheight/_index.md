## PdfViewOptions.ImageHeight property

Ορίζει το ύψος μιας εξόδου εικόνας (σε εικονοστοιχεία).

```csharp
public int ImageHeight { get; set; }
```

### Παρατηρήσεις

Χρησιμοποιήστε αυτήν την ιδιότητα για να ορίσετε το ύψος της εικόνας εξόδου (σε εικονοστοιχεία). Το GroupDocs.Viewer εφαρμόζει αυτήν την ιδιότητα μόνο κατά την απόδοση μιας μόνο εικόνας σε HTML. Για λεπτομέρειες, δείτε την [documentation](https://docs.groupdocs.com/viewer/net/set-image-size-limits-when-rendering-to-pdf/).

Εάν ορίσετε αυτήν την ιδιότητα, η ιδιότητα [`ImageMaxHeight`](../imagemaxheight) αγνοείται.
