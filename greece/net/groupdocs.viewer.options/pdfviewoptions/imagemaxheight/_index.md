## PdfViewOptions.ImageMaxHeight property

Ορίζει το μέγιστο ύψος μιας εικόνας εξόδου (σε εικονοστοιχεία).

```csharp
public int ImageMaxHeight { get; set; }
```

### Παρατηρήσεις

Χρησιμοποιήστε αυτήν την ιδιότητα για να ορίσετε το μέγιστο ύψος της εικόνας εξόδου (σε εικονοστοιχεία). Το GroupDocs.Viewer εφαρμόζει αυτήν την ιδιότητα κατά την απόδοση μιας μόνο εικόνας σε PDF. Για λεπτομέρειες, δείτε την [documentation](https://docs.groupdocs.com/viewer/net/set-image-size-limits-when-rendering-to-pdf/).

Εάν ορίσετε την ιδιότητα [`ImageHeight`](../imageheight), αυτή η ιδιότητα αγνοείται.
