## ViewInfoOptions.MaxHeight property

Ορίζει το μέγιστο ύψος μιας εξαγόμενης εικόνας (σε εικονοστοιχεία, μόνο για απόδοση σε PNG/JPG).

```csharp
public int MaxHeight { get; set; }
```

### Παρατηρήσεις

Χρησιμοποιήστε αυτήν την ιδιότητα για να ορίσετε το μέγιστο ύψος της εικόνας εξόδου (σε εικονοστοιχεία). Για παράδειγμα κώδικα, δείτε την [τεκμηρίωση](https://docs.groupdocs.com/viewer/net/set-image-size-limits-when-rendering-to-png-jpg/).

Εάν ορίσετε την ιδιότητα [`Height`](../height), αυτή η ιδιότητα αγνοείται.
