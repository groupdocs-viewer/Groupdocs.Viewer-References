## ViewInfoOptions.Height property

Το ύψος της εξαγόμενης εικόνας (σε εικονοστοιχεία, μόνο για απόδοση σε PNG/JPG).

```csharp
public int Height { get; set; }
```

### Παρατηρήσεις

Χρησιμοποιήστε αυτήν την ιδιότητα για να ορίσετε το ύψος της εικόνας εξόδου (σε εικονοστοιχεία). Για παράδειγμα κώδικα, δείτε την [τεκμηρίωση](https://docs.groupdocs.com/viewer/net/image-viewer-adjust-image-size/).

Αν ορίσετε αυτήν την ιδιότητα, η ιδιότητα [`MaxHeight`](../maxheight) αγνοείται.
