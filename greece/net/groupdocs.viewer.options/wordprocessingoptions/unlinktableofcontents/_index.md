## WordProcessingOptions.UnlinkTableOfContents property

Κατά την απόδοση σε HTML ή PDF, μπορείτε να ορίσετε αυτήν την επιλογή σε `true` για να απενεργοποιήσετε την πλοήγηση από τον πίνακα περιεχομένων. Για την απόδοση HTML, οι ετικέτες `a` με σχετικούς συνδέσμους θα αντικατασταθούν με ετικέτες `span`, αφαιρώντας τη λειτουργικότητα αλλά διατηρώντας την οπτική εμφάνιση. Για την απόδοση PDF, ο πίνακας περιεχομένων θα αποδοθεί ως απλό κείμενο χωρίς συνδέσμους προς τις ενότητες του εγγράφου.

```csharp
public bool UnlinkTableOfContents { get; set; }
```

### Παρατηρήσεις

Η προεπιλεγμένη τιμή είναι `false`

Για λεπτομέρειες, δείτε την [τεκμηρίωση](https://docs.groupdocs.com/viewer/net/render-word-documents/#unlink-table-of-contents).
