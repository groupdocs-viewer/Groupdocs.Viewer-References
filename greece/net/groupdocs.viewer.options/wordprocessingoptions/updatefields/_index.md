## WordProcessingOptions.UpdateFields property

Αποκτά ή ορίζει μια τιμή που καθορίζει εάν τα πεδία ορισμένων τύπων πρέπει να ενημερωθούν πριν από την αποθήκευση του εισερχόμενου εγγράφου WordProcessing σε μορφές εξόδου HTML, PDF, PNG ή JPEG. Η προεπιλεγμένη τιμή για αυτήν την ιδιότητα είναι `true` — τα πεδία θα ενημερωθούν πριν από την αποθήκευση.

```csharp
public bool UpdateFields { get; set; }
```

### Παρατηρήσεις

Για λεπτομέρειες, δείτε την [τεκμηρίωση](https://docs.groupdocs.com/viewer/net/render-word-documents/#disable-updating-fields-when-saving).
