## WordProcessingOptions.VerticalResolution property

Αποκτά ή ορίζει την κάθετη ανάλυση για τις παραγόμενες εικόνες σε κουκίδες ανά ίντσα. Αυτή η επιλογή χρησιμοποιείται μόνο κατά την απόδοση εγγράφων WordProcessing σε μορφές PNG ή JPEG.

```csharp
public int VerticalResolution { get; set; }
```

### Παρατηρήσεις

Η προεπιλεγμένη τιμή είναι 96 DPI. Η ελάχιστη δυνατή τιμή - 72 DPI, η μέγιστη δυνατή τιμή - 600 DPI. Εάν η τιμή που καθορίζεται από το χρήστη είναι εκτός αυτών των ορίων, θα εφαρμοστεί η ελάχιστη ή η μέγιστη δυνατή τιμή.
