## MailStorageOptions.MaxItems property

Ορίζει τον μέγιστο αριθμό μηνυμάτων ή αντικειμένων προς απόδοση.

```csharp
public int MaxItems { get; set; }
```

### Παρατηρήσεις

Τα αρχεία δεδομένων αποθήκευσης αλληλογραφίας μπορεί να είναι μεγάλα και η ανάκτηση όλων των μηνυμάτων μπορεί να απαιτήσει σημαντικό χρόνο. Αυτή η ιδιότητα περιορίζει τον μέγιστο αριθμό μηνυμάτων ή στοιχείων που αποδίδονται. Η προεπιλεγμένη τιμή είναι 0 - αποδίδονται όλα τα μηνύματα.

Για παράδειγμα κώδικα, δείτε την [τεκμηρίωση](https://docs.groupdocs.com/viewer/net/render-lotus-notes-database-files/#limit-the-number-of-items-to-render).
