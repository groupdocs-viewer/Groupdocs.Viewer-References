## MailStorageOptions.AddressFilter property

Ορίζει τη διεύθυνση email που χρησιμοποιείται για το φιλτράρισμα των μηνυμάτων ανά αποστολέα ή παραλήπτη.

```csharp
public string AddressFilter { get; set; }
```

### Παρατηρήσεις

Χρησιμοποιήστε αυτήν την ιδιότητα για να αποδώσετε όλα τα μηνύματα που περιέχουν συγκεκριμένο κείμενο στη διεύθυνση του αποστολέα ή του παραλήπτη. Για παράδειγμα κώδικα, δείτε την [τεκμηρίωση](https://docs.groupdocs.com/viewer/net/render-lotus-notes-database-files/#filter-messages).
