## PdfOptimizationOptions.MaxResolution property

Ορίζει τη μέγιστη ανάλυση στο αρχείο PDF εξόδου.

```csharp
public int MaxResolution { get; set; }
```

### Παρατηρήσεις

Για να ενεργοποιήσετε αυτήν την επιλογή, ορίστε τις ιδιότητες [`CompressImages`](../compressimages) και `MaxResolution` σε `true`.

Η προεπιλεγμένη τιμή είναι `300`.

Για παράδειγμα κώδικα, δείτε αυτήν την [τεκμηρίωση](https://docs.groupdocs.com/viewer/net/optimization-pdf-set-max-resolution/).
