## PdfOptimizationOptions.OptimizeSpreadsheets property

Ενεργοποιεί τη βελτιστοποίηση των υπολογιστικών φύλλων στα αρχεία PDF.

```csharp
public bool OptimizeSpreadsheets { get; set; }
```

### Παρατηρήσεις

Αυτή η βελτιστοποίηση επιτρέπει τη μείωση του μεγέθους του αρχείου εξόδου ορίζοντας γραμμές περιγράμματος. Επιπλέον, αφαιρεί τους χαρακτήρες Arial και Times New Roman των κωδίκων 32-127.

Για παράδειγμα κώδικα, δείτε αυτήν την [τεκμηρίωση](https://docs.groupdocs.com/viewer/net/optimization-pdf-spreadsheets/).
