## PdfOptimizationOptions.ResizeImages property

Επιτρέπει τον ορισμό της μέγιστης ανάλυσης στο παραγόμενο αρχείο PDF.

```csharp
public bool ResizeImages { get; set; }
```

### Παρατηρήσεις

Για να ενεργοποιήσετε αυτήν την επιλογή, ορίστε την ιδιότητα [`CompressImages`](../compressimages) σε `true`. Αυτή η επιλογή επιτρέπει τον ορισμό της ιδιότητας [`MaxResolution`](../maxresolution). Για παράδειγμα κώδικα, δείτε αυτή τη [τεκμηρίωση](https://docs.groupdocs.com/viewer/net/optimization-pdf-set-max-resolution/).
