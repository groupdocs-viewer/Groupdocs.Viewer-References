## PdfOptimizationOptions.ImageQuality property

Ορίζει την ποιότητα εικόνας στο αρχείο PDF εξόδου (σε ποσοστό).

```csharp
public int ImageQuality { get; set; }
```

### Παρατηρήσεις

Για να αλλάξετε την ποιότητα της εικόνας, πρώτα ορίστε την ιδιότητα [`CompressImages`](../compressimages) σε `true`. Για παράδειγμα κώδικα, δείτε αυτή τη [τεκμηρίωση](https://docs.groupdocs.com/viewer/net/optimization-pdf-reduce-image-quality/).
