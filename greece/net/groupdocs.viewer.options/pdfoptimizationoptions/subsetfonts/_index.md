## PdfOptimizationOptions.SubsetFonts property

Δημιουργεί υποσύνολα γραμματοσειρών στο παραγόμενο αρχείο PDF.

```csharp
public bool SubsetFonts { get; set; }
```

### Παρατηρήσεις

Εάν το αρχείο χρησιμοποιεί ενσωματωμένες γραμματοσειρές, περιέχει όλα τα δεδομένα γραμματοσειράς. Το GroupDocs.Viewer μπορεί να υποσύνολο ενσωματωμένων γραμματοσειρών για να μειώσει το μέγεθος του αρχείου. Για παράδειγμα κώδικα, δείτε αυτήν την [τεκμηρίωση](https://docs.groupdocs.com/viewer/net/optimization-pdf-subset-fonts/).
