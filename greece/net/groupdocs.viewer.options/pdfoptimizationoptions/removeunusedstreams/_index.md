## PdfOptimizationOptions.RemoveUnusedStreams property

Αφαιρεί αχρησιμοποίητες (ορφανές) ροές από ένα αρχείο PDF, οι οποίες εξακολουθούν να αναφέρονται από το λεξικό πόρων της σελίδας, αλλά στην πραγματικότητα δεν χρησιμοποιούνται ποτέ στο περιεχόμενο της σελίδας. Από προεπιλογή είναι απενεργοποιημένη (`false`), η ενεργοποίησή της (`true`) θα μειώσει το μέγεθος του παραγόμενου εγγράφου PDF.

```csharp
public bool RemoveUnusedStreams { get; set; }
```
