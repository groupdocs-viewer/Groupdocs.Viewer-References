## PdfOptimizationOptions.RemoveUnusedObjects property

Αφαιρεί αχρησιμοποίητα (ορφανά) αντικείμενα από ένα αρχείο PDF, τα οποία τοποθετούνται στο έγγραφο PDF, αλλά δεν αναφέρονται από τα λεξικά πόρων καμίας σελίδας και έτσι δεν χρησιμοποιούνται καθόλου. Η ενεργοποίηση αυτής της ιδιότητας (`true`) θα μειώσει το μέγεθος του παραγόμενου εγγράφου PDF. Από προεπιλογή είναι απενεργοποιημένη (`false`).

```csharp
public bool RemoveUnusedObjects { get; set; }
```
