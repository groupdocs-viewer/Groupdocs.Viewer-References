## JpgViewOptions.MaxWidth property

Ορίζει το μέγιστο πλάτος μιας εικόνας εξόδου (σε εικονοστοιχεία).

```csharp
public int MaxWidth { get; set; }
```

### Παρατηρήσεις

Χρησιμοποιήστε αυτήν την ιδιότητα για να ορίσετε το μέγιστο πλάτος της εικόνας εξόδου (σε εικονοστοιχεία). Για παράδειγμα κώδικα, δείτε την [τεκμηρίωση](https://docs.groupdocs.com/viewer/net/set-image-size-limits-when-rendering-to-png-jpg/).

Εάν ορίσετε την ιδιότητα [`Width`](../width), αυτή η ιδιότητα αγνοείται.
