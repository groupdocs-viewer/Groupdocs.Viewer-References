## JpgViewOptions.Quality property

Ορίζει την ποιότητα της εικόνας εξόδου.

```csharp
public byte Quality { get; set; }
```

### Παρατηρήσεις

Χρησιμοποιήστε αυτήν την ιδιότητα για να ρυθμίσετε την ποιότητα των εικόνων. Η τιμή πρέπει να είναι μεταξύ 1 (ελάχιστη ποιότητα) και 100. Η προεπιλεγμένη τιμή είναι 90.

Για παράδειγμα κώδικα, δείτε την [τεκμηρίωση](https://docs.groupdocs.com/viewer/net/image-viewer-adjust-quality-for-jpg/).
