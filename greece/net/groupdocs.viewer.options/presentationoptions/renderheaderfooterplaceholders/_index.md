## PresentationOptions.RenderHeaderFooterPlaceholders property

Ενεργοποιεί την απόδοση των placeholders στην κεφαλίδα και το υποσέλιδο μιας διαφάνειας. Απενεργοποιημένο από προεπιλογή (`false`). Αυτή η επιλογή ισχύει για όλες τις 4 λειτουργίες απόδοσης των παρουσιάσεων: HTML, PDF, PNG και JPEG. Δεν εφαρμόζεται όταν η παρουσίαση αποδίδεται σε καθαρό HTML/CSS markup χρησιμοποιώντας [`RenderToPureHtml`](../rendertopurehtml).

```csharp
public bool RenderHeaderFooterPlaceholders { get; set; }
```
