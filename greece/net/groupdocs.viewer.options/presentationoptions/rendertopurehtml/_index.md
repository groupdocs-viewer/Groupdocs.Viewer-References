## PresentationOptions.RenderToPureHtml property

Ενεργοποιεί μια νέα λειτουργία απόδοσης HTML για τα έγγραφα Presentation — σε αυτή τη λειτουργία τα αρχεία Presentation αποδίδονται σε **pure HTML/CSS markup**, χωρίς εικόνες SVG. Από προεπιλογή είναι απενεργοποιημένο (`false`) — χρησιμοποιείται ο υπάρχων HTML-renderer βασισμένος σε SVG.

```csharp
public bool RenderToPureHtml { get; set; }
```
