## SearchHighlightOptions.SearchTerm property

Λαμβάνει ή ορίζει το κείμενο (ή το πρότυπο regex, εάν η ιδιότητα [`IsSearchTermRegEx`](../issearchtermregex) είναι `true`) για αναζήτηση.

```csharp
public string SearchTerm { get; set; }
```

### Παρατηρήσεις

Εάν η [`IsSearchTermRegEx`](../issearchtermregex) είναι `true`, αυτή η ιδιότητα πρέπει να περιέχει ένα έγκυρο πρότυπο κανονικής έκφρασης.
