## CadOptions.EnablePerformanceConversionMode property

Ορίζοντας αυτή τη σημαία σε `true` ενεργοποιεί μια ειδική λειτουργία μετατροπής προσανατολισμένη στην απόδοση για όλες τις μορφές της οικογένειας CAD — σε αυτή τη λειτουργία η ταχύτητα μετατροπής είναι πολύ πιο γρήγορη, αλλά η ποιότητα των παραγόμενων εγγράφων είναι σημαντικά χειρότερη. Από προεπιλογή είναι απενεργοποιημένη (`false`) — η ποιότητα των παραγόμενων εγγράφων είναι η καλύτερη δυνατή με κόστος στην απόδοση.

```csharp
public bool EnablePerformanceConversionMode { get; set; }
```
