## BaseViewOptions.RemoveComments property

Απενεργοποιεί την απόδοση σχολίων όταν ορίζεται σε `true`. Από προεπιλογή είναι `false` — όλα τα σχόλια εμφανίζονται.

```csharp
public bool RemoveComments { get; set; }
```

### Παρατηρήσεις

Ορισμένες μορφές εγγράφων όπως PDF και WordProcessing ενδέχεται να περιέχουν σχόλια. Από προεπιλογή το GroupDocs.Viewer τα αποδίδει. Με αυτήν την επιλογή ορισμένη σε `true` τα σχόλια μπορεί να εξαιρεθούν από το τελικό έγγραφο.

Αυτή η επιλογή αντικαθιστά την παρωχημένη ιδιότητα 'RenderComments'.
