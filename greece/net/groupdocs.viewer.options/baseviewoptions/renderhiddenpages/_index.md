## BaseViewOptions.RenderHiddenPages property

Ενεργοποιεί την απόδοση κρυφών σελίδων.

```csharp
public bool RenderHiddenPages { get; set; }
```

### Παρατηρήσεις

Ορισμένα αρχεία, όπως παρουσιάσεις ή λογιστικά φύλλα, ενδέχεται να περιέχουν κρυφές σελίδες. Από προεπιλογή, το GroupDocs.Viewer δεν αποδίδει αυτές τις σελίδες. Για να το κάνετε αυτό, ορίστε αυτήν την ιδιότητα σε `true`.

Για παράδειγμα κώδικα, δείτε την [τεκμηρίωση](https://docs.groupdocs.com/viewer/net/render-presentations/#render-hidden-slides).
