## HtmlViewOptions.RenderResponsive property

Ενεργοποιεί την ανταποκρινόμενη απόδοση.

```csharp
public bool RenderResponsive { get; set; }
```

### Παρατηρήσεις

Ο σχεδιασμός responsive στοχεύει στο να κάνει τις ιστοσελίδες να αποδίδουν καλά σε ποικίλες συσκευές. Για να αποδώσετε με responsive διάταξη, ορίστε αυτή την ιδιότητα σε `true`.

Για παράδειγμα κώδικα, δείτε την [τεκμηρίωση](https://docs.groupdocs.com/viewer/net/render-with-responsive-layout/).
