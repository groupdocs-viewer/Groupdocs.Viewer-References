## HtmlViewOptions.FontsToExclude property

Η λίστα με τα ονόματα γραμματοσειρών που θα εξαλειφθούν από το έγγραφο HTML.

```csharp
public List<string> FontsToExclude { get; set; }
```

### Παρατηρήσεις

Οι γραμματοσειρές που προστίθενται στο HTML έγγραφο βελτιώνουν τη σταθερότητα της τελικής προβολής, ενώ ταυτόχρονα αυξάνουν το μέγεθος του αποτελέσματος απόδοσης. Αυτή η επιλογή σας επιτρέπει να ισορροπήσετε μεταξύ σταθερότητας και μεγέθους εξόδου. Συμπεριλάβετε τα ονόματα γραμματοσειρών που είναι δημοφιλή και εγκατεστημένα στα περισσότερα συστήματα.

Παρακαλούμε σημειώστε ότι αυτή η ιδιότητα είναι ενεργή μόνο όταν η επιλογή [`ExcludeFonts`](../excludefonts) είναι απενεργοποιημένη.

Για λεπτομέρειες και παράδειγμα κώδικα, δείτε την [τεκμηρίωση](https://docs.groupdocs.com/viewer/net/exclude-fonts/).
