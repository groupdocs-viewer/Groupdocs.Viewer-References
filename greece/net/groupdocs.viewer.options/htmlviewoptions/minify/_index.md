## HtmlViewOptions.Minify property

Ενεργοποιεί τη συμπίεση περιεχομένου HTML και πόρων HTML.

```csharp
public bool Minify { get; set; }
```

### Παρατηρήσεις

Η συμπίεση του εξαγόμενου περιεχομένου (HTML, CSS και SVG) είναι ένας από τους τρόπους βελτιστοποίησης του αρχείου HTML. Για να το κάνετε αυτό, ορίστε αυτήν την ιδιότητα σε `true`.

Για παράδειγμα κώδικα, δείτε την [τεκμηρίωση](https://docs.groupdocs.com/viewer/net/minify-html/).
