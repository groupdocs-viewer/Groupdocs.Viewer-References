## HtmlViewOptions.ExcludeFonts property

Απενεργοποιεί την προσθήκη οποιασδήποτε γραμματοσειράς στο έγγραφο HTML.

```csharp
public bool ExcludeFonts { get; set; }
```

### Παρατηρήσεις

Από προεπιλογή, το GroupDocs.Viewer ενσωματώνει τις γραμματοσειρές που χρησιμοποιούνται στο έγγραφο στο HTML markup, και αυτή η ιδιότητα έχει τιμή `false`. Για να αποτρέψετε την ενσωμάτωση γραμματοσειρών, ορίστε αυτή την ιδιότητα σε `true`.

Για λεπτομέρειες και παράδειγμα κώδικα, δείτε την [τεκμηρίωση](https://docs.groupdocs.com/viewer/net/exclude-fonts/).
