## HtmlViewOptions.RemoveJavaScript property

Επιτρέπει την αφαίρεση του κώδικα πηγαίου JavaScript από τους συνδέσμους στα τελικά έγγραφα HTML, κατά την απόδοση των εισερχόμενων εγγράφων που περιέχουν τα σενάρια. Από προεπιλογή είναι ενεργοποιημένο (`true`).

```csharp
public bool RemoveJavaScript { get; set; }
```

### Παρατηρήσεις

Για λεπτομέρειες σχετικά με την αφαίρεση του JavaScript, δείτε την [τεκμηρίωση](https://docs.groupdocs.com/viewer/net/rendering-to-html/#preserving-or-disabling-javascript-when-rendering-to-html).
