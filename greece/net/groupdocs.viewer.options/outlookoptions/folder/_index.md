## OutlookOptions.Folder property

Ορίζει το όνομα του φακέλου (π.χ. Inbox, Sent Item ή Deleted Items) που θα αποδοθεί.

```csharp
public string Folder { get; set; }
```

### Παρατηρήσεις

Κατά την απόδοση ενός αρχείου δεδομένων Outlook, το GroupDocs.Viewer αποδίδει μηνύματα από όλους τους φακέλους που περιέχονται στο αρχείο (συμπεριλαμβανομένων των ένθετων φακέλων). Χρησιμοποιήστε αυτή την ιδιότητα για να αποδώσετε στοιχεία από συγκεκριμένο φάκελο.

Για παράδειγμα κώδικα, δείτε αυτή τη [τεκμηρίωση](https://docs.groupdocs.com/viewer/net/render-outlook-data-files/#render-a-specific-folder).
