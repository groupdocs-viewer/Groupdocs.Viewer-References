Ο ονοματοχώρος παρέχει διεπαφές για τη δημιουργία και την απελευθέρωση του τελικού εγγράφου και των πόρων του.

## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [CreateFileStream](./createfilestream) | Αντιπροσωπεύει τη μέθοδο που δημιουργεί τη ροή που χρησιμοποιείται για την εγγραφή των δεδομένων του αρχείου εξόδου. |
| [CreatePageStream](./createpagestream) | Αντιπροσωπεύει τη μέθοδο που δημιουργεί τη ροή που χρησιμοποιείται για την εγγραφή των δεδομένων της σελίδας εξόδου. |
| [CreateResourceStream](./createresourcestream) | Αντιπροσωπεύει τη μέθοδο που δημιουργεί τη ροή που χρησιμοποιείται για την εγγραφή των δεδομένων του πόρου HTML εξόδου. |
| [CreateResourceUrl](./createresourceurl) | Αντιπροσωπεύει τη μέθοδο που δημιουργεί το URL για τον πόρο HTML. |
| [ReleaseFileStream](./releasefilestream) | Απελευθερώνει τη ροή που δημιουργήθηκε από τη μέθοδο που σχετίζεται με τον delegate [`CreateFileStream`](../groupdocs.viewer.interfaces/createfilestream). |
| [ReleasePageStream](./releasepagestream) | Απελευθερώνει τη ροή που δημιουργήθηκε από τη μέθοδο που σχετίζεται με τον delegate [`CreatePageStream`](../groupdocs.viewer.interfaces/createpagestream). |
| [ReleaseResourceStream](./releaseresourcestream) | Απελευθερώνει τη ροή που δημιουργήθηκε από τη μέθοδο που σχετίζεται με τον delegate [`CreateResourceStream`](../groupdocs.viewer.interfaces/createresourcestream). |
## Διεπαφές

| Διεπαφή | Περιγραφή |
| --- | --- |
| [IFileStreamFactory](./ifilestreamfactory) | Ορίζει τις μεθόδους που απαιτούνται για τη δημιουργία και την απελευθέρωση της ροής αρχείου εξόδου. |
| [IPageStreamFactory](./ipagestreamfactory) | Ορίζει τις μεθόδους που απαιτούνται για τη δημιουργία και την απελευθέρωση της ροής σελίδας εξόδου. |
| [IResourceStreamFactory](./iresourcestreamfactory) | Ορίζει τις μεθόδους που απαιτούνται για τη δημιουργία του URL πόρου, τη δημιουργία και την απελευθέρωση της ροής πόρου HTML εξόδου. |
