## Layout Inequality operator


| Παράμετρος | Type | Περιγραφή |
| --- | --- | --- |
| left | Layout | Αριστερό αντικείμενο [`Layout`](../../layout). |
| right | Layout | Δεξιό αντικείμενο [`Layout`](../../layout). |
