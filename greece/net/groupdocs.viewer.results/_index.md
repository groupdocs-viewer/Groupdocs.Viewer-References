Ο ονοματοχώρος παρέχει κλάσεις που αντιπροσωπεύουν τα αποτελέσματα απόδοσης εγγράφων.

## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [ArchiveViewInfo](./archiveviewinfo) | Αντιπροσωπεύει πληροφορίες προβολής για αρχείο αρχειοθήκης. |
| [Attachment](./attachment) | Αντιπροσωπεύει αρχείο συνημμένου που περιέχεται σε μήνυμα email, αρχείο αρχειοθήκης, έγγραφο PDF ή αρχείο δεδομένων Outlook. |
| [CadViewInfo](./cadviewinfo) | Αντιπροσωπεύει πληροφορίες προβολής για σχέδιο CAD. |
| [Character](./character) | Αντιπροσωπεύει ορθογώνιο σχετικό θέση που περιέχει έναν μόνο χαρακτήρα. |
| [FileInfo](./fileinfo) | Περιέχει πληροφορίες σχετικά με το αρχείο. |
| [Layer](./layer) | Αντιπροσωπεύει στρώση που περιέχεται στο σχέδιο CAD. |
| [Layout](./layout) | Αντιπροσωπεύει διάταξη που περιέχεται στο σχέδιο CAD. |
| [Line](./line) | Αντιπροσωπεύει ορθογώνιο σχετικό θέση που περιέχει μια μόνο γραμμή. |
| [LotusNotesViewInfo](./lotusnotesviewinfo) | Αντιπροσωπεύει πληροφορίες προβολής για αποθήκευση βάσης δεδομένων Lotus Notes. |
| [MailMessageViewInfo](./mailmessageviewinfo) | Αντιπροσωπεύει πληροφορίες προβολής για ένα μήνυμα email. |
| [MboxViewInfo](./mboxviewinfo) | Αντιπροσωπεύει πληροφορίες προβολής για αποθήκευση αρχείων Mbox. |
| [OutlookViewInfo](./outlookviewinfo) | Αντιπροσωπεύει πληροφορίες προβολής για αρχείο δεδομένων Outlook. |
| [Page](./page) | Αντιπροσωπεύει μία σελίδα που μπορεί να προβληθεί. |
| [PdfViewInfo](./pdfviewinfo) | Αντιπροσωπεύει πληροφορίες προβολής για έγγραφο PDF. |
| [ProjectManagementViewInfo](./projectmanagementviewinfo) | Αντιπροσωπεύει πληροφορίες προβολής για έγγραφο MS Project. |
| [Resource](./resource) | Αντιπροσωπεύει πόρο HTML όπως γραμματοσειρά, στυλ, εικόνα ή γραφικά. |
| [TextElement&lt;T&gt;](./textelement-1) | Αντιπροσωπεύει γενικό στοιχείο κειμένου. |
| [ViewInfo](./viewinfo) | Αντιπροσωπεύει πληροφορίες προβολής για γενικό έγγραφο. |
| [Word](./word) | Αντιπροσωπεύει ορθογώνιο σχετικό θέση που περιέχει μία μόνο λέξη. |
