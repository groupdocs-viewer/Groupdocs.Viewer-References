Η κύρια κλάση σε αυτό το πακέτο είναι [CacheableFactory](../../com.groupdocs.viewer.caching.extra/cacheablefactory),
που βοηθά στην προσαρμογή της cache παρέχοντας πρόσθετη λειτουργικότητα.


Για περισσότερες λεπτομέρειες σχετικά με τη χρήση προσαρμοσμένων μοντέλων στην υλοποίηση cache στο GroupDocs.Viewer, παρακαλούμε ανατρέξτε στο
[GroupDocs.Viewer Documentation](../https://docs.groupdocs.com/viewer/java/).
