Το πακέτο παρέχει κλάσεις για τη διαμόρφωση του συστήματος καταγραφής στο GroupDocs.Viewer.


Χρησιμοποιώντας αυτές τις κλάσεις, μπορείτε να ελέγξετε πώς διαχειρίζονται τα μηνύματα καταγραφής, όπως η εγγραφή τους σε
ένα αρχείο ή την κατεύθυνσή τους σε μια συγκεκριμένη υλοποίηση καταγραφέα.

Οι κύριες κλάσεις σε αυτό το πακέτο είναι:

* [FileLogger](../../com.groupdocs.viewer.logging/filelogger) - Writes log messages to a file.
* [ViewerLogger](../../com.groupdocs.viewer.logging/viewerlogger) - Implements logging messages to an integrated or user-defined logger.


Για περισσότερες λεπτομέρειες σχετικά με τη διαμόρφωση του συστήματος καταγραφής στο GroupDocs.Viewer και την προσαρμογή της διαχείρισης μηνυμάτων καταγραφής,
παρακαλούμε ανατρέξτε στην [GroupDocs.Viewer Documentation](../https://docs.groupdocs.com/viewer/java/).
