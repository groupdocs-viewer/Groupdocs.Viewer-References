Το πακέτο παρέχει κλάσεις και διεπαφές που αντιπροσωπεύουν τα αποτελέσματα απόδοσης εγγράφων.


Αυτές οι κλάσεις περιλαμβάνουν πληροφορίες σχετικά με διάφορα στοιχεία και συστατικά του αποδοθέντος εγγράφου,
όπως σελίδες, συνημμένα, προβολές, πόροι και άλλα.

Οι κύριες κλάσεις σε αυτό το πακέτο είναι:

* [Page](../../com.groupdocs.viewer.results/page) - Represents a single page that can be viewed.
* [Attachment](../../com.groupdocs.viewer.results/attachment) - Represents an attachment file contained by an email message, archive, PDF document, or Outlook data file.
* [PdfViewInfo](../../com.groupdocs.viewer.results/pdfviewinfo) - Represents view information for a PDF document.


Για περισσότερες λεπτομέρειες σχετικά με τη δουλειά με τα αποτελέσματα απόδοσης εγγράφων χρησιμοποιώντας το GroupDocs.Viewer,
παρακαλούμε ανατρέξτε στην [GroupDocs.Viewer Documentation](../https://docs.groupdocs.com/viewer/java/).
