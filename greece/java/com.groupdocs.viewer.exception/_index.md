Το πακέτο παρέχει κλάσεις για εξαιρέσεις που μπορεί να προκύψουν κατά την εργασία με ένα έγγραφο.

Οι κύριες κλάσεις σε αυτό το πακέτο είναι:

* com.groupdocs.viewer.exception.ArchiveSecurityException - Thrown when an archive being opened exceeds specified limits.
* [FileNotFoundException](../../com.groupdocs.viewer.exception/filenotfoundexception) - Represents an exception thrown when a file or directory is not found.
* [GroupDocsViewerException](../../com.groupdocs.viewer.exception/groupdocsviewerexception) - Represents generic errors that occur during document processing.


Για περισσότερες λεπτομέρειες σχετικά με τη διαχείριση εξαιρέσεων στο GroupDocs.Viewer, παρακαλούμε ανατρέξτε στο
[GroupDocs.Viewer Documentation](../https://docs.groupdocs.com/viewer/java/).



## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [ArchiveSecurityException](../com.groupdocs.viewer.exception/archivesecurityexception) | Αυτή η εξαίρεση προκαλείται όταν ένα αρχείο που ανοίγεται υπερβαίνει οποιονδήποτε από τους περιορισμούς που καθορίζονται στις ArchiveSecurityOptions. |
| [FileNotFoundException](../com.groupdocs.viewer.exception/filenotfoundexception) | Αυτή η εξαίρεση προκαλείται όταν δεν βρεθεί ένα αρχείο ή κατάλογος. |
| [GroupDocsViewerException](../com.groupdocs.viewer.exception/groupdocsviewerexception) | Αυτή η εξαίρεση αντιπροσωπεύει γενικά σφάλματα που μπορούν να προκύψουν κατά την επεξεργασία εγγράφων. |
| [IncorrectPasswordException](../com.groupdocs.viewer.exception/incorrectpasswordexception) | Αυτή η εξαίρεση προκαλείται όταν ο καθορισμένος κωδικός πρόσβασης είναι λανθασμένος. |
| [NotSupportedException](../com.groupdocs.viewer.exception/notsupportedexception) | Αυτή η εξαίρεση προκαλείται όταν η ζητούμενη λειτουργία δεν υποστηρίζεται. |
| [PasswordRequiredException](../com.groupdocs.viewer.exception/passwordrequiredexception) | Αυτή η εξαίρεση προκαλείται όταν απαιτείται κωδικός πρόσβασης για τη φόρτωση του εγγράφου. |
