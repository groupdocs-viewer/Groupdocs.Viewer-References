Το πακέτο παρέχει κλάσεις και απαριθμήσεις για τη διαχείριση των γραμματοσειρών που χρησιμοποιούνται κατά τη διαδικασία απόδοσης.

Οι κύριες κλάσεις και διεπαφές σε αυτό το πακέτο είναι:

* [FolderFontSource](../../com.groupdocs.viewer.fonts/folderfontsource) - Represents a folder that contains TrueType fonts.
* [FontSettings](../../com.groupdocs.viewer.fonts/fontsettings) - Provides methods for working with sources to look for TrueType fonts.
* [FontSource](../../com.groupdocs.viewer.fonts/fontsource) - Marker interface for the font sources.


Για περισσότερες λεπτομέρειες σχετικά με τη χρήση γραμματοσειρών στο GroupDocs.Viewer, παρακαλούμε ανατρέξτε στο
[GroupDocs.Viewer Documentation](../https://docs.groupdocs.com/viewer/java/).



## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [FolderFontSource](../com.groupdocs.viewer.fonts/folderfontsource) | Αντιπροσωπεύει έναν φάκελο που περιέχει γραμματοσειρές TrueType. |
| [FontFormat](../com.groupdocs.viewer.fonts/fontformat) | Αντιπροσωπεύει όλες τις μορφές γραμματοσειρών, που ενδέχεται να υπάρχουν στην κλάση UsedFontInfo. |
| [FontSettings](../com.groupdocs.viewer.fonts/fontsettings) | Παρέχει μεθόδους για εργασία με πηγές που αναζητούν γραμματοσειρές TrueType. |
| [FontStyles](../com.groupdocs.viewer.fonts/fontstyles) | Αντιπροσωπεύει 4 πιθανές μορφές γραμματοσειράς, που χρησιμοποιούνται στο έγγραφο: Regular, Bold, Italic ή Bold Italic. |
| [PdfFontInfo](../com.groupdocs.viewer.fonts/pdffontinfo) | Περιλαμβάνει μεταπληροφορίες και δυαδικά δεδομένα μιας γραμματοσειράς από έγγραφο PDF, που φορτώθηκε στο αντίγραφο Viewer. |
| [PresentationFontInfo](../com.groupdocs.viewer.fonts/presentationfontinfo) | Περιλαμβάνει μεταδεδομένα και δυαδικά δεδομένα μιας γραμματοσειράς που χρησιμοποιείται σε έγγραφο Presentation, που φορτώθηκε στο αντίγραφο Viewer. |
| [SpreadsheetFontInfo](../com.groupdocs.viewer.fonts/spreadsheetfontinfo) | Περιλαμβάνει μεταπληροφορίες και δυαδικά δεδομένα μιας γραμματοσειράς από έγγραφο Spreadsheet, που φορτώθηκε στο αντίγραφο Viewer. |
| [WordProcessingFontInfo](../com.groupdocs.viewer.fonts/wordprocessingfontinfo) | Περιλαμβάνει μεταπληροφορίες και δυαδικά δεδομένα μιας γραμματοσειράς από έγγραφο WordProcessing, που φορτώθηκε στο αντίγραφο Viewer. |
| [WordProcessingSubstitutedFontInfo](../com.groupdocs.viewer.fonts/wordprocessingsubstitutedfontinfo) | Περιλαμβάνει μεταδεδομένα και δυαδικά δεδομένα μιας αντικατεστημένης γραμματοσειράς που χρησιμοποιείται σε έγγραφο WordProcessing μέσω του GroupDocs.Viewer. |
