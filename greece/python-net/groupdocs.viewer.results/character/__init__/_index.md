## __init__ {#character-x-y-width-height}

Αρχικοποιεί ένα νέο αντίγραφο του [`Character`](/viewer/python-net/groupdocs.viewer.results/character/).

```python
def __init__(self, character, x, y, width, height):
    ...
```

| Παράμετρος | Τύπος | Περιγραφή |
| :- | :- | :- |
| character | `str` | Ο χαρακτήρας. |
| x | `float` | Η συντεταγμένη X του υψηλότερου αριστερού σημείου στη διάταξη της σελίδας όπου αρχίζει το ορθογώνιο που περιέχει τον χαρακτήρα. |
| y | `float` | Η συντεταγμένη Y του υψηλότερου αριστερού σημείου στη διάταξη της σελίδας όπου αρχίζει το ορθογώνιο που περιέχει τον χαρακτήρα. |
| width | `float` | Το πλάτος του ορθογωνίου που περιέχει έναν μόνο χαρακτήρα (σε pixel). |
| height | `float` | Το ύψος του ορθογωνίου που περιέχει έναν μόνο χαρακτήρα (σε pixel). |
