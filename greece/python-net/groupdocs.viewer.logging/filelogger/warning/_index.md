## warning {#message}

Γράφει ένα μήνυμα προειδοποίησης στην κονσόλα.

Τα μηνύματα καταγραφής προειδοποιήσεων παρέχουν πληροφορίες για απρόσμενα και ανακτήσιμα γεγονότα στη ροή της εφαρμογής.

```python
def warning(self, message):
    ...
```

| Παράμετρος | Τύπος | Περιγραφή |
| :- | :- | :- |
| message | `str` | Το προειδοποιητικό μήνυμα. |

| Αναφέρει | Περιγραφή |
| :- | :- |
| `ValueError` | Ανακύπτει όταν `message` είναι None. |
