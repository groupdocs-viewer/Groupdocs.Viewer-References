## trace {#message}

Γράφει ένα μήνυμα εντοπισμού στην κονσόλα.

Τα μηνύματα καταγραφής εντοπισμού παρέχουν γενικά χρήσιμες πληροφορίες σχετικά με τη ροή της εφαρμογής.

```python
def trace(self, message):
    ...
```

| Παράμετρος | Τύπος | Περιγραφή |
| :- | :- | :- |
| message | `str` | Το μήνυμα εντοπισμού. |

| Αναφέρει | Περιγραφή |
| :- | :- |
| `ValueError` | Ανακύπτει όταν `message` είναι None. |
