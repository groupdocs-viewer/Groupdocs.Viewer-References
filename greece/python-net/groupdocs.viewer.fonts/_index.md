Διαμόρφωση φόρτωσης και αντικατάστασης γραμματοσειρών.

### Κλάσεις
| Κλάση | Περιγραφή |
| :- | :- |
| [`FolderFontSource`](/viewer/python-net/groupdocs.viewer.fonts/folderfontsource/) | Αναπαριστά το φάκελο που περιέχει γραμματοσειρές TrueType. |
| [`FontSettings`](/viewer/python-net/groupdocs.viewer.fonts/fontsettings/) | Παρέχει μεθόδους για εργασία με πηγές για την αναζήτηση γραμματοσειρών TrueType. |
| [`FontStyles`](/viewer/python-net/groupdocs.viewer.fonts/fontstyles/) | Αντιπροσωπεύει 4 πιθανές μορφές της γραμματοσειράς, που χρησιμοποιούνται στο έγγραφο: Regular, Bold, Italic ή Bold Italic. |
| [`IFontInfo`](/viewer/python-net/groupdocs.viewer.fonts/ifontinfo/) | Αντιπροσωπεύει μια κοινή διεπαφή για όλες τις γραμματοσειρές που μπορούν να εξαχθούν από όλες τις υποστηριζόμενες οικογένειες μορφών εγγράφων: PDF, WordProcessing, Spreadsheet και Presentation. |
| [`PdfFontInfo`](/viewer/python-net/groupdocs.viewer.fonts/pdffontinfo/) | Περιλαμβάνει μεταδεδομένα και δυαδικά δεδομένα μιας γραμματοσειράς PDF που φορτώθηκε σε ένα αντικείμενο του [`Viewer`](/viewer/python-net/groupdocs.viewer/viewer/), η οποία μπορεί να ενσωματωθεί στο έγγραφο ή να εγκατασταθεί στο λειτουργικό σύστημα όπου εκτελείται το GroupDocs.Viewer. |
| [`PresentationFontInfo`](/viewer/python-net/groupdocs.viewer.fonts/presentationfontinfo/) | Αντιπροσωπεύει μεταπληροφορίες και δυαδικά δεδομένα μιας γραμματοσειράς από ένα έγγραφο Presentation που φορτώθηκε σε ένα [`Viewer`](/viewer/python-net/groupdocs.viewer/viewer/) αντικείμενο. Η γραμματοσειρά χρησιμοποιείται στο περιεχόμενο του εγγράφου και μπορεί να ενσωματωθεί στο έγγραφο ή να εγκατασταθεί στο λειτουργικό σύστημα όπου εκτελείται ο viewer. |
| [`SpreadsheetFontInfo`](/viewer/python-net/groupdocs.viewer.fonts/spreadsheetfontinfo/) | Περιλαμβάνει μεταπληροφορίες και δυαδικά δεδομένα μιας γραμματοσειράς από ένα έγγραφο λογιστικού φύλλου που φορτώθηκε σε ένα [`Viewer`](/viewer/python-net/groupdocs.viewer/viewer/) αντικείμενο. Τα έγγραφα λογιστικού φύλλου δεν μπορούν να έχουν ενσωματωμένες γραμματοσειρές, έτσι μια γραμματοσειρά που επιστρέφεται από το [`Viewer.get_all_fonts`](/viewer/python-net/groupdocs.viewer/viewer/get_all_fonts/) εγκαθίσταται στο λειτουργικό σύστημα όπου εκτελείται ο viewer. |
| [`WordProcessingFontInfo`](/viewer/python-net/groupdocs.viewer.fonts/wordprocessingfontinfo/) | Περιλαμβάνει μεταπληροφορίες και δυαδικά δεδομένα μιας γραμματοσειράς από ένα έγγραφο WordProcessing που φορτώθηκε σε ένα [`Viewer`](/viewer/python-net/groupdocs.viewer/viewer/) αντικείμενο. |
| [`WordProcessingSubstitutedFontInfo`](/viewer/python-net/groupdocs.viewer.fonts/wordprocessingsubstitutedfontinfo/) | Περιλαμβάνει μεταπληροφορίες και δυαδικά δεδομένα μιας γραμματοσειράς από ένα έγγραφο WordProcessing, η οποία αρχικά δεν χρησιμοποιείται στο φορτωμένο έγγραφο του [`Viewer`](/viewer/python-net/groupdocs.viewer/viewer/), αλλά λειτουργεί ως γραμματοσειρά αντικατάστασης για εκείνες που δεν μπορούν να βρεθούν στο στόχο μηχάνημα. Οι αντικατεστημένες γραμματοσειρές υπάρχουν μόνο για την οικογένεια μορφών WordProcessing. |
