## format property

Η μορφή αυτής της γραμματοσειράς.

Τα έγγραφα ενδέχεται να χρησιμοποιούν γραμματοσειρές στις ακόλουθες μορφές: TrueType, TrueType Collection, OpenType, Embedded OpenType. Εάν είναι διαθέσιμα μόνο μεταδεδομένα για τη γραμματοσειρά και το δυαδικό της περιεχόμενο λείπει, η ιδιότητα επιστρέφει `FontFormat.unknown`.
