## format property

Η μορφή αυτής της αντικατεστημένης (μη αρχικής) γραμματοσειράς.

Μπορεί να είναι TrueType, TrueType Collection, OpenType, Embedded OpenType. Για την αντικατεστημένη γραμματοσειρά, επειδή το δυαδικό της περιεχόμενο είναι διαθέσιμο κατ' ορισμό, αυτή η ιδιότητα δεν επιστρέφει ποτέ τιμή `FontFormat.unknown`.
