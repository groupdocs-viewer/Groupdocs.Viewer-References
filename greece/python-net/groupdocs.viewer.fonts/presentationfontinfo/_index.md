## PresentationFontInfo class

Αντιπροσωπεύει μεταπληροφορίες και δυαδικά δεδομένα μιας γραμματοσειράς από ένα έγγραφο Presentation που φορτώθηκε σε ένα [`Viewer`](/viewer/python-net/groupdocs.viewer/viewer/) αντικείμενο. Η γραμματοσειρά χρησιμοποιείται στο περιεχόμενο του εγγράφου και μπορεί να ενσωματωθεί στο έγγραφο ή να εγκατασταθεί στο λειτουργικό σύστημα όπου εκτελείται ο viewer.
