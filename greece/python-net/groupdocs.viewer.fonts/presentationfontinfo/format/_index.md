## format property

Η μορφή αυτής της γραμματοσειράς.

Τα έγγραφα ενδέχεται να χρησιμοποιούν γραμματοσειρές στις ακόλουθες μορφές: TrueType, TrueType Collection, OpenType, Embedded OpenType. Εάν είναι διαθέσιμα μόνο μεταδεδομένα για αυτή τη γραμματοσειρά και το δυαδικό της περιεχόμενο δεν είναι διαθέσιμο, η ιδιότητα επιστρέφει `FontFormat.unknown`.
