## is_embedded property

Η ιδιότητα υποδεικνύει εάν η γραμματοσειρά είναι ενσωματωμένη μέσα στο έγγραφο και φορτώθηκε στην [`Viewer`](/viewer/python-net/groupdocs.viewer/viewer/) παρουσία (`True`), ή είναι γραμματοσειρά συστήματος (`False`).

Τα έγγραφα Spreadsheet δεν μπορούν να περιέχουν ενσωματωμένες γραμματοσειρές, επομένως αυτή η ιδιότητα πάντα επιστρέφει `False` για αυτά.
