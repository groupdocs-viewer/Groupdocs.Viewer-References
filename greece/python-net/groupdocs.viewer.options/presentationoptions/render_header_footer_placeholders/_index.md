## render_header_footer_placeholders property

Η ιδιότητα ενεργοποιεί την απόδοση δεσμευτικών θέσεων στην κεφαλίδα και το υποσέλιδο μιας διαφάνειας.

Απενεργοποιείται από προεπιλογή (`False`). Αυτή η επιλογή ισχύει για όλες τις τέσσερις λειτουργίες απόδοσης παρουσιάσεων: HTML, PDF, PNG και JPEG. Δεν εφαρμόζεται όταν η παρουσίαση αποδίδεται σε καθαρό HTML/CSS markup χρησιμοποιώντας [`PresentationOptions.render_to_pure_html`](/viewer/python-net/groupdocs.viewer.options/presentationoptions/render_to_pure_html/).
