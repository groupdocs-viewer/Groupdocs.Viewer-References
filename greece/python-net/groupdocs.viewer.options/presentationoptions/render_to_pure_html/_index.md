## render_to_pure_html property

Η ιδιότητα ενεργοποιεί μια νέα λειτουργία απόδοσης HTML για έγγραφα Presentation — σε αυτή τη λειτουργία τα αρχεία αποδίδονται σε καθαρό σήμανση HTML/CSS χωρίς εικόνες SVG. Από προεπιλογή είναι απενεργοποιημένη (`False`), και χρησιμοποιείται ο υπάρχων HTML renderer βασισμένος σε SVG.

Για παράδειγμα κώδικα, δείτε την τεκμηρίωση στο https://docs.groupdocs.com/viewer/net/render-presentations/#generate-pure-htmlcss-markup.
