## default_font_name property

Η προεπιλεγμένη γραμματοσειρά για ένα έγγραφο που χρησιμοποιείται κατά την απόδοση όταν λείπει η απαιτούμενη γραμματοσειρά.

Χρησιμοποιήστε αυτή την ιδιότητα για να ορίσετε την προεπιλεγμένη γραμματοσειρά για ένα έγγραφο. Το GroupDocs.Viewer χρησιμοποιεί αυτή τη γραμματοσειρά κατά την απόδοση αντί για οποιεσδήποτε μη εγκατεστημένες γραμματοσειρές.
