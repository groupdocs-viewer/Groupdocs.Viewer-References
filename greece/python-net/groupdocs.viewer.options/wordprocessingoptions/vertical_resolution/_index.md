## vertical_resolution property

Η κάθετη ανάλυση για τις παραγόμενες εικόνες σε κουκκίδες ανά ίντσα, χρησιμοποιείται μόνο κατά την απόδοση εγγράφων WordProcessing σε μορφές PNG ή JPEG.

Η προεπιλεγμένη τιμή είναι 96 DPI.

Η ελάχιστη δυνατή τιμή είναι 72 DPI και η μέγιστη δυνατή τιμή είναι 600 DPI. Εάν μια τιμή που καθορίζεται από το χρήστη είναι εκτός αυτών των ορίων, θα εφαρμοστεί το πλησιέστερο όριο.
