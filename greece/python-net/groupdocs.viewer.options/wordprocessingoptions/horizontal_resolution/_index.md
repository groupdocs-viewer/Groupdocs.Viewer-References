## horizontal_resolution property

Η οριζόντια ανάλυση για τις παραγόμενες εικόνες σε κουκκίδες ανά ίντσα. Αυτή η επιλογή χρησιμοποιείται μόνο κατά την απόδοση εγγράφων WordProcessing σε μορφές PNG ή JPEG.

Η προεπιλεγμένη τιμή είναι 96 DPI. Η ελάχιστη δυνατή τιμή είναι 72 DPI· η μέγιστη δυνατή τιμή είναι 600 DPI. Εάν μια τιμή που καθορίζεται από το χρήστη είναι εκτός αυτών των ορίων, θα εφαρμοστεί το πλησιέστερο όριο (ελάχιστο ή μέγιστο).
