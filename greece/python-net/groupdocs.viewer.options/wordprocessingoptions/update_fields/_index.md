## update_fields property

Η ιδιότητα καθορίζει εάν πεδία ορισμένων τύπων ενημερώνονται πριν από την αποθήκευση του εγγράφου WordProcessing σε μορφές HTML, PDF, PNG ή JPEG. Η προεπιλογή είναι True, που σημαίνει ότι τα πεδία ενημερώνονται.

Για λεπτομέρειες, δείτε την τεκμηρίωση: https://docs.groupdocs.com/viewer/net/render-word-documents/#disable-updating-fields-when-saving
