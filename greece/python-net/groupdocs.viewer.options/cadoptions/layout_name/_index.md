## layout_name property

Το όνομα της συγκεκριμένης διάταξης για απόδοση. Το όνομα διάταξης είναι ευαίσθητο σε πεζά/κεφαλαία.

Αυτή η επιλογή είναι διαθέσιμη μόνο για τα CAD σχέδια που υποστηρίζουν διατάξεις: [`FileType.dxf`](/viewer/python-net/groupdocs.viewer/filetype/dxf/), [`FileType.dwg`](/viewer/python-net/groupdocs.viewer/filetype/dwg/), [`FileType.dwt`](/viewer/python-net/groupdocs.viewer/filetype/dwt/), [`FileType.dwf`](/viewer/python-net/groupdocs.viewer/filetype/dwf/), και [`FileType.dwfx`](/viewer/python-net/groupdocs.viewer/filetype/dwfx/); Από προεπιλογή μόνο το Model αποδίδεται.
