## extract_text property

Η ιδιότητα ενεργοποιεί την εξαγωγή κειμένου.

Χρησιμοποιήστε αυτήν την ιδιότητα για να λάβετε το κείμενο που περιέχεται σε ένα έγγραφο προέλευσης και τις συντεταγμένες του. Στη συνέχεια, μπορείτε να χρησιμοποιήσετε αυτά τα δεδομένα για να προσθέσετε επιλέξιμο κείμενο πάνω στην εικόνα ή για να υλοποιήσετε αναζήτηση κειμένου σε απόδοση βασισμένη σε εικόνα.

Για παράδειγμα κώδικα, δείτε την τεκμηρίωση: https://docs.groupdocs.com/viewer/net/image-viewer-get-text-coordinates/
