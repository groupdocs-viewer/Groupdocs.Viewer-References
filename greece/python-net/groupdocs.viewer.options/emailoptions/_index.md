## EmailOptions class

Περιέχει επιλογές για απόδοση μηνυμάτων ηλεκτρονικού ταχυδρομείου.

Το GroupDocs.Viewer υποστηρίζει την κλάση EmailOptions που σας επιτρέπει να καθορίσετε διαφορετικές επιλογές για την απόδοση μηνυμάτων email. Για να αποκτήσετε πρόσβαση σε αυτές τις επιλογές, χρησιμοποιήστε την ιδιότητα EmailOptions σε μία από τις παρακάτω κλάσεις επιλογών προβολής, ανάλογα με τη ζητούμενη μορφή εξόδου:

- [`HtmlViewOptions`](/viewer/python-net/groupdocs.viewer.options/htmlviewoptions/)
- [`PdfViewOptions`](/viewer/python-net/groupdocs.viewer.options/pdfviewoptions/)
- [`PngViewOptions`](/viewer/python-net/groupdocs.viewer.options/pngviewoptions/)
- [`JpgViewOptions`](/viewer/python-net/groupdocs.viewer.options/jpgviewoptions/)

Ο τύπος EmailOptions εκθέτει τα παρακάτω μέλη:
