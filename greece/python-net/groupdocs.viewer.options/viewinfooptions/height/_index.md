## height property

Το ύψος της εξαγόμενης εικόνας (σε εικονοστοιχεία, μόνο για απόδοση σε PNG/JPG).

Χρησιμοποιήστε αυτήν την ιδιότητα για να ορίσετε το ύψος της εξαγόμενης εικόνας (σε εικονοστοιχεία). Για παράδειγμα κώδικα, δείτε την τεκμηρίωση.
