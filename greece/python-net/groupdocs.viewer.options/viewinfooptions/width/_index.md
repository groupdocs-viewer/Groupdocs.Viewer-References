## width property

Χρησιμοποιήστε αυτήν την ιδιότητα για να ορίσετε το πλάτος της εξαγόμενης εικόνας (σε εικονοστοιχεία). Για παράδειγμα κώδικα, δείτε την τεκμηρίωση.
