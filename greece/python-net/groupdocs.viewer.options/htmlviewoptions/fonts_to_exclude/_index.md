## fonts_to_exclude property

Η λίστα με τα ονόματα γραμματοσειρών που θα εξαλειφθούν από το έγγραφο HTML.

Οι γραμματοσειρές που προστίθενται στο έγγραφο HTML βελτιώνουν τη σταθερότητα της προβολής εξόδου, ενώ ταυτόχρονα αυξάνουν το μέγεθος του αποτελέσματος απόδοσης. Αυτή η επιλογή σας επιτρέπει να ισορροπήσετε μεταξύ σταθερότητας και μεγέθους εξόδου. Συμπεριλάβετε τα ονόματα γραμματοσειρών που είναι δημοφιλή και εγκατεστημένα στα περισσότερα συστήματα.

Παρακαλώ σημειώστε, αυτή η ιδιότητα είναι ενεργή μόνο όταν οι επιλογές [`HtmlViewOptions.ExcludeFonts`](/viewer/python-net/groupdocs.viewer.options/htmlviewoptions/exclude_fonts/) είναι απενεργοποιημένες.
