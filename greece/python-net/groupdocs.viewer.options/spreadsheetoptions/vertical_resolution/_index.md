## vertical_resolution property

Η κάθετη ανάλυση για τις παραγόμενες εικόνες σε σημεία ανά ίντσα. Αυτή η επιλογή χρησιμοποιείται μόνο όταν γίνεται απόδοση λογιστικών φύλλων σε μορφές PNG ή JPEG.

Η προεπιλεγμένη τιμή είναι 96 DPI. Η ελάχιστη δυνατή τιμή είναι 72 DPI· η μέγιστη δυνατή τιμή είναι 600 DPI. Εάν μια τιμή που καθορίζεται από τον χρήστη είναι εκτός αυτών των ορίων, θα εφαρμοστεί το πλησιέστερο όριο.
