## disable_chars_grouping property

Η ιδιότητα απενεργοποιεί την ομαδοποίηση συμβόλων για ακριβή τοποθέτηση συμβόλων κατά την απόδοση της σελίδας.

Κατά τη μετατροπή αρχείων PDF, το GroupDocs.Viewer ομαδοποιεί μεμονωμένους χαρακτήρες σε λέξεις για βελτιωμένη απόδοση. Εάν το έγγραφό σας περιλαμβάνει ιερογλυφικά ή ειδικά σύμβολα, ίσως θέλετε να απαγορεύσετε την ομαδοποίηση χαρακτήρων για να εξασφαλίσετε πιο ακριβή διάταξη. Η προεπιλεγμένη τιμή είναι False.
