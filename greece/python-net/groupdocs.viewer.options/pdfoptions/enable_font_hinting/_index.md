## enable_font_hinting property

Η ιδιότητα ενεργοποιεί την υποδείξη γραμματοσειράς.

Η υποδείξη γραμματοσειράς (font hinting) ρυθμίζει τον τρόπο εμφάνισης μιας γραμματοσειράς περιγράμματος. Ισχύει μόνο για γραμματοσειρές TTF που χρησιμοποιούνται στο πηγαίο έγγραφο. Αυτή η επιλογή είναι διαθέσιμη για απόδοση σε μορφές PNG ή JPG. Η προεπιλεγμένη τιμή είναι False.
