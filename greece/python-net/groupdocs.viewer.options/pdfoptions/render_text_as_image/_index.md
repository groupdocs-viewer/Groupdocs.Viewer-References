## render_text_as_image property

Η επιλογή ενεργοποιεί την απόδοση κειμένων σε αρχεία PDF ως εικόνα στην έξοδο HTML.

Όταν αυτή η επιλογή οριστεί σε True, το GroupDocs.Viewer αποδίδει το κείμενο ως εικόνα στην έξοδο HTML. Αυτό καθιστά το κείμενο μη επιλέξιμο και βελτιώνει την απόδοση χαρακτήρων, εξασφαλίζοντας εμφάνιση παρόμοια με PDF στο HTML. Η προεπιλεγμένη τιμή είναι False.

Αυτή η επιλογή είναι διαθέσιμη για απόδοση σε HTML.
