## TIFF field

Το Tagged Image File Format (.tiff) αντιπροσωπεύει ραστερικές εικόνες που προορίζονται για χρήση σε ποικίλες συσκευές που συμμορφώνονται με αυτό το πρότυπο μορφής αρχείου. Είναι ικανό να περιγράφει δεδομένα εικόνας διπλού επιπέδου, γκρι κλίμακας, χρωματικής παλέτας και πλήρους χρώματος σε διάφορους χρωματικούς χώρους. Μάθετε περισσότερα για αυτή τη μορφή αρχείου εδώ.
