## DWG field

Το AutoCAD Drawing Database File (.dwg) αντιπροσωπεύει ιδιόκτητα δυαδικά αρχεία που χρησιμοποιούνται για την αποθήκευση δεδομένων σχεδίασης 2D και 3D. Όπως το DXF, που είναι αρχεία ASCII, το DWG αντιπροσωπεύει τη δυαδική μορφή αρχείου για σχέδια CAD (Computer Aided Design). Μάθετε περισσότερα για αυτή τη μορφή αρχείου εδώ.
