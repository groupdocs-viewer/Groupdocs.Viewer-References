## XLTX field

Το Excel Open XML Spreadsheet Template (.xltx) αντιπροσωπεύει το Microsoft Excel Template που βασίζεται στις προδιαγραφές του αρχείου Office OpenXML. Χρησιμοποιείται για τη δημιουργία ενός τυπικού αρχείου προτύπου που μπορεί να αξιοποιηθεί για την παραγωγή αρχείων XLSX με τις ίδιες ρυθμίσεις όπως ορίζονται στο αρχείο XLTX. Μάθετε περισσότερα για αυτό το μορφότυπο αρχείου εδώ.
