## VDX field

Το Visio Drawing XML File (.vdx) αντιπροσωπεύει οποιοδήποτε σχέδιο ή διάγραμμα που δημιουργείται στο Microsoft Visio, αλλά αποθηκεύεται σε μορφότυπο XML με επέκταση .VDX. Ένα αρχείο Visio drawing XML δημιουργείται στο λογισμικό Visio, το οποίο αναπτύχθηκε από τη Microsoft. Μάθετε περισσότερα για αυτό το μορφότυπο αρχείου εδώ.
