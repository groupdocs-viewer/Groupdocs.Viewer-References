## GZIP field

Το Gnu Zipped File (.gzip) εισήχθη ως δωρεάν βοηθητικό πρόγραμμα για την αντικατάσταση του προγράμματος Compress που χρησιμοποιείται σε συστήματα Unix. Τέτοια αρχεία μπορούν να ανοιχτούν και να εξαχθούν με διάφορες εφαρμογές όπως το WinZip, το οποίο είναι διαθέσιμο τόσο για Windows όσο και για MacOS. Μάθετε περισσότερα για αυτή τη μορφή αρχείου εδώ.
