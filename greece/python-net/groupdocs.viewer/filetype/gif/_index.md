## GIF field

Το Graphical Interchange Format File (.gif) είναι ένας τύπος εξαιρετικά συμπιεσμένης εικόνας. Για κάθε εικόνα, το GIF επιτρέπει συνήθως έως 8 bits ανά pixel και έως 256 χρώματα σε όλη την εικόνα. Μάθετε περισσότερα για αυτή τη μορφή αρχείου εδώ.
