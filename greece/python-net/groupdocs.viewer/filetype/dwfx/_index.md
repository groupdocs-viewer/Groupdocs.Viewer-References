## DWFX field

Το Design Web Format File XPS (.dwfx) αντιπροσωπεύει σχέδιο 2D/3D ως έγγραφο XPS σε συμπιεσμένη μορφή για προβολή, ανασκόπηση ή εκτύπωση αρχείων σχεδίου. Περιέχει γραφικά και κείμενο ως μέρος των δεδομένων σχεδίου και μειώνει το μέγεθος του αρχείου λόγω της συμπιεσμένης μορφής του. Μάθετε περισσότερα για αυτή τη μορφή αρχείου εδώ.
