## VTX field

Το Visio Template XML File (.vtx) είναι ένα πρότυπο σχεδίου Microsoft Visio που αποθηκεύεται σε δίσκο σε μορφότυπο XML. Το πρότυπο αποσκοπεί στην παροχή ενός αρχείου με βασικές ρυθμίσεις που μπορούν να χρησιμοποιηθούν για τη δημιουργία πολλαπλών αρχείων Visio με τις ίδιες ρυθμίσεις.
