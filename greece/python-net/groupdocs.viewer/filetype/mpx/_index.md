## MPX field

Το αρχείο Microsoft Project Exchange (.mpx) είναι μια μορφή αρχείου ASCII για τη μεταφορά πληροφοριών έργου μεταξύ του Microsoft Project (MSP) και άλλων εφαρμογών που υποστηρίζουν τη μορφή αρχείου MPX, όπως το Primavera Project Planner, το Sciforma και το Timerline Precision Estimating.
