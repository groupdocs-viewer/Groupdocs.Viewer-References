## XLT field

Το Microsoft Excel Template (.xlt) είναι αρχεία προτύπων που δημιουργούνται με το Microsoft Excel, μια εφαρμογή λογιστικού φύλλου που αποτελεί μέρος της σουίτας Microsoft Office. Το Microsoft Office 97-2003 υποστήριζε τη δημιουργία νέων αρχείων XLT καθώς και το άνοιγμά τους. Μάθετε περισσότερα για αυτό το μορφότυπο αρχείου εδώ.
