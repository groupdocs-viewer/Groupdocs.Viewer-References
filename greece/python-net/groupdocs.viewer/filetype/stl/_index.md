## STL field

Το Stereolithography File (.stl) είναι μια εναλλάξιμη μορφή αρχείου που αντιπροσωπεύει γεωμετρία επιφάνειας τριών διαστάσεων. Η μορφή αρχείου αυτή χρησιμοποιείται σε διάφορους τομείς όπως η γρήγορη πρωτοτυποποίηση, η 3D εκτύπωση και η υπολογιστική κατασκευή. Μάθετε περισσότερα για αυτή τη μορφή αρχείου εδώ.
