## VST field

Το Visio Drawing Template (.vst) είναι αρχεία διανυσματικών εικόνων που δημιουργήθηκαν με το Microsoft Visio και λειτουργούν ως πρότυπο για τη δημιουργία περαιτέρω αρχείων. Αυτά τα αρχεία προτύπων είναι σε δυαδικό μορφότυπο και περιέχουν την προεπιλεγμένη διάταξη και ρυθμίσεις που χρησιμοποιούνται για τη δημιουργία νέων σχεδίων Visio.
