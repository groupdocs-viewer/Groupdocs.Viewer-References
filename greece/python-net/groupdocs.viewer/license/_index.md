## License class

Διαχειρίζεται την αδειοδότηση του GroupDocs.Viewer.

Οι αδειοδοτημένες εκδόσεις ξεκλειδώνουν το πλήρες σύνολο λειτουργιών του wrapper στο
runtime. Οι μη αδειοδοτημένες εκδόσεις εκτελούνται σε λειτουργία αξιολόγησης με το ίδιο API
επιφάνεια, αλλά με περιορισμούς στο μέγεθος εξόδου και στο υδατογράφημα περιεχομένου.

Ο τύπος License εκθέτει τα ακόλουθα μέλη:
