Κύριος χώρος ονομάτων GroupDocs.Viewer με κλάσεις API ανώτερου επιπέδου.

### Κλάσεις
| Κλάση | Περιγραφή |
| :- | :- |
| [`FileType`](/viewer/python-net/groupdocs.viewer/filetype/) | Αντιπροσωπεύει έναν τύπο αρχείου και παρέχει μεθόδους για την απόκτηση της λίστας όλων των τύπων αρχείων που υποστηρίζονται από το GroupDocs.Viewer. |
| [`IAuxDisposable`](/viewer/python-net/groupdocs.viewer/iauxdisposable/) | Επεκτείνει την τυπική διεπαφή `System.IDisposable`, επιτρέπει την απόκτηση της τρέχουσας κατάστασης ενός αντικειμένου και την εγγραφή σε ένα γεγονός αποδέσμευσης. |
| [`License`](/viewer/python-net/groupdocs.viewer/license/) | Διαχειρίζεται την αδειοδότηση του GroupDocs.Viewer. |
| [`Metered`](/viewer/python-net/groupdocs.viewer/metered/) | Διαχειρίζεται την αδειοδότηση μετρητή (πληρωμή ανά χρήση). |
| [`Viewer`](/viewer/python-net/groupdocs.viewer/viewer/) | Αντιπροσωπεύει την κύρια κλάση που ελέγχει τη διαδικασία απόδοσης του εγγράφου. |
| [`ViewerSettings`](/viewer/python-net/groupdocs.viewer/viewersettings/) | Ορίζει ρυθμίσεις για την προσαρμογή της συμπεριφοράς του [`Viewer`](/viewer/python-net/groupdocs.viewer/viewer/). |

| [`IncorrectPasswordException`](/viewer/python-net/groupdocs.viewer/incorrectpasswordexception/) | Η εξαίρεση που προκαλείται όταν ο καθορισμένος κωδικός πρόσβασης είναι λανθασμένος. |
| [`InvalidFontFormatException`](/viewer/python-net/groupdocs.viewer/invalidfontformatexception/) | Η εξαίρεση που προκαλείται όταν προσπαθείτε να ανοίξετε, φορτώσετε, αποθηκεύσετε ή επεξεργαστείτε με κάποιον τρόπο κάποιο περιεχόμενο, το οποίο υποτίθεται ότι είναι μια γραμματοσειρά υποστηριζόμενης (γνωστής) μορφής, αλλά στην πραγματικότητα είναι μια γραμματοσειρά απροσδόκητης και/ή μη υποστηριζόμενης μορφής ή καθόλου δεν είναι γραμματοσειρά. |
| [`InvalidImageFormatException`](/viewer/python-net/groupdocs.viewer/invalidimageformatexception/) | Η εξαίρεση που προκαλείται όταν προσπαθείτε να ανοίξετε, φορτώσετε, αποθηκεύσετε ή επεξεργαστείτε με κάποιον τρόπο κάποιο περιεχόμενο, το οποίο υποτίθεται ότι είναι μια εικόνα (ραστική ή διανυσματική), αλλά στην πραγματικότητα είναι μια εικόνα απροσδόκητης και/ή μη υποστηριζόμενης μορφής ή καθόλου δεν είναι εικόνα. |
| [`PasswordRequiredException`](/viewer/python-net/groupdocs.viewer/passwordrequiredexception/) | Η εξαίρεση που προκαλείται όταν απαιτείται κωδικός πρόσβασης για τη φόρτωση του εγγράφου. |
