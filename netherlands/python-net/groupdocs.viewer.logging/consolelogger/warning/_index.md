## warning {#message}

Schrijft een waarschuwingsbericht naar de console.

Warning-logberichten bieden informatie over onverwachte en herstelbare gebeurtenissen in de applicatiestroom.

```python
def warning(self, message):
    ...
```

| Parameter | Type | Beschrijving |
| :- | :- | :- |
| message | `str` | Het waarschuwingsbericht. |

| Gooit | Beschrijving |
| :- | :- |
| `ValueError` | Wanneer `message` None is. |
