## remove_java_script property

De eigenschap bepaalt of JavaScript‑broncode wordt verwijderd uit koppelingen in de gegenereerde HTML‑documenten bij het renderen van invoerdocumenten die scripts bevatten. Standaard ingeschakeld (`True`).

Voor details over het verwijderen van JavaScript, zie de documentatie: https://docs.groupdocs.com/viewer/net/rendering-to-html/#preserving-or-disabling-javascript-when-rendering-to-html
