## default_font_name property

Het standaardlettertype voor een document dat tijdens het renderen wordt gebruikt wanneer een vereist lettertype ontbreekt.

Gebruik deze eigenschap om het standaardlettertype voor een document in te stellen. GroupDocs.Viewer gebruikt dit lettertype tijdens het renderen in plaats van niet‑geïnstalleerde lettertypen.
