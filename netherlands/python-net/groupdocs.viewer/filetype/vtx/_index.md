## VTX field

Visio Template XML File (.vtx) is een Microsoft Visio‑tekeningssjabloon dat op schijf wordt opgeslagen in XML‑bestandsformaat. Het sjabloon is bedoeld om een bestand met basisinstellingen te bieden dat kan worden gebruikt om meerdere Visio‑bestanden met dezelfde instellingen te maken. Leer meer over dit bestandsformaat hier.
