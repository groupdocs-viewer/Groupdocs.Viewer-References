## EXCEL_2003XML field

Excel 2003 XML (SpreadsheetML) vertegenwoordigt het Excel Binary File Format. Dergelijke bestanden kunnen worden gemaakt met Microsoft Excel evenals andere vergelijkbare spreadsheet‑programma's zoals OpenOffice Calc of Apple Numbers. Meer informatie over dit bestandsformaat vindt u hier.
