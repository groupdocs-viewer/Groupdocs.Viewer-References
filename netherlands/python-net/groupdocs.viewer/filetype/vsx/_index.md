## VSX field

Visio Stencil XML File (.vsx) verwijst naar stencils die bestaan uit tekeningen en vormen die worden gebruikt voor het maken van diagrammen in Microsoft Visio. VSX‑bestanden worden opgeslagen in XML‑bestandsformaat en werden ondersteund tot Visio 2013. Leer meer over dit bestandsformaat hier.
