## PNG field

Portable Network Graphic (.png) is een type rasterafbeeldingsformaat dat verliesloze compressie gebruikt. Dit bestandsformaat is gemaakt als vervanging van Graphics Interchange Format (GIF) en heeft geen auteursrechtelijke beperkingen. Meer informatie over dit bestandsformaat hier.
