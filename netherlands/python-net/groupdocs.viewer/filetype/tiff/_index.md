## TIFF field

Tagged Image File Format (.tiff) vertegenwoordigt rasterafbeeldingen die bedoeld zijn voor gebruik op verschillende apparaten die voldoen aan deze bestandsformaatstandaard. Het kan bilevel-, grijswaarden-, palet‑kleur‑ en full‑color‑beeldgegevens beschrijven in verschillende kleurruimtes. Meer informatie over dit bestandsformaat hier.
