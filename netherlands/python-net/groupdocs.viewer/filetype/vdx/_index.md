## VDX field

Visio Drawing XML File (.vdx) vertegenwoordigt elke tekening of grafiek die is gemaakt in Microsoft Visio, maar opgeslagen in XML‑formaat met .VDX‑extensie. Een Visio‑tekenings‑XML‑bestand wordt aangemaakt in Visio‑software, die door Microsoft is ontwikkeld. Leer meer over dit bestandsformaat hier.
