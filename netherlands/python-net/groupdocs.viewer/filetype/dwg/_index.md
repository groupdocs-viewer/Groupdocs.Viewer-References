## DWG field

AutoCAD Drawing Database File (.dwg) vertegenwoordigt propriëtaire binaire bestanden die worden gebruikt voor het bevatten van 2D‑ en 3D‑ontwerpgegevens. Net als DXF, dat ASCII‑bestanden zijn, vertegenwoordigt DWG het binaire bestandsformaat voor CAD‑ (Computer‑Aided‑Design) tekeningen. Leer meer over dit bestandsformaat hier.
