## IAuxDisposable class

Breidt de standaard `System.IDisposable` interface uit, waardoor het mogelijk is de huidige status van een object op te halen en zich te abonneren op een verwijderings‑evenement.

Het IAuxDisposable-type exposeert de volgende leden:

### Eigenschappen
| Eigenschap | Beschrijving |
| :- | :- |
| [is_disposed](/viewer/python-net/groupdocs.viewer/iauxdisposable/is_disposed/) | De eigenschap geeft aan of een resource al is verwijderd (`True`) of niet (`False`). |
