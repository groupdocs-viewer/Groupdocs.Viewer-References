Het pakket biedt klassen en interfaces die documentrenderresultaten vertegenwoordigen.


Deze klassen kapselen informatie in over verschillende elementen en componenten van het gerenderde document,
zoals pagina's, bijlagen, weergaven, bronnen en meer.

De belangrijkste klassen in dit pakket zijn:

* [Page](../../com.groupdocs.viewer.results/page) - Represents a single page that can be viewed.
* [Attachment](../../com.groupdocs.viewer.results/attachment) - Represents an attachment file contained by an email message, archive, PDF document, or Outlook data file.
* [PdfViewInfo](../../com.groupdocs.viewer.results/pdfviewinfo) - Represents view information for a PDF document.


Voor meer details over het werken met renderresultaten van documenten met GroupDocs.Viewer,
raadpleeg de [GroupDocs.Viewer Documentation](../https://docs.groupdocs.com/viewer/java/).
