Geeft een 24-bit kleur weer in RGB-indeling, met 8 bits per elk kanaal (Rood, Groen, Blauw). Ondersteunt geen transparantie. Ontworpen om nuttig te zijn voor (maar niet beperkt tot) CSS-bewerkingen. Zie meer: https://developer.mozilla.org/en-US/docs/Web/CSS/color_value
