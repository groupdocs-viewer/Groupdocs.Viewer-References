Het pakket biedt klassen voor het aanpassen van het cache‑gedrag.

De belangrijkste klassen en interfaces in dit pakket zijn:

* [CacheKeys](../../com.groupdocs.viewer.caching/cachekeys) - Provides methods to retrieve unique identifiers for the cache entry.
* [FileCache](../../com.groupdocs.viewer.caching/filecache) - Represents a local on-disk cache.


De [Cache](../../com.groupdocs.viewer.caching/cache) interface definieert methoden die vereist zijn voor het opslaan van gerenderde documenten
en documentbronnen in de cache.


Voor meer details over het aanpassen van cachegedrag in GroupDocs.Viewer, raadpleeg de
[GroupDocs.Viewer Documentation](../https://docs.groupdocs.com/viewer/java/).
