Het pakket biedt klassen om extra opties op te geven bij het renderen van documenten.

Het bevat opties voor het renderen van verschillende documentformaten, het definiëren van permissies en beveiligingsinstellingen, het specificeren van watermerk-eigenschappen, en het ophalen van informatie over weergaven.

De belangrijkste klassen in dit pakket zijn:

 *  [ArchiveOptions](../../com.groupdocs.viewer.options/archiveoptions) - Provides options for rendering archive files.
 *  [PdfOptions](../../com.groupdocs.viewer.options/pdfoptions) - Provides options for rendering PDF documents.
 *  [WordProcessingOptions](../../com.groupdocs.viewer.options/wordprocessingoptions) - Provides options for rendering word processing documents.

Voor meer details over het configureren van het loggingsysteem in GroupDocs.Viewer en het aanpassen van de logberichtafhandeling, raadpleeg dan de [GroupDocs.Viewer Documentation][].


[GroupDocs.Viewer Documentation]: https://docs.groupdocs.com/viewer/java/
