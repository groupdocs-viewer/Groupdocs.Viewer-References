## PdfViewOptions.ImageMaxWidth property

Stelt de maximale breedte van een uitvoerafbeelding in (in pixels).

```csharp
public int ImageMaxWidth { get; set; }
```

### Opmerkingen

Gebruik deze eigenschap om de maximale breedte van de uitvoerafbeelding (in pixels) in te stellen. GroupDocs.Viewer past deze eigenschap toe bij het renderen van een enkele afbeelding naar PDF. Voor details, zie de [documentatie](https://docs.groupdocs.com/viewer/net/set-image-size-limits-when-rendering-to-pdf/).

Als u de eigenschap [`ImageWidth`](../imagewidth) instelt, wordt deze eigenschap genegeerd.
