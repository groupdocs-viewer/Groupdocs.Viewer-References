## PdfViewOptions.ImageHeight property

Stelt de hoogte van een uitvoerafbeelding in (in pixels).

```csharp
public int ImageHeight { get; set; }
```

### Opmerkingen

Gebruik deze eigenschap om de hoogte van de uitvoerafbeelding (in pixels) in te stellen. GroupDocs.Viewer past deze eigenschap alleen toe bij het renderen van een enkele afbeelding naar HTML. Voor details, zie de [documentatie](https://docs.groupdocs.com/viewer/net/set-image-size-limits-when-rendering-to-pdf/).

Als u deze eigenschap instelt, wordt de eigenschap [`ImageMaxHeight`](../imagemaxheight) genegeerd.
