## PdfViewOptions.ImageMaxHeight property

Stelt de maximale hoogte van een uitvoerafbeelding in (in pixels).

```csharp
public int ImageMaxHeight { get; set; }
```

### Opmerkingen

Gebruik deze eigenschap om de maximale hoogte van de uitvoerafbeelding (in pixels) in te stellen. GroupDocs.Viewer past deze eigenschap toe bij het renderen van een enkele afbeelding naar PDF. Voor details, zie de [documentatie](https://docs.groupdocs.com/viewer/net/set-image-size-limits-when-rendering-to-pdf/).

Als u de eigenschap [`ImageHeight`](../imageheight) instelt, wordt deze eigenschap genegeerd.
