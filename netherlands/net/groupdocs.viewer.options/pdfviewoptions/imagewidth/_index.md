## PdfViewOptions.ImageWidth property

Stelt de breedte van een uitvoerafbeelding in (in pixels).

```csharp
public int ImageWidth { get; set; }
```

### Opmerkingen

Gebruik deze eigenschap om de breedte van de uitvoerafbeelding (in pixels) in te stellen. GroupDocs.Viewer past deze eigenschap toe bij het renderen van een enkele afbeelding naar PDF. Voor details, zie de [documentatie](https://docs.groupdocs.com/viewer/net/set-image-size-limits-when-rendering-to-pdf/).

Als u deze eigenschap instelt, wordt de eigenschap [`ImageMaxWidth`](../imagemaxwidth) genegeerd.
