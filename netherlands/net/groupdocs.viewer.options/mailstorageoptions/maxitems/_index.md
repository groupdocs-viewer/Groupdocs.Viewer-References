## MailStorageOptions.MaxItems property

Stelt het maximale aantal berichten of items in dat moet worden gerenderd.

```csharp
public int MaxItems { get; set; }
```

### Opmerkingen

Mailopslagbestanden kunnen groot zijn en het ophalen van alle berichten kan veel tijd kosten. Deze eigenschap beperkt het maximale aantal berichten of items dat wordt weergegeven. Standaardwaarde is 0 – alle berichten worden weergegeven.

Voor een codevoorbeeld, zie de [documentatie](https://docs.groupdocs.com/viewer/net/render-lotus-notes-database-files/#limit-the-number-of-items-to-render).
