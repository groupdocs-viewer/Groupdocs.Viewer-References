## SpreadsheetOptions.HorizontalResolution property

Haalt op of stelt de horizontale resolutie voor gegenereerde afbeeldingen in dots per inch in. Deze optie wordt alleen gebruikt bij het renderen van spreadsheets naar PNG‑ of JPEG‑formaten.

```csharp
public int HorizontalResolution { get; set; }
```

### Opmerkingen

Standaardwaarde is 96 DPI. Minimum mogelijke waarde - 72 DPI, maximum mogelijke waarde - 600 DPI. Als de door de gebruiker opgegeven waarde buiten deze limieten valt, wordt de minimum- of maximumwaarde toegepast.
