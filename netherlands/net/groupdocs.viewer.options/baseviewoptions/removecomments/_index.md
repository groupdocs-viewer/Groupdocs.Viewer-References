## BaseViewOptions.RemoveComments property

Schakelt het renderen van opmerkingen uit wanneer ingesteld op `true`. Standaard is `false` — alle opmerkingen worden weergegeven.

```csharp
public bool RemoveComments { get; set; }
```

### Opmerkingen

Sommige documentformaten zoals PDF en WordProcessing kunnen opmerkingen bevatten. Standaard rendert GroupDocs.Viewer ze. Met deze optie ingesteld op `true` kunnen de opmerkingen worden weggelaten uit het resulterende document.

Deze optie vervangt de verouderde eigenschap 'RenderComments'.
