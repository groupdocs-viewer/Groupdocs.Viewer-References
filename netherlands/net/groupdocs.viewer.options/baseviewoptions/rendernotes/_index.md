## BaseViewOptions.RenderNotes property

Schakelt het renderen van notities en annotaties in voor sommige indelingen.

```csharp
public bool RenderNotes { get; set; }
```

### Opmerkingen

Sommige formaten, zoals presentaties of Microsoft Project‑bestanden, kunnen notities bevatten. PDF‑bestanden kunnen ook pop‑upannotaties (ballon‑tips) hebben, die standaard verborgen zijn en alleen zichtbaar zijn in een PDF‑viewer wanneer de muiscursor erover wordt bewogen. Standaard rendert GroupDocs.Viewer dergelijke notities en annotaties niet (`false`). Om dit te doen, stel deze eigenschap in op `true`.

Voor een codevoorbeeld, zie de [documentatie](https://docs.groupdocs.com/viewer/net/render-presentations/#render-speaker-notes).
