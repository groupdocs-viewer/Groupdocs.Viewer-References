## OutlookOptions.MaxItemsInFolder property

Het maximale aantal berichten of items dat kan worden gerenderd vanuit één map.

```csharp
public int MaxItemsInFolder { get; set; }
```

### Opmerkingen

Outlook-gegevensbestanden kunnen groot zijn en het ophalen van alle berichten kan aanzienlijke tijd kosten. Deze eigenschap beperkt het maximale aantal berichten of items dat wordt gerenderd. Standaardwaarde is `50`. Om alle berichten te renderen, stel de waarde in op `0`.

Voor een codevoorbeeld, zie de [documentatie](https://docs.groupdocs.com/viewer/net/render-outlook-data-files/#limit-the-number-of-folder-items-to-render).
