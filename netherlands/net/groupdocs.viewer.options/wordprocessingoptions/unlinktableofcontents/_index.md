## WordProcessingOptions.UnlinkTableOfContents property

Bij het renderen naar HTML of PDF kun je deze optie op `true` zetten om navigatie vanuit de inhoudsopgave uit te schakelen. Voor HTML-rendering worden `a`-tags met relatieve links vervangen door `span`-tags, waardoor functionaliteit wordt verwijderd maar de visuele weergave behouden blijft. Voor PDF-rendering wordt de inhoudsopgave weergegeven als platte tekst zonder links naar documentsecties.

```csharp
public bool UnlinkTableOfContents { get; set; }
```

### Opmerkingen

Standaardwaarde is `false`
