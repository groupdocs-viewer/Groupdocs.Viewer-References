## PdfOptions.RenderTextAsImage property

Schakelt het renderen van tekst in PDF‑bestanden als een afbeelding in de HTML‑uitvoer in.

```csharp
public bool RenderTextAsImage { get; set; }
```

### Opmerkingen

Wanneer deze optie is ingesteld op `true`, rendert GroupDocs.Viewer tekst als een afbeelding in de HTML‑output. Hierdoor is de tekst niet selecteerbaar en wordt de weergave van tekens verbeterd, waardoor een PDF‑achtige weergave in HTML wordt gegarandeerd. De standaardwaarde is `false`.

Deze optie is beschikbaar voor het renderen naar HTML.

Voor een code‑voorbeeld, zie de [documentatie](https://docs.groupdocs.com/viewer/net/render-pdf-documents/#render-text-as-an-image).
