## PdfOptions.DisableCopyProtection property

Schakelt inhoudskopie‑bescherming uit bij het renderen naar HTML.

```csharp
public bool DisableCopyProtection { get; set; }
```

### Opmerkingen

Bij het renderen van PDF‑bestanden met bescherming tegen het kopiëren van tekst en afbeeldingen naar HTML, voegt GroupDocs.Viewer een 'inert' HTML‑attribuut toe aan de HTML‑BODY‑tag. De standaardwaarde van deze optie is `false`, wat aangeeft dat het 'intent' HTML‑attribuut alleen wordt toegevoegd als het PDF‑document beschermd is.

Voor een code‑voorbeeld, zie de [documentatie](https://docs.groupdocs.com/viewer/net/render-pdf-documents/#disable-copy-protection).
