## PdfOptions.RenderOriginalPageSize property

Stelt de uitvoer‑paginagrootte in gelijk aan de paginagrootte van het bron‑PDF‑document.

```csharp
public bool RenderOriginalPageSize { get; set; }
```

### Opmerkingen

Standaard berekent GroupDocs.Viewer de paginagrootte van de uitvoerafbeelding voor een betere renderkwaliteit. Schakel deze optie in om ervoor te zorgen dat de uitvoerpagina's dezelfde grootte hebben als de paginagrootte van het bron‑PDF‑document (in pixels). De standaardwaarde is `false`.

Deze optie is beschikbaar voor het renderen naar PNG‑ of JPG‑formaten.

Voor een code‑voorbeeld, zie de [documentatie](https://docs.groupdocs.com/viewer/net/render-pdf-documents/#preserve-the-size-of-document-pages).
