## PdfOptions.DisableCharsGrouping property

Schakelt symboolgroepering uit voor precieze symboolpositionering tijdens het renderen van pagina's.

```csharp
public bool DisableCharsGrouping { get; set; }
```

### Opmerkingen

Bij het converteren van PDF‑bestanden groepeert GroupDocs.Viewer individuele tekens tot woorden voor betere renderprestaties. Als uw document hiërogliefen of speciale symbolen bevat, wilt u mogelijk het groeperen van tekens verbieden om een nauwkeurigere lay-out te garanderen. De standaardwaarde is `false`.
