पैकेज दस्तावेज़ के साथ काम करते समय उत्पन्न हो सकने वाले अपवादों के लिए क्लास प्रदान करता है।

इस पैकेज की मुख्य क्लास हैं:

 *  com.groupdocs.viewer.exception.ArchiveSecurityException - Thrown when an archive being opened exceeds specified limits.
 *  [FileNotFoundException](../../com.groupdocs.viewer.exception/filenotfoundexception) - Represents an exception thrown when a file or directory is not found.
 *  [GroupDocsViewerException](../../com.groupdocs.viewer.exception/groupdocsviewerexception) - Represents generic errors that occur during document processing.

GroupDocs.Viewer में एक्सेप्शन के साथ काम करने के बारे में अधिक विवरण के लिए, कृपया [GroupDocs.Viewer Documentation][] देखें।


[GroupDocs.Viewer Documentation]: https://docs.groupdocs.com/viewer/java/


## क्लास

| क्लास | विवरण |
| --- | --- |
| [ArchiveSecurityException](../com.groupdocs.viewer.exception/archivesecurityexception) | यह एक्सेप्शन तब फेंका जाता है जब खोला जा रहा आर्काइव ArchiveSecurityOptions में निर्दिष्ट किसी भी सीमा से अधिक हो जाता है। |
| [FileNotFoundException](../com.groupdocs.viewer.exception/filenotfoundexception) | जब कोई फ़ाइल या निर्देशिका नहीं मिलती है, तो यह अपवाद फेंका जाता है। |
| [GroupDocsViewerException](../com.groupdocs.viewer.exception/groupdocsviewerexception) | यह अपवाद दस्तावेज़ प्रसंस्करण के दौरान हो सकने वाली सामान्य त्रुटियों को दर्शाता है। |
| [IncorrectPasswordException](../com.groupdocs.viewer.exception/incorrectpasswordexception) | जब निर्दिष्ट पासवर्ड गलत होता है, तो यह अपवाद फेंका जाता है। |
| [NotSupportedException](../com.groupdocs.viewer.exception/notsupportedexception) | जब अनुरोधित ऑपरेशन समर्थित नहीं होता है, तो यह अपवाद फेंका जाता है। |
| [PasswordRequiredException](../com.groupdocs.viewer.exception/passwordrequiredexception) | जब दस्तावेज़ लोड करने के लिए पासवर्ड आवश्यक होता है, तो यह अपवाद फेंका जाता है। |
