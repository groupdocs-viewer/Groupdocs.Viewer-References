पैकेज रेंडरिंग प्रक्रिया के दौरान उपयोग किए जाने वाले फ़ॉन्ट को प्रबंधित करने के लिए क्लास और एन्यूमरेशन प्रदान करता है।

इस पैकेज में मुख्य क्लासेस और इंटरफ़ेस हैं:

* [FolderFontSource](../../com.groupdocs.viewer.fonts/folderfontsource) - Represents a folder that contains TrueType fonts.
* [FontSettings](../../com.groupdocs.viewer.fonts/fontsettings) - Provides methods for working with sources to look for TrueType fonts.
* [FontSource](../../com.groupdocs.viewer.fonts/fontsource) - Marker interface for the font sources.


GroupDocs.Viewer में फ़ॉन्ट्स के साथ काम करने के बारे में अधिक विवरण के लिए, कृपया देखें।
[GroupDocs.Viewer Documentation](../https://docs.groupdocs.com/viewer/java/).



## क्लास

| क्लास | विवरण |
| --- | --- |
| [FolderFontSource](../com.groupdocs.viewer.fonts/folderfontsource) | TrueType फ़ॉन्ट्स वाले फ़ोल्डर का प्रतिनिधित्व करता है। |
| [FontFormat](../com.groupdocs.viewer.fonts/fontformat) | UsedFontInfo क्लास में मौजूद हो सकने वाले सभी फ़ॉन्ट फ़ॉर्मेट्स का प्रतिनिधित्व करता है। |
| [FontSettings](../com.groupdocs.viewer.fonts/fontsettings) | TrueType फ़ॉन्ट्स खोजने के लिए स्रोतों के साथ काम करने की विधियाँ प्रदान करता है। |
| [FontStyles](../com.groupdocs.viewer.fonts/fontstyles) | दस्तावेज़ में उपयोग किए जाने वाले फ़ॉन्ट के 4 संभावित शैलियों का प्रतिनिधित्व करता है: रेगुलर, बोल्ड, इटैलिक, या बोल्ड इटैलिक। |
| [PdfFontInfo](../com.groupdocs.viewer.fonts/pdffontinfo) | Viewer इंस्टेंस में लोड किए गए PDF दस्तावेज़ से एक फ़ॉन्ट की मेटा‑सूचना और बाइनरी डेटा को संलग्न करता है। |
| [PresentationFontInfo](../com.groupdocs.viewer.fonts/presentationfontinfo) | Viewer इंस्टेंस में लोड किए गए प्रेज़ेंटेशन दस्तावेज़ में उपयोग किए गए फ़ॉन्ट की मेटा‑डेटा और बाइनरी डेटा को संलग्न करता है। |
| [SpreadsheetFontInfo](../com.groupdocs.viewer.fonts/spreadsheetfontinfo) | Viewer इंस्टेंस में लोड किए गए स्प्रेडशीट दस्तावेज़ से एक फ़ॉन्ट की मेटा‑जानकारी और बाइनरी डेटा को संलग्न करता है। |
| [WordProcessingFontInfo](../com.groupdocs.viewer.fonts/wordprocessingfontinfo) | Viewer इंस्टेंस में लोड किए गए वर्डप्रोसेसिंग दस्तावेज़ से एक फ़ॉन्ट की मेटा‑जानकारी और बाइनरी डेटा को संलग्न करता है। |
| [WordProcessingSubstitutedFontInfo](../com.groupdocs.viewer.fonts/wordprocessingsubstitutedfontinfo) | GroupDocs.Viewer के माध्यम से वर्डप्रोसेसिंग दस्तावेज़ में उपयोग किए गए एक प्रतिस्थापित फ़ॉन्ट की मेटा‑डेटा और बाइनरी डेटा को संलग्न करता है। |
