पैकेज GroupDocs.Viewer में लॉगिंग सिस्टम को कॉन्फ़िगर करने के लिए क्लास प्रदान करता है।


इन क्लासों का उपयोग करके, आप लॉग संदेशों को कैसे संभाला जाए, जैसे उन्हें लिखना
एक फ़ाइल में या उन्हें किसी विशिष्ट लॉगर कार्यान्वयन की ओर निर्देशित करना।

इस पैकेज में मुख्य क्लास हैं:

* [FileLogger](../../com.groupdocs.viewer.logging/filelogger) - Writes log messages to a file.
* [ViewerLogger](../../com.groupdocs.viewer.logging/viewerlogger) - Implements logging messages to an integrated or user-defined logger.


GroupDocs.Viewer में लॉगिंग सिस्टम को कॉन्फ़िगर करने और लॉग संदेश हैंडलिंग को अनुकूलित करने के बारे में अधिक विवरण के लिए,
कृपया [GroupDocs.Viewer Documentation](../https://docs.groupdocs.com/viewer/java/) देखें।
