ARGB फ़ॉर्मेट में 8 बिट प्रति चैनल (Alpha, Red, Green, Blue) के साथ 32-बिट रंग को दर्शाता है। पारदर्शिता का समर्थन करता है। (परंतु केवल CSS संचालन तक सीमित नहीं) उपयोगी होने के लिए डिज़ाइन किया गया है। अधिक देखें: https://developer.mozilla.org/en-US/docs/Web/CSS/color_value
