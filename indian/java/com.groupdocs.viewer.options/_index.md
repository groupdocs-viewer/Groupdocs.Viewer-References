पैकेज दस्तावेज़ रेंडर करते समय अतिरिक्त विकल्प निर्दिष्ट करने के लिए क्लास प्रदान करता है।


यह विभिन्न दस्तावेज़ फ़ॉर्मेट को रेंडर करने, अनुमतियों और सुरक्षा सेटिंग्स को परिभाषित करने के विकल्प शामिल करता है,
वॉटरमार्क गुण निर्दिष्ट करने और दृश्यों के बारे में जानकारी प्राप्त करने के लिए।

इस पैकेज में मुख्य क्लास हैं:

* [ArchiveOptions](../../com.groupdocs.viewer.options/archiveoptions) - Provides options for rendering archive files.
* [PdfOptions](../../com.groupdocs.viewer.options/pdfoptions) - Provides options for rendering PDF documents.
* [WordProcessingOptions](../../com.groupdocs.viewer.options/wordprocessingoptions) - Provides options for rendering word processing documents.


GroupDocs.Viewer में लॉगिंग सिस्टम को कॉन्फ़िगर करने और लॉग संदेश हैंडलिंग को अनुकूलित करने के बारे में अधिक विवरण के लिए,
कृपया [GroupDocs.Viewer Documentation](../https://docs.groupdocs.com/viewer/java/) देखें।
