पैकेज दस्तावेज़ के साथ काम करते समय उत्पन्न हो सकने वाले अपवादों के लिए क्लास प्रदान करता है।

इस पैकेज में मुख्य क्लास हैं:

* com.groupdocs.viewer.exception.ArchiveSecurityException - Thrown when an archive being opened exceeds specified limits.
* [FileNotFoundException](../../com.groupdocs.viewer.exception/filenotfoundexception) - Represents an exception thrown when a file or directory is not found.
* [GroupDocsViewerException](../../com.groupdocs.viewer.exception/groupdocsviewerexception) - Represents generic errors that occur during document processing.


GroupDocs.Viewer में अपवादों के साथ काम करने के बारे में अधिक विवरण के लिए, कृपया देखें
[GroupDocs.Viewer Documentation](../https://docs.groupdocs.com/viewer/java/).

| --- | --- |
| [ArchiveSecurityException](../com.groupdocs.viewer.exception/archivesecurityexception) | यह अपवाद तब फेंका जाता है जब खोला जा रहा अभिलेख़ ArchiveSecurityOptions में निर्दिष्ट किसी भी सीमा से अधिक हो जाता है। |
| [FileNotFoundException](../com.groupdocs.viewer.exception/filenotfoundexception) | यह अपवाद तब फेंका जाता है जब फ़ाइल या निर्देशिका नहीं मिलती। |
| [GroupDocsViewerException](../com.groupdocs.viewer.exception/groupdocsviewerexception) | यह अपवाद दस्तावेज़ प्रसंस्करण के दौरान हो सकने वाली सामान्य त्रुटियों का प्रतिनिधित्व करता है। |
| [IncorrectPasswordException](../com.groupdocs.viewer.exception/incorrectpasswordexception) | यह अपवाद तब फेंका जाता है जब निर्दिष्ट पासवर्ड गलत हो। |
| [NotSupportedException](../com.groupdocs.viewer.exception/notsupportedexception) | यह अपवाद तब फेंका जाता है जब अनुरोधित ऑपरेशन समर्थित नहीं है। |
| [PasswordRequiredException](../com.groupdocs.viewer.exception/passwordrequiredexception) | यह अपवाद तब फेंका जाता है जब दस्तावेज़ लोड करने के लिए पासवर्ड आवश्यक हो। |
