मुख्य GroupDocs.Viewer नामस्थान ऊपर-स्तरीय API क्लास के साथ।

### क्लास
| क्लास | विवरण |
| :- | :- |
| [`FileType`](/viewer/python-net/groupdocs.viewer/filetype/) | एक फ़ाइल प्रकार का प्रतिनिधित्व करता है और GroupDocs.Viewer द्वारा समर्थित सभी फ़ाइल प्रकारों की सूची प्राप्त करने के लिए मेथड्स प्रदान करता है। |
| [`IAuxDisposable`](/viewer/python-net/groupdocs.viewer/iauxdisposable/) | मानक `System.IDisposable` इंटरफ़ेस का विस्तार करता है, एक ऑब्जेक्ट की वर्तमान स्थिति प्राप्त करने और एक डिस्पोज़िंग इवेंट की सदस्यता लेने की अनुमति देता है। |
| [`License`](/viewer/python-net/groupdocs.viewer/license/) | GroupDocs.Viewer लाइसेंसिंग का प्रबंधन करता है। |
| [`Metered`](/viewer/python-net/groupdocs.viewer/metered/) | मीटर (पे-पर-यूज़) लाइसेंसिंग का प्रबंधन करता है। |
| [`Viewer`](/viewer/python-net/groupdocs.viewer/viewer/) | दस्तावेज़ रेंडरिंग प्रक्रिया को नियंत्रित करने वाली मुख्य क्लास का प्रतिनिधित्व करता है। |
| [`ViewerSettings`](/viewer/python-net/groupdocs.viewer/viewersettings/) | [`Viewer`](/viewer/python-net/groupdocs.viewer/viewer/) के व्यवहार को अनुकूलित करने के लिए सेटिंग्स को परिभाषित करता है। |

| [`InvalidImageFormatException`](/viewer/python-net/groupdocs.viewer/invalidimageformatexception/) | जब किसी सामग्री को खोलने, लोड करने, सहेजने या प्रोसेस करने का प्रयास किया जाता है, जो संभवतः एक छवि (रास्टर या वेक्टर) है, लेकिन वास्तव में वह अप्रत्याशित और/या असमर्थित फ़ॉर्मेट की छवि है या बिल्कुल छवि नहीं है, तो फेंका जाने वाला अपवाद। |
| [`PasswordRequiredException`](/viewer/python-net/groupdocs.viewer/passwordrequiredexception/) | जब दस्तावेज़ लोड करने के लिए पासवर्ड आवश्यक होता है, तो फेंका जाने वाला अपवाद। |
