## VSX field

Visio Stencil XML File (.vsx) उन स्टेंसिल्स को दर्शाता है जिनमें ड्रॉइंग्स और आकार होते हैं जो Microsoft Visio में आरेख बनाने के लिए उपयोग होते हैं। VSX फ़ाइलें XML फ़ाइल फ़ॉर्मेट में सहेजी जाती हैं और Visio 2013 तक समर्थित थीं। इस फ़ाइल फ़ॉर्मेट के बारे में अधिक जानें।
