## PPTX field

PowerPoint Open XML प्रस्तुति (.pptx) लोकप्रिय Microsoft PowerPoint एप्लिकेशन द्वारा बनाई गई प्रस्तुति फ़ाइलें हैं। पहले के PPT बाइनरी फ़ॉर्मेट के विपरीत, PPTX फ़ॉर्मेट Microsoft PowerPoint के ओपन XML प्रस्तुति फ़ाइल फ़ॉर्मेट पर आधारित है। इस फ़ाइल फ़ॉर्मेट के बारे में यहाँ अधिक जानें।
