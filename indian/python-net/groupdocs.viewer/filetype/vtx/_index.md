## VTX field

Visio Template XML File (.vtx) एक Microsoft Visio ड्रॉइंग टेम्पलेट है जो XML फ़ाइल फ़ॉर्मेट में डिस्क पर सहेजा जाता है। यह टेम्पलेट मूल सेटिंग्स वाली फ़ाइल प्रदान करने के लिए बनाया गया है जिसे समान सेटिंग्स वाली कई Visio फ़ाइलें बनाने में उपयोग किया जा सकता है। इस फ़ाइल फ़ॉर्मेट के बारे में अधिक जानें।
