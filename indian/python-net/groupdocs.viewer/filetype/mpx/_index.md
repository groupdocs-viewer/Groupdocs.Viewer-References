## MPX field

Microsoft Project Exchange फ़ाइल (.mpx) एक ASCII फ़ाइल फ़ॉर्मेट है जो Microsoft Project (MSP) और अन्य अनुप्रयोगों जैसे Primavera Project Planner, Sciforma और Timerline Precision Estimating के बीच परियोजना जानकारी के स्थानांतरण के लिए उपयोग होती है। इस फ़ाइल फ़ॉर्मेट के बारे में अधिक जानने के लिए यहाँ देखें।
