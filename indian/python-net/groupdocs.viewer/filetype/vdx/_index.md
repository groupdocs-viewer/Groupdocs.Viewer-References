## VDX field

Visio Drawing XML File (.vdx) Microsoft Visio में बनाई गई किसी भी ड्रॉइंग या चार्ट को दर्शाता है, लेकिन XML फ़ॉर्मेट में सहेजी गई फ़ाइलों का .VDX एक्सटेंशन होता है। Visio ड्रॉइंग XML फ़ाइल Visio सॉफ़्टवेयर में बनाई जाती है, जिसे Microsoft ने विकसित किया है। इस फ़ाइल फ़ॉर्मेट के बारे में अधिक जानें।
