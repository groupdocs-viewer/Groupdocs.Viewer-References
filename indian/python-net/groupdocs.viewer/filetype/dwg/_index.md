## DWG field

AutoCAD Drawing Database File (.dwg) स्वामित्व वाले बाइनरी फ़ाइलों को दर्शाता है जो 2D और 3D डिज़ाइन डेटा को रखने के लिए उपयोग होती हैं। DXF की तरह, जो ASCII फ़ाइलें हैं, DWG CAD (Computer Aided Design) ड्रॉइंग्स के लिए बाइनरी फ़ाइल स्वरूप का प्रतिनिधित्व करता है। इस फ़ाइल स्वरूप के बारे में अधिक जानें यहाँ।
