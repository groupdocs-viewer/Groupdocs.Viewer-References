## warning {#message}

कंसोल में एक चेतावनी संदेश लिखता है।

चेतावनी लॉग संदेश एप्लिकेशन प्रवाह में अप्रत्याशित और पुनर्प्राप्ति योग्य घटनाओं के बारे में जानकारी प्रदान करते हैं।

```python
def warning(self, message):
    ...
```

| पैरामीटर | टाइप | विवरण |
| :- | :- | :- |
| message | `str` | चेतावनी संदेश। |

| उत्पन्न करता है | विवरण |
| :- | :- |
| `ValueError` | जब `message` None है। |
