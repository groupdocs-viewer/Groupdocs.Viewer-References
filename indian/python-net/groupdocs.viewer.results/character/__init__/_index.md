## __init__ {#character-x-y-width-height}

एक नया [`Character`](/viewer/python-net/groupdocs.viewer.results/character/) उदाहरण प्रारंभ करता है।

```python
def __init__(self, character, x, y, width, height):
    ...
```

| पैरामीटर | टाइप | विवरण |
| :- | :- | :- |
| character | `str` | अक्षर। |
| x | `float` | पृष्ठ लेआउट में सबसे ऊँचा बायाँ बिंदु का X निर्देशांक जहाँ अक्षर को सम्मिलित करने वाला आयत शुरू होता है। |
| y | `float` | पृष्ठ लेआउट में सबसे ऊँचा बायाँ बिंदु का Y निर्देशांक जहाँ अक्षर को सम्मिलित करने वाला आयत शुरू होता है। |
| width | `float` | एकल अक्षर को सम्मिलित करने वाले आयत की चौड़ाई (पिक्सेल में)। |
| height | `float` | एकल अक्षर को सम्मिलित करने वाले आयत की ऊँचाई (पिक्सेल में)। |
