## __init__ {#name-width-height}

एक नया उदाहरण प्रारंभ करता है [`Layout`](/viewer/python-net/groupdocs.viewer.results/layout/) का।

```python
def __init__(self, name, width, height):
    ...
```

| पैरामीटर | टाइप | विवरण |
| :- | :- | :- |
| name | `str` | लेआउट का नाम। |
| width | `float` | लेआउट की चौड़ाई पिक्सेल में। |
| height | `float` | लेआउट की ऊँचाई पिक्सेल में। |

| उत्पन्न करता है | विवरण |
| :- | :- |
| `ValueError` | जब `name` None या खाली हो। |
