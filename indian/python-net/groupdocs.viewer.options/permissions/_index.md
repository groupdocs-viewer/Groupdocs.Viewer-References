## Permissions class

Permissions टाइप निम्नलिखित सदस्य प्रदर्शित करता है:

### फ़ील्ड्स
| फ़ील्ड | विवरण |
| :- | :- |
| [ALLOW_ALL](/viewer/python-net/groupdocs.viewer.options/permissions/allow_all/) | प्रिंटिंग, संशोधन और डेटा एक्सट्रैक्शन की अनुमति दें। |
| [DENY_PRINTING](/viewer/python-net/groupdocs.viewer.options/permissions/deny_printing/) | प्रिंटिंग को अस्वीकार करें। |
| [DENY_MODIFICATION](/viewer/python-net/groupdocs.viewer.options/permissions/deny_modification/) | सामग्री संशोधन, फ़ॉर्म भरना, एनोटेशन जोड़ना या संशोधित करना अस्वीकार करें। |
| [DENY_DATA_EXTRACTION](/viewer/python-net/groupdocs.viewer.options/permissions/deny_data_extraction/) | टेक्स्ट और ग्राफ़िक्स एक्सट्रैक्शन को अस्वीकार करें। |
| [DENY_ALL](/viewer/python-net/groupdocs.viewer.options/permissions/deny_all/) | प्रिंटिंग, सामग्री संशोधन और डेटा एक्सट्रैक्शन को अस्वीकार करें। |
