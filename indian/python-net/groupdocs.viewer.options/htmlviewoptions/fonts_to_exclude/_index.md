## fonts_to_exclude property

HTML दस्तावेज़ से बाहर रखने के लिए फ़ॉन्ट नामों की सूची।

HTML दस्तावेज़ में जो फ़ॉन्ट जोड़े जाते हैं वे आउटपुट दृश्य की स्थिरता को सुधारते हैं, साथ ही रेंडरिंग परिणाम का आकार बढ़ाते हैं। यह विकल्प आपको स्थिरता और आउटपुट आकार के बीच संतुलन बनाने देता है। उन फ़ॉन्ट नामों को शामिल करें जो लोकप्रिय हैं और अधिकांश सिस्टम में स्थापित हैं।

कृपया ध्यान दें, यह प्रॉपर्टी केवल तभी सक्रिय होती है जब [`HtmlViewOptions.ExcludeFonts`](/viewer/python-net/groupdocs.viewer.options/htmlviewoptions/exclude_fonts/) विकल्प निष्क्रिय हो।

For details and code example, see the documentation.
