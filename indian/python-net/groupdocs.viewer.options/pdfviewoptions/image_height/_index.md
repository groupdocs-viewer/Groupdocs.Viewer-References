## image_height property

आउटपुट छवि की ऊँचाई पिक्सेल में।

इस प्रॉपर्टी का उपयोग आउटपुट छवि ऊँचाई (पिक्सेल में) सेट करने के लिए करें। GroupDocs.Viewer इस प्रॉपर्टी को केवल एकल छवि को HTML में रेंडर करते समय लागू करता है। विवरण के लिए, https://docs.groupdocs.com/viewer/net/set-image-size-limits-when-rendering-to-pdf/ पर दस्तावेज़ देखें।
