## FontFormat enumeration

सभी फ़ॉन्ट फ़ॉर्मेट को दर्शाता है, जो [`IFontInfo`](../ifontinfo) इनहेरिटर्स में मौजूद हो सकते हैं

```csharp
public enum FontFormat : byte
```

### मान

| नाम | मान | विवरण |
| --- | --- | --- |
| Unknown | `0` | अज्ञात या अमान्य फ़ॉन्ट फ़ॉर्मेट |
| TrueType | `1` | TrueType फ़ॉन्ट फ़ॉर्मेट (TTF) |
| OpenType | `2` | OpenType फ़ॉन्ट फ़ॉर्मेट (OTF) |
| TrueTypeCollection | `3` | TrueType कलेक्शन फ़ॉन्ट फ़ॉर्मेट (TTC) |
| EmbeddedOpenType | `4` | एम्बेडेड OpenType फ़ॉन्ट फ़ॉर्मेट (EOT) |
