## HtmlViewOptions.RenderResponsive property

रिस्पॉन्सिव रेंडरिंग सक्षम करता है।

```csharp
public bool RenderResponsive { get; set; }
```

### टिप्पणियाँ

रिस्पॉन्सिव डिज़ाइन विभिन्न उपकरणों पर वेब पेजों को अच्छी तरह रेंडर करने का लक्ष्य रखता है। रिस्पॉन्सिव लेआउट के साथ रेंडर करने के लिए, इस प्रॉपर्टी को `true` सेट करें।

कोड उदाहरण के लिए, देखें [documentation](https://docs.groupdocs.com/viewer/net/render-with-responsive-layout/)।
