## HtmlViewOptions.ExcludeFonts property

HTML दस्तावेज़ में किसी भी फ़ॉन्ट को जोड़ने को अक्षम करता है।

```csharp
public bool ExcludeFonts { get; set; }
```

### टिप्पणियाँ

डिफ़ॉल्ट रूप से, GroupDocs.Viewer दस्तावेज़ में उपयोग किए गए फ़ॉन्ट्स को HTML मार्कअप में एम्बेड करता है, और इस प्रॉपर्टी का मान `false` है। फ़ॉन्ट्स को एम्बेड करने से रोकने के लिए, इस प्रॉपर्टी को `true` सेट करें।

विवरण और कोड उदाहरण के लिए, देखें [documentation](https://docs.groupdocs.com/viewer/net/exclude-fonts/)।
