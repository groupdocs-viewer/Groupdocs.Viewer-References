## HtmlViewOptions.RemoveJavaScript property

इनपुट दस्तावेज़ों को रेंडर करते समय, जिनमें स्क्रिप्ट्स हैं, परिणामस्वरूप HTML दस्तावेज़ों में लिंक से JavaScript स्रोत कोड को हटाने की अनुमति देता है। डिफ़ॉल्ट रूप से यह सक्षम है (`true`).

```csharp
public bool RemoveJavaScript { get; set; }
```

### टिप्पणियाँ

JavaScript को हटाने के बारे में विवरण के लिए, देखें [documentation](https://docs.groupdocs.com/viewer/net/rendering-to-html/#preserving-or-disabling-javascript-when-rendering-to-html)।
