## HtmlViewOptions.FontsToExclude property

HTML दस्तावेज़ से बाहर रखने के लिए फ़ॉन्ट नामों की सूची।

```csharp
public List<string> FontsToExclude { get; set; }
```

### टिप्पणियाँ

HTML दस्तावेज़ में जोड़े गए फ़ॉन्ट्स आउटपुट व्यू की स्थिरता को बढ़ाते हैं, साथ ही रेंडरिंग परिणाम का आकार भी बढ़ाते हैं। यह विकल्प आपको स्थिरता और आउटपुट आकार के बीच संतुलन बनाने देता है। उन फ़ॉन्ट नामों को शामिल करें जो लोकप्रिय हैं और अधिकांश सिस्टम में स्थापित हैं।

कृपया ध्यान दें, यह प्रॉपर्टी केवल तब सक्रिय होती है जब [`ExcludeFonts`](../excludefonts) विकल्प निष्क्रिय हो।

विवरण और कोड उदाहरण के लिए, देखें [documentation](https://docs.groupdocs.com/viewer/net/exclude-fonts/)।
