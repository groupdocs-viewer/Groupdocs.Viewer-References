## PdfViewOptions.ImageWidth property

आउटपुट छवि की चौड़ाई सेट करता है (पिक्सेल में)।

```csharp
public int ImageWidth { get; set; }
```

### टिप्पणियाँ

इस प्रॉपर्टी का उपयोग आउटपुट इमेज की चौड़ाई (पिक्सेल में) सेट करने के लिए करें। GroupDocs.Viewer इस प्रॉपर्टी को तब लागू करता है जब एकल इमेज को PDF में रेंडर किया जाता है। विवरण के लिए, [documentation](https://docs.groupdocs.com/viewer/net/set-image-size-limits-when-rendering-to-pdf/) देखें।

यदि आप इस प्रॉपर्टी को सेट करते हैं, तो [`ImageMaxWidth`](../imagemaxwidth) प्रॉपर्टी अनदेखी कर दी जाएगी।
