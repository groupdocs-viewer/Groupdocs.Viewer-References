## PdfViewOptions.ImageMaxHeight property

आउटपुट छवि की अधिकतम ऊँचाई सेट करता है (पिक्सेल में)।

```csharp
public int ImageMaxHeight { get; set; }
```

### टिप्पणियाँ

इस प्रॉपर्टी का उपयोग अधिकतम आउटपुट इमेज ऊँचाई (पिक्सेल में) सेट करने के लिए करें। GroupDocs.Viewer इस प्रॉपर्टी को तब लागू करता है जब एकल इमेज को PDF में रेंडर किया जाता है। विवरण के लिए, [documentation](https://docs.groupdocs.com/viewer/net/set-image-size-limits-when-rendering-to-pdf/) देखें।

यदि आप [`ImageHeight`](../imageheight) प्रॉपर्टी सेट करते हैं, तो यह प्रॉपर्टी अनदेखी कर दी जाएगी।
