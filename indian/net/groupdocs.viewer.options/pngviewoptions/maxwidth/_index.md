## PngViewOptions.MaxWidth property

आउटपुट छवि की अधिकतम चौड़ाई सेट करता है (पिक्सेल में)।

```csharp
public int MaxWidth { get; set; }
```

### टिप्पणियाँ

इस प्रॉपर्टी का उपयोग अधिकतम आउटपुट छवि चौड़ाई (पिक्सेल में) सेट करने के लिए करें। कोड उदाहरण के लिए, [डॉक्यूमेंटेशन](https://docs.groupdocs.com/viewer/net/set-image-size-limits-when-rendering-to-png-jpg/) देखें।

यदि आप [`Width`](../width) प्रॉपर्टी सेट करते हैं, तो यह प्रॉपर्टी अनदेखी की जाती है।
