## PresentationOptions.RenderHeaderFooterPlaceholders property

स्लाइड के हेडर और फुटर में प्लेसहोल्डर रेंडरिंग को सक्षम करता है। डिफ़ॉल्ट रूप से यह निष्क्रिय (`false`) है। यह विकल्प प्रेजेंटेशन के सभी 4 रेंडरिंग मोड्स: HTML, PDF, PNG, और JPEG पर लागू होता है। यह तब लागू नहीं होता जब प्रेजेंटेशन को शुद्ध HTML/CSS मार्कअप में [`RenderToPureHtml`](../rendertopurehtml) का उपयोग करके रेंडर किया जाता है।

```csharp
public bool RenderHeaderFooterPlaceholders { get; set; }
```
