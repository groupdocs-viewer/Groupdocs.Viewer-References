## PresentationOptions.RenderToPureHtml property

प्रेजेंटेशन दस्तावेज़ों के लिए एक नया HTML रेंडरिंग मोड सक्षम करता है — इस मोड में प्रेजेंटेशन फ़ाइलें **pure HTML/CSS markup** में रेंडर की जाती हैं, बिना SVG छवियों के। डिफ़ॉल्ट रूप से यह अक्षम (`false`) है — मौजूदा SVG-आधारित HTML-रेंडरर उपयोग किया जाता है।

```csharp
public bool RenderToPureHtml { get; set; }
```
