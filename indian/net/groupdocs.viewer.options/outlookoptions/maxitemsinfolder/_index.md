## OutlookOptions.MaxItemsInFolder property

एक फ़ोल्डर से render किए जा सकने वाले संदेशों या आइटमों की अधिकतम संख्या।

```csharp
public int MaxItemsInFolder { get; set; }
```

### टिप्पणियाँ

Outlook डेटा फ़ाइलें बड़ी हो सकती हैं और सभी संदेशों को प्राप्त करने में काफी समय लग सकता है। यह प्रॉपर्टी रेंडर किए जाने वाले संदेशों या आइटमों की अधिकतम संख्या को सीमित करती है। डिफ़ॉल्ट मान `50` है। सभी संदेशों को रेंडर करने के लिए, मान को `0` सेट करें।

कोड उदाहरण के लिए, देखें [documentation](https://docs.groupdocs.com/viewer/net/render-outlook-data-files/#limit-the-number-of-folder-items-to-render).
