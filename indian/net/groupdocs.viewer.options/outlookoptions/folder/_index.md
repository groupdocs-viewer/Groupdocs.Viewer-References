## OutlookOptions.Folder property

रेंडर करने के लिए फ़ोल्डर (जैसे Inbox, Sent Item या Deleted Items) का नाम सेट करता है।

```csharp
public string Folder { get; set; }
```

### टिप्पणियाँ

जब Outlook डेटा फ़ाइल को रेंडर किया जाता है, तो GroupDocs.Viewer फ़ाइल में मौजूद सभी फ़ोल्डरों (नेस्टेड फ़ोल्डरों सहित) से संदेश रेंडर करता है। किसी विशिष्ट फ़ोल्डर से आइटम रेंडर करने के लिए इस प्रॉपर्टी का उपयोग करें।

कोड उदाहरण के लिए, देखें यह [documentation](https://docs.groupdocs.com/viewer/net/render-outlook-data-files/#render-a-specific-folder).
