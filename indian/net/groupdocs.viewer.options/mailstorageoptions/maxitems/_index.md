## MailStorageOptions.MaxItems property

रेंडर करने के लिए संदेशों या आइटमों की अधिकतम संख्या सेट करता है।

```csharp
public int MaxItems { get; set; }
```

### टिप्पणियाँ

मेल स्टोरेज डेटा फ़ाइलें बड़ी हो सकती हैं और सभी संदेशों को प्राप्त करने में काफी समय लग सकता है। यह प्रॉपर्टी रेंडर किए जाने वाले संदेशों या आइटमों की अधिकतम संख्या को सीमित करती है। डिफ़ॉल्ट मान 0 है - सभी संदेश रेंडर किए जाते हैं।

कोड उदाहरण के लिए, देखें [documentation](https://docs.groupdocs.com/viewer/net/render-lotus-notes-database-files/#limit-the-number-of-items-to-render).
