## BaseViewOptions.RemoveComments property

जब `true` पर सेट किया जाता है तो टिप्पणी रेंडरिंग को निष्क्रिय करता है। डिफ़ॉल्ट रूप से यह `false` है — सभी टिप्पणियाँ प्रदर्शित होती हैं।

```csharp
public bool RemoveComments { get; set; }
```

### टिप्पणियाँ

कुछ दस्तावेज़ फ़ॉर्मेट जैसे PDF और WordProcessing में टिप्पणियाँ हो सकती हैं। डिफ़ॉल्ट रूप से GroupDocs.Viewer उन्हें रेंडर करता है। इस विकल्प को `true` सेट करने पर टिप्पणियों को परिणामी दस्तावेज़ से बाहर रखा जा सकता है।

यह विकल्प पुरानी 'RenderComments' प्रॉपर्टी को बदलता है।
