## WordProcessingOptions.VerticalResolution property

उत्पन्न छवियों के लिए डॉट्स प्रति इंच में लंबवत रिज़ॉल्यूशन प्राप्त करता है या सेट करता है। यह विकल्प केवल WordProcessing दस्तावेज़ों को PNG या JPEG फ़ॉर्मेट में रेंडर करते समय उपयोग किया जाता है।

```csharp
public int VerticalResolution { get; set; }
```

### टिप्पणियाँ

डिफ़ॉल्ट मान 96 DPI है। न्यूनतम संभव मान - 72 DPI, अधिकतम संभव मान - 600 DPI। यदि उपयोगकर्ता द्वारा निर्दिष्ट मान इन सीमाओं से बाहर है, तो न्यूनतम या अधिकतम संभव मान लागू किया जाएगा।
