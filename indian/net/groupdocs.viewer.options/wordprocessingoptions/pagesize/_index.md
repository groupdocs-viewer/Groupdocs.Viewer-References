## WordProcessingOptions.PageSize property

आउटपुट पृष्ठ का आकार। डिफ़ॉल्ट मान Unspecified है, जिसका अर्थ है कि पृष्ठ सेटिंग्स (Page Setup) में निर्धारित पृष्ठ आकार उपयोग किया जाता है। HTM और HTML फ़ाइलों को रेंडर करते समय डिफ़ॉल्ट पृष्ठ आकार Letter 792 x 612 पॉइंट्स पर सेट होता है। परिणामस्वरूप, कुछ सामग्री पृष्ठ फ्रेम में फिट नहीं हो सकती। सामग्री को फिट करने के लिए बड़ा पृष्ठ आकार, जैसे A3, सेट करें।

```csharp
public PageSize PageSize { get; set; }
```
