## WordProcessingOptions.UpdateFields property

निर्धारित करता है कि कुछ प्रकार के फ़ील्ड को इनपुट WordProcessing दस्तावेज़ को HTML, PDF, PNG, या JPEG आउटपुट फ़ॉर्मेट में सहेजने से पहले अपडेट किया जाना चाहिए या नहीं। इस प्रॉपर्टी का डिफ़ॉल्ट मान `true` है — फ़ील्ड सहेजने से पहले अपडेट हो जाएंगे।

```csharp
public bool UpdateFields { get; set; }
```

### टिप्पणियाँ

विवरण के लिए, देखें [दस्तावेज़](https://docs.groupdocs.com/viewer/net/render-word-documents/#disable-updating-fields-when-saving).
