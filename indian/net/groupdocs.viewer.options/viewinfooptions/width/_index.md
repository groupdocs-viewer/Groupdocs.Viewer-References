## ViewInfoOptions.Width property

आउटपुट इमेज की चौड़ाई (पिक्सेल में, केवल PNG/JPG रेंडरिंग के लिए)।

```csharp
public int Width { get; set; }
```

### टिप्पणियाँ

इस प्रॉपर्टी का उपयोग आउटपुट छवि की चौड़ाई (पिक्सेल में) सेट करने के लिए करें। कोड उदाहरण के लिए, देखें [documentation](https://docs.groupdocs.com/viewer/net/image-viewer-adjust-image-size/).

यदि आप इस प्रॉपर्टी को सेट करते हैं, तो [`MaxWidth`](../maxwidth) प्रॉपर्टी को नजरअंदाज किया जाता है।
