## ViewInfoOptions.MaxHeight property

आउटपुट इमेज की अधिकतम ऊँचाई सेट करता है (पिक्सेल में, केवल PNG/JPG रेंडरिंग के लिए)।

```csharp
public int MaxHeight { get; set; }
```

### टिप्पणियाँ

इस प्रॉपर्टी का उपयोग अधिकतम आउटपुट छवि ऊँचाई (पिक्सेल में) सेट करने के लिए करें। कोड उदाहरण के लिए, [डॉक्यूमेंटेशन](https://docs.groupdocs.com/viewer/net/set-image-size-limits-when-rendering-to-png-jpg/) देखें।

यदि आप [`Height`](../height) प्रॉपर्टी सेट करते हैं, तो यह प्रॉपर्टी अनदेखी की जाती है।
