## PdfOptimizationOptions.RemoveUnusedObjects property

PDF फ़ाइल से अनउपयोगी (अनाथ) ऑब्जेक्ट हटाता है, जो PDF दस्तावेज़ में रखे गए हैं, लेकिन किसी पृष्ठ के रिसोर्स डिक्शनरी से संदर्भित नहीं होते और इसलिए बिल्कुल भी उपयोग नहीं होते। इस प्रॉपर्टी को सक्रिय करने से (`true`) आउटपुट PDF दस्तावेज़ का आकार घटेगा। डिफ़ॉल्ट रूप से यह अक्षम है (`false`).

```csharp
public bool RemoveUnusedObjects { get; set; }
```
