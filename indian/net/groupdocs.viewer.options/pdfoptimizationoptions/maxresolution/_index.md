## PdfOptimizationOptions.MaxResolution property

आउटपुट PDF फ़ाइल में अधिकतम रिज़ॉल्यूशन सेट करता है।

```csharp
public int MaxResolution { get; set; }
```

### टिप्पणियाँ

इस विकल्प को सक्षम करने के लिए, [`CompressImages`](../compressimages) और `MaxResolution` गुणों को `true` पर सेट करें।

डिफ़ॉल्ट मान `300` है।

कोड उदाहरण के लिए, इस [दस्तावेज़ीकरण](https://docs.groupdocs.com/viewer/net/optimization-pdf-set-max-resolution/) को देखें।
