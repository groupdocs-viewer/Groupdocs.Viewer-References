## PdfOptimizationOptions.RemoveUnusedStreams property

PDF फ़ाइल से अनउपयोगी (अनाथ) स्ट्रीम हटाता है, जो पृष्ठ के रिसोर्स डिक्शनरी से अभी भी संदर्भित हैं, लेकिन वास्तव में पृष्ठ सामग्री में कभी उपयोग नहीं होते। डिफ़ॉल्ट रूप से यह अक्षम है (`false`), इसे सक्षम करने से (`true`) आउटपुट PDF दस्तावेज़ का आकार घटेगा।

```csharp
public bool RemoveUnusedStreams { get; set; }
```
