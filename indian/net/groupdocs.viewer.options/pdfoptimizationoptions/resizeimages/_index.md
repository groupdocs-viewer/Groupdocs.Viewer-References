## PdfOptimizationOptions.ResizeImages property

आउटपुट PDF फ़ाइल में अधिकतम रिज़ॉल्यूशन सेट करने को सक्षम करता है।

```csharp
public bool ResizeImages { get; set; }
```

### टिप्पणियाँ

इस विकल्प को सक्षम करने के लिए, [`CompressImages`](../compressimages) प्रॉपर्टी को `true` सेट करें। यह विकल्प [`MaxResolution`](../maxresolution) प्रॉपर्टी सेट करने की अनुमति देता है। कोड उदाहरण के लिए, इस [documentation](https://docs.groupdocs.com/viewer/net/optimization-pdf-set-max-resolution/) देखें।
