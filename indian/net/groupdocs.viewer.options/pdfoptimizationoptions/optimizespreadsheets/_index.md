## PdfOptimizationOptions.OptimizeSpreadsheets property

PDF फ़ाइलों में स्प्रेडशीट्स के ऑप्टिमाइज़ेशन को सक्षम करता है।

```csharp
public bool OptimizeSpreadsheets { get; set; }
```

### टिप्पणियाँ

यह अनुकूलन बॉर्डर लाइनों को सेट करके आउटपुट फ़ाइल आकार को कम करने की अनुमति देता है। इसके अलावा, यह Arial और Times New Roman के 32-127 कोड के अक्षरों को हटाता है।

कोड उदाहरण के लिए, इस [दस्तावेज़ीकरण](https://docs.groupdocs.com/viewer/net/optimization-pdf-spreadsheets/) को देखें।
