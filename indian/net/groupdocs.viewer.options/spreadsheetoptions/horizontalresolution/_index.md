## SpreadsheetOptions.HorizontalResolution property

जनरेटेड इमेज़ की क्षैतिज रिज़ॉल्यूशन को डॉट्स पर इंच में प्राप्त करता है या सेट करता है। यह विकल्प केवल स्प्रेडशीट को PNG या JPEG फ़ॉर्मेट में रेंडर करने पर उपयोग किया जाता है।

```csharp
public int HorizontalResolution { get; set; }
```

### टिप्पणियाँ

डिफ़ॉल्ट मान 96 DPI है। न्यूनतम संभव मान - 72 DPI, अधिकतम संभव मान - 600 DPI। यदि उपयोगकर्ता द्वारा निर्दिष्ट मान इन सीमाओं से बाहर है, तो न्यूनतम या अधिकतम संभव मान लागू किया जाएगा।
