## PdfOptions.DisableCharsGrouping property

पृष्ठ रेंडरिंग के दौरान सटीक प्रतीक स्थान निर्धारण के लिए प्रतीक समूह बनाना अक्षम करता है।

```csharp
public bool DisableCharsGrouping { get; set; }
```

### टिप्पणियाँ

PDF फ़ाइलों को परिवर्तित करते समय, GroupDocs.Viewer व्यक्तिगत अक्षरों को शब्दों में समूहित करता है ताकि रेंडरिंग प्रदर्शन बेहतर हो सके। यदि आपके दस्तावेज़ में हाइरोग्लिफ़ या विशेष प्रतीक शामिल हैं, तो आप अधिक सटीक लेआउट सुनिश्चित करने के लिए अक्षर समूह बनाना रोकना चाह सकते हैं। डिफ़ॉल्ट मान `false` है।

कोड उदाहरण के लिए, देखें [documentation](https://docs.groupdocs.com/viewer/net/render-pdf-documents/#disable-character-grouping).
