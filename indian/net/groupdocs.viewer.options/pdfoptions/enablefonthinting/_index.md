## PdfOptions.EnableFontHinting property

फ़ॉन्ट हिंटिंग को सक्षम करता है।

```csharp
public bool EnableFontHinting { get; set; }
```

### टिप्पणियाँ

फ़ॉन्ट हिंटिंग निर्धारित करता है कि रूपरेखा फ़ॉन्ट कैसे प्रदर्शित होता है। केवल स्रोत दस्तावेज़ में उपयोग किए गए TTF फ़ॉन्ट पर लागू होता है। यह विकल्प PNG या JPG स्वरूपों में रेंडर करने के लिए उपलब्ध है। डिफ़ॉल्ट मान `false` है।

कोड उदाहरण के लिए, [दस्तावेज़ीकरण](https://docs.groupdocs.com/viewer/net/render-pdf-documents/#enable-font-hinting) देखें।
