## PdfOptions.RenderTextAsImage property

HTML आउटपुट में PDF फ़ाइलों के टेक्स्ट को इमेज के रूप में रेंडर करने को सक्षम करता है।

```csharp
public bool RenderTextAsImage { get; set; }
```

### टिप्पणियाँ

जब यह विकल्प `true` पर सेट किया जाता है, तो GroupDocs.Viewer HTML आउटपुट में टेक्स्ट को छवि के रूप में रेंडर करता है। इससे टेक्स्ट चयन योग्य नहीं रहता और अक्षर रेंडरिंग में सुधार होता है, जिससे HTML में PDF जैसा रूप मिलता है। डिफ़ॉल्ट मान `false` है।

यह विकल्प HTML में रेंडर करने के लिए उपलब्ध है।

कोड उदाहरण के लिए, देखें [documentation](https://docs.groupdocs.com/viewer/net/render-pdf-documents/#render-text-as-an-image).
