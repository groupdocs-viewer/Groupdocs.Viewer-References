## PdfOptions.EnableLayeredRendering property

HTML में रेंडर करते समय मूल PDF दस्तावेज़ के z-ऑर्डर में टेक्स्ट और ग्राफ़िक्स को रेंडर करने को सक्षम करता है।

```csharp
public bool EnableLayeredRendering { get; set; }
```

### टिप्पणियाँ

डिफ़ॉल्ट रूप से, GroupDocs.Veiewer टेक्स्ट और ग्राफ़िक्स को HTML में एकल लेयर के रूप में रेंडर करता है। यह विकल्प आपको स्रोत फ़ाइल के समान क्रम में वस्तुओं को व्यवस्थित करने देता है। डिफ़ॉल्ट मान `false` है।

कोड उदाहरण के लिए, [दस्तावेज़ीकरण](https://docs.groupdocs.com/viewer/net/render-pdf-documents/#enable-multi-layer-rendering) देखें।
