## CadOptions.EnablePerformanceConversionMode property

`true` पर इस फ़्लैग को सेट करने से CAD परिवार के सभी फ़ॉर्मैट्स के लिए एक विशेष प्रदर्शन‑उन्मुख रूपांतरण मोड सक्रिय हो जाता है — इस मोड में रूपांतरण गति बहुत तेज़ होती है, लेकिन परिणामी दस्तावेज़ों की गुणवत्ता उल्लेखनीय रूप से खराब हो जाती है। डिफ़ॉल्ट रूप से यह निष्क्रिय रहता है (`false`) — परिणामी दस्तावेज़ों की गुणवत्ता प्रदर्शन की कीमत पर संभव सर्वोत्तम रहती है।

```csharp
public bool EnablePerformanceConversionMode { get; set; }
```
