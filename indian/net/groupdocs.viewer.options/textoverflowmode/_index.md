## TextOverflowMode enumeration

स्प्रेडशीट दस्तावेज़ों को HTML में रेंडर करने के लिए टेक्स्ट ओवरफ़्लो मोड सेट करता है।

```csharp
public enum TextOverflowMode
```

### मान

| नाम | मान | विवरण |
| --- | --- | --- |
| Overlay | `0` | अगले सेल्स को ओवरले करें भले ही वे खाली न हों। |
| OverlayIfNextIsEmpty | `1` | अगले सेल्स को केवल तभी ओवरले करें जब वे खाली हों। डिफ़ॉल्ट मान। |
| AutoFitColumn | `2` | पाठ को फिट करने के लिए कॉलम का विस्तार करें। |
| HideText | `3` | ओवरफ़्लो टेक्स्ट को छिपाएँ। |
