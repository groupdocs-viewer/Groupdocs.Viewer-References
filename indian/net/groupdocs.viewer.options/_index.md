यह नेमस्पेस दस्तावेज़ों को रेंडर करते समय अतिरिक्त विकल्प निर्दिष्ट करने के लिए क्लासेस प्रदान करता है।

## क्लासेस

| क्लास | विवरण |
| --- | --- |
| [ArchiveOptions](./archiveoptions) | आर्काइव फ़ाइलों को रेंडर करने के विकल्प शामिल हैं। विवरण के लिए, देखें [डॉक्यूमेंटेशन](https://docs.groupdocs.com/viewer/net/render-archive-files/)। |
| [BaseViewOptions](./baseviewoptions) | बेस रेंडरिंग विकल्प शामिल हैं। |
| [CadOptions](./cadoptions) | CAD ड्रॉइंग्स को रेंडर करने के विकल्प शामिल हैं। अधिक जानकारी और कोड उदाहरणों के लिए, देखें [CAD ड्रॉइंग्स और मॉडल्स को HTML, PDF, और इमेज फ़ाइलों के रूप में रेंडर करें](https://docs.groupdocs.com/viewer/net/render-cad-drawings-and-models/) और [CAD फ़ाइलों के लिए रेंडरिंग विकल्प निर्दिष्ट करें](https://docs.groupdocs.com/viewer/net/specify-cad-rendering-options/)। |
| [EmailOptions](./emailoptions) | ईमेल संदेशों को रेंडर करने के विकल्प शामिल हैं। विवरण के लिए, देखें [डॉक्यूमेंटेशन](https://docs.groupdocs.com/viewer/net/render-email-messages/)। |
| [Field](./field) | ईमेल संदेश फ़ील्ड को दर्शाता है, जैसे From, To, Subject आदि। विवरण के लिए, देखें [डॉक्यूमेंटेशन](https://docs.groupdocs.com/viewer/net/render-email-messages/#rename-fields-in-the-message-header)। |
| [FileName](./filename) | फ़ाइलनाम। |
| [HtmlViewOptions](./htmlviewoptions) | दस्तावेज़ों को HTML फ़ॉर्मेट में रेंडर करने के विकल्प शामिल हैं। विवरण के लिए, देखें [विषय](https://docs.groupdocs.com/viewer/net/rendering-to-html/) और इसके चाइल्ड। |
| [JpgViewOptions](./jpgviewoptions) | दस्तावेज़ों को JPG फ़ॉर्मेट में रेंडर करने के विकल्प प्रदान करता है। विवरण के लिए, देखें यह [पृष्ठ](https://docs.groupdocs.com/viewer/net/rendering-to-png-or-jpeg/) और इसके चाइल्ड। |
| [LoadOptions](./loadoptions) | फ़ाइल खोलने के लिए उपयोग किए जाने वाले विकल्प शामिल हैं। विवरण के लिए, देखें यह [पृष्ठ](https://docs.groupdocs.com/viewer/net/loading/) और इसके चाइल्ड। |
| [MailStorageOptions](./mailstorageoptions) | मेल स्टोरेज (Lotus Notes, MBox) डेटा फ़ाइलों को रेंडर करने के विकल्प शामिल हैं। विवरण के लिए, देखें [डॉक्यूमेंटेशन](https://docs.groupdocs.com/viewer/net/render-lotus-notes-database-files/#specify-rendering-options)। |
| [OutlookOptions](./outlookoptions) | Outlook डेटा फ़ाइलों को रेंडर करने के विकल्प शामिल हैं। विवरण के लिए, देखें [डॉक्यूमेंटेशन](https://docs.groupdocs.com/viewer/net/render-lotus-notes-database-files/#specify-rendering-options)। |
| [PdfOptimizationOptions](./pdfoptimizationoptions) | आउटपुट PDF फ़ाइल पर लागू करने के लिए PDF ऑप्टिमाइज़ेशन विकल्प शामिल हैं। विवरण और कोड उदाहरणों के लिए, देखें यह [पृष्ठ](https://docs.groupdocs.com/viewer/net/optimization-pdf-options/) और इसके चाइल्ड। |
| [PdfOptions](./pdfoptions) | PDF दस्तावेज़ों को रेंडर करने के विकल्प शामिल हैं। विवरण के लिए, देखें [डॉक्यूमेंटेशन](https://docs.groupdocs.com/viewer/net/render-pdf-documents/)। |
| [PdfViewOptions](./pdfviewoptions) | दस्तावेज़ों को PDF फ़ॉर्मेट में रेंडर करने के विकल्प शामिल हैं। विवरण के लिए, देखें [डॉक्यूमेंटेशन](https://docs.groupdocs.com/viewer/net/rendering-to-pdf/)। |
| [PngViewOptions](./pngviewoptions) | दस्तावेज़ों को PNG फ़ॉर्मेट में रेंडर करने के विकल्प शामिल हैं। विवरण के लिए, देखें यह [पृष्ठ](https://docs.groupdocs.com/viewer/net/rendering-to-png-or-jpeg/) और इसके चाइल्ड। |
| [PresentationOptions](./presentationoptions) | प्रेज़ेंटेशन को रेंडर करने के विकल्प शामिल हैं। विवरण के लिए, देखें [डॉक्यूमेंटेशन](https://docs.groupdocs.com/viewer/net/render-presentations/)। |
| [ProjectManagementOptions](./projectmanagementoptions) | प्रोजेक्ट मैनेजमेंट फ़ाइलों को रेंडर करने के विकल्प शामिल हैं। विवरण के लिए, देखें [डॉक्यूमेंटेशन](https://docs.groupdocs.com/viewer/net/render-ms-project-files/)। |
| [Resolution](./resolution) | आउटपुट दस्तावेज़ में छवियों के रिज़ॉल्यूशन को सेट करने का विकल्प शामिल है। |
| [SearchHighlightOptions](./searchhighlightoptions) | दस्तावेज़ों में टेक्स्ट को खोजने और हाइलाइट करने के विकल्प प्रदान करता है, जो [`Viewer`](../groupdocs.viewer/viewer) क्लास में लोड किए गए हैं। |
| [Security](./security) | PDF दस्तावेज़ सुरक्षा विकल्प शामिल हैं। विवरण के लिए, देखें [डॉक्यूमेंटेशन](https://docs.groupdocs.com/viewer/net/protect-pdf-documents/)। |
| [Size](./size) | वॉटरमार्क आकार शामिल है। |
| [SpreadsheetOptions](./spreadsheetoptions) | स्प्रेडशीट फ़ाइलों को रेंडर करने के विकल्प शामिल हैं। विवरण के लिए, देखें [स्प्रेडशीट फ़ाइलों को रेंडर करें](https://docs.groupdocs.com/viewer/net/render-spreadsheets/) विषय के चाइल्ड। |
| [TextOptions](./textoptions) | टेक्स्ट फ़ाइलों को पेजों में विभाजित करने के विकल्प। |
| [Tile](./tile) | ड्रॉइंग क्षेत्र को दर्शाता है। |
| [ViewInfoOptions](./viewinfooptions) | व्यू के बारे में जानकारी प्राप्त करने के विकल्प शामिल हैं। |
| [ViewOptions](./viewoptions) | रेंडरिंग विकल्पों को शामिल करता है। |
| [VisioRenderingOptions](./visiorenderingoptions) | Visio दस्तावेज़ों को रेंडर करने के विकल्पों को शामिल करता है। विवरण के लिए, देखें [दस्तावेज़ीकरण](https://docs.groupdocs.com/viewer/net/render-visio-documents/)। |
| [Watermark](./watermark) | एक टेक्स्ट वॉटरमार्क का प्रतिनिधित्व करता है। विवरण के लिए, देखें [दस्तावेज़ीकरण](https://docs.groupdocs.com/viewer/net/add-text-watermark/)। |
| [WebDocumentOptions](./webdocumentoptions) | वेब दस्तावेज़ों को रेंडर करने के विकल्पों को शामिल करता है। विवरण के लिए, देखें [दस्तावेज़ीकरण](https://docs.groupdocs.com/viewer/net/render-web-documents/)। |
| [WordProcessingOptions](./wordprocessingoptions) | Word दस्तावेज़ों को रेंडर करने के विकल्पों को शामिल करता है। विवरण के लिए, देखें [दस्तावेज़ीकरण](https://docs.groupdocs.com/viewer/net/render-word-documents/)। |
