## FileType.VDX field

Visio Drawing XML File (.vdx) किसी भी ड्राइंग या चार्ट को दर्शाता है जो Microsoft Visio में बनाया गया है, लेकिन XML स्वरूप में .VDX एक्सटेंशन के साथ सहेजा गया है। Visio ड्राइंग XML फ़ाइल Visio सॉफ़्टवेयर में बनाई जाती है, जिसे माइक्रोसॉफ्ट ने विकसित किया है। इस फ़ाइल फ़ॉर्मेट के बारे में अधिक जानने के लिए [यहाँ](https://wiki.fileformat.com/image/vdx) देखें।

```csharp
public static readonly FileType VDX;
```
