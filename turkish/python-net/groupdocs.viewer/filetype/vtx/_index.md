## VTX field

Visio Template XML File (.vtx), XML dosya formatında diske kaydedilen bir Microsoft Visio çizim şablonudur. Şablon, aynı ayarlarla birden fazla Visio dosyası oluşturmak için kullanılabilecek temel ayarları içeren bir dosya sağlamayı amaçlar. Bu dosya formatı hakkında daha fazla bilgi edinin.
