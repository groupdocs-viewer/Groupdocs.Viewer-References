## VSTM field

Visio Macro-Enabled Drawing Template (.vstm), makroları destekleyen Microsoft Visio ile oluşturulan şablon dosyalarıdır. VSDX dosyalarından farklı olarak, VSTM şablonlarından oluşturulan dosyalar Visual Basic for Applications (VBA) kodunda geliştirilen makroları çalıştırabilir. Bu dosya formatı hakkında daha fazla bilgi edinin.
