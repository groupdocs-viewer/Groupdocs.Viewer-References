## XPS field

XML Paper Specification File (.xps), Microsoft tarafından oluşturulan XML Paper Specification temelli sayfa düzeni dosyalarını temsil eder. Bu format, EMF dosya formatının yerine Microsoft tarafından geliştirilmiş olup PDF dosya formatına benzer, ancak bir belgenin düzen, görünüm ve baskı bilgileri için XML kullanır. Bu dosya formatı hakkında daha fazla bilgi edinin.
