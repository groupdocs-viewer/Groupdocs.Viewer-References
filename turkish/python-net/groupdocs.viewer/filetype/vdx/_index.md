## VDX field

Visio Drawing XML File (.vdx), Microsoft Visio'da oluşturulan ve XML formatında .VDX uzantısıyla kaydedilen herhangi bir çizim veya grafiği temsil eder. Visio çizim XML dosyası, Microsoft tarafından geliştirilen Visio yazılımında oluşturulur. Bu dosya formatı hakkında daha fazla bilgi edinin.
