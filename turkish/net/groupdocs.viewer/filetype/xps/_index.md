## FileType.XPS field

XML Paper Specification File (.xps), Microsoft tarafından oluşturulan XML Paper Specification'lara dayalı sayfa düzeni dosyalarını temsil eder. Bu format, Microsoft tarafından EMF dosya formatının yerine geliştirilmiş olup PDF dosya formatına benzer, ancak belgenin düzen, görünüm ve baskı bilgileri için XML kullanır. Bu dosya formatı hakkında daha fazla bilgi edinin [burada](https://wiki.fileformat.com/page-description-language/xps).
