## MailStorageOptions.MaxItems property

Renderlenecek mesaj veya öğe sayısının maksimumunu ayarlar.

```csharp
public int MaxItems { get; set; }
```

### Açıklamalar

Posta depolama veri dosyaları büyük olabilir ve tüm mesajları almak önemli zaman alabilir. Bu özellik, oluşturulan mesajların veya öğelerin maksimum sayısını sınırlar. Varsayılan değer 0'dır - tüm mesajlar oluşturulur.

Kod örneği için, [belgeler](https://docs.groupdocs.com/viewer/net/render-lotus-notes-database-files/#limit-the-number-of-items-to-render).
