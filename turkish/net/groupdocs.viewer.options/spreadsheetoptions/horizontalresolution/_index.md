## SpreadsheetOptions.HorizontalResolution property

Oluşturulan görüntüler için inç başına nokta cinsinden yatay çözünürlüğü alır veya ayarlar. Bu seçenek yalnızca elektronik tablolar PNG veya JPEG formatına render edilirken kullanılır.

```csharp
public int HorizontalResolution { get; set; }
```

### Açıklamalar

Varsayılan değer 96 DPI'dir. Minimum olası değer - 72 DPI, maksimum olası değer - 600 DPI. Kullanıcı tarafından belirtilen değer bu sınırların dışındaysa, minimum veya maksimum olası değer uygulanır.
