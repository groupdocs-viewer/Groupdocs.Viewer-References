## SpreadsheetOptions.VerticalResolution property

Oluşturulan görüntüler için dikey çözünürlüğü dpi cinsinden alır veya ayarlar. Bu seçenek yalnızca elektronik tablolar PNG veya JPEG formatlarına render edildiğinde kullanılır.

```csharp
public int VerticalResolution { get; set; }
```

### Açıklamalar

Varsayılan değer 96 DPI'dir. Minimum olası değer - 72 DPI, maksimum olası değer - 600 DPI. Kullanıcı tarafından belirtilen değer bu sınırların dışındaysa, minimum veya maksimum olası değer uygulanır.
