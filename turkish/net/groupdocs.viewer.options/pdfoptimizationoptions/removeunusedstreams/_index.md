## PdfOptimizationOptions.RemoveUnusedStreams property

PDF dosyasından kullanılmayan (sahipsiz) akışları kaldırır; bu akışlar sayfanın kaynak sözlüğünden hâlâ referans alınmış olsa da sayfa içeriğinde hiç kullanılmaz. Varsayılan olarak devre dışıdır (`false`); etkinleştirildiğinde (`true`) çıktı PDF belgesinin boyutu azalır.

```csharp
public bool RemoveUnusedStreams { get; set; }
```
