## PdfOptimizationOptions.RemoveUnusedObjects property

PDF dosyasından kullanılmayan (sahipsiz) nesneleri kaldırır; bu nesneler PDF belgesine yerleştirilmiş, ancak herhangi bir sayfanın kaynak sözlüklerinden referans alınmamış ve bu yüzden hiç kullanılmamaktadır. Bu özellik (`true`) etkinleştirildiğinde çıktı PDF belgesinin boyutu azalır. Varsayılan olarak devre dışıdır (`false`).

```csharp
public bool RemoveUnusedObjects { get; set; }
```
