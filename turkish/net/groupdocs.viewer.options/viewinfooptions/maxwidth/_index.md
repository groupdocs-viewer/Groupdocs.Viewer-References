## ViewInfoOptions.MaxWidth property

Çıktı görüntüsünün maksimum genişliğini ayarlar (piksel cinsinden, yalnızca PNG/JPG renderleme için).

```csharp
public int MaxWidth { get; set; }
```

### Açıklamalar

Bu özelliği, maksimum çıktı görüntüsü genişliğini (piksel cinsinden) ayarlamak için kullanın. Kod örneği için, [belgelere](https://docs.groupdocs.com/viewer/net/set-image-size-limits-when-rendering-to-png-jpg/) bakın.

Eğer [`Width`](../width) özelliğini ayarlarsanız, bu özellik yok sayılır.
