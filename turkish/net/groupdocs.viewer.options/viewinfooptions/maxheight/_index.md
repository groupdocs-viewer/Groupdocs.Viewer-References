## ViewInfoOptions.MaxHeight property

Çıktı görüntüsünün maksimum yüksekliğini ayarlar (piksel cinsinden, yalnızca PNG/JPG renderleme için).

```csharp
public int MaxHeight { get; set; }
```

### Açıklamalar

Bu özelliği, maksimum çıktı görüntüsü yüksekliğini (piksel cinsinden) ayarlamak için kullanın. Kod örneği için, [belgelere](https://docs.groupdocs.com/viewer/net/set-image-size-limits-when-rendering-to-png-jpg/) bakın.

Eğer [`Height`](../height) özelliğini ayarlarsanız, bu özellik yok sayılır.
