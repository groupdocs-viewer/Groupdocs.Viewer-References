## HtmlViewOptions.FontsToExclude property

HTML belgesinden hariç tutulacak yazı tipi adlarının listesi.

```csharp
public List<string> FontsToExclude { get; set; }
```

### Açıklamalar

HTML belgesine eklenen yazı tipleri, çıktı görünümünün kararlılığını artırır, aynı zamanda render sonucunun boyutunu büyütür. Bu seçenek, kararlılık ile çıktı boyutu arasında denge kurmanıza olanak tanır. Çoğu sistemde popüler ve yüklü olan yazı tipi adlarını ekleyin.

Lütfen unutmayın, bu özellik yalnızca [`ExcludeFonts`](../excludefonts) seçeneği devre dışı bırakıldığında aktiftir.

Ayrıntılar ve kod örneği için, [belgelere](https://docs.groupdocs.com/viewer/net/exclude-fonts/) bakın.
