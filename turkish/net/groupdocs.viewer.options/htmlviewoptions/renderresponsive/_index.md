## HtmlViewOptions.RenderResponsive property

Duyarlı renderlamayı etkinleştirir.

```csharp
public bool RenderResponsive { get; set; }
```

### Açıklamalar

Duyarlı tasarım, web sayfalarının çeşitli cihazlarda iyi render edilmesini hedefler. Duyarlı bir düzenle renderlemek için bu özelliği `true` olarak ayarlayın.

Kod örneği için, [belgelere](https://docs.groupdocs.com/viewer/net/render-with-responsive-layout/) bakın.
