## HtmlViewOptions.Minify property

HTML içeriği ve HTML kaynaklarının küçültülmesini etkinleştirir.

```csharp
public bool Minify { get; set; }
```

### Açıklamalar

Çıktı içeriğinin (HTML, CSS ve SVG) sıkıştırılması, HTML dosyasını optimize etmenin yollarından biridir. Bunu yapmak için bu özelliği `true` olarak ayarlayın.

Kod örneği için, [belgeler](https://docs.groupdocs.com/viewer/net/minify-html/).
