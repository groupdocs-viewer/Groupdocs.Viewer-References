## PresentationOptions.RenderToPureHtml property

Sunum belgeleri için yeni bir HTML render modunu etkinleştirir — bu modda Sunum dosyaları **saf HTML/CSS markup** olarak render edilir, SVG görüntüsü olmadan. Varsayılan olarak devre dışı (`false`) — mevcut SVG tabanlı HTML-renderer kullanılır.

```csharp
public bool RenderToPureHtml { get; set; }
```
