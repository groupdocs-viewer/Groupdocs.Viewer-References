## BaseViewOptions.RenderNotes property

Bazı formatlar için notların ve ek açıklamaların işlenmesini etkinleştirir

```csharp
public bool RenderNotes { get; set; }
```

### Açıklamalar

Sunumlar veya Microsoft Project dosyaları gibi bazı formatlar notlar içerebilir. Ayrıca, PDF dosyalarında varsayılan olarak gizli olan ve yalnızca fare imlecini üzerine getirdiğinizde PDF görüntüleyicide görülen açılır açıklamalar (balon ipuçları) bulunabilir. Varsayılan olarak, GroupDocs.Viewer bu notları ve açıklamaları render etmez (`false`). Bunu yapmak için bu özelliği `true` olarak ayarlayın.

Kod örneği için, [belgelendirmeye](https://docs.groupdocs.com/viewer/net/render-presentations/#render-speaker-notes) bakın.
