## BaseViewOptions.RenderHiddenPages property

Gizli sayfaların işlenmesini etkinleştirir.

```csharp
public bool RenderHiddenPages { get; set; }
```

### Açıklamalar

Sunumlar veya elektronik tablolar gibi bazı dosyalar gizli sayfalar içerebilir. Varsayılan olarak, GroupDocs.Viewer bu sayfaları render etmez. Bunu yapmak için bu özelliği `true` olarak ayarlayın.

Kod örneği için, [belgelendirmeye](https://docs.groupdocs.com/viewer/net/render-presentations/#render-hidden-slides) bakın.
