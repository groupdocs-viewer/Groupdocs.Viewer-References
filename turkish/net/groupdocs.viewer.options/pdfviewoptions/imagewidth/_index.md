## PdfViewOptions.ImageWidth property

Çıktı görüntüsünün genişliğini (piksel cinsinden) ayarlar.

```csharp
public int ImageWidth { get; set; }
```

### Açıklamalar

Bu özelliği, çıktı görüntüsü genişliğini (piksel olarak) ayarlamak için kullanın. GroupDocs.Viewer, tek bir görüntüyü PDF'ye render ederken bu özelliği uygular. Ayrıntılar için [belgelendirme](https://docs.groupdocs.com/viewer/net/set-image-size-limits-when-rendering-to-pdf/) sayfasına bakın.

Bu özelliği ayarlarsanız, [`ImageMaxWidth`](../imagemaxwidth) özelliği yok sayılır.
