## PdfViewOptions.ImageMaxWidth property

Çıktı görüntüsünün maksimum genişliğini (piksel cinsinden) ayarlar.

```csharp
public int ImageMaxWidth { get; set; }
```

### Açıklamalar

Bu özelliği, maksimum çıktı görüntüsü genişliğini (piksel olarak) ayarlamak için kullanın. GroupDocs.Viewer, tek bir görüntüyü PDF'ye render ederken bu özelliği uygular. Ayrıntılar için [belgelendirme](https://docs.groupdocs.com/viewer/net/set-image-size-limits-when-rendering-to-pdf/) sayfasına bakın.

Eğer [`ImageWidth`](../imagewidth) özelliğini ayarlarsanız, bu özellik yok sayılır.
