## PdfViewOptions.ImageMaxHeight property

Çıktı görüntüsünün maksimum yüksekliğini (piksel cinsinden) ayarlar.

```csharp
public int ImageMaxHeight { get; set; }
```

### Açıklamalar

Bu özelliği, maksimum çıktı görüntüsü yüksekliğini (piksel olarak) ayarlamak için kullanın. GroupDocs.Viewer, tek bir görüntüyü PDF'ye render ederken bu özelliği uygular. Ayrıntılar için [belgelendirme](https://docs.groupdocs.com/viewer/net/set-image-size-limits-when-rendering-to-pdf/) sayfasına bakın.

Eğer [`ImageHeight`](../imageheight) özelliğini ayarlarsanız, bu özellik yok sayılır.
