## PdfViewOptions.ImageHeight property

Çıktı görüntüsünün yüksekliğini (piksel olarak) ayarlar.

```csharp
public int ImageHeight { get; set; }
```

### Açıklamalar

Bu özelliği, çıktı görüntüsü yüksekliğini (piksel olarak) ayarlamak için kullanın. GroupDocs.Viewer, tek bir görüntüyü yalnızca HTML'ye render ederken bu özelliği uygular. Ayrıntılar için [belgelendirme](https://docs.groupdocs.com/viewer/net/set-image-size-limits-when-rendering-to-pdf/) sayfasına bakın.

Bu özelliği ayarlarsanız, [`ImageMaxHeight`](../imagemaxheight) özelliği yok sayılır.
