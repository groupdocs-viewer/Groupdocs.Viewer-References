## WordProcessingOptions.UpdateFields property

Belirli tipteki alanların, giriş WordProcessing belgesi HTML, PDF, PNG veya JPEG çıktı formatlarına kaydedilmeden önce güncellenip güncellenmeyeceğini belirleyen bir değeri alır veya ayarlar. Bu özelliğin varsayılan değeri `true` — alanlar kaydetmeden önce güncellenecektir.

```csharp
public bool UpdateFields { get; set; }
```
