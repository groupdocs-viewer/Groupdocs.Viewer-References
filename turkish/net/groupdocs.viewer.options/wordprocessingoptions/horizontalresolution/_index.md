## WordProcessingOptions.HorizontalResolution property

Oluşturulan görüntüler için inç başına nokta cinsinden yatay çözünürlüğü alır veya ayarlar. Bu seçenek yalnızca WordProcessing belgelerinin PNG veya JPEG formatlarına işlenmesi sırasında kullanılır.

```csharp
public int HorizontalResolution { get; set; }
```

### Açıklamalar

Varsayılan değer 96 DPI'dir. Minimum olası değer - 72 DPI, maksimum olası değer - 600 DPI. Kullanıcı tarafından belirtilen değer bu sınırların dışındaysa, minimum veya maksimum olası değer uygulanır.
