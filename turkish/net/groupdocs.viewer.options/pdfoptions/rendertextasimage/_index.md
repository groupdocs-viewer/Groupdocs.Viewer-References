## PdfOptions.RenderTextAsImage property

PDF dosyalarındaki metinlerin HTML çıktısında görüntü olarak renderlenmesini etkinleştirir.

```csharp
public bool RenderTextAsImage { get; set; }
```

### Açıklamalar

Bu seçenek `true` olarak ayarlandığında, GroupDocs.Viewer HTML çıktısında metni bir görüntü olarak render eder. Bu, metnin seçilemez olmasını sağlar ve karakter renderını iyileştirerek HTML'de PDF benzeri bir görünüm elde eder. Varsayılan değer `false`.

Bu seçenek HTML'e render için kullanılabilir.

Kod örneği için, [belgelere](https://docs.groupdocs.com/viewer/net/render-pdf-documents/#render-text-as-an-image) bakın.
