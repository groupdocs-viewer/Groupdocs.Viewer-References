## PdfOptions.DisableCharsGrouping property

Sayfa renderleme sırasında hassas sembol konumlandırması için sembol gruplandırmasını devre dışı bırakır.

```csharp
public bool DisableCharsGrouping { get; set; }
```

### Açıklamalar

PDF dosyaları dönüştürülürken, GroupDocs.Viewer bireysel karakterleri kelimelere gruplayarak render performansını artırır. Belgeniz hiyeroglifler veya özel semboller içeriyorsa, daha kesin bir düzen sağlamak için karakter gruplamasını engellemek isteyebilirsiniz. Varsayılan değer `false`.

Kod örneği için, [belgelere](https://docs.groupdocs.com/viewer/net/render-pdf-documents/#disable-character-grouping) bakın.
