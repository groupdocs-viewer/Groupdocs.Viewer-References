## PdfOptions.EnableFontHinting property

Yazı tipi ipuçlarını etkinleştirir.

```csharp
public bool EnableFontHinting { get; set; }
```

### Açıklamalar

Font ipucu, bir kontur fontunun nasıl görüntüleneceğini ayarlar. Yalnızca kaynak belgede kullanılan TTF fontları için geçerlidir. Bu seçenek PNG veya JPG formatlarına render için kullanılabilir. Varsayılan değer `false`dır.

Kod örneği için, [belgelere](https://docs.groupdocs.com/viewer/net/render-pdf-documents/#enable-font-hinting) bakın.
