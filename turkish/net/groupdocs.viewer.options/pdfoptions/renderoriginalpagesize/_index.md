## PdfOptions.RenderOriginalPageSize property

Çıktı sayfa boyutunu kaynak PDF belgesinin sayfa boyutu ile aynı yapar.

```csharp
public bool RenderOriginalPageSize { get; set; }
```

### Açıklamalar

Varsayılan olarak, GroupDocs.Viewer daha iyi render kalitesi için çıktı görüntü sayfa boyutunu hesaplar. Bu seçeneği etkinleştirerek çıktı sayfalarının, kaynak PDF belgesinin sayfa boyutu (piksel olarak) ile aynı olmasını sağlayabilirsiniz. Varsayılan değer `false`dır.

Bu seçenek PNG veya JPG formatlarına render için kullanılabilir.

Kod örneği için, [belgelere](https://docs.groupdocs.com/viewer/net/render-pdf-documents/#preserve-the-size-of-document-pages) bakın.
