## SearchHighlightOptions.IsSearchTermRegEx property

Arama teriminin düzenli ifade mi yoksa düz metin mi olarak ele alınacağını belirten bir değeri alır veya ayarlar. Varsayılan `false` — düz metin olarak ele alınır.

```csharp
public bool IsSearchTermRegEx { get; set; }
```

### Açıklamalar

Eğer `true` ise, [`SearchTerm`](../searchterm) .NET Regex deseni olarak yorumlanır.

Eğer `false` ise, [`SearchTerm`](../searchterm) belgede düz metin olarak aranır.
