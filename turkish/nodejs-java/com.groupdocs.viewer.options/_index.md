Paket, belgeleri renderlerken ek seçenekleri belirtmek için sınıflar sağlar.

Çeşitli belge formatlarını renderleme, izin ve güvenlik ayarlarını tanımlama, filigran özelliklerini belirleme ve görünümler hakkında bilgi alma seçeneklerini içerir.

Bu paketteki ana sınıflar şunlardır:

 *  [ArchiveOptions](../../com.groupdocs.viewer.options/archiveoptions) - Provides options for rendering archive files.
 *  [PdfOptions](../../com.groupdocs.viewer.options/pdfoptions) - Provides options for rendering PDF documents.
 *  [WordProcessingOptions](../../com.groupdocs.viewer.options/wordprocessingoptions) - Provides options for rendering word processing documents.

GroupDocs.Viewer'da günlükleme sistemini yapılandırma ve günlük mesajı işleme özelleştirme hakkında daha fazla ayrıntı için lütfen [GroupDocs.Viewer Documentation][] adresine bakın.


[GroupDocs.Viewer Documentation]: https://docs.groupdocs.com/viewer/java/
