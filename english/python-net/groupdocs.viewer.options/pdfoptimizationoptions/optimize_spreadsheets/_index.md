## optimize_spreadsheets property

The property enables optimization of spreadsheets in the PDF files. The default value is False.

This optimization reduces the output file size by setting up border lines and removes the Arial and Times New Roman characters with codes 32‑127.

For a code example, see the GroupDocs documentation.
