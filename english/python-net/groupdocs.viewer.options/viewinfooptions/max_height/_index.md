## max_height property

The maximum height of an output image (in pixels, for rendering to PNG/JPG only).

Use this property to set the maximum output image height (in pixels). For code example, see the documentation.

If you set the [`ViewInfoOptions.Height`](/viewer/python-net/groupdocs.viewer.options/viewinfooptions/height/) property, this property is ignored.
