## CadOptions.EnableLayeredRendering property

Setting this flag to `true` enables layer-oriented rendering of CAD drawings to the HTML format: each layer is rendered with its ID, and also objects with same layer name will be grouped into top-level groups with "id" tag set to layer name. Is disabled (`false`) by default.
