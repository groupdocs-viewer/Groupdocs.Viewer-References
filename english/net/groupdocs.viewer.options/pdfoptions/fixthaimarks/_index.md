## PdfOptions.FixThaiMarks property

When rendering PDF to HTML format the produced HTML documents may have stranded Thai marks. This option, when enabled, applies special Thai glyphs analyzer and tries to fix these issues. By default is disabled (`false`). When enabled, may significantly degrade performance.

```csharp
public bool FixThaiMarks { get; set; }
```

### Remarks

This option is appliable only when rendering input PDF to output HTML with embedded resources only, HTML with external resources are not supported yet.
