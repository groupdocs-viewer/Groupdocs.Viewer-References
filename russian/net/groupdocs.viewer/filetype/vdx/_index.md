## FileType.VDX field

Visio Drawing XML File (.vdx) представляет любой чертёж или диаграмму, созданные в Microsoft Visio, но сохранённые в XML‑формате с расширением .VDX. Файл Visio Drawing XML создаётся в программном обеспечении Visio, разработанном Microsoft. Узнайте больше об этом формате файла [здесь](https://wiki.fileformat.com/image/vdx).
