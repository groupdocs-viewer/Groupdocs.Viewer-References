## FileType.POTM field

PowerPoint Open XML Macro-Enabled Presentation Template (.potm) — это шаблоны файлов Microsoft PowerPoint с поддержкой макросов. Файлы POTM создаются в PowerPoint 2007 и новее и содержат настройки по умолчанию, которые можно использовать для создания последующих файлов презентаций. Узнайте больше о этом формате файла [здесь](https://wiki.fileformat.com/presentation/potm).
