## FileType.XPS field

XML Paper Specification File (.xps) представляет файлы разметки страниц, основанные на XML Paper Specifications, созданных Microsoft. Этот формат был разработан Microsoft как замена формата EMF и похож на формат PDF, но использует XML для описания макета, внешнего вида и печатной информации документа. Узнайте больше об этом формате файла [здесь](https://wiki.fileformat.com/page-description-language/xps).
