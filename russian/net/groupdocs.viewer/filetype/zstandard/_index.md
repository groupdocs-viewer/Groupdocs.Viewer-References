## FileType.Zstandard field

ZST file — это сжатый файл, созданный с помощью алгоритма сжатия Zstandard (zstd). Это сжатый файл, полученный без потерь благодаря этому алгоритму. Файлы ZST могут использоваться для сжатия различных типов файлов, таких как базы данных, файловые системы, сети и игры. Узнайте больше об этом формате файла [здесь](https://docs.fileformat.com/compression/zst/).
