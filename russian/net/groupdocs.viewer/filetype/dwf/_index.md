## FileType.DWF field

Файл Design Web Format (.dwf) представляет собой 2D/3D чертеж в сжатом формате для просмотра, рецензирования или печати проектных файлов. Он содержит графику и текст как часть данных проекта и уменьшает размер файла благодаря сжатому формату. Узнайте больше об этом формате файла [здесь](https://wiki.fileformat.com/cad/dwf).

public static readonly FileType DWF;
