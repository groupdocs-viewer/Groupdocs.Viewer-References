## FileType.FromMediaType method

Отображает тип медиа файла на тип файла, например 'application/pdf' будет сопоставлен с [`PDF`](../pdf).

```csharp
public static FileType FromMediaType(string mediaType)
```

| Параметр | Type | Описание |
| --- | --- | --- |
| mediaType | String | Тип медиа файла, например application/pdf. |

### Возвращаемое значение

Возвращает соответствующий тип медиа, если найден, иначе возвращает тип файла по умолчанию [`Unknown`](../unknown).
