## FileType.PPT field

PowerPoint Presentation (.ppt) представляет файл PowerPoint, содержащий набор слайдов для отображения в виде слайд-шоу. Он определяет двоичный формат файла, используемый Microsoft PowerPoint 97‑2003. Узнайте больше о этом формате файла [здесь](https://wiki.fileformat.com/presentation/ppt).
