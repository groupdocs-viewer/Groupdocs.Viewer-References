## FileType.CDR field

CorelDraw Vector Graphic Drawing (.cdr) — векторный графический файл, изначально созданный в CorelDRAW для хранения закодированных и сжатых цифровых изображений. Такой файл содержит текст, линии, формы, изображения, цвета и эффекты для векторного представления содержимого изображения. Подробнее о этом формате файла читайте [здесь](https://wiki.fileformat.com/image/cdr).
