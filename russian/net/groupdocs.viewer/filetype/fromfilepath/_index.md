## FileType.FromFilePath method

Извлекает расширение файла и сопоставляет его типу файла.

```csharp
public static FileType FromFilePath(string filePath)
```

| Параметр | Type | Описание |
| --- | --- | --- |
| filePath | String | Имя файла или путь к файлу. |

### Возвращаемое значение

Если тип файла поддерживается, возвращает его, иначе возвращает тип файла по умолчанию [`Unknown`](../unknown).
