## FileType.XLTX field

Excel Open XML Spreadsheet Template (.xltx) представляет шаблоны Microsoft Excel, основанные на спецификациях формата Office OpenXML. Они используются для создания стандартного шаблона, который может генерировать файлы XLSX с теми же настройками, что указаны в файле XLTX. Узнайте больше об этом формате файла [здесь](https://wiki.fileformat.com/spreadsheet/xltx).
