Это пространство имён предоставляет классы для быстрого и качественного рендеринга документов в режимах HTML5, Image или PDF.

## Классы

| Класс | Описание |
| --- | --- |
| [FileType](./filetype) | Представляет тип файла. Предоставляет методы для получения списка всех типов файлов, поддерживаемых **GroupDocs.Viewer**. |
| [License](./license) | Предоставляет методы лицензирования компонента. Узнайте больше о лицензировании [здесь](https://purchase.groupdocs.com/faqs/licensing). |
| [Metered](./metered) | Предоставляет методы применения лицензии [Metered](https://purchase.groupdocs.com/faqs/licensing/metered). |
| [Viewer](./viewer) | Представляет основной класс, управляющий процессом рендеринга документа. |
| [ViewerSettings](./viewersettings) | Определяет настройки для настройки поведения [`Viewer`](../groupdocs.viewer/viewer). |
