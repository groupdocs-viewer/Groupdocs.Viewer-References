## WordProcessingSubstitutedFontInfo.Format property

Формат этого заменяющего (не оригинального) шрифта. Может быть TrueType, TrueType Collection, OpenType, Embedded OpenType. Для заменяющего шрифта, поскольку его бинарное содержимое доступно по определению, это свойство никогда не возвращает значение Unknown.
