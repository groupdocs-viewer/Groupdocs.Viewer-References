## FontStyles Subtraction operator

Вычитает второй (вычитаемый) указанный стиль шрифта из первого (вычитаемого) указанного стиля шрифта и создаёт новый результирующий стиль шрифта, в котором присутствуют только те флаги первого операнда, которые не найдены во втором операнде (разность)

```csharp
public static FontStyles operator -(FontStyles minuend, FontStyles subtrahend)
```

| Параметр | Type | Описание |
| --- | --- | --- |
| уменьшаемое | FontStyles | Операнд стиля шрифта (уменьшаемое) |
| вычитаемое | FontStyles | Операнд стиля шрифта (вычитаемое) |

### Возвращаемое значение

Результат разности между первым (уменьшаемым) и вторым (вычитаемым) операндами
