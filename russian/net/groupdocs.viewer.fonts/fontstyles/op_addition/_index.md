## FontStyles Addition operator

Объединяет (сливает) два указанных стиля шрифта и создаёт новый результирующий стиль шрифта, где флаги объединены (union)

```csharp
public static FontStyles operator +(FontStyles first, FontStyles second)
```

| Параметр | Type | Описание |
| --- | --- | --- |
| first | FontStyles | Первый операнд стиля шрифта. |
| second | FontStyles | Второй операнд стиля шрифта. |

### Возвращаемое значение

Результат объединения указанных операндов.
