## PresentationFontInfo.IsEmbedded property

Указывает, встроен ли этот шрифт в документ, загруженный в экземпляр [`Viewer`](../../../groupdocs.viewer/viewer) (`true`), или это системный шрифт (`false`). Табличные документы не могут содержать встроенные шрифты, поэтому для них это свойство всегда возвращает `false`.

```csharp
public bool IsEmbedded { get; }
```
