## FromOtherWithAlpha(Argb32Color, byte) {#fromotherwithalpha}

Создает новый экземпляр [`Argb32Color`](../../argb32color) из указанного, но с переопределенным значением альфа (непрозрачность)

```csharp
public static Argb32Color FromOtherWithAlpha(Argb32Color other, byte newAlpha)
```

| Параметр | Type | Описание |
| --- | --- | --- |
| other | Argb32Color | Другой экземпляр [`Argb32Color`](../../argb32color), из которого будет создан новый |
| newAlpha | Byte | Переопределенное значение альфа-канала (255 — полностью непрозрачный, 0 — полностью прозрачный) |

### Возвращаемое значение
