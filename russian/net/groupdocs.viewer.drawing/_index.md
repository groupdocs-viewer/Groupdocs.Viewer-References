Это пространство имён предоставляет типы, заменяющие платформенно-специфичные графические типы, такие как Color.

## Классы

| Класс | Описание |
| --- | --- |
| [Rgb24Color.KnownColors](./rgb24color.knowncolors) | Содержит все "известные цвета", которые имеют фиксированное уникальное имя и значение в стандарте CSS. |
## Structures

| Структура | Описание |
| --- | --- |
| [Argb32Color](./argb32color) | Представляет 32‑битный цвет в формате ARGB, с 8 битами на каждый канал (Alpha, Red, Green, Blue). Поддерживает прозрачность. |
| [Image2DFormat](./image2dformat) | Представляет наиболее распространённые 2D форматы изображений, поддерживает как растровые, так и векторные форматы |
| [Rgb24Color](./rgb24color) | Представляет 24‑битный цвет в формате RGB, с 8 битами на каждый канал (Red, Green, Blue). Не поддерживает прозрачность. |
