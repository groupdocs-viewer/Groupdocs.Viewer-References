## ILogger interface

Определяет методы, используемые для выполнения логирования.

```csharp
public interface ILogger
```

## Методы

| Имя | Описание |
| --- | --- |
| [Error](../../groupdocs.viewer.logging/ilogger/error)(string, Exception) | Записывает сообщение об ошибке. Сообщения журнала ошибок предоставляют информацию о необратимых событиях в потоке приложения. |
| [Trace](../../groupdocs.viewer.logging/ilogger/trace)(string) | Записывает трассировочное сообщение. Трассировочные сообщения журнала предоставляют общую полезную информацию о потоке приложения. |
| [Warning](../../groupdocs.viewer.logging/ilogger/warning)(string) | Записывает предупреждающее сообщение. Предупреждающие сообщения журнала предоставляют информацию о неожиданных и восстанавливаемых событиях в потоке приложения. |
