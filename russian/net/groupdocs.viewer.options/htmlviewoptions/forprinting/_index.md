## HtmlViewOptions.ForPrinting property

Включает оптимизацию выходного HTML для печати.

```csharp
public bool ForPrinting { get; set; }
```

### Примечания

Включите эту опцию, чтобы преобразовать выводимые HTML‑страницы в векторный формат SVG.

Для получения подробностей и примера кода см. [документацию](https://docs.groupdocs.com/viewer/net/how-to-optimize-output-html-for-printing/).
