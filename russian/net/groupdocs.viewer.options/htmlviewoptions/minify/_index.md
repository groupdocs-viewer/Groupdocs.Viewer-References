## HtmlViewOptions.Minify property

Включает минификацию HTML‑контента и HTML‑ресурсов.

```csharp
public bool Minify { get; set; }
```

### Примечания

Сжатие выходного контента (HTML, CSS и SVG) — один из способов оптимизировать HTML‑файл. Чтобы сделать это, установите это свойство в `true`.

Для примера кода см. [документацию](https://docs.groupdocs.com/viewer/net/minify-html/).
