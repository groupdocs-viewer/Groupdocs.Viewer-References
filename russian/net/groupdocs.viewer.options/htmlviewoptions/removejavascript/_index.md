## HtmlViewOptions.RemoveJavaScript property

Позволяет удалить исходный код JavaScript из ссылок в результирующих HTML‑документах при рендеринге входных документов, содержащих скрипты. По умолчанию включено (`true`).

```csharp
public bool RemoveJavaScript { get; set; }
```

### Примечания

Для получения подробностей об удалении JavaScript см. [документацию](https://docs.groupdocs.com/viewer/net/rendering-to-html/#preserving-or-disabling-javascript-when-rendering-to-html).
