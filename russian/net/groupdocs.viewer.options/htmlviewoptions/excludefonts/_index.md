## HtmlViewOptions.ExcludeFonts property

Отключает добавление любых шрифтов в HTML‑документ.

```csharp
public bool ExcludeFonts { get; set; }
```

### Примечания

По умолчанию GroupDocs.Viewer встраивает шрифты, используемые в документе, в разметку HTML, и это свойство имеет значение `false`. Чтобы предотвратить встраивание шрифтов, установите это свойство в `true`.

Для получения подробностей и примера кода см. [документацию](https://docs.groupdocs.com/viewer/net/exclude-fonts/).
