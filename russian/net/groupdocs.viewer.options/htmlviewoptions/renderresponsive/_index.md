## HtmlViewOptions.RenderResponsive property

Включает адаптивный рендеринг.

```csharp
public bool RenderResponsive { get; set; }
```

### Примечания

Адаптивный дизайн направлен на корректное отображение веб‑страниц на различных устройствах. Чтобы выполнить рендеринг с адаптивным макетом, установите это свойство в `true`.

Для примера кода см. [документацию](https://docs.groupdocs.com/viewer/net/render-with-responsive-layout/).
