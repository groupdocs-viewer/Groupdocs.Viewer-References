## SearchHighlightOptions.SearchTerm property

Получает или задает текст (или шаблон regex, если свойство [`IsSearchTermRegEx`](../issearchtermregex) равно `true`) для поиска.

```csharp
public string SearchTerm { get; set; }
```

### Примечания

Если [`IsSearchTermRegEx`](../issearchtermregex) равно `true`, это свойство должно содержать корректный шаблон регулярного выражения.
