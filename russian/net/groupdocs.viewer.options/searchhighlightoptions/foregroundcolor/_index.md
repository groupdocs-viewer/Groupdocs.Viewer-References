## SearchHighlightOptions.ForegroundColor property

Получает или задаёт цвет переднего плана (текста) для выделения.

```csharp
public Argb32Color ForegroundColor { get; set; }
```

### Примечания

Если этот цвет пустой или полностью прозрачный, явный цвет переднего плана не применяется (оставляя оригинальный цвет текста).
