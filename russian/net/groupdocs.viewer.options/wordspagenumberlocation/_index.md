## WordsPageNumberLocation enumeration

Управляет тем, следует ли принудительно применять нумерацию страниц к загруженному документу WordProcessing, и если да, где размещать номера страниц.

```csharp
public enum WordsPageNumberLocation : byte
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| NotApply | `0` | Оставить загруженный документ WordProcessing без изменений. Значение по умолчанию. |
| TopLeft | `1` | Поместить номер страницы в левый верхний угол страницы |
| TopCenter | `2` | Поместить номер страницы в верхний центр страницы |
| TopRight | `3` | Поместить номер страницы в правый верхний угол страницы |
| BottomLeft | `4` | Поместить номер страницы в левый нижний угол страницы |
| BottomCenter | `5` | Поместить номер страницы в нижний центр страницы |
| BottomRight | `6` | Поместить номер страницы в правый нижний угол страницы |
