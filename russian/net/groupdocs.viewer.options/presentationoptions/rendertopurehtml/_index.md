## PresentationOptions.RenderToPureHtml property

Включает новый режим отрисовки HTML для документов Presentation — в этом режиме файлы Presentation отрисовываются в **pure HTML/CSS markup**, без SVG‑изображений. По умолчанию отключено (`false`) — используется существующий HTML‑рендерер на основе SVG.

```csharp
public bool RenderToPureHtml { get; set; }
```

Для примера кода см. [документацию](https://docs.groupdocs.com/viewer/net/render-presentations/#generate-pure-htmlcss-markup).
