## PresentationOptions.RenderHeaderFooterPlaceholders property

Включает рендеринг заполнителей в заголовке и нижнем колонтитуле слайда. Отключено по умолчанию (`false`). Эта опция применяется ко всем 4 режимам рендеринга презентаций: HTML, PDF, PNG и JPEG. Не применяется при рендеринге презентации в чистую разметку HTML/CSS с использованием [`RenderToPureHtml`](../rendertopurehtml).

```csharp
public bool RenderHeaderFooterPlaceholders { get; set; }
```
