## ViewInfoOptions.Width property

Ширина выходного изображения (в пикселях, только для рендеринга в PNG/JPG).

```csharp
public int Width { get; set; }
```

### Примечания

Используйте это свойство, чтобы задать ширину выходного изображения (в пикселях). Для примера кода см. [документацию](https://docs.groupdocs.com/viewer/net/image-viewer-adjust-image-size/).

Если вы задаете это свойство, свойство [`MaxWidth`](../maxwidth) игнорируется.
