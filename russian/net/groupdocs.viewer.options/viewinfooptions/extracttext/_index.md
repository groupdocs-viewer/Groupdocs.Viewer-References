## ViewInfoOptions.ExtractText property

Включает извлечение текста.

```csharp
public bool ExtractText { get; set; }
```

### Примечания

Используйте это свойство, чтобы получить текст, содержащийся в исходном документе, и его координаты. Затем вы можете использовать эти данные, чтобы добавить выделяемый текст поверх изображения или реализовать поиск текста в рендеринге на основе изображения.

Для примера кода см. [документацию](https://docs.groupdocs.com/viewer/net/image-viewer-get-text-coordinates/).
