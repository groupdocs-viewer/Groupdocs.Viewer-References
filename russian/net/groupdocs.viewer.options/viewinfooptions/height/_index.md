## ViewInfoOptions.Height property

Высота выходного изображения (в пикселях, только для рендеринга в PNG/JPG).

```csharp
public int Height { get; set; }
```

### Примечания

Используйте это свойство, чтобы задать высоту выходного изображения (в пикселях). Для примера кода см. [документацию](https://docs.groupdocs.com/viewer/net/image-viewer-adjust-image-size/).

Если вы задаете это свойство, свойство [`MaxHeight`](../maxheight) игнорируется.
