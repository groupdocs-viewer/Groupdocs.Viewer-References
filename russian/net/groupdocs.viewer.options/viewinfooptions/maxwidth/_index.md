## ViewInfoOptions.MaxWidth property

Устанавливает максимальную ширину выходного изображения (в пикселях, только для рендеринга в PNG/JPG).

```csharp
public int MaxWidth { get; set; }
```

### Примечания

Используйте это свойство, чтобы задать максимальную ширину выходного изображения (в пикселях). Для примера кода см. [документацию](https://docs.groupdocs.com/viewer/net/set-image-size-limits-when-rendering-to-png-jpg/).

Если вы задаете свойство [`Width`](../width), это свойство игнорируется.
