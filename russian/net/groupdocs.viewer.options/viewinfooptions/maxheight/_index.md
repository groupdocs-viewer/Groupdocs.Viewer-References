## ViewInfoOptions.MaxHeight property

Устанавливает максимальную высоту выходного изображения (в пикселях, только для рендеринга в PNG/JPG).

```csharp
public int MaxHeight { get; set; }
```

### Примечания

Используйте это свойство, чтобы задать максимальную высоту выходного изображения (в пикселях). Для примера кода см. [документацию](https://docs.groupdocs.com/viewer/net/set-image-size-limits-when-rendering-to-png-jpg/).

Если вы задаете свойство [`Height`](../height), это свойство игнорируется.
