## BaseViewOptions.RenderHiddenPages property

Включает отображение скрытых страниц.

```csharp
public bool RenderHiddenPages { get; set; }
```

### Примечания

Некоторые файлы, такие как презентации или электронные таблицы, могут содержать скрытые страницы. По умолчанию GroupDocs.Viewer не отображает эти страницы. Чтобы сделать это, установите это свойство в `true`.

Для примера кода см. [документацию](https://docs.groupdocs.com/viewer/net/render-presentations/#render-hidden-slides).
