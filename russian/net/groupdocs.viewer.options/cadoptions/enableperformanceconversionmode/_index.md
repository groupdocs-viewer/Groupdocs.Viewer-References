## CadOptions.EnablePerformanceConversionMode property

Установка этого флага в `true` включает специальный режим конвертации, ориентированный на производительность, для всех форматов семейства CAD — в этом режиме скорость конвертации значительно выше, но качество получаемых документов существенно хуже. По умолчанию отключён (`false`) — качество получаемых документов максимально возможное, но за счёт производительности.

```csharp
public bool EnablePerformanceConversionMode { get; set; }
```
