## CadOptions.ForRenderingByWidth method

Инициализирует экземпляр класса [`CadOptions`](../../cadoptions) для рендеринга по ширине.

```csharp
public static CadOptions ForRenderingByWidth(int width)
```

| Параметр | Type | Описание |
| --- | --- | --- |
| width | Int32 | Ширина результата вывода (в пикселях). |

### Возвращаемое значение

Новый экземпляр класса [`CadOptions`](../../cadoptions) для рендеринга по ширине.

### Исключения

| исключение | условие |
| --- | --- |
