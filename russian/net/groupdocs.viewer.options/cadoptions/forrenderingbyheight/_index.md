## CadOptions.ForRenderingByHeight method

Инициализирует экземпляр класса [`CadOptions`](../../cadoptions) для рендеринга по высоте.

```csharp
public static CadOptions ForRenderingByHeight(int height)
```

| Параметр | Type | Описание |
| --- | --- | --- |
| height | Int32 | Высота выходного результата (в пикселях). |

### Возвращаемое значение

Новый экземпляр класса [`CadOptions`](../../cadoptions) для рендеринга по высоте.

### Исключения

| исключение | условие |
