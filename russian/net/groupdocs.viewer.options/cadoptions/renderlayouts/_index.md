## CadOptions.RenderLayouts property

Флаг, указывающий, следует ли рендерить макеты из CAD‑документа.

```csharp
public bool RenderLayouts { get; set; }
```

### Примечания

Эта опция доступна только для CAD‑чертежей, поддерживающих макеты [`DXF`](../../../groupdocs.viewer/filetype/dxf), [`DWG`](../../../groupdocs.viewer/filetype/dwg), [`DWT`](../../../groupdocs.viewer/filetype/dwt), [`DWF`](../../../groupdocs.viewer/filetype/dwf) и [`DWFX`](../../../groupdocs.viewer/filetype/dwfx). По умолчанию рендерится только модель.
