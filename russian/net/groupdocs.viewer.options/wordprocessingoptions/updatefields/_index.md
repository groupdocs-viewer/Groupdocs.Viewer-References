## WordProcessingOptions.UpdateFields property

Получает или задает значение, определяющее, должны ли поля определённых типов обновляться перед сохранением входного документа WordProcessing в форматы HTML, PDF, PNG или JPEG. Значение по умолчанию для этого свойства — `true`, поля будут обновлены перед сохранением.

```csharp
public bool UpdateFields { get; set; }
```

### Примечания

Для получения подробностей см. [документацию](https://docs.groupdocs.com/viewer/net/render-word-documents/#disable-updating-fields-when-saving).
