## WordProcessingOptions.UnlinkTableOfContents property

При рендеринге в HTML или PDF вы можете установить эту опцию в `true`, чтобы отключить навигацию из оглавления. При рендеринге HTML теги `a` с относительными ссылками будут заменены на теги `span`, что удалит функциональность, но сохранит визуальный вид. При рендеринге PDF оглавление будет выводиться как простой текст без ссылок на разделы документа.

```csharp
public bool UnlinkTableOfContents { get; set; }
```

### Примечания

Значение по умолчанию — `false`.

Для получения подробной информации см. [документацию](https://docs.groupdocs.com/viewer/net/render-word-documents/#unlink-table-of-contents).
