## WordProcessingOptions.PageSize property

Размер выходной страницы. Значение по умолчанию — Unspecified, что означает, что используется размер страницы, заданный в настройках страницы (Page Setup). При рендеринге файлов HTM и HTML размер страницы по умолчанию устанавливается как Letter 792 × 612 пунктов. В результате часть содержимого может не помещаться в рамку страницы. Установите больший размер страницы, например A3, чтобы разместить содержимое.

```csharp
public PageSize PageSize { get; set; }
```
