## WordProcessingOptions.VerticalResolution property

Получает или задает вертикальное разрешение генерируемых изображений в точках на дюйм. Эта опция используется только при рендеринге документов WordProcessing в форматы PNG или JPEG.

```csharp
public int VerticalResolution { get; set; }
```

### Примечания

Значение по умолчанию — 96 DPI. Минимально возможное значение — 72 DPI, максимально возможное значение — 600 DPI. Если указанное пользователем значение выходит за эти пределы, будет применено минимальное или максимальное возможное значение.
