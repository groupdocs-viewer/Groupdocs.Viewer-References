## PdfOptions.EnableFontHinting property

Включает хинтинг шрифтов.

```csharp
public bool EnableFontHinting { get; set; }
```

### Примечания

Подсказки шрифтов регулируют отображение контурного шрифта. Применимо только к TTF‑шрифтам, используемым в исходном документе. Эта опция доступна при рендеринге в форматы PNG или JPG. Значение по умолчанию — `false`.

Для примера кода см. [документацию](https://docs.groupdocs.com/viewer/net/render-pdf-documents/#enable-font-hinting).
