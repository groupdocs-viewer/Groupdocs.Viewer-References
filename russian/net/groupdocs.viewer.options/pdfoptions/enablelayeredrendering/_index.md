## PdfOptions.EnableLayeredRendering property

Включает рендеринг текста и графики в оригинальном порядке слоёв PDF‑документа при рендеринге в HTML.

```csharp
public bool EnableLayeredRendering { get; set; }
```

### Примечания

По умолчанию GroupDocs.Veiewer рендерит текст и графику как один слой в HTML. Эта опция позволяет располагать объекты в том же порядке, что и в исходном файле. Значение по умолчанию — `false`.

Для примера кода см. [документацию](https://docs.groupdocs.com/viewer/net/render-pdf-documents/#enable-multi-layer-rendering).
