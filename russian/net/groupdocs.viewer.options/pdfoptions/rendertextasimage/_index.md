## PdfOptions.RenderTextAsImage property

Включает рендеринг текста из PDF‑файлов в виде изображения в HTML‑выводе.

```csharp
public bool RenderTextAsImage { get; set; }
```

### Примечания

Когда эта опция установлена в `true`, GroupDocs.Viewer рендерит текст как изображение в HTML‑выводе. Это делает текст нечитаемым для выделения и улучшает отображение символов, обеспечивая внешний вид, похожий на PDF, в HTML. Значение по умолчанию — `false`.

Эта опция доступна при рендеринге в HTML.

Для примера кода см. [документацию](https://docs.groupdocs.com/viewer/net/render-pdf-documents/#render-text-as-an-image).
