## SpreadsheetOptions.ForRenderingPrintAreaAndPageBreaks method

Инициализирует экземпляр класса [`SpreadsheetOptions`](../../spreadsheetoptions) для рендеринга областей печати и разрывов страниц.

```csharp
public static SpreadsheetOptions ForRenderingPrintAreaAndPageBreaks()
```

### Возвращаемое значение

Новый экземпляр класса [`SpreadsheetOptions`](../../spreadsheetoptions) для рендеринга страниц на основе разрывов страниц, включенных в область печати. Поведение аналогично печати в Excel.
