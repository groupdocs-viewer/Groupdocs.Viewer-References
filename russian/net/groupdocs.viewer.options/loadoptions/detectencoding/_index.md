## LoadOptions.DetectEncoding property

Включает определение кодировки для файлов [`TXT`](../../../groupdocs.viewer/filetype/txt), [`CSV`](../../../groupdocs.viewer/filetype/csv) и [`TSV`](../../../groupdocs.viewer/filetype/tsv).

```csharp
public bool DetectEncoding { get; set; }
```

### Примечания

Если кодировка не может быть определена, используется кодировка по умолчанию [`Encoding`](../encoding). Для примера кода см. [документацию](https://docs.groupdocs.com/viewer/net/detect-encoding-when-loading-documents/).
