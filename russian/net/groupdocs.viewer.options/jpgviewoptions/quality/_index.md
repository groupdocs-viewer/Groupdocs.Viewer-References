## JpgViewOptions.Quality property

Устанавливает качество выходного изображения.

```csharp
public byte Quality { get; set; }
```

### Примечания

Используйте это свойство для настройки качества изображений. Значение должно быть между 1 (минимальное качество) и 100. Значение по умолчанию — 90.

Для примера кода см. [документацию](https://docs.groupdocs.com/viewer/net/image-viewer-adjust-quality-for-jpg/).
