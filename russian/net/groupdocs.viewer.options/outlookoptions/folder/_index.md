## OutlookOptions.Folder property

Устанавливает имя папки (например, Inbox, Sent Item или Deleted Items) для рендеринга.

```csharp
public string Folder { get; set; }
```

### Примечания

При отрисовке файла данных Outlook GroupDocs.Viewer выводит сообщения из всех папок, содержащихся в файле (включая вложенные папки). Используйте это свойство для отрисовки элементов из конкретной папки.

Для примера кода см. эту [документацию](https://docs.groupdocs.com/viewer/net/render-outlook-data-files/#render-a-specific-folder).
