## ArchiveOptions.FileName property

Устанавливает отображаемое имя архивного файла.

```csharp
public FileName FileName { get; set; }
```

### Примечания

По умолчанию GroupDocs.Viewer отображает имя архивного файла в заголовке каждой страницы. Чтобы изменить или скрыть это имя, установите это свойство.

Для получения дополнительной информации и примера кода см. [документацию](https://docs.groupdocs.com/viewer/net/render-archive-files/#specify-the-archive-document-name).
