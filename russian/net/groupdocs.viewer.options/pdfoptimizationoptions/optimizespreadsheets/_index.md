## PdfOptimizationOptions.OptimizeSpreadsheets property

Включает оптимизацию электронных таблиц в PDF‑файлах.

```csharp
public bool OptimizeSpreadsheets { get; set; }
```

### Примечания

Эта оптимизация позволяет уменьшить размер выходного файла, устанавливая границы. Кроме того, она удаляет символы Arial и Times New Roman с кодами 32‑127.

Для примера кода см. эту [документацию](https://docs.groupdocs.com/viewer/net/optimization-pdf-spreadsheets/).
