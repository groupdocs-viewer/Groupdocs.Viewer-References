## PdfOptimizationOptions.RemoveUnusedStreams property

Удаляет неиспользуемые (осиротевшие) потоки из PDF‑файла, которые всё ещё указаны в словаре ресурсов страницы, но фактически никогда не используются в содержимом страницы. По умолчанию отключено (`false`), включение (`true`) уменьшит размер выходного PDF‑документа.

```csharp
public bool RemoveUnusedStreams { get; set; }
```
