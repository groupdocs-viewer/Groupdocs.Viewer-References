## PdfOptimizationOptions.Lineriaze property

Включает оптимизацию выходного PDF‑файла для онлайн‑просмотра в веб‑браузере.

```csharp
public bool Lineriaze { get; set; }
```

### Примечания

Эта оптимизация позволяет браузеру отображать первые страницы PDF‑файла при открытии документа, вместо ожидания полной загрузки файла. Для примера кода см. эту [документацию](https://docs.groupdocs.com/viewer/net/optimization-pdf-for-web/).
