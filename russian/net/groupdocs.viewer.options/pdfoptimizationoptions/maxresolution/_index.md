## PdfOptimizationOptions.MaxResolution property

Устанавливает максимальное разрешение в выходном PDF‑файле.

```csharp
public int MaxResolution { get; set; }
```

### Примечания

Чтобы включить эту опцию, установите свойства [`CompressImages`](../compressimages) и `MaxResolution` в `true`.

Значение по умолчанию — `300`.

Для примера кода см. эту [документацию](https://docs.groupdocs.com/viewer/net/optimization-pdf-set-max-resolution/).
