## PdfOptimizationOptions.RemoveUnusedObjects property

Удаляет неиспользуемые (осиротевшие) объекты из PDF‑файла, которые находятся в документе PDF, но не ссылаются из словарей ресурсов любой страницы и поэтому вообще не используются. Включение этого свойства (`true`) уменьшит размер выходного PDF‑документа. По умолчанию отключено (`false`).

```csharp
public bool RemoveUnusedObjects { get; set; }
```
