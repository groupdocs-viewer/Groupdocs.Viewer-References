## PdfOptimizationOptions.ResizeImages property

Позволяет задать максимальное разрешение в выходном PDF‑файле.

```csharp
public bool ResizeImages { get; set; }
```

### Примечания

Чтобы включить эту опцию, установите свойство [`CompressImages`](../compressimages) в `true`. Эта опция позволяет задать свойство [`MaxResolution`](../maxresolution). Для примера кода см. эту [документацию](https://docs.groupdocs.com/viewer/net/optimization-pdf-set-max-resolution/).
