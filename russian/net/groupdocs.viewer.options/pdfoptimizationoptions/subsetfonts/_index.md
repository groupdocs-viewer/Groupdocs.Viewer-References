## PdfOptimizationOptions.SubsetFonts property

Создаёт подмножества шрифтов в выходном PDF‑файле.

```csharp
public bool SubsetFonts { get; set; }
```

### Примечания

Если файл использует встроенные шрифты, он содержит все данные шрифтов. GroupDocs.Viewer может выполнять подмножество встроенных шрифтов для уменьшения размера файла. Для примера кода см. эту [документацию](https://docs.groupdocs.com/viewer/net/optimization-pdf-subset-fonts/).
