## ViewOptions.Watermark property

Текстовый водяной знак, применяемый к каждой странице.

```csharp
public Watermark Watermark { get; set; }
```

### Примечания

Если одновременно указаны `Watermark` и [`PageRotations`](../pagerotations), водяной знак применяется к повернутым страницам.

Для получения подробностей см. [документацию](https://docs.groupdocs.com/viewer/net/add-text-watermark/).
