## PdfViewOptions.ImageHeight property

Устанавливает высоту выходного изображения (в пикселях).

```csharp
public int ImageHeight { get; set; }
```

### Примечания

Используйте это свойство, чтобы задать высоту выходного изображения (в пикселях). GroupDocs.Viewer применяет это свойство только при рендеринге отдельного изображения в HTML. Для подробностей см. [documentation](https://docs.groupdocs.com/viewer/net/set-image-size-limits-when-rendering-to-pdf/).

Если вы задаёте это свойство, свойство [`ImageMaxHeight`](../imagemaxheight) игнорируется.
