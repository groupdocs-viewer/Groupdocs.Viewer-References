## PdfViewOptions.ImageMaxHeight property

Устанавливает максимальную высоту выходного изображения (в пикселях).

```csharp
public int ImageMaxHeight { get; set; }
```

### Примечания

Используйте это свойство, чтобы задать максимальную высоту выходного изображения (в пикселях). GroupDocs.Viewer применяет это свойство при рендеринге отдельного изображения в PDF. Для подробностей см. [documentation](https://docs.groupdocs.com/viewer/net/set-image-size-limits-when-rendering-to-pdf/).

Если вы задаёте свойство [`ImageHeight`](../imageheight), это свойство игнорируется.
