## PdfViewOptions.ImageWidth property

Устанавливает ширину выходного изображения (в пикселях).

```csharp
public int ImageWidth { get; set; }
```

### Примечания

Используйте это свойство, чтобы задать ширину выходного изображения (в пикселях). GroupDocs.Viewer применяет это свойство при рендеринге отдельного изображения в PDF. Для подробностей см. [documentation](https://docs.groupdocs.com/viewer/net/set-image-size-limits-when-rendering-to-pdf/).

Если вы задаёте это свойство, свойство [`ImageMaxWidth`](../imagemaxwidth) игнорируется.
