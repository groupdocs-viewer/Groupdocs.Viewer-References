## MailStorageOptions.MaxItems property

Устанавливает максимальное количество сообщений или элементов для рендеринга.

```csharp
public int MaxItems { get; set; }
```

### Примечания

Файлы данных хранилища почты могут быть большими, и получение всех сообщений может занять значительное время. Это свойство ограничивает максимальное количество сообщений или элементов, которые отображаются. Значение по умолчанию — 0, что означает отображение всех сообщений.

Для примера кода см. [документацию](https://docs.groupdocs.com/viewer/net/render-lotus-notes-database-files/#limit-the-number-of-items-to-render).
