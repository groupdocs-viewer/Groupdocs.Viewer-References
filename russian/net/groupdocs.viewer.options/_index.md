Это пространство имён предоставляет классы для указания дополнительных параметров при рендеринге документов.

## Классы

| Класс | Описание |
| --- | --- |
| [ArchiveOptions](./archiveoptions) | Содержит параметры для рендеринга архивных файлов. Для подробностей см. [документацию](https://docs.groupdocs.com/viewer/net/render-archive-files/). |
| [BaseViewOptions](./baseviewoptions) | Содержит базовые параметры рендеринга. |
| [CadOptions](./cadoptions) | Содержит параметры для рендеринга CAD‑чертежей. Для получения дополнительной информации и примеров кода см. [Рендеринг CAD‑чертежей и моделей в HTML, PDF и графические файлы](https://docs.groupdocs.com/viewer/net/render-cad-drawings-and-models/) и [Указание параметров рендеринга для CAD‑файлов](https://docs.groupdocs.com/viewer/net/specify-cad-rendering-options/). |
| [EmailOptions](./emailoptions) | Содержит параметры для рендеринга электронных сообщений. Для подробностей см. [документацию](https://docs.groupdocs.com/viewer/net/render-email-messages/). |
| [Field](./field) | Представляет поле сообщения электронной почты, например From, To, Subject и т.д. Для подробностей см. [документацию](https://docs.groupdocs.com/viewer/net/render-email-messages/#rename-fields-in-the-message-header). |
| [FileName](./filename) | Имя файла. |
| [HtmlViewOptions](./htmlviewoptions) | Содержит параметры для рендеринга документов в формат HTML. Для подробностей см. [тему](https://docs.groupdocs.com/viewer/net/rendering-to-html/) и её дочерние элементы. |
| [JpgViewOptions](./jpgviewoptions) | Предоставляет параметры для рендеринга документов в формат JPG. Для подробностей см. эту [страницу](https://docs.groupdocs.com/viewer/net/rendering-to-png-or-jpeg/) и её дочерние элементы. |
| [LoadOptions](./loadoptions) | Содержит параметры, используемые для открытия файла. Для подробностей см. эту [страницу](https://docs.groupdocs.com/viewer/net/loading/) и её дочерние элементы. |
| [MailStorageOptions](./mailstorageoptions) | Содержит параметры для рендеринга файлов хранилища почты (Lotus Notes, MBox). Для подробностей см. [документацию](https://docs.groupdocs.com/viewer/net/render-lotus-notes-database-files/#specify-rendering-options). |
| [OutlookOptions](./outlookoptions) | Содержит параметры для рендеринга файлов данных Outlook. Для подробностей см. [документацию](https://docs.groupdocs.com/viewer/net/render-lotus-notes-database-files/#specify-rendering-options). |
| [PdfOptimizationOptions](./pdfoptimizationoptions) | Содержит параметры оптимизации PDF, применяемые к выходному PDF‑файлу. Для подробностей и примеров кода см. эту [страницу](https://docs.groupdocs.com/viewer/net/optimization-pdf-options/) и её дочерние элементы. |
| [PdfOptions](./pdfoptions) | Содержит параметры для рендеринга в PDF‑документы. Для подробностей см. [документацию](https://docs.groupdocs.com/viewer/net/render-pdf-documents/). |
| [PdfViewOptions](./pdfviewoptions) | Содержит параметры для рендеринга документов в формат PDF. Для подробностей см. [документацию](https://docs.groupdocs.com/viewer/net/rendering-to-pdf/). |
| [PngViewOptions](./pngviewoptions) | Содержит параметры для рендеринга документов в формат PNG. Для подробностей см. эту [страницу](https://docs.groupdocs.com/viewer/net/rendering-to-png-or-jpeg/) и её дочерние элементы. |
| [PresentationOptions](./presentationoptions) | Содержит параметры для рендеринга презентаций. Для подробностей см. [документацию](https://docs.groupdocs.com/viewer/net/render-presentations/). |
| [ProjectManagementOptions](./projectmanagementoptions) | Содержит параметры для рендеринга файлов управления проектами. Для подробностей см. [документацию](https://docs.groupdocs.com/viewer/net/render-ms-project-files/). |
| [Resolution](./resolution) | Содержит параметр для установки разрешения изображений в выходном документе. |
| [SearchHighlightOptions](./searchhighlightoptions) | Предоставляет параметры для поиска и выделения текста в документах, загруженных в класс [`Viewer`](../groupdocs.viewer/viewer). |
| [Security](./security) | Содержит параметры защиты PDF‑документа. Для подробностей см. [документацию](https://docs.groupdocs.com/viewer/net/protect-pdf-documents/). |
| [Size](./size) | Содержит размер водяного знака. |
| [SpreadsheetOptions](./spreadsheetoptions) | Содержит параметры для рендеринга электронных таблиц. Для подробностей см. дочерние элементы темы [Рендеринг файлов электронных таблиц](https://docs.groupdocs.com/viewer/net/render-spreadsheets/). |
| [TextOptions](./textoptions) | Параметры разбиения текстовых файлов на страницы. |
| [Tile](./tile) | Представляет область рисования. |
| [ViewInfoOptions](./viewinfooptions) | Содержит параметры для получения информации о представлении. |
| [ViewOptions](./viewoptions) | Содержит параметры рендеринга. |
| [VisioRenderingOptions](./visiorenderingoptions) | Содержит параметры для рендеринга документов Visio. Для подробностей см. [документацию](https://docs.groupdocs.com/viewer/net/render-visio-documents/). |
| [Watermark](./watermark) | Представляет текстовый водяной знак. Для подробностей см. [документацию](https://docs.groupdocs.com/viewer/net/add-text-watermark/). |
| [WebDocumentOptions](./webdocumentoptions) | Содержит параметры для рендеринга веб‑документов. Для подробностей см. [документацию](https://docs.groupdocs.com/viewer/net/render-web-documents/). |
| [WordProcessingOptions](./wordprocessingoptions) | Содержит параметры для рендеринга документов Word. Для подробностей см. [документацию](https://docs.groupdocs.com/viewer/net/render-word-documents/). |
