## remove_java_script property

Свойство определяет, будет ли исходный код JavaScript удалён из ссылок в сгенерированных HTML‑документах при рендеринге входных документов, содержащих скрипты. Включено по умолчанию (`True`).

Подробности об удалении JavaScript см. в документации: https://docs.groupdocs.com/viewer/net/rendering-to-html/#preserving-or-disabling-javascript-when-rendering-to-html
