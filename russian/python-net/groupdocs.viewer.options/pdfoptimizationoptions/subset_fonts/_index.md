## subset_fonts property

Свойство создает подмножества шрифтов в выходном PDF‑файле.

Если файл использует встроенные шрифты, он содержит все данные шрифтов. GroupDocs.Viewer может создавать подмножества встроенных шрифтов, чтобы уменьшить размер файла. Для примера кода см. документацию.
