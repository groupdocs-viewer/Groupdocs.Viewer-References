## optimize_spreadsheets property

Свойство, позволяющее оптимизировать электронные таблицы в PDF‑файлах.

Эта оптимизация уменьшает размер выходного файла, устанавливая границы, и удаляет символы шрифтов Arial и Times New Roman с кодами 32‑127. Значение по умолчанию — `False`.

Для примера кода см. документацию GroupDocs.
