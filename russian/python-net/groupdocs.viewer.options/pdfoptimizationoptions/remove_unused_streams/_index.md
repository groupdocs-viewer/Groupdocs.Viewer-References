## remove_unused_streams property

Свойство удаляет неиспользуемые (осиротевшие) потоки из PDF‑файла, которые указаны в словаре ресурсов страниц, но никогда не используются в содержимом страниц. Отключено по умолчанию (`False`); установка значения `True` уменьшает размер выходного PDF.
