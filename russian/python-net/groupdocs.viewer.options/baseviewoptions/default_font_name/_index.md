## default_font_name property

Шрифт по умолчанию для документа, используемый при рендеринге, когда требуемый шрифт отсутствует.

Используйте это свойство, чтобы задать шрифт по умолчанию для документа. GroupDocs.Viewer использует этот шрифт при рендеринге вместо любых неустановленных шрифтов.

Для примеров кода см. документацию: https://docs.groupdocs.com/viewer/net/replace-missing-font/
