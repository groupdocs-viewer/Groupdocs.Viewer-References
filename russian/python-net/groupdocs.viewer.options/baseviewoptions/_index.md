## BaseViewOptions class

Тип BaseViewOptions раскрывает следующие члены:

| :- | :- |
| [archive_options](/viewer/python-net/groupdocs.viewer.options/baseviewoptions/archive_options/) | Параметры просмотра архивных файлов. |

| [email_options](/viewer/python-net/groupdocs.viewer.options/baseviewoptions/email_options/) | Параметры просмотра электронных сообщений. |
