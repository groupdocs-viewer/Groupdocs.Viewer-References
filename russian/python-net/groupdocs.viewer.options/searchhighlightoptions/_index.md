## SearchHighlightOptions class

Предоставляет опции для поиска и выделения текста в документах, загруженных в класс [`Viewer`](/viewer/python-net/groupdocs.viewer/viewer/).

Тип SearchHighlightOptions раскрывает следующие члены:

### Конструкторы
| Конструктор | Описание |
| :- | :- |
| [__init__](/viewer/python-net/groupdocs.viewer.options/searchhighlightoptions/__init__/) |  |

### Свойства
| Свойство | Описание |
| :- | :- |
| [background_color](/viewer/python-net/groupdocs.viewer.options/searchhighlightoptions/background_color/) | Цвет фона для выделения. |
| [foreground_color](/viewer/python-net/groupdocs.viewer.options/searchhighlightoptions/foreground_color/) | Цвет переднего плана (текста) для выделения. |
| [is_search_term_reg_ex](/viewer/python-net/groupdocs.viewer.options/searchhighlightoptions/is_search_term_reg_ex/) | Свойство, указывающее, следует ли рассматривать поисковый запрос как регулярное выражение или как буквальный текст. По умолчанию False — рассматривать как буквальный текст. |
| [search_term](/viewer/python-net/groupdocs.viewer.options/searchhighlightoptions/search_term/) | Текст (или шаблон регулярного выражения, если свойство [`SearchHighlightOptions.is_search_term_reg_ex`](/viewer/python-net/groupdocs.viewer.options/searchhighlightoptions/is_search_term_reg_ex/) равно True) для поиска. |
