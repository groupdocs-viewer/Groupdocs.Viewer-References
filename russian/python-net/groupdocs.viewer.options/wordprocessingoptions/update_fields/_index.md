## update_fields property

Это свойство определяет, обновляются ли поля определённых типов перед сохранением документа WordProcessing в форматы HTML, PDF, PNG или JPEG. По умолчанию значение True, что означает обновление полей.

Для получения подробностей см. документацию: https://docs.groupdocs.com/viewer/net/render-word-documents/#disable-updating-fields-when-saving
