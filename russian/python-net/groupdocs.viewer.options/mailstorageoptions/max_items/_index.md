## max_items property

Максимальное количество сообщений или элементов для отображения.

Файлы данных почтового хранилища могут быть большими, и извлечение всех сообщений может занять значительное время. Это свойство ограничивает максимальное количество сообщений или элементов, которые рендерятся. Значение по умолчанию — 0, что означает рендеринг всех сообщений.
