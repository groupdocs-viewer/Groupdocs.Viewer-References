## Resolution class

Содержит опцию установки разрешения изображений в выходном документе.

Тип Resolution раскрывает следующие члены:

### Конструкторы
| Конструктор | Описание |
| :- | :- |
| [__init__](/viewer/python-net/groupdocs.viewer.options/resolution/__init__/#value) | Инициализирует разрешение в DPI. |

### Свойства
| Свойство | Описание |
| :- | :- |
| [value](/viewer/python-net/groupdocs.viewer.options/resolution/value/) | DPI качества. |

### Поля
| Поле | Описание |
| :- | :- |
| [DPI330](/viewer/python-net/groupdocs.viewer.options/resolution/dpi330/) | Хорошее качество для дисплеев высокой чёткости (HD). |
| [DPI220](/viewer/python-net/groupdocs.viewer.options/resolution/dpi220/) | Отличное качество на большинстве принтеров и экранов. |
| [DPI150](/viewer/python-net/groupdocs.viewer.options/resolution/dpi150/) | Подходит для веб-страниц и проекторов. |
| [DPI96](/viewer/python-net/groupdocs.viewer.options/resolution/dpi96/) | Подходит для веб-страниц и проекторов. |
| [DPI72](/viewer/python-net/groupdocs.viewer.options/resolution/dpi72/) | Уровень сжатия по умолчанию. |
| [DOCUMENT_RESOLUTION](/viewer/python-net/groupdocs.viewer.options/resolution/document_resolution/) | Уровень сжатия по умолчанию — как в документе. |
