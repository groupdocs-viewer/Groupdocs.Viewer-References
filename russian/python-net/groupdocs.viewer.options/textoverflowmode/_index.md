## TextOverflowMode class

Тип TextOverflowMode раскрывает следующие члены:

### Поля
| Поле | Описание |
| :- | :- |
| [OVERLAY](/viewer/python-net/groupdocs.viewer.options/textoverflowmode/overlay/) | Наложить на следующие ячейки, даже если они не пусты. |
| [OVERLAY_IF_NEXT_IS_EMPTY](/viewer/python-net/groupdocs.viewer.options/textoverflowmode/overlay_if_next_is_empty/) | Наложить на следующие ячейки только если они пусты. Значение по умолчанию. |
| [AUTO_FIT_COLUMN](/viewer/python-net/groupdocs.viewer.options/textoverflowmode/auto_fit_column/) | Расширить столбцы, чтобы вместить текст. |
| [HIDE_TEXT](/viewer/python-net/groupdocs.viewer.options/textoverflowmode/hide_text/) | Скрыть переполняющий текст. |
