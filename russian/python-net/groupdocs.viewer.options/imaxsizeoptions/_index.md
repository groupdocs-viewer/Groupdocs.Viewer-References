## IMaxSizeOptions class

Представляет ограничения опций размера изображения.

Тип IMaxSizeOptions раскрывает следующие члены:

### Свойства
| Свойство | Описание |
| :- | :- |
| [max_height](/viewer/python-net/groupdocs.viewer.options/imaxsizeoptions/max_height/) | Максимальная высота выходного изображения в пикселях. |
| [max_width](/viewer/python-net/groupdocs.viewer.options/imaxsizeoptions/max_width/) | Максимальная ширина выходного изображения в пикселях. |
