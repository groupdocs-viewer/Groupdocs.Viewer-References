## extract_text property

Свойство позволяет извлекать текст.

Используйте это свойство, чтобы получить текст, содержащийся в исходном документе, и его координаты. Затем вы можете использовать эти данные, чтобы добавить выделяемый текст поверх изображения или реализовать поиск текста в рендеринге на основе изображений.

Для примера кода см. документацию по адресу https://docs.groupdocs.com/viewer/net/image-viewer-get-text-coordinates/.
