## detect_encoding property

Свойство включает обнаружение кодировки для файлов [`FileType.txt`](/viewer/python-net/groupdocs.viewer/filetype/txt/), [`FileType.csv`](/viewer/python-net/groupdocs.viewer.filetype/csv/), и [`FileType.tsv`](/viewer/python-net/groupdocs.viewer.filetype/tsv/).

Если кодировку не удалось обнаружить, используется значение по умолчанию [`LoadOptions.encoding`](/viewer/python-net/groupdocs.viewer.options/loadoptions/encoding/). Для примера кода см. документацию.
