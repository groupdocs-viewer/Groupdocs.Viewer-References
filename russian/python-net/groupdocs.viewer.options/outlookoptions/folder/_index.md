## folder property

Имя папки (например, Inbox, Sent Item или Deleted Items), которую нужно отобразить.

При рендеринге файла данных Outlook, GroupDocs.Viewer отображает сообщения из всех папок, содержащихся в файле (включая вложенные папки). Используйте это свойство, чтобы отобразить элементы из конкретной папки.
