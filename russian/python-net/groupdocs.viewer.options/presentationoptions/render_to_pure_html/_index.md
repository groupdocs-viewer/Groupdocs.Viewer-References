## render_to_pure_html property

Свойство включает новый режим отображения HTML для документов Presentation — в этом режиме файлы преобразуются в чистую разметку HTML/CSS без изображений SVG. По умолчанию он отключён (`False`), и используется существующий рендерер HTML на основе SVG.

Для примера кода см. документацию по адресу https://docs.groupdocs.com/viewer/net/render-presentations/#generate-pure-htmlcss-markup.
