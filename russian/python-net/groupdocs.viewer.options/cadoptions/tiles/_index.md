## tiles property

Области чертежа для рендеринга.

Эта опция доступна только для файловых типов [`FileType.dwg`](/viewer/python-net/groupdocs.viewer/filetype/dwg/) и [`FileType.dwt`](/viewer/python-net/groupdocs.viewer/filetype/dwt/). Параметры [`CadOptions.render_layouts`](/viewer/python-net/groupdocs.viewer.options/cadoptions/render_layouts/) и [`CadOptions.layout_name`](/viewer/python-net/groupdocs.viewer.options/cadoptions/layout_name/) игнорируются при рендеринге по тайлам.
