## for_rendering_by_width_and_height {#width-height}

Инициализирует экземпляр класса CadOptions для рендеринга по ширине и высоте.

Для примера кода см. документацию.

```python
def for_rendering_by_width_and_height(cls, width, height):
    ...
```

| Параметр | Тип | Описание |
| :- | :- | :- |
| width | `int` | Ширина результирующего вывода (в пикселях). |
| height | `int` | Высота результирующего вывода (в пикселях). |

**Returns:** CadOptions: New instance of CadOptions class for rendering by width and height.

| Исключения | Описание |
| :- | :- |
| `ValueError` | Если `height` меньше или равен нулю. |
