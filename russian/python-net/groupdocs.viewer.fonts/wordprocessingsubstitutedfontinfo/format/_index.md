## format property

Формат этого заменяющего (не оригинального) шрифта.

Может быть TrueType, TrueType Collection, OpenType, Embedded OpenType. Для заменённого шрифта, поскольку его бинарное содержимое доступно по определению, это свойство никогда не возвращает значение `FontFormat.unknown`.
