Основное пространство имён GroupDocs.Viewer с классами верхнего уровня API.

### Классы
| Класс | Описание |
| :- | :- |
| [`FileType`](/viewer/python-net/groupdocs.viewer/filetype/) | Представляет тип файла и предоставляет методы для получения списка всех типов файлов, поддерживаемых GroupDocs.Viewer. |
| [`IAuxDisposable`](/viewer/python-net/groupdocs.viewer/iauxdisposable/) | Расширяет стандартный интерфейс `System.IDisposable`, позволяет получать текущее состояние объекта и подписываться на событие освобождения. |
| [`License`](/viewer/python-net/groupdocs.viewer/license/) | Управляет лицензированием GroupDocs.Viewer. |
| [`Metered`](/viewer/python-net/groupdocs.viewer/metered/) | Управляет почасовым (pay-per-use) лицензированием. |
| [`Viewer`](/viewer/python-net/groupdocs.viewer/viewer/) | Представляет основной класс, контролирующий процесс рендеринга документа. |
| [`ViewerSettings`](/viewer/python-net/groupdocs.viewer/viewersettings/) | Определяет настройки для кастомизации поведения [`Viewer`](/viewer/python-net/groupdocs.viewer/viewer/). |

### Исключения
| Исключение | Описание |
| :- | :- |
| [`GroupDocsViewerException`](/viewer/python-net/groupdocs.viewer/groupdocsviewerexception/) | Представляет общие ошибки, возникающие при обработке документа. |
| [`IncorrectPasswordException`](/viewer/python-net/groupdocs.viewer/incorrectpasswordexception/) | Исключение, которое выбрасывается, когда указан пароль неверен. |
| [`InvalidFontFormatException`](/viewer/python-net/groupdocs.viewer/invalidfontformatexception/) | Исключение, которое выбрасывается при попытке открыть, загрузить, сохранить или иным образом обработать некоторый контент, который предположительно является шрифтом поддерживаемого (известного) формата, но на самом деле является шрифтом неожиданного и/или неподдерживаемого формата или вовсе не шрифтом. |
| [`InvalidImageFormatException`](/viewer/python-net/groupdocs.viewer/invalidimageformatexception/) | Исключение, которое выбрасывается при попытке открыть, загрузить, сохранить или иным образом обработать некоторый контент, который предположительно является изображением (растровым или векторным), но на самом деле является изображением неожиданного и/или неподдерживаемого формата или вовсе не изображением. |
| [`PasswordRequiredException`](/viewer/python-net/groupdocs.viewer/passwordrequiredexception/) | Исключение, которое выбрасывается, когда для загрузки документа требуется пароль. |
