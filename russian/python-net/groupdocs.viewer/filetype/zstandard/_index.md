## ZSTANDARD field

ZST‑файл — это сжатый файл, созданный с помощью алгоритма сжатия Zstandard (zstd). Это сжатый файл, полученный без потерь благодаря этому алгоритму. ZST‑файлы могут использоваться для сжатия различных типов файлов, таких как базы данных, файловые системы, сети и игры. Узнайте больше о этом формате файла здесь.
