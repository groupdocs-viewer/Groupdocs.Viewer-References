## DWG field

AutoCAD Drawing Database File (.dwg) представляет собой проприетарные бинарные файлы, используемые для хранения 2‑D и 3‑D данных дизайна. Как и DXF, который является ASCII‑файлом, DWG представляет бинарный формат файлов для чертежей CAD (Computer Aided Design). Узнайте больше о этом формате файла здесь.
