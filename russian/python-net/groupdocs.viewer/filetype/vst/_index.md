## VST field

Visio Drawing Template (.vst) — это векторные файлы изображений, созданные в Microsoft Visio и служащие шаблонами для создания последующих файлов. Эти шаблонные файлы находятся в бинарном формате и содержат макет и настройки по умолчанию, используемые при создании новых чертежей Visio. Узнайте больше о этом формате файла здесь.
