## VSTM field

Visio Macro-Enabled Drawing Template (.vstm) — это шаблонные файлы, созданные в Microsoft Visio с поддержкой макросов. В отличие от файлов VSDX, файлы, созданные из шаблонов VSTM, могут выполнять макросы, разработанные на языке Visual Basic for Applications (VBA). Узнайте больше о этом формате файла здесь.
