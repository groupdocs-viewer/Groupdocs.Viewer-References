## POTM field

PowerPoint Open XML Macro-Enabled Presentation Template (.potm) — это файлы шаблонов Microsoft PowerPoint с поддержкой макросов. Файлы POTM создаются в PowerPoint 2007 или новее и содержат настройки по умолчанию, которые можно использовать для создания дальнейших файлов презентаций. Узнайте больше об этом формате файла здесь.
