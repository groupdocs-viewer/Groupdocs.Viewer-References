## TZST field

TZST‑файлы (.tar.zst, .tzst) представляют собой архивы Zstandard (ZST), которые внутри содержат объединённый Unix‑архив (Tar), созданный с помощью Unix‑утилиты для сбора одного или нескольких файлов.
