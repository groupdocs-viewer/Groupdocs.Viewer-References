## VDX field

Visio Drawing XML File (.vdx) представляет любой чертеж или схему, созданные в Microsoft Visio, но сохранённые в формате XML с расширением .VDX. Файл XML‑чертежа Visio создаётся в программном обеспечении Visio, разработанном Microsoft. Узнайте больше о этом формате файла здесь.
