## PPS field

Слайд‑шоу PowerPoint (.pps) создаётся с помощью Microsoft PowerPoint для целей показа слайдов. Чтение и создание файлов PPS поддерживается Microsoft PowerPoint 97‑2003. Узнайте больше о этом формате файла здесь.
