## XPS field

Файл XML Paper Specification (.xps) представляет файлы разметки страниц, основанные на XML Paper Specification, созданной Microsoft. Этот формат был разработан Microsoft как замена формата EMF и похож на формат PDF, но использует XML для описания разметки, внешнего вида и печатной информации документа. Узнайте больше о этом формате файла здесь.
