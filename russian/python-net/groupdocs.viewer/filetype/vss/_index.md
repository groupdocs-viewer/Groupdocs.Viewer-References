## VSS field

Visio Stencil File (.vss) — это файлы шаблонов, созданные в Microsoft Visio 2007 и более ранних версиях. Файлы шаблонов предоставляют объекты чертежа, которые могут быть включены в чертёж Visio формата .VSD. Узнайте больше о этом формате файла здесь.
