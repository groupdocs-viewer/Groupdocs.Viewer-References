## XLTM field

Microsoft Excel Macro-Enabled Template (.xltm) представляет файлы, генерируемые Microsoft Excel как шаблоны с поддержкой макросов. Файлы XLTM похожи на XLTX по структуре, за исключением того, что последние не поддерживают создание шаблонов с макросами. Узнайте больше об этом формате файла здесь.
