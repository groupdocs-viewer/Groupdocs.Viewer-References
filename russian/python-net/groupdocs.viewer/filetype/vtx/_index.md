## VTX field

Visio Template XML File (.vtx) — это шаблон чертежа Microsoft Visio, сохраняемый на диск в формате XML. Шаблон предназначен для предоставления файла с базовыми настройками, которые можно использовать для создания нескольких файлов Visio с одинаковыми параметрами. Узнайте больше о этом формате файла здесь.
