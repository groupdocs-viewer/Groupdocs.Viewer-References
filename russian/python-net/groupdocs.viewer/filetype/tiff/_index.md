## TIFF field

Tagged Image File Format (.tiff) представляет растровые изображения, предназначенные для использования на различных устройствах, соответствующих этому стандарту формата файлов. Он способен описывать двухуровневые, градации серого, палитровые и полноцветные данные изображений в нескольких цветовых пространствах. Узнайте больше об этом формате файла здесь.
