## DWFX field

Design Web Format File XPS (.dwfx) представляет 2‑D/3‑D чертеж в виде XPS‑документа в сжатом формате для просмотра, рецензирования или печати файлов дизайна. Он содержит графику и текст как часть данных дизайна и уменьшает размер файла благодаря сжатому формату. Узнайте больше о этом формате файла здесь.
