## PPTX field

Презентация PowerPoint Open XML (.pptx) — это файлы презентаций, созданные популярным приложением Microsoft PowerPoint. В отличие от предыдущей версии формата PPT, который был бинарным, формат PPTX основан на открытом XML‑формате презентаций Microsoft PowerPoint. Узнайте больше о этом формате файла здесь.
