## VSDX field

Visio Drawing (.vsdx) представляет файловый формат Microsoft Visio, представленный, начиная с Microsoft Office 2013. Он был разработан для замены бинарного формата .VSD, поддерживаемого более ранними версиями Microsoft Visio. Узнайте больше о этом формате файла здесь.
