## VSSM field

Visio Macro-Enabled Stencil File (.vssm) — это файлы шаблонов Microsoft Visio, поддерживающие макросы. При открытии файла VSSM можно выполнять макросы для достижения требуемого форматирования и размещения фигур в диаграмме. Узнайте больше о этом формате файла здесь.
