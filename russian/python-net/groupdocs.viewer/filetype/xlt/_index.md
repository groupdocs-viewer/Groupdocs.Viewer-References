## XLT field

Microsoft Excel Template (.xlt) — это файлы шаблонов, созданные в Microsoft Excel, который является приложением для работы с электронными таблицами и входит в состав пакета Microsoft Office. Microsoft Office 97‑2003 поддерживал создание новых файлов XLT, а также их открытие. Узнайте больше об этом формате файла здесь.
