## PPT field

Презентация PowerPoint (.ppt) представляет файл PowerPoint, содержащий набор слайдов для отображения в виде слайд‑шоу. Он определяет бинарный формат файла, используемый Microsoft PowerPoint 97‑2003. Узнайте больше о этом формате файла здесь.
