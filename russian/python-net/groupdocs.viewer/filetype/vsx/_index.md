## VSX field

Visio Stencil XML File (.vsx) относится к шаблонам, состоящим из чертежей и фигур, используемых для создания диаграмм в Microsoft Visio. Файлы VSX сохраняются в формате XML и поддерживались до Visio 2013. Узнайте больше о этом формате файла здесь.
