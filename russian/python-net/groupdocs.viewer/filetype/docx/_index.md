## DOCX field

Документ Microsoft Word Open XML (.docx) — известный формат документов Microsoft Word. Появился в 2007 году с выпуском Microsoft Office 2007, структура этого нового формата документа была изменена с обычного бинарного на комбинацию XML и бинарных файлов. Узнайте больше о этом формате файла здесь.
