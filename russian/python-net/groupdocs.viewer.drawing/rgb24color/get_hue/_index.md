## get_hue

Возвращает компонент оттенка (hue) цвета в цветовом пространстве HSL, выраженный в градусах. Если цвет является оттенком серого (R == G == B), оттенок не определён, и метод возвращает 0.

```python
def get_hue(self):
    ...
```

**Returns:** float: Hue value in degrees.
