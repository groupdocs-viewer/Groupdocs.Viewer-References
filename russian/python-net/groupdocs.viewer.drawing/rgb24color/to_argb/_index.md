Возвращает значение ARGB данного экземпляра [`Rgb24Color`](/viewer/python-net/groupdocs.viewer.drawing/rgb24color/), совместимое с `System.Drawing.Color`.

```python
def to_argb(self):
    ...
```

**Returns:** 32-bit ARGB value of this instance as int, identical to `System.Drawing.Color.ToArgb` call for the same color. Never throws an exception.
