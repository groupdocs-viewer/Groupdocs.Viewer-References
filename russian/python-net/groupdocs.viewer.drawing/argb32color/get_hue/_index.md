## get_hue

Возвращает значение оттенка (hue) модели Hue‑Saturation‑Lightness (HSL) в градусах для данного экземпляра [`Argb32Color`](/viewer/python-net/groupdocs.viewer.drawing/argb32color/); если R == G == B, оттенок не имеет смысла, и метод возвращает 0.

```python
def get_hue(self):
    ...
```

**Returns:** float: The hue in degrees, or 0 if the color is achromatic.
