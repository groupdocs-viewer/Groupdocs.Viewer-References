## CacheKeys class

Предоставляет методы для получения уникального идентификатора записи кэша.

Тип CacheKeys предоставляет следующие члены:

### Методы
| Метод | Описание |
| :- | :- |
| [get_attachment_key](/viewer/python-net/groupdocs.viewer.caching/cachekeys/get_attachment_key/#attachment_id) | Возвращает уникальный идентификатор для кэш‑записи, представляющей файл вложения. |
| [get_attachments_key](/viewer/python-net/groupdocs.viewer.caching/cachekeys/get_attachments_key/) | Возвращает уникальный идентификатор для кэш‑записи, представляющей коллекцию объектов [`Attachment`](/viewer/python-net/groupdocs.viewer.results/attachment/). |
| [get_file_info_key](/viewer/python-net/groupdocs.viewer.caching/cachekeys/get_file_info_key/) | Возвращает уникальный идентификатор для кэш‑записи, представляющей объект [`ViewInfo`](/viewer/python-net/groupdocs.viewer.results/viewinfo/). |
| [get_file_key](/viewer/python-net/groupdocs.viewer.caching/cachekeys/get_file_key/#extension) | Возвращает уникальный идентификатор для кэш‑записи, представляющей файл. |
| [get_page_key](/viewer/python-net/groupdocs.viewer.caching/cachekeys/get_page_key/#page_number-extension) | Возвращает уникальный идентификатор для кэш‑записи, представляющей файл страницы. |
| [get_resource_filter](/viewer/python-net/groupdocs.viewer.caching/cachekeys/get_resource_filter/#page_number) | Возвращает строку фильтра для поиска кэш‑записей, представляющих объекты [`Resource`](/viewer/python-net/groupdocs.viewer.results/resource/). |
| [get_resource_key](/viewer/python-net/groupdocs.viewer.caching/cachekeys/get_resource_key/#page_number-resource) | Возвращает уникальный идентификатор для кэш‑записи, представляющей объект [`Resource`](/viewer/python-net/groupdocs.viewer.results/resource/). |
| [get_view_info_key](/viewer/python-net/groupdocs.viewer.caching/cachekeys/get_view_info_key/) | Возвращает уникальный идентификатор для кэш‑записи, представляющей объект [`ViewInfo`](/viewer/python-net/groupdocs.viewer.results/viewinfo/). |
