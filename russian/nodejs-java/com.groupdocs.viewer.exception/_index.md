Пакет предоставляет классы для исключений, которые могут возникнуть при работе с документом.

Основные классы в этом пакете:

 *  com.groupdocs.viewer.exception.ArchiveSecurityException - Thrown when an archive being opened exceeds specified limits.
 *  [FileNotFoundException](../../com.groupdocs.viewer.exception/filenotfoundexception) - Represents an exception thrown when a file or directory is not found.
 *  [GroupDocsViewerException](../../com.groupdocs.viewer.exception/groupdocsviewerexception) - Represents generic errors that occur during document processing.

Для получения более подробной информации о работе с исключениями в GroupDocs.Viewer, пожалуйста, обратитесь к [GroupDocs.Viewer Documentation][].


[GroupDocs.Viewer Documentation]: https://docs.groupdocs.com/viewer/java/


## Классы

| Класс | Описание |
| --- | --- |
| [ArchiveSecurityException](../com.groupdocs.viewer.exception/archivesecurityexception) | Это исключение выбрасывается, когда открываемый архив превышает любые из ограничений, указанных в ArchiveSecurityOptions. |
| [FileNotFoundException](../com.groupdocs.viewer.exception/filenotfoundexception) | Это исключение выбрасывается, когда файл или каталог не найден. |
| [GroupDocsViewerException](../com.groupdocs.viewer.exception/groupdocsviewerexception) | Это исключение представляет собой общие ошибки, которые могут возникнуть при обработке документа. |
| [IncorrectPasswordException](../com.groupdocs.viewer.exception/incorrectpasswordexception) | Это исключение выбрасывается, когда указанный пароль неверен. |
| [NotSupportedException](../com.groupdocs.viewer.exception/notsupportedexception) | Это исключение выбрасывается, когда запрошенная операция не поддерживается. |
| [PasswordRequiredException](../com.groupdocs.viewer.exception/passwordrequiredexception) | Это исключение выбрасывается, когда для загрузки документа требуется пароль. |
