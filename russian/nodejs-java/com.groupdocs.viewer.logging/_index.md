Пакет предоставляет классы для настройки системы логирования в GroupDocs.Viewer.

Используя эти классы, вы можете управлять тем, как обрабатываются сообщения журнала, например, записывая их в файл или направляя в конкретную реализацию логгера.

Основные классы в этом пакете:

 *  [FileLogger](../../com.groupdocs.viewer.logging/filelogger) - Writes log messages to a file.
 *  [ViewerLogger](../../com.groupdocs.viewer.logging/viewerlogger) - Implements logging messages to an integrated or user-defined logger.

Для получения более подробной информации о настройке системы логирования в GroupDocs.Viewer и кастомизации обработки сообщений журнала, пожалуйста, обратитесь к [GroupDocs.Viewer Documentation][].


[GroupDocs.Viewer Documentation]: https://docs.groupdocs.com/viewer/java/


## Классы

| Класс | Описание |
| --- | --- |
| [FileLogger](../com.groupdocs.viewer.logging/filelogger) | Записывает сообщения журнала в файл. |
| [ViewerLogger](../com.groupdocs.viewer.logging/viewerlogger) | Глобальный журнал просмотрщика. |
