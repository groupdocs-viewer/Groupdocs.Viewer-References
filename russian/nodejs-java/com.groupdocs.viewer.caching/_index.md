Пакет предоставляет классы для настройки поведения кэширования.

Основные классы и интерфейсы в этом пакете:

 *  [CacheKeys](../../com.groupdocs.viewer.caching/cachekeys) - Provides methods to retrieve unique identifiers for the cache entry.
 *  [FileCache](../../com.groupdocs.viewer.caching/filecache) - Represents a local on-disk cache.

Интерфейс [Cache](../../com.groupdocs.viewer.caching/cache) определяет методы, необходимые для хранения отрисованных документов и ресурсов документов в кэше.

Для получения более подробной информации о настройке поведения кэширования в GroupDocs.Viewer, пожалуйста, обратитесь к [GroupDocs.Viewer Documentation][].


[GroupDocs.Viewer Documentation]: https://docs.groupdocs.com/viewer/java/
