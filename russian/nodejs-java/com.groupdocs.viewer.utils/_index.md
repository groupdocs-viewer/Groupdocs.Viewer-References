Пакет предоставляет вспомогательные и утилитные классы для различных функций.

Эти классы предлагают удобные методы и функции для помощи в различных операциях.

Основные классы в этом пакете:

 *  [MemoryCleaner](../../com.groupdocs.viewer.utils/memorycleaner) - Provides methods to clean up resources and free memory.
 *  [PathUtils](../../com.groupdocs.viewer.utils/pathutils) - Represents the type for working with paths.

Для получения более подробной информации об использовании утилитных классов в пакете com.groupdocs.viewer.utils, пожалуйста, обратитесь к [GroupDocs.Viewer Documentation][].
