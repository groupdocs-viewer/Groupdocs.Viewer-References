Пакет предоставляет классы для указания дополнительных параметров при рендеринге документов.


Он включает параметры для рендеринга различных форматов документов, определения разрешений и настроек безопасности,
указания свойств водяного знака и получения информации о представлениях.

Основные классы в этом пакете:

* [ArchiveOptions](../../com.groupdocs.viewer.options/archiveoptions) - Provides options for rendering archive files.
* [PdfOptions](../../com.groupdocs.viewer.options/pdfoptions) - Provides options for rendering PDF documents.
* [WordProcessingOptions](../../com.groupdocs.viewer.options/wordprocessingoptions) - Provides options for rendering word processing documents.


Для получения более подробной информации о настройке системы логирования в GroupDocs.Viewer и кастомизации обработки сообщений журнала,
пожалуйста, обратитесь к [Документации GroupDocs.Viewer](../https://docs.groupdocs.com/viewer/java/).
