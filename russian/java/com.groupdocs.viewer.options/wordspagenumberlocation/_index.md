Контролирует, следует ли принудительно применять нумерацию страниц к загруженному документу WordProcessing и, если да, где размещать номера страниц.

## Поля

| Поле | Описание |
| --- | --- |
|  | [NOT_APPLY](#NOT-APPLY) | Оставить загруженный документ WordProcessing без изменений. |
|
|  | [TOP_LEFT](#TOP-LEFT) | Поместить номер страницы в левый верхний угол страницы. |
|
|  | [TOP_CENTER](#TOP-CENTER) | Поместить номер страницы в верхний центр страницы. |
|
|  | [TOP_RIGHT](#TOP-RIGHT) | Поместить номер страницы в правый верхний угол страницы. |
|
|  | [BOTTOM_LEFT](#BOTTOM-LEFT) | Поместить номер страницы в левый нижний угол страницы. |
|
|  | [BOTTOM_CENTER](#BOTTOM-CENTER) | Поместить номер страницы в нижний центр страницы. |
|
|  | [BOTTOM_RIGHT](#BOTTOM-RIGHT) | Поместить номер страницы в правый нижний угол страницы. |
|
