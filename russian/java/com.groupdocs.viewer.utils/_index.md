Пакет предоставляет вспомогательные и утилитные классы для различных функций.


Эти классы предлагают удобные методы и функции, помогающие в различных операциях.

Основные классы в этом пакете:

* [CancellationToken](../../com.groupdocs.viewer.utils/cancellationtoken) - Propagates a request to cancel rendering.
* [CancellationTokenSource](../../com.groupdocs.viewer.utils/cancellationtokensource) - Creates and signals a [CancellationToken](../../com.groupdocs.viewer.utils/cancellationtoken).
* [MemoryCleaner](../../com.groupdocs.viewer.utils/memorycleaner) - Provides methods to clean up resources and free memory.
* [PathUtils](../../com.groupdocs.viewer.utils/pathutils) - Represents the type for working with paths.


Для получения более подробной информации об использовании утилитных классов в пакете com.groupdocs.viewer.utils,
пожалуйста, обратитесь к [Документации GroupDocs.Viewer](../https://docs.groupdocs.com/viewer/java/).

| [CancellationTokenSource](../com.groupdocs.viewer.utils/cancellationtokensource) | Сигнализирует [CancellationToken](../com.groupdocs.viewer.utils/cancellationtoken), что операция должна быть отменена. |
| [MemoryCleaner](../com.groupdocs.viewer.utils/memorycleaner) | Очищает различные ресурсы для освобождения памяти. |
