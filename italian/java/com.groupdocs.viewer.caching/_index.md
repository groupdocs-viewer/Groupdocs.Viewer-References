Il pacchetto fornisce classi per personalizzare il comportamento della cache.

Le classi e le interfacce principali in questo pacchetto sono:

* [CacheKeys](../../com.groupdocs.viewer.caching/cachekeys) - Provides methods to retrieve unique identifiers for the cache entry.
* [FileCache](../../com.groupdocs.viewer.caching/filecache) - Represents a local on-disk cache.


L'interfaccia [Cache](../../com.groupdocs.viewer.caching/cache) definisce i metodi richiesti per memorizzare i documenti renderizzati
e le risorse dei documenti nella cache.


Per maggiori dettagli sulla personalizzazione del comportamento della cache in GroupDocs.Viewer, fare riferimento al
[GroupDocs.Viewer Documentation](../https://docs.groupdocs.com/viewer/java/).



## Classi

| Classe | Descrizione |
| --- | --- |
| [CacheKeys](../com.groupdocs.viewer.caching/cachekeys) | Fornisce metodi per recuperare l'identificatore univoco di una voce della cache. |
| [FileCache](../com.groupdocs.viewer.caching/filecache) | Rappresenta una cache locale su disco. |

## Interfacce

| Interfaccia | Descrizione |
| --- | --- |
