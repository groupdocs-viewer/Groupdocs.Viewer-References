Il pacchetto fornisce classi per le eccezioni che possono verificarsi durante la lavorazione di un documento.

Le classi principali in questo pacchetto sono:

* com.groupdocs.viewer.exception.ArchiveSecurityException - Thrown when an archive being opened exceeds specified limits.
* [FileNotFoundException](../../com.groupdocs.viewer.exception/filenotfoundexception) - Represents an exception thrown when a file or directory is not found.
* [GroupDocsViewerException](../../com.groupdocs.viewer.exception/groupdocsviewerexception) - Represents generic errors that occur during document processing.


Per maggiori dettagli su come gestire le eccezioni in GroupDocs.Viewer, fare riferimento al
[GroupDocs.Viewer Documentation](../https://docs.groupdocs.com/viewer/java/).

| Classe | Descrizione |

| [ArchiveSecurityException](../com.groupdocs.viewer.exception/archivesecurityexception) | Questa eccezione viene sollevata quando un archivio aperto supera uno dei limiti specificati in ArchiveSecurityOptions. |
| [FileNotFoundException](../com.groupdocs.viewer.exception/filenotfoundexception) | Questa eccezione viene sollevata quando un file o una directory non viene trovata. |
| [GroupDocsViewerException](../com.groupdocs.viewer.exception/groupdocsviewerexception) | Questa eccezione rappresenta errori generici che possono verificarsi durante l'elaborazione del documento. |

| [PasswordRequiredException](../com.groupdocs.viewer.exception/passwordrequiredexception) | Questa eccezione viene sollevata quando è necessaria una password per caricare il documento. |
