public interface FontSource
```

Marker interface for the font sources.


The FontSource interface serves as a marker interface for all types of font sources used in the GroupDocs.Viewer API.


***Note:** This is a marker interface and does not define any additional methods or functionality.
Its purpose is to categorize and identify font source implementations.*
