Il pacchetto fornisce classi e interfacce che rappresentano i risultati del rendering dei documenti.


Queste classi incapsulano informazioni su vari elementi e componenti del documento renderizzato,
come pagine, allegati, visualizzazioni, risorse e altro.

Le classi principali in questo pacchetto sono:

* [Page](../../com.groupdocs.viewer.results/page) - Represents a single page that can be viewed.
* [Attachment](../../com.groupdocs.viewer.results/attachment) - Represents an attachment file contained by an email message, archive, PDF document, or Outlook data file.
* [PdfViewInfo](../../com.groupdocs.viewer.results/pdfviewinfo) - Represents view information for a PDF document.


Per ulteriori dettagli sul lavoro con i risultati del rendering dei documenti usando GroupDocs.Viewer,
Si prega di fare riferimento alla [Documentazione GroupDocs.Viewer](../https://docs.groupdocs.com/viewer/java/).
