Il pacchetto fornisce classi per configurare il sistema di logging in GroupDocs.Viewer.


Utilizzando queste classi, è possibile controllare come vengono gestiti i messaggi di log, ad esempio scrivendoli su
un file o indirizzandoli a un'implementazione specifica del logger.

Le classi principali in questo pacchetto sono:

* [FileLogger](../../com.groupdocs.viewer.logging/filelogger) - Writes log messages to a file.
* [ViewerLogger](../../com.groupdocs.viewer.logging/viewerlogger) - Implements logging messages to an integrated or user-defined logger.


Per maggiori dettagli sulla configurazione del sistema di logging in GroupDocs.Viewer e sulla personalizzazione della gestione dei messaggi di log,
Si prega di fare riferimento alla [Documentazione GroupDocs.Viewer](../https://docs.groupdocs.com/viewer/java/).



## Classi

| Classe | Descrizione |
| --- | --- |
| [FileLogger](../com.groupdocs.viewer.logging/filelogger) | Scrive i messaggi di log su un file. |
| [ViewerLogger](../com.groupdocs.viewer.logging/viewerlogger) | Logger globale del visualizzatore. |
