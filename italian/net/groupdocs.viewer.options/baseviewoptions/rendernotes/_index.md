## BaseViewOptions.RenderNotes property

Abilita il rendering di note e annotazioni per alcuni formati.

```csharp
public bool RenderNotes { get; set; }
```

### Osservazioni

Alcuni formati, come presentazioni o file Microsoft Project, possono contenere note. Inoltre, i file PDF possono avere annotazioni popup (suggerimenti a fumetto), che sono nascoste per impostazione predefinita e sono visibili in un visualizzatore PDF solo quando si passa il cursore del mouse su di esse. Per impostazione predefinita, GroupDocs.Viewer non rende tali note e annotazioni (`false`). Per farlo, impostare questa proprietà su `true`.

Per un esempio di codice, vedere la [documentazione](https://docs.groupdocs.com/viewer/net/render-presentations/#render-speaker-notes).
