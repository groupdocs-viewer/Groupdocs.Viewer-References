## JpgViewOptions.Quality property

Imposta la qualità dell'immagine di output.

```csharp
public byte Quality { get; set; }
```

### Osservazioni

Utilizzare questa proprietà per regolare la qualità delle immagini. Il valore deve essere compreso tra 1 (qualità minima) e 100. Il valore predefinito è 90.

Per un esempio di codice, vedere la [documentazione](https://docs.groupdocs.com/viewer/net/image-viewer-adjust-quality-for-jpg/).
