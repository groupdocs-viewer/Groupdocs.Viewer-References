## PresentationOptions.RenderToPureHtml property

Abilita una nuova modalità di rendering HTML per i documenti Presentation — in questa modalità i file Presentation vengono renderizzati in **pure HTML/CSS markup**, senza immagini SVG. Per impostazione predefinita è disabilitata (`false`) — viene utilizzato il renderer HTML basato su SVG esistente.

```csharp
public bool RenderToPureHtml { get; set; }
```
