## PresentationOptions.RenderHeaderFooterPlaceholders property

Abilita il rendering dei segnaposto nell'intestazione e nel piè di pagina di una diapositiva. Disabilitato per impostazione predefinita (`false`). Questa opzione si applica a tutte le 4 modalità di rendering delle presentazioni: HTML, PDF, PNG e JPEG. Non è applicabile quando si renderizza la presentazione in markup HTML/CSS puro utilizzando [`RenderToPureHtml`](../rendertopurehtml).

public bool RenderHeaderFooterPlaceholders { get; set; }
