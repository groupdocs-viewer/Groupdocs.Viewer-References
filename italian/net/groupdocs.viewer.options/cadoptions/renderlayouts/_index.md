## CadOptions.RenderLayouts property

Indica se i layout del documento CAD devono essere renderizzati.

```csharp
public bool RenderLayouts { get; set; }
```

### Osservazioni

Questa opzione è disponibile solo per i disegni CAD che supportano layout [`DXF`](../../../groupdocs.viewer/filetype/dxf), [`DWG`](../../../groupdocs.viewer/filetype/dwg), [`DWT`](../../../groupdocs.viewer/filetype/dwt), e [`DWF`](../../../groupdocs.viewer/filetype/dwf), e [`DWFX`](../../../groupdocs.viewer/filetype/dwfx). Per impostazione predefinita viene renderizzato solo il Modello.
