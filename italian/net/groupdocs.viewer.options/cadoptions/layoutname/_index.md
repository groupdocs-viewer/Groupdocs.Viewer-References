## CadOptions.LayoutName property

Il nome del layout specifico da renderizzare. Il nome del layout è sensibile al maiuscolo/minuscolo.

```csharp
public string LayoutName { get; set; }
```

### Osservazioni

Questa opzione è disponibile solo per i disegni CAD che supportano layout: [`DXF`](../../../groupdocs.viewer/filetype/dxf), [`DWG`](../../../groupdocs.viewer/filetype/dwg), [`DWT`](../../../groupdocs.viewer/filetype/dwt), [`DWF`](../../../groupdocs.viewer/filetype/dwf) e [`DWFX`](../../../groupdocs.viewer/filetype/dwfx); per impostazione predefinita viene renderizzato solo il Modello.
