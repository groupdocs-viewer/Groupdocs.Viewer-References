## SearchHighlightOptions.IsSearchTermRegEx property

Ottiene o imposta un valore che indica se il termine di ricerca deve essere trattato come espressione regolare o come stringa letterale. Il valore predefinito è `false` — trattare come stringa letterale.

```csharp
public bool IsSearchTermRegEx { get; set; }
```

### Osservazioni

Se `true`, [`SearchTerm`](../searchterm) è interpretato come modello Regex .NET.

Se `false`, [`SearchTerm`](../searchterm) è cercato come testo letterale nel documento.
