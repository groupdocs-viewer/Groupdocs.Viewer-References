## MailStorageOptions.MaxItems property

Imposta il numero massimo di messaggi o elementi da renderizzare.

```csharp
public int MaxItems { get; set; }
```

### Osservazioni

I file di dati di archiviazione della posta possono essere grandi e il recupero di tutti i messaggi può richiedere molto tempo. Questa proprietà limita il numero massimo di messaggi o elementi che vengono renderizzati. Il valore predefinito è 0 - tutti i messaggi vengono renderizzati.

Per un esempio di codice, vedere la [documentazione](https://docs.groupdocs.com/viewer/net/render-lotus-notes-database-files/#limit-the-number-of-items-to-render).
