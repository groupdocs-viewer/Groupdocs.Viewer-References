## OutlookOptions.MaxItemsInFolder property

Il numero massimo di messaggi o elementi che possono essere renderizzati da una cartella.

```csharp
public int MaxItemsInFolder { get; set; }
```

### Osservazioni

I file di dati Outlook possono essere grandi e il recupero di tutti i messaggi può richiedere molto tempo. Questa proprietà limita il numero massimo di messaggi o elementi che vengono renderizzati. Il valore predefinito è `50`. Per renderizzare tutti i messaggi, impostare il valore a `0`.

Per un esempio di codice, vedere la [documentazione](https://docs.groupdocs.com/viewer/net/render-outlook-data-files/#limit-the-number-of-folder-items-to-render).
