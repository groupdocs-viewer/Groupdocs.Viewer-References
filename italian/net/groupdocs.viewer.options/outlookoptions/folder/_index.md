## OutlookOptions.Folder property

Imposta il nome della cartella (ad es. Inbox, Sent Item o Deleted Items) da renderizzare.

```csharp
public string Folder { get; set; }
```

### Osservazioni

Durante il rendering di un file di dati Outlook, GroupDocs.Viewer renderizza i messaggi da tutte le cartelle contenute nel file (incluse le cartelle nidificate). Utilizzare questa proprietà per renderizzare gli elementi da una cartella specifica.

Per un esempio di codice, vedere questa [documentazione](https://docs.groupdocs.com/viewer/net/render-outlook-data-files/#render-a-specific-folder).
