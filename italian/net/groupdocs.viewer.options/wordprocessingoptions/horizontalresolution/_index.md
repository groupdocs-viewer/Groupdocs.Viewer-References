## WordProcessingOptions.HorizontalResolution property

Ottiene o imposta la risoluzione orizzontale per le immagini generate in punti per pollice. Questa opzione è utilizzata solo durante il rendering di documenti WordProcessing in formati PNG o JPEG.

```csharp
public int HorizontalResolution { get; set; }
```

### Osservazioni

Il valore predefinito è 96 DPI. Valore minimo possibile - 72 DPI, valore massimo possibile - 600 DPI. Se il valore specificato dall'utente è fuori da questi limiti, verrà applicato il valore minimo o massimo possibile.
