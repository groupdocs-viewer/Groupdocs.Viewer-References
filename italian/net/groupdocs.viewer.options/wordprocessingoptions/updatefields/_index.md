## WordProcessingOptions.UpdateFields property

Ottiene o imposta un valore che determina se i campi di determinati tipi devono essere aggiornati prima di salvare il documento WordProcessing di input nei formati di output HTML, PDF, PNG o JPEG. Il valore predefinito per questa proprietà è `true` — i campi saranno aggiornati prima del salvataggio.

```csharp
public bool UpdateFields { get; set; }
```
