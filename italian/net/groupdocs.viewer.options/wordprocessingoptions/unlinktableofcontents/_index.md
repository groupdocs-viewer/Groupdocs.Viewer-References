## WordProcessingOptions.UnlinkTableOfContents property

Durante il rendering in HTML o PDF, è possibile impostare questa opzione su `true` per disabilitare la navigazione dall'indice. Per il rendering HTML, i tag `a` con collegamenti relativi saranno sostituiti da tag `span`, rimuovendo la funzionalità ma mantenendo l'aspetto visivo. Per il rendering PDF, l'indice verrà renderizzato come testo semplice senza collegamenti alle sezioni del documento.

```csharp
public bool UnlinkTableOfContents { get; set; }
```

### Osservazioni

Il valore predefinito è `false`.

Per i dettagli, vedere la [documentazione](https://docs.groupdocs.com/viewer/net/render-word-documents/#unlink-table-of-contents).
