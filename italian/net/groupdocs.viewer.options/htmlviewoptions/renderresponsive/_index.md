## HtmlViewOptions.RenderResponsive property

Abilita il rendering responsivo.

```csharp
public bool RenderResponsive { get; set; }
```

### Osservazioni

Il design responsivo mira a far sì che le pagine web vengano visualizzate correttamente su una varietà di dispositivi. Per renderizzare con un layout responsivo, impostare questa proprietà su `true`.

Per un esempio di codice, vedere la [documentazione](https://docs.groupdocs.com/viewer/net/render-with-responsive-layout/).
