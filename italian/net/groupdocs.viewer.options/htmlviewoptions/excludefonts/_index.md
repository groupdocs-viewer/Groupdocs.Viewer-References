## HtmlViewOptions.ExcludeFonts property

Disabilita l'aggiunta di qualsiasi font nel documento HTML.

```csharp
public bool ExcludeFonts { get; set; }
```

### Osservazioni

Per impostazione predefinita, GroupDocs.Viewer incorpora i caratteri usati nel documento nel markup HTML, e questa proprietà ha valore `false`. Per impedire l'incorporamento dei caratteri, impostare questa proprietà su `true`.

Per ulteriori dettagli e un esempio di codice, vedere la [documentazione](https://docs.groupdocs.com/viewer/net/exclude-fonts/).
