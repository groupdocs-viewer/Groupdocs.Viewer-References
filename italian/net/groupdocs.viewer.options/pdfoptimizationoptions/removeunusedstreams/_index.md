## PdfOptimizationOptions.RemoveUnusedStreams property

Rimuove i flussi inutilizzati (orfani) da un file PDF, che sono ancora referenziati dal dizionario delle risorse della pagina, ma in realtà non vengono mai utilizzati nei contenuti della pagina. Per impostazione predefinita è disabilitata (`false`), abilitarla (`true`) ridurrà la dimensione del documento PDF di output.

```csharp
public bool RemoveUnusedStreams { get; set; }
```
