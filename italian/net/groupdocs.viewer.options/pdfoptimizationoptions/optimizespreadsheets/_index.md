## PdfOptimizationOptions.OptimizeSpreadsheets property

Abilita l'ottimizzazione dei fogli di calcolo nei file PDF.

```csharp
public bool OptimizeSpreadsheets { get; set; }
```

### Osservazioni

Questa ottimizzazione consente di ridurre la dimensione del file di output impostando le linee di bordo. Inoltre, rimuove i caratteri Arial e Times New Roman dei codici da 32 a 127.
