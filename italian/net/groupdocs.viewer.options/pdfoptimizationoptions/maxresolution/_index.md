## PdfOptimizationOptions.MaxResolution property

Imposta la risoluzione massima nel file PDF di output.

```csharp
public int MaxResolution { get; set; }
```

### Osservazioni

Per consentire questa opzione, impostare le proprietà [`CompressImages`](../compressimages) e `MaxResolution` su `true`.

Il valore predefinito è `300`.

Per un esempio di codice, vedere questa [documentazione](https://docs.groupdocs.com/viewer/net/optimization-pdf-set-max-resolution/).
