## PdfOptimizationOptions.RemoveUnusedObjects property

Rimuove gli oggetti inutilizzati (orfani) da un file PDF, che sono presenti nel documento PDF ma non sono referenziati dai dizionari delle risorse di alcuna pagina e quindi non sono utilizzati affatto. Attivare questa proprietà (`true`) ridurrà la dimensione del documento PDF di output. Per impostazione predefinita è disabilitata (`false`).

```csharp
public bool RemoveUnusedObjects { get; set; }
```
