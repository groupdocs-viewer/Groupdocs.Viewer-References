## PdfViewOptions.ImageMaxWidth property

Imposta la larghezza massima di un'immagine di output (in pixel).

```csharp
public int ImageMaxWidth { get; set; }
```

### Osservazioni

Utilizza questa proprietà per impostare la larghezza massima dell'immagine di output (in pixel). GroupDocs.Viewer applica questa proprietà durante il rendering di un'unica immagine in PDF. Per ulteriori dettagli, consulta la [documentazione](https://docs.groupdocs.com/viewer/net/set-image-size-limits-when-rendering-to-pdf/).

Se imposti la proprietà [`ImageWidth`](../imagewidth), questa proprietà viene ignorata.
