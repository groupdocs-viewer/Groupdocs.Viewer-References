## PdfViewOptions.ImageHeight property

Imposta l'altezza di un'immagine di output (in pixel).

```csharp
public int ImageHeight { get; set; }
```

### Osservazioni

Utilizza questa proprietà per impostare l'altezza dell'immagine di output (in pixel). GroupDocs.Viewer applica questa proprietà durante il rendering di un'unica immagine solo in HTML. Per ulteriori dettagli, consulta la [documentazione](https://docs.groupdocs.com/viewer/net/set-image-size-limits-when-rendering-to-pdf/).

Se imposti questa proprietà, la proprietà [`ImageMaxHeight`](../imagemaxheight) viene ignorata.
