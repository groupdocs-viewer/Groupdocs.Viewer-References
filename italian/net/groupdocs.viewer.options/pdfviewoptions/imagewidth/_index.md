## PdfViewOptions.ImageWidth property

Imposta la larghezza di un'immagine di output (in pixel).

```csharp
public int ImageWidth { get; set; }
```

### Osservazioni

Utilizza questa proprietà per impostare la larghezza dell'immagine di output (in pixel). GroupDocs.Viewer applica questa proprietà durante il rendering di un'unica immagine in PDF. Per ulteriori dettagli, consulta la [documentazione](https://docs.groupdocs.com/viewer/net/set-image-size-limits-when-rendering-to-pdf/).

Se imposti questa proprietà, la proprietà [`ImageMaxWidth`](../imagemaxwidth) viene ignorata.
