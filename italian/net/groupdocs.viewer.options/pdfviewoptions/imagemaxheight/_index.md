## PdfViewOptions.ImageMaxHeight property

Imposta l'altezza massima di un'immagine di output (in pixel).

```csharp
public int ImageMaxHeight { get; set; }
```

### Osservazioni

Utilizza questa proprietà per impostare l'altezza massima dell'immagine di output (in pixel). GroupDocs.Viewer applica questa proprietà durante il rendering di un'unica immagine in PDF. Per ulteriori dettagli, consulta la [documentazione](https://docs.groupdocs.com/viewer/net/set-image-size-limits-when-rendering-to-pdf/).

Se imposti la proprietà [`ImageHeight`](../imageheight), questa proprietà viene ignorata.
