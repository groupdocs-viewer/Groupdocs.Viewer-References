## ViewInfoOptions.MaxWidth property

Imposta la larghezza massima di un'immagine di output (in pixel, solo per il rendering in PNG/JPG).

```csharp
public int MaxWidth { get; set; }
```

### Osservazioni

Usa questa proprietà per impostare la larghezza massima dell'immagine di output (in pixel). Per l'esempio di codice, vedere la [documentazione](https://docs.groupdocs.com/viewer/net/set-image-size-limits-when-rendering-to-png-jpg/).

Se imposti la proprietà [`Width`](../width), questa proprietà viene ignorata.
