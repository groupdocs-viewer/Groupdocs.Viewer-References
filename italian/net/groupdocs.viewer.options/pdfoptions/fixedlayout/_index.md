## PdfOptions.FixedLayout property

Abilita il rendering dei documenti PDF ed EPUB in HTML con un layout fisso.

```csharp
public bool FixedLayout { get; set; }
```

### Osservazioni

I documenti PDF ed EPUB vengono inizialmente renderizzati in HTML con un layout fisso per mantenere l'aspetto del documento originale. Questo layout fisso significa che tutti gli elementi HTML hanno posizioni precise all'interno di un contenitore di dimensioni impostate. Ridimensionare la finestra del browser non influisce sulla posizione e sulla dimensione degli elementi nel documento.

Questa opzione è disponibile solo durante il rendering in HTML. Il valore predefinito è `true`. Per renderizzare con un layout fluido, imposta questa proprietà su `false`.

Durante il rendering con layout fluido, le immagini vengono omesse. Usa il layout fluido quando renderizzi documenti PDF con contenuto testuale.

Per un esempio di codice, vedi la [documentazione](https://docs.groupdocs.com/viewer/net/render-pdf-documents/#create-html-with-fluid-layout).
