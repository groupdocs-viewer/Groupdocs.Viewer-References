## PdfOptions.DisableCharsGrouping property

Disabilita il raggruppamento dei simboli per un posizionamento preciso dei simboli durante il rendering della pagina.

```csharp
public bool DisableCharsGrouping { get; set; }
```

### Osservazioni

Durante la conversione dei file PDF, GroupDocs.Viewer raggruppa i singoli caratteri in parole per migliorare le prestazioni di rendering. Se il tuo documento contiene geroglifici o simboli speciali, potresti voler proibire il raggruppamento dei caratteri per garantire un layout più preciso. Il valore predefinito è `false`.

Per un esempio di codice, vedi la [documentazione](https://docs.groupdocs.com/viewer/net/render-pdf-documents/#disable-character-grouping).
