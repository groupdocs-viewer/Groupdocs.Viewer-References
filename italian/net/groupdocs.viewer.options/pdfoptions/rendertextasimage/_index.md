## PdfOptions.RenderTextAsImage property

Abilita il rendering del testo nei file PDF come immagine nell'output HTML.

```csharp
public bool RenderTextAsImage { get; set; }
```

### Osservazioni

Quando questa opzione è impostata su `true`, GroupDocs.Viewer renderizza il testo come immagine nell'output HTML. Questo rende il testo non selezionabile e migliora il rendering dei caratteri, garantendo un aspetto simile a PDF in HTML. Il valore predefinito è `false`.

Questa opzione è disponibile per il rendering in HTML.

Per un esempio di codice, vedi la [documentazione](https://docs.groupdocs.com/viewer/net/render-pdf-documents/#render-text-as-an-image).
