## PdfOptions.DisableCopyProtection property

Disattiva la protezione contro la copia del contenuto durante il rendering in HTML.

```csharp
public bool DisableCopyProtection { get; set; }
```

### Osservazioni

Durante il rendering di file PDF con protezione contro la copia di testo e immagini in HTML, GroupDocs.Viewer aggiunge un attributo HTML 'inert' al tag BODY dell'HTML. Il valore predefinito di questa opzione è `false`, indicando che l'attributo HTML 'intent' viene aggiunto solo se il documento PDF è protetto.

Per un esempio di codice, vedi la [documentazione](https://docs.groupdocs.com/viewer/net/render-pdf-documents/#disable-copy-protection).
