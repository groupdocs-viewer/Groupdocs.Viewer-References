## PdfOptions.EnableFontHinting property

Abilita il hinting dei font.

```csharp
public bool EnableFontHinting { get; set; }
```

### Osservazioni

Il font hinting regola il modo in cui viene visualizzato un font contorno. Applicabile solo ai font TTF utilizzati nel documento di origine. Questa opzione è disponibile per il rendering in formati PNG o JPG. Il valore predefinito è `false`.

Per un esempio di codice, vedere la [documentazione](https://docs.groupdocs.com/viewer/net/render-pdf-documents/#enable-font-hinting).
