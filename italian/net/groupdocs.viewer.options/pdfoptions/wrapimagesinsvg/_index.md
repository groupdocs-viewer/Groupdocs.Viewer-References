## PdfOptions.WrapImagesInSvg property

Abilita l'avvolgimento di ogni immagine nell'output HTML in un tag SVG per migliorare la qualità dell'output.

```csharp
public bool WrapImagesInSvg { get; set; }
```

### Osservazioni

Per impostazione predefinita, durante il rendering di file PDF e Page Layout in HTML, tutte le immagini vengono renderizzate come un'unica immagine PNG. L'immagine PNG renderizzata viene utilizzata come sfondo per il documento HTML di output.

Questa opzione è disponibile durante il rendering dei [formati di file PDF e Page Layout](https://docs.groupdocs.com/viewer/net/supported-document-formats/#pdf-and-page-layout-file-formats) in HTML con risorse incorporate ed esterne. Consente di avvolgere ogni immagine nel documento HTML di output in un tag SVG. Il valore predefinito è `false`.

Per un esempio di codice, vedere la [documentazione](https://docs.groupdocs.com/viewer/net/render-pdf-documents/#enclose-images-in-svg-when-rendering-pdf-and-page-layout-files).
