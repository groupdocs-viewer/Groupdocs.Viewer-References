## PdfOptions.EnableLayeredRendering property

Abilita il rendering di testo e grafica nell'ordine Z del documento PDF originale durante il rendering in HTML.

```csharp
public bool EnableLayeredRendering { get; set; }
```

### Osservazioni

Per impostazione predefinita, GroupDocs.Veiewer rende testo e grafica come un unico livello in HTML. Questa opzione consente di disporre gli oggetti nello stesso ordine del file di origine. Il valore predefinito è `false`.

Per un esempio di codice, vedere la [documentazione](https://docs.groupdocs.com/viewer/net/render-pdf-documents/#enable-multi-layer-rendering).
