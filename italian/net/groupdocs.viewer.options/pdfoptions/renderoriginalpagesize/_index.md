## PdfOptions.RenderOriginalPageSize property

Imposta la dimensione della pagina di output uguale a quella della pagina del documento PDF di origine.

```csharp
public bool RenderOriginalPageSize { get; set; }
```

### Osservazioni

Per impostazione predefinita, GroupDocs.Viewer calcola la dimensione della pagina immagine di output per una migliore qualità di rendering. Abilita questa opzione per garantire che le pagine di output abbiano la stessa dimensione della pagina del documento PDF di origine (in pixel). Il valore predefinito è `false`.

Questa opzione è disponibile per il rendering in formati PNG o JPG.

Per un esempio di codice, vedere la [documentazione](https://docs.groupdocs.com/viewer/net/render-pdf-documents/#preserve-the-size-of-document-pages).
