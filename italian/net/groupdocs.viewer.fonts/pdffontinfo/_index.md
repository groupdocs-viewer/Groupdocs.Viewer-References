## PdfFontInfo structure

Incapsula metainformazioni e dati binari di un font dal documento PDF, caricato nell'istanza [`Viewer`](../../groupdocs.viewer/viewer). Questo font è utilizzato nel contenuto del documento ed è incorporato all'interno del documento stesso o è installato nel sistema operativo, dove è in esecuzione GroupDocs.Viewer.

public struct PdfFontInfo : IFontInfo
