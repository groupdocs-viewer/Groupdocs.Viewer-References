## FileType.CDR field

CorelDraw Vector Graphic Drawing (.cdr) è un file immagine vettoriale creato nativamente con CorelDRAW per memorizzare immagini digitali codificate e compresse. Questo tipo di file contiene testo, linee, forme, immagini, colori ed effetti per la rappresentazione vettoriale del contenuto dell'immagine.
