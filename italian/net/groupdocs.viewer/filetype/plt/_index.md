## FileType.PLT field

Il file PLT (HPGL) (.plt) è un file plotter basato su vettori introdotto da Autodesk, Inc. e contiene informazioni per un determinato file CAD. I dettagli della stampa richiedono accuratezza e precisione nella produzione, e l'uso del file PLT garantisce ciò poiché tutte le immagini vengono stampate usando linee anziché punti. Scopri di più su questo formato di file [qui](https://wiki.fileformat.com/cad/plt).
