## FileType.DWF field

Il file Design Web Format (.dwf) rappresenta disegni 2D/3D in formato compresso per la visualizzazione, revisione o stampa di file di progettazione. Contiene grafica e testo come parte dei dati di progettazione e riduce le dimensioni del file grazie al suo formato compresso. Scopri di più su questo formato di file [qui](https://wiki.fileformat.com/cad/dwf).
