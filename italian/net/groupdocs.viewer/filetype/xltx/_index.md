## FileType.XLTX field

Excel Open XML Spreadsheet Template (.xltx) rappresenta i modelli di Microsoft Excel basati sulle specifiche del formato di file Office OpenXML. Viene utilizzato per creare un file modello standard che può essere impiegato per generare file XLSX che presentano le stesse impostazioni specificate nel file XLTX.
