## FileType.XPS field

XML Paper Specification File (.xps) rappresenta file di layout di pagina basati sulle Specifiche di Carta XML create da Microsoft. Questo formato è stato sviluppato da Microsoft come sostituto del formato di file EMF ed è simile al formato PDF, ma utilizza XML per il layout, l'aspetto e le informazioni di stampa di un documento. Scopri di più su questo formato di file [qui](https://wiki.fileformat.com/page-description-language/xps).
