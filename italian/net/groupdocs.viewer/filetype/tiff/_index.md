## FileType.TIFF field

Il Tagged Image File Format (.tiff) rappresenta immagini raster destinate all'uso su una varietà di dispositivi che rispettano lo standard di questo formato di file. È in grado di descrivere dati immagine bi‑livello, in scala di grigi, a colori palette e a colori completi in diversi spazi colore. Scopri di più su questo formato di file [qui](https://wiki.fileformat.com/image/tiff).
