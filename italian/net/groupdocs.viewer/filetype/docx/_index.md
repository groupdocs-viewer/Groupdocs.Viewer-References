## FileType.DOCX field

Il documento Microsoft Word Open XML (.docx) è un formato noto per i documenti Microsoft Word. Introdotto dal 2007 con il rilascio di Microsoft Office 2007, la struttura di questo nuovo formato di documento è passata da binario puro a una combinazione di file XML e binari.
