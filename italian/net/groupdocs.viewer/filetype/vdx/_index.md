## FileType.VDX field

Il Visio Drawing XML File (.vdx) rappresenta qualsiasi disegno o diagramma creato in Microsoft Visio, ma salvato in formato XML con estensione .VDX. Un file Visio drawing XML è creato nel software Visio, sviluppato da Microsoft. Scopri di più su questo formato di file [qui](https://wiki.fileformat.com/image/vdx).
