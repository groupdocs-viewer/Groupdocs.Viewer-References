## FileType.Zstandard field

ZST file è un file compresso generato con l'algoritmo di compressione Zstandard (zstd). È un file compresso creato con compressione senza perdita di dati dall'algoritmo. I file ZST possono essere usati per comprimere diversi tipi di file come database, file system, reti e giochi.
