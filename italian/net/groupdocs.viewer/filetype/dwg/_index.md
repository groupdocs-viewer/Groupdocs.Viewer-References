## FileType.DWG field

Il file AutoCAD Drawing Database (.dwg) rappresenta file binari proprietari utilizzati per contenere dati di progettazione 2D e 3D. Come DXF, che sono file ASCII, DWG rappresenta il formato file binario per i disegni CAD (Computer Aided Design). Scopri di più su questo formato di file [qui](https://wiki.fileformat.com/cad/dwg).
