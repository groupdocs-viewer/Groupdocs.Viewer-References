## FileType.Excel2003XML field

Excel 2003 XML (SpreadsheetML) rappresenta il formato file binario di Excel. Tali file possono essere creati da Microsoft Excel così come da altri programmi di fogli di calcolo simili come OpenOffice Calc o Apple Numbers.
