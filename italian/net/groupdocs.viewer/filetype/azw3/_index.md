## FileType.AZW3 field

Amazon Kindle Format 8 (KF8) ebook è il formato di file digitale sviluppato per i dispositivi Amazon Kindle. Il formato è un miglioramento rispetto ai vecchi file AZW ed è utilizzato sui dispositivi Kindle Fire solo con compatibilità retroattiva per il formato di file originale, cioè MOBI e AZW. Scopri di più su questo formato di file [qui](https://wiki.fileformat.com/ebook/azw3).
