## FileType.XLTM field

Microsoft Excel Macro-Enabled Template (.xltm) rappresenta i file generati da Microsoft Excel come modelli abilitati alle macro. I file XLTM sono simili a XLTX nella struttura, tranne per il fatto che quest'ultimo non supporta la creazione di modelli con macro.
