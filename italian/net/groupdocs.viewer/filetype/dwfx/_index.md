## FileType.DWFX field

Il file Design Web Format XPS (.dwfx) rappresenta disegni 2D/3D come documento XPS in formato compresso per visualizzare, revisionare o stampare file di progettazione. Contiene grafica e testo come parte dei dati di progettazione e riduce la dimensione del file grazie al suo formato compresso. Scopri di più su questo formato di file [qui](https://wiki.fileformat.com/cad/dwfx).
