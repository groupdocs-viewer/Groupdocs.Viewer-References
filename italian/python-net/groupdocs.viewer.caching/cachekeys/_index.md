## CacheKeys class

Fornisce metodi per recuperare l'identificatore univoco per la voce della cache.

Il tipo CacheKeys espone i seguenti membri:

### Metodi
| Metodo | Descrizione |
| :- | :- |
| [get_attachment_key](/viewer/python-net/groupdocs.viewer.caching/cachekeys/get_attachment_key/#attachment_id) | Restituisce un identificatore univoco per la voce della cache che rappresenta il file di allegato. |
| [get_attachments_key](/viewer/python-net/groupdocs.viewer.caching/cachekeys/get_attachments_key/) | Restituisce un identificatore univoco per la voce della cache che rappresenta una collezione di oggetti [`Attachment`](/viewer/python-net/groupdocs.viewer.results/attachment/). |
| [get_file_info_key](/viewer/python-net/groupdocs.viewer.caching/cachekeys/get_file_info_key/) | Restituisce un identificatore univoco per la voce della cache che rappresenta l'oggetto [`ViewInfo`](/viewer/python-net/groupdocs.viewer.results/viewinfo/). |
| [get_file_key](/viewer/python-net/groupdocs.viewer.caching/cachekeys/get_file_key/#extension) | Restituisce un identificatore univoco per la voce della cache che rappresenta il file. |
| [get_page_key](/viewer/python-net/groupdocs.viewer.caching/cachekeys/get_page_key/#page_number-extension) | Restituisce un identificatore univoco per la voce della cache che rappresenta il file della pagina. |
| [get_resource_filter](/viewer/python-net/groupdocs.viewer.caching/cachekeys/get_resource_filter/#page_number) | Restituisce una stringa di filtro per cercare le voci della cache che rappresentano oggetti [`Resource`](/viewer/python-net/groupdocs.viewer.results/resource/). |
| [get_resource_key](/viewer/python-net/groupdocs.viewer.caching/cachekeys/get_resource_key/#page_number-resource) | Restituisce un identificatore univoco per la voce della cache che rappresenta l'oggetto [`Resource`](/viewer/python-net/groupdocs.viewer.results/resource/). |
| [get_view_info_key](/viewer/python-net/groupdocs.viewer.caching/cachekeys/get_view_info_key/) | Restituisce un identificatore univoco per la voce della cache che rappresenta l'oggetto [`ViewInfo`](/viewer/python-net/groupdocs.viewer.results/viewinfo/). |
