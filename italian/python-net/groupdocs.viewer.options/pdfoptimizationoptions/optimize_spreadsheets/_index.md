## optimize_spreadsheets property

La proprietà che consente l'ottimizzazione dei fogli di calcolo nei file PDF.

Questa ottimizzazione riduce le dimensioni del file di output impostando linee di bordo e rimuove i caratteri Arial e Times New Roman con codici 32‑127. Il valore predefinito è `False`.

Per un esempio di codice, vedere la documentazione di GroupDocs.
