## lineriaze property

La proprietà consente l'ottimizzazione del file PDF di output per la visualizzazione online con un browser web.

Questa ottimizzazione consente al browser di visualizzare le prime pagine di un file PDF quando si apre il documento, invece di attendere il download dell'intero file. Per un esempio di codice, vedere la documentazione.
