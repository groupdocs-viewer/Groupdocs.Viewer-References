## subset_fonts property

La proprietà crea sottoinsiemi di caratteri nel file PDF di output.

Se il file utilizza caratteri incorporati, contiene tutti i dati dei caratteri. GroupDocs.Viewer può creare un sottoinsieme dei caratteri incorporati per ridurre le dimensioni del file. Per un esempio di codice, vedere la documentazione.
