## resize_images property

La proprietà consente di impostare la risoluzione massima nel file PDF di output.

Per abilitare questa opzione, impostare la proprietà [`PdfOptimizationOptions.compress_images`](/viewer/python-net/groupdocs.viewer.options/pdfoptimizationoptions/compress_images/) su `True`. Questa opzione consente di impostare la proprietà [`PdfOptimizationOptions.max_resolution`](/viewer/python-net/groupdocs.viewer.options/pdfoptimizationoptions/max_resolution/).
