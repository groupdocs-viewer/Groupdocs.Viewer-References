## update_fields property

La proprietà determina se i campi di determinati tipi vengono aggiornati prima di salvare il documento WordProcessing in formati HTML, PDF, PNG o JPEG. Il valore predefinito è True, il che significa che i campi vengono aggiornati.

Per ulteriori dettagli, consulta la documentazione: https://docs.groupdocs.com/viewer/net/render-word-documents/#disable-updating-fields-when-saving
