## extract_text property

La proprietà consente l'estrazione del testo.

Utilizza questa proprietà per ottenere il testo contenuto in un documento sorgente e le sue coordinate. Poi puoi usare questi dati per aggiungere un testo selezionabile sull'immagine o per implementare una ricerca di testo nella resa basata su immagine.

Per un esempio di codice, consulta la documentazione: https://docs.groupdocs.com/viewer/net/image-viewer-get-text-coordinates/
