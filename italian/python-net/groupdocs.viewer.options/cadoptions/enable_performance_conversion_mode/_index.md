## enable_performance_conversion_mode property

Il flag che abilita una modalità di conversione orientata alle prestazioni per tutti i formati CAD, dove impostarlo su True accelera la conversione a costo di una qualità di output ridotta; il valore predefinito è False per la massima qualità.
