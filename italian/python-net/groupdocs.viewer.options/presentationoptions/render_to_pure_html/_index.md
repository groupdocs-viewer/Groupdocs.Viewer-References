## render_to_pure_html property

La proprietà abilita una nuova modalità di rendering HTML per i documenti Presentation — in questa modalità i file vengono renderizzati in puro markup HTML/CSS senza immagini SVG. Per impostazione predefinita è disabilitata (`False`) e viene utilizzato il renderer HTML basato su SVG esistente.

Per un esempio di codice, vedere la documentazione all'indirizzo https://docs.groupdocs.com/viewer/net/render-presentations/#generate-pure-htmlcss-markup.
