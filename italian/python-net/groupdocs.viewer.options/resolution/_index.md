## Resolution class

Contiene l'opzione per impostare la risoluzione delle immagini nel documento di output.

Il tipo Resolution espone i seguenti membri:

### Costruttori
| Costruttore | Descrizione |
| :- | :- |
| [__init__](/viewer/python-net/groupdocs.viewer.options/resolution/__init__/#value) | Inizializza la risoluzione in DPI. |

### Proprietà
| Proprietà | Descrizione |
| :- | :- |
| [value](/viewer/python-net/groupdocs.viewer.options/resolution/value/) | Il DPI di qualità. |

### Campi
| Campo | Descrizione |
| :- | :- |
| [DPI330](/viewer/python-net/groupdocs.viewer.options/resolution/dpi330/) | Buona qualità per display ad alta definizione (HD). |
| [DPI220](/viewer/python-net/groupdocs.viewer.options/resolution/dpi220/) | Qualità eccellente sulla maggior parte delle stampanti e degli schermi. |
| [DPI150](/viewer/python-net/groupdocs.viewer.options/resolution/dpi150/) | Buono per pagine web e proiettori. |
| [DPI96](/viewer/python-net/groupdocs.viewer.options/resolution/dpi96/) | Buono per pagine web e proiettori. |
| [DPI72](/viewer/python-net/groupdocs.viewer.options/resolution/dpi72/) | Livello di compressione predefinito. |
| [DOCUMENT_RESOLUTION](/viewer/python-net/groupdocs.viewer.options/resolution/document_resolution/) | Livello di compressione predefinito - come nel documento. |
