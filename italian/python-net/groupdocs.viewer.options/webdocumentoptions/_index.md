## WebDocumentOptions class

Rappresenta le opzioni per il rendering dei documenti web.

Per i dettagli, vedere la documentazione.

Il tipo WebDocumentOptions espone i seguenti membri:

### Costruttori
| Costruttore | Descrizione |
| :- | :- |
| [__init__](/viewer/python-net/groupdocs.viewer.options/webdocumentoptions/__init__/) | Inizializza un'istanza della classe [`WebDocumentOptions`](/viewer/python-net/groupdocs.viewer.options/webdocumentoptions/). |

### Proprietà
| Proprietà | Descrizione |
| :- | :- |
| [bottom_margin](/viewer/python-net/groupdocs.viewer.options/webdocumentoptions/bottom_margin/) | Il margine inferiore di una pagina. Il valore predefinito è 72 punti. |
| [left_margin](/viewer/python-net/groupdocs.viewer.options/webdocumentoptions/left_margin/) | Il margine sinistro di una pagina (il valore predefinito è 5 punti). |
| [page_size](/viewer/python-net/groupdocs.viewer.options/webdocumentoptions/page_size/) | La dimensione della pagina di output. |
| [right_margin](/viewer/python-net/groupdocs.viewer.options/webdocumentoptions/right_margin/) | Il margine destro di una pagina. Il valore predefinito è 5 punti. |
| [top_margin](/viewer/python-net/groupdocs.viewer.options/webdocumentoptions/top_margin/) | Il margine superiore di una pagina (il valore predefinito è 72 punti). |
