## image_width property

La larghezza dell'immagine di output in pixel.

Utilizza questa proprietà per impostare la larghezza dell'immagine di output (in pixel). GroupDocs.Viewer applica questa proprietà durante il rendering di un'unica immagine in PDF. Per ulteriori dettagli, consulta la documentazione.

Se imposti questa proprietà, la proprietà [`PdfViewOptions.ImageMaxWidth`](/viewer/python-net/groupdocs.viewer.options/pdfviewoptions/image_max_width/) viene ignorata.
