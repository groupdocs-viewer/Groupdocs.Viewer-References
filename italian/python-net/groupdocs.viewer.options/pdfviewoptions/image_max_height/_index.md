## image_max_height property

L'altezza massima di un'immagine di output in pixel.

Utilizza questa proprietà per impostare l'altezza massima dell'immagine di output (in pixel). GroupDocs.Viewer applica questa proprietà durante il rendering di un'unica immagine in PDF. Per ulteriori dettagli, consulta la documentazione.

Se imposti la proprietà [`PdfViewOptions.ImageHeight`](/viewer/python-net/groupdocs.viewer.options/pdfviewoptions/image_height/), questa proprietà viene ignorata.
