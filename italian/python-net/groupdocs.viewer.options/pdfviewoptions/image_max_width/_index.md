## image_max_width property

La larghezza massima di un'immagine di output in pixel.

Utilizza questa proprietà per impostare la larghezza massima dell'immagine di output (in pixel). GroupDocs.Viewer applica questa proprietà durante il rendering di un'unica immagine in PDF. Per ulteriori dettagli, consulta la documentazione.

Se imposti la proprietà [`PdfViewOptions.ImageWidth`](/viewer/python-net/groupdocs.viewer.options/pdfviewoptions/image_width/), questa proprietà viene ignorata.
