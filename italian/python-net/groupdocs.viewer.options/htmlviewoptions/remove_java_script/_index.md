## remove_java_script property

La proprietà determina se il codice sorgente JavaScript viene rimosso dai collegamenti nei documenti HTML generati durante il rendering di documenti di input che contengono script. Abilitata per impostazione predefinita (`True`).

Per dettagli sulla rimozione di JavaScript, vedere la documentazione: https://docs.groupdocs.com/viewer/net/rendering-to-html/#preserving-or-disabling-javascript-when-rendering-to-html
