## minify property

La proprietà abilita la minificazione del contenuto HTML e delle risorse HTML.

La compressione del contenuto di output (HTML, CSS e SVG) è uno dei modi per ottimizzare il file HTML. Per farlo, impostare questa proprietà su `True`.
