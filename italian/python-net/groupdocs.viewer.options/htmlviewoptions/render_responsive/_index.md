## render_responsive property

La proprietà abilita il rendering responsivo.

Il design responsivo mira a far sì che le pagine web vengano visualizzate correttamente su una varietà di dispositivi. Per renderizzare con un layout responsivo, impostare questa proprietà su `True`.
