## max_width property

La larghezza massima di un'immagine di output in pixel (solo per il rendering in PNG/JPG).

Usa questa proprietà per impostare la larghezza massima dell'immagine di output (in pixel). Per un esempio di codice, consulta la documentazione.

Se imposti la proprietà [`ViewInfoOptions.Width`](/viewer/python-net/groupdocs.viewer.options/viewinfooptions/width/), questa proprietà viene ignorata.
