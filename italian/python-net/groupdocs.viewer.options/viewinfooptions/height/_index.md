## height property

L'altezza dell'immagine di output (in pixel, solo per il rendering in PNG/JPG).

Usa questa proprietà per impostare l'altezza dell'immagine di output (in pixel). Per un esempio di codice, consulta la documentazione.

Se imposti questa proprietà, la proprietà [`ViewInfoOptions.max_height`](/viewer/python-net/groupdocs.viewer.options/viewinfooptions/max_height/) viene ignorata.
