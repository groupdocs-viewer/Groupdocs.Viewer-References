## width property

La larghezza dell'immagine di output (in pixel, solo per il rendering in PNG/JPG).

Utilizza questa proprietà per impostare la larghezza dell'immagine di output (in pixel). Per un esempio di codice, consulta la documentazione.

Se imposti questa proprietà, la proprietà [`ViewInfoOptions.MaxWidth`](/viewer/python-net/groupdocs.viewer.options/viewinfooptions/max_width/) viene ignorata.
