## folder property

Il nome della cartella (ad es. Posta in arrivo, Posta inviata o Elementi eliminati) da rendere.

Durante il rendering di un file di dati Outlook, GroupDocs.Viewer visualizza i messaggi da tutte le cartelle contenute nel file (incluse le cartelle nidificate). Usa questa proprietà per visualizzare gli elementi da una cartella specifica.
