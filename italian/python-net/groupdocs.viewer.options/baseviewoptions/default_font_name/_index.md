## default_font_name property

Il font predefinito per un documento utilizzato durante il rendering quando un font richiesto è mancante.

Utilizzare questa proprietà per impostare il carattere predefinito per un documento. GroupDocs.Viewer utilizza questo carattere durante il rendering al posto di eventuali caratteri non installati.

Per esempi di codice, vedere la documentazione: https://docs.groupdocs.com/viewer/net/replace-missing-font/
