## BaseViewOptions class

Rappresenta le opzioni di rendering di base.

Il tipo BaseViewOptions espone i seguenti membri:

### Proprietà
| Proprietà | Descrizione |
| :- | :- |
| [archive_options](/viewer/python-net/groupdocs.viewer.options/baseviewoptions/archive_options/) | Le opzioni di visualizzazione dei file di archivio. |
| [cad_options](/viewer/python-net/groupdocs.viewer.options/baseviewoptions/cad_options/) | Le opzioni di visualizzazione del disegno CAD. |
| [default_font_name](/viewer/python-net/groupdocs.viewer.options/baseviewoptions/default_font_name/) | Il font predefinito per un documento utilizzato durante il rendering quando un font richiesto è mancante. |
| [email_options](/viewer/python-net/groupdocs.viewer.options/baseviewoptions/email_options/) | Le opzioni di visualizzazione dei messaggi email. |
| [mail_storage_options](/viewer/python-net/groupdocs.viewer.options/baseviewoptions/mail_storage_options/) | Le opzioni di visualizzazione dei file di dati di archiviazione della posta. |
| [outlook_options](/viewer/python-net/groupdocs.viewer.options/baseviewoptions/outlook_options/) | Le opzioni di visualizzazione dei file di dati di Microsoft Outlook. |
| [pdf_options](/viewer/python-net/groupdocs.viewer.options/baseviewoptions/pdf_options/) | Le opzioni di visualizzazione del documento PDF. |
| [presentation_options](/viewer/python-net/groupdocs.viewer.options/baseviewoptions/presentation_options/) | Le opzioni di visualizzazione dei file di presentazione. |
| [project_management_options](/viewer/python-net/groupdocs.viewer.options/baseviewoptions/project_management_options/) | Le opzioni di visualizzazione dei file di gestione progetti. |
| [remove_comments](/viewer/python-net/groupdocs.viewer.options/baseviewoptions/remove_comments/) | La proprietà disabilita il rendering dei commenti quando impostata su True. Per impostazione predefinita è False, quindi tutti i commenti sono visualizzati. |
| [render_comments](/viewer/python-net/groupdocs.viewer.options/baseviewoptions/render_comments/) | La proprietà abilita o disabilita il rendering dei commenti. |
| [render_hidden_pages](/viewer/python-net/groupdocs.viewer.options/baseviewoptions/render_hidden_pages/) | La proprietà abilita il rendering delle pagine nascoste. |
| [render_notes](/viewer/python-net/groupdocs.viewer.options/baseviewoptions/render_notes/) | La proprietà abilita il rendering di note e annotazioni per alcuni formati. |
| [spreadsheet_options](/viewer/python-net/groupdocs.viewer.options/baseviewoptions/spreadsheet_options/) | Le opzioni di visualizzazione dei file di foglio di calcolo. |
| [text_options](/viewer/python-net/groupdocs.viewer.options/baseviewoptions/text_options/) | Le opzioni di testo per il rendering dei file di testo. |
| [visio_rendering_options](/viewer/python-net/groupdocs.viewer.options/baseviewoptions/visio_rendering_options/) | Le opzioni di visualizzazione dei file Visio. |
| [web_document_options](/viewer/python-net/groupdocs.viewer.options/baseviewoptions/web_document_options/) | Le opzioni di visualizzazione dei file Web. |
| [word_processing_options](/viewer/python-net/groupdocs.viewer.options/baseviewoptions/word_processing_options/) | Le opzioni di visualizzazione dei file di elaborazione testi. |
