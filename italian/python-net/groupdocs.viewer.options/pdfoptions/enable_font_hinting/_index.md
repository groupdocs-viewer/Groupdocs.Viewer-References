## enable_font_hinting property

La proprietà abilita il hinting dei caratteri.

Il font hinting regola il modo in cui un font outline viene visualizzato. Applicabile solo ai font TTF utilizzati nel documento di origine. Questa opzione è disponibile per il rendering in formati PNG o JPG. Il valore predefinito è False.
