## AZW3 field

L'ebook Amazon Kindle Format 8 (KF8) è il formato di file digitale sviluppato per i dispositivi Amazon Kindle. Il formato è un miglioramento dei file AZW più vecchi ed è usato sui dispositivi Kindle Fire solo con compatibilità retroattiva per i formati di file precedenti, cioè MOBI e AZW. Scopri di più su questo formato di file qui.
