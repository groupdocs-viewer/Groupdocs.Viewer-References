## VTX field

Visio Template XML File (.vtx) è un modello di disegno Microsoft Visio salvato su disco in formato XML. Il modello è pensato per fornire un file con impostazioni di base che può essere usato per creare più file Visio con le stesse impostazioni. Scopri di più su questo formato di file qui.
