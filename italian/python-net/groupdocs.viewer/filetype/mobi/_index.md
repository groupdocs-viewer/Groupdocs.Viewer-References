## MOBI field

Il Mobipocket eBook (.mobi) è uno dei formati di file e-book più ampiamente utilizzati. Il formato è un miglioramento del vecchio formato OEB (Open Ebook Format) ed è stato usato come formato proprietario per Mobipocket Reader. Scopri di più su questo formato di file qui.
