## XPS field

Il file XML Paper Specification (.xps) rappresenta file di layout di pagina basati sulle XML Paper Specifications create da Microsoft. Questo formato è stato sviluppato da Microsoft come sostituto del formato EMF ed è simile al formato PDF, ma utilizza XML per il layout, l'aspetto e le informazioni di stampa di un documento. Scopri di più su questo formato di file qui.
