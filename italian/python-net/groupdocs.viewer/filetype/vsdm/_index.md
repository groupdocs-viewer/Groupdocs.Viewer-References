## VSDM field

Visio Macro-Enabled Drawing (.vsdm) sono file di disegno creati con l'applicazione Microsoft Visio che supporta macro. I file VSDM sono disegni OPC/XML simili a VSDX, ma offrono anche la possibilità di eseguire macro quando il file viene aperto. Scopri di più su questo formato di file qui.
