## XLT field

Microsoft Excel Template (.xlt) sono file modello creati con Microsoft Excel, un'applicazione di foglio di calcolo inclusa nella suite Microsoft Office. Microsoft Office 97-2003 supportava la creazione di nuovi file XLT così come l'apertura di questi. Scopri di più su questo formato di file qui.
