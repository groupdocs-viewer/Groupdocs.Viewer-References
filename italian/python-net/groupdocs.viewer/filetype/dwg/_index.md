## DWG field

Il file AutoCAD Drawing Database (.dwg) rappresenta file binari proprietari usati per contenere dati di progettazione 2D e 3D. Come DXF, che sono file ASCII, DWG rappresenta il formato di file binario per i disegni CAD (Computer Aided Design). Scopri di più su questo formato di file qui.
