## DWFX field

Il file Design Web Format XPS (.dwfx) rappresenta disegni 2D/3D come documento XPS in formato compresso per visualizzare, revisionare o stampare i file di progetto. Contiene grafica e testo come parte dei dati di progetto e riduce le dimensioni del file grazie al suo formato compresso. Scopri di più su questo formato di file qui.
