## VST field

Visio Drawing Template (.vst) sono file immagine vettoriali creati con Microsoft Visio e fungono da modello per creare altri file. Questi file modello sono in formato binario e contengono il layout predefinito e le impostazioni utilizzate per la creazione di nuovi disegni Visio. Scopri di più su questo formato di file qui.
