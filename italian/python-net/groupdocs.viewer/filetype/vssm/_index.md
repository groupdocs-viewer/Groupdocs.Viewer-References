## VSSM field

Visio Macro-Enabled Stencil File (.vssm) sono file stencil di Microsoft Visio che supportano macro. Un file VSSM, quando aperto, consente di eseguire le macro per ottenere la formattazione e il posizionamento desiderati delle forme in un diagramma. Scopri di più su questo formato di file qui.
