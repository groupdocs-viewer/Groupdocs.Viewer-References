## TIF field

Il Tagged Image File (.tif) rappresenta immagini raster destinate all'uso su una varietà di dispositivi che rispettano lo standard di questo formato di file. È in grado di descrivere dati immagine bi-livello, in scala di grigi, a palette di colori e a colori completi in diversi spazi colore. Scopri di più su questo formato di file qui.
