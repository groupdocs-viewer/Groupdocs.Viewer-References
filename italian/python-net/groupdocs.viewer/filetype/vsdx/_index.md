## VSDX field

Visio Drawing (.vsdx) rappresenta il formato di file Microsoft Visio introdotto a partire da Microsoft Office 2013. È stato sviluppato per sostituire il formato di file binario, .VSD, supportato dalle versioni precedenti di Microsoft Visio. Scopri di più su questo formato di file qui.
