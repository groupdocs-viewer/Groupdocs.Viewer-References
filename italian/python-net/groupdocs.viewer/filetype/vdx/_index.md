## VDX field

Visio Drawing XML File (.vdx) rappresenta qualsiasi disegno o grafico creato in Microsoft Visio, ma salvato in formato XML con estensione .VDX. Un file Visio Drawing XML è creato nel software Visio, sviluppato da Microsoft. Scopri di più su questo formato di file qui.
