## XLTX field

Excel Open XML Spreadsheet Template (.xltx) rappresenta il modello di Microsoft Excel basato sulle specifiche del formato file Office OpenXML. Viene utilizzato per creare un file modello standard che può essere impiegato per generare file XLSX con le stesse impostazioni specificate nel file XLTX. Scopri di più su questo formato di file qui.
