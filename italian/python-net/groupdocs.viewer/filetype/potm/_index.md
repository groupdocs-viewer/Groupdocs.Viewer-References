## POTM field

PowerPoint Open XML Macro-Enabled Presentation Template (.potm) sono file modello di Microsoft PowerPoint con supporto per le macro. I file POTM sono creati con PowerPoint 2007 o versioni successive e contengono impostazioni predefinite che possono essere usate per creare ulteriori file di presentazione. Scopri di più su questo formato di file qui.
