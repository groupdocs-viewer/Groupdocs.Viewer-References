## PPT field

La presentazione PowerPoint (.ppt) rappresenta un file PowerPoint che consiste in una raccolta di diapositive da visualizzare come presentazione. Specifica il Binary File Format usato da Microsoft PowerPoint 97-2003. Scopri di più su questo formato di file qui.
