## BMP field

Il file immagine bitmap (.bmp) è usato per memorizzare immagini digitali bitmap. Queste immagini sono indipendenti dall'adattatore grafico e sono anche chiamate formato file bitmap indipendente dal dispositivo (DIB). Scopri di più su questo formato file qui.
