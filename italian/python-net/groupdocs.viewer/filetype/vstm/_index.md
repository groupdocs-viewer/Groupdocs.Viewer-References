## VSTM field

Visio Macro-Enabled Drawing Template (.vstm) sono file modello creati con Microsoft Visio che supportano macro. A differenza dei file VSDX, i file creati da modelli VSTM possono eseguire macro sviluppate in codice Visual Basic for Applications (VBA). Scopri di più su questo formato di file qui.
