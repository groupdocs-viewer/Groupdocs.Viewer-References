## XLS field

Excel Spreadsheet (.xls) rappresenta il formato di file binario di Excel. Tali file possono essere creati da Microsoft Excel così come da altri programmi di fogli di calcolo simili, come OpenOffice Calc o Apple Numbers. Scopri di più su questo formato di file qui.
