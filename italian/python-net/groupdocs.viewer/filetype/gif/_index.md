## GIF field

Il file Graphical Interchange Format (.gif) è un tipo di immagine altamente compressa. Per ogni immagine GIF tipicamente consente fino a 8 bit per pixel e fino a 256 colori sono consentiti nell'immagine. Scopri di più su questo formato di file qui.
