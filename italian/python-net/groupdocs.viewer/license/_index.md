## License class

Gestisce la licenza di GroupDocs.Viewer.

Le build con licenza sbloccano l'intero set di funzionalità del wrapper a
runtime. Le build senza licenza funzionano in modalità di valutazione con la stessa API
ma con limiti sulla dimensione dell'output e sul contenuto con filigrana.

Il tipo License espone i seguenti membri:

### Metodi
| Metodo | Descrizione |
| :- | :- |
| [set_license](/viewer/python-net/groupdocs.viewer/license/set_license/#license_source) | Applica una licenza al processo corrente. |
