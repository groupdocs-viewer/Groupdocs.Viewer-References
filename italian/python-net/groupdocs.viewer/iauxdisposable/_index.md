## IAuxDisposable class

Il tipo IAuxDisposable espone i seguenti membri:

### Proprietà
| Proprietà | Descrizione |
| :- | :- |
| [is_disposed](/viewer/python-net/groupdocs.viewer/iauxdisposable/is_disposed/) | La proprietà indica se una risorsa è già rilasciata (`True`) o no (`False`). |
