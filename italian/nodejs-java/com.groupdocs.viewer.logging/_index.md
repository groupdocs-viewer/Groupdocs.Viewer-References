Il pacchetto fornisce classi per configurare il sistema di logging in GroupDocs.Viewer.

Utilizzando queste classi, è possibile controllare come vengono gestiti i messaggi di log, ad esempio scrivendoli su un file o indirizzandoli a una specifica implementazione di logger.

Le classi principali in questo pacchetto sono:

 *  [FileLogger](../../com.groupdocs.viewer.logging/filelogger) - Writes log messages to a file.
 *  [ViewerLogger](../../com.groupdocs.viewer.logging/viewerlogger) - Implements logging messages to an integrated or user-defined logger.

Per ulteriori dettagli sulla configurazione del sistema di logging in GroupDocs.Viewer e sulla personalizzazione della gestione dei messaggi di log, consultare la [GroupDocs.Viewer Documentazione][].


[GroupDocs.Viewer Documentation]: https://docs.groupdocs.com/viewer/java/
