Il pacchetto fornisce classi per specificare opzioni aggiuntive durante il rendering dei documenti.

Include opzioni per il rendering di vari formati di documento, la definizione di permessi e impostazioni di sicurezza, la specifica delle proprietà dei watermark e il recupero delle informazioni sulle visualizzazioni.

Le classi principali in questo pacchetto sono:

 *  [ArchiveOptions](../../com.groupdocs.viewer.options/archiveoptions) - Provides options for rendering archive files.
 *  [PdfOptions](../../com.groupdocs.viewer.options/pdfoptions) - Provides options for rendering PDF documents.
 *  [WordProcessingOptions](../../com.groupdocs.viewer.options/wordprocessingoptions) - Provides options for rendering word processing documents.

Per ulteriori dettagli sulla configurazione del sistema di logging in GroupDocs.Viewer e sulla personalizzazione della gestione dei messaggi di log, consultare la [GroupDocs.Viewer Documentazione][].


[GroupDocs.Viewer Documentation]: https://docs.groupdocs.com/viewer/java/
