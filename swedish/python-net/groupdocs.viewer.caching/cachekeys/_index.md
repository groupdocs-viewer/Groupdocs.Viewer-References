## CacheKeys class

Tillhandahåller metoder för att hämta unik identifierare för cacheposten.

CacheKeys-typen exponerar följande medlemmar:

### Metoder
| Metod | Beskrivning |
| :- | :- |
| [get_attachment_key](/viewer/python-net/groupdocs.viewer.caching/cachekeys/get_attachment_key/#attachment_id) | Returnerar en unik identifierare för cacheposten som representerar bilagafilen. |
| [get_attachments_key](/viewer/python-net/groupdocs.viewer.caching/cachekeys/get_attachments_key/) | Returnerar en unik identifierare för cacheposten som representerar en samling av [`Attachment`](/viewer/python-net/groupdocs.viewer.results/attachment/) objekt. |
| [get_file_info_key](/viewer/python-net/groupdocs.viewer.caching/cachekeys/get_file_info_key/) | Returnerar en unik identifierare för cacheposten som representerar [`ViewInfo`](/viewer/python-net/groupdocs.viewer.results/viewinfo/) objekt. |
| [get_file_key](/viewer/python-net/groupdocs.viewer.caching/cachekeys/get_file_key/#extension) | Returnerar unik identifierare för cacheposten som representerar filen. |
| [get_page_key](/viewer/python-net/groupdocs.viewer.caching/cachekeys/get_page_key/#page_number-extension) | Returnerar unik identifierare för cacheposten som representerar sidfilen. |
| [get_resource_filter](/viewer/python-net/groupdocs.viewer.caching/cachekeys/get_resource_filter/#page_number) | Returnerar en filtersträng för att söka efter cacheposter som representerar [`Resource`](/viewer/python-net/groupdocs.viewer.results/resource/) objekt. |
| [get_resource_key](/viewer/python-net/groupdocs.viewer.caching/cachekeys/get_resource_key/#page_number-resource) | Returnerar unik identifierare för cacheposten som representerar [`Resource`](/viewer/python-net/groupdocs.viewer.results/resource/) objekt. |
| [get_view_info_key](/viewer/python-net/groupdocs.viewer.caching/cachekeys/get_view_info_key/) | Returnerar en unik identifierare för cacheposten som representerar [`ViewInfo`](/viewer/python-net/groupdocs.viewer.results/viewinfo/) objekt. |
