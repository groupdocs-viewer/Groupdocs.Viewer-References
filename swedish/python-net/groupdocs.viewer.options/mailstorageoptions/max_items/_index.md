## max_items property

Det maximala antalet meddelanden eller objekt att rendera.

Mail lagringsdatafiler kan vara stora och att hämta alla meddelanden kan ta betydande tid. Denna egenskap begränsar det maximala antalet meddelanden eller objekt som renderas. Standardvärdet är 0 – alla meddelanden renderas.
