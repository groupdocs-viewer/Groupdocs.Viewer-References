## EmailOptions class

Innehåller alternativ för att rendera e‑postmeddelanden.

GroupDocs.Viewer stöder EmailOptions-klassen som låter dig ange olika alternativ för rendering av e-postmeddelanden. För att komma åt dessa alternativ, använd EmailOptions-egenskapen på en av följande visningsalternativklasser, beroende på önskat utdataformat:

- [`HtmlViewOptions`](/viewer/python-net/groupdocs.viewer.options/htmlviewoptions/)
- [`PdfViewOptions`](/viewer/python-net/groupdocs.viewer.options/pdfviewoptions/)
- [`PngViewOptions`](/viewer/python-net/groupdocs.viewer.options/pngviewoptions/)
- [`JpgViewOptions`](/viewer/python-net/groupdocs.viewer.options/jpgviewoptions/)
