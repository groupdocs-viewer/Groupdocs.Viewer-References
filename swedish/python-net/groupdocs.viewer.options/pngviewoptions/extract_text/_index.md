## extract_text property

Egenskapen möjliggör textutdrag.

Använd den här egenskapen för att hämta texten som finns i ett källdokument och dess koordinater. Därefter kan du använda dessa data för att lägga till markerbar text över bilden eller för att implementera textsökning i bildbaserad rendering.

För ett kodexempel, se dokumentationen: https://docs.groupdocs.com/viewer/net/image-viewer-get-text-coordinates/
