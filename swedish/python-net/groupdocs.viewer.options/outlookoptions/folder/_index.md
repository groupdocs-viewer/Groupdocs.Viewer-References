## folder property

Namnet på mappen (t.ex. Inkorg, Skickade objekt eller Borttagna objekt) som ska renderas.

När en Outlook-datafil renderas, renderar GroupDocs.Viewer meddelanden från alla mappar som finns i filen (inklusive nästlade mappar). Använd den här egenskapen för att rendera objekt från en specifik mapp.
