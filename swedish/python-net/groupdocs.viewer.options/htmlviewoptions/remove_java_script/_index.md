## remove_java_script property

Egenskapen bestämmer om JavaScript-källkod tas bort från länkar i de genererade HTML-dokumenten när inmatningsdokument som innehåller skript renderas. Aktiverad som standard (`True`).

För detaljer om borttagning av JavaScript, se dokumentationen: https://docs.groupdocs.com/viewer/net/rendering-to-html/#preserving-or-disabling-javascript-when-rendering-to-html
