## max_width property

Den maximala bredden på en utgående bild i pixlar (endast för rendering till PNG/JPG).

Använd den här egenskapen för att ange den maximala bredden på utdata‑bilden (i pixlar). För kodexempel, se dokumentationen.

Om du anger [`ViewInfoOptions.Width`](/viewer/python-net/groupdocs.viewer.options/viewinfooptions/width/) egenskapen, ignoreras den här egenskapen.
