## render_original_page_size property

Utdata sidstorlek är inställd för att matcha käll-PDF-dokumentets sidstorlek.

Som standard beräknar GroupDocs.Viewer sidstorleken för utdata‑bilden för bättre renderingskvalitet. Aktivera detta alternativ för att säkerställa att utdata‑sidorna har samma storlek som käll‑PDF‑dokumentets sidstorlek (i pixlar). Standardvärdet är False.

Detta alternativ är tillgängligt för rendering till PNG‑ eller JPG‑format.
