## image_width property

Bredden på en utdata bild i pixlar.

Använd den här egenskapen för att ange bildbredden för utdata (i pixlar). GroupDocs.Viewer tillämpar denna egenskap när en enda bild renderas till PDF. För detaljer, se dokumentationen.

Om du anger denna egenskap, ignoreras egenskapen [`PdfViewOptions.ImageMaxWidth`](/viewer/python-net/groupdocs.viewer.options/pdfviewoptions/image_max_width/).
