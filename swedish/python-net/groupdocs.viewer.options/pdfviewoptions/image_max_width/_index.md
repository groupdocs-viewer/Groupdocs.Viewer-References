## image_max_width property

Den maximala bredden för en utdata‑bild i pixlar.

Använd den här egenskapen för att ange den maximala bildbredden för utdata (i pixlar). GroupDocs.Viewer tillämpar denna egenskap när en enda bild renderas till PDF. För detaljer, se dokumentationen.

Om du anger egenskapen [`PdfViewOptions.ImageWidth`](/viewer/python-net/groupdocs.viewer.options/pdfviewoptions/image_width/), ignoreras denna egenskap.
