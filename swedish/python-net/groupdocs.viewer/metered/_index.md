## Metered class

Hantera mätbaserad (betala per användning) licensiering.

Metered-licenser faktureras baserat på faktisk förbrukning (vanligtvis sidor eller
dokument som bearbetas). Ställ in offentliga/privata nyckelparet en gång vid
applikationsstart; omslaget rapporterar användning tillbaka till GroupDocs
licensserver i bakgrunden.

Metered-typen exponerar följande medlemmar:

### Metoder
| Metod | Beskrivning |
| :- | :- |
| [get_consumption_credit](/viewer/python-net/groupdocs.viewer/metered/get_consumption_credit/) | Returnerar återstående meterade kredit för den aktuella nyckeln. |
| [get_consumption_quantity](/viewer/python-net/groupdocs.viewer/metered/get_consumption_quantity/) | Returnerar den totala meterade mängden som har förbrukats hittills. |
| [set_metered_key](/viewer/python-net/groupdocs.viewer/metered/set_metered_key/#public_key-private_key) | Aktivera meterad fakturering med det angivna offentliga/privata nyckelparet. |
