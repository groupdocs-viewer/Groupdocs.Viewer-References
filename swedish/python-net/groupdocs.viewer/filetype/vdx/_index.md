## VDX field

Visio Drawing XML File (.vdx) representerar alla ritningar eller diagram som skapats i Microsoft Visio, men som sparas i XML-format med .VDX-filändelse. En Visio-ritnings‑XML‑fil skapas i Visio‑programvaran, som utvecklats av Microsoft. Läs mer om detta filformat här.
