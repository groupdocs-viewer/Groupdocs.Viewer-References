## VTX field

Visio Template XML File (.vtx) är en Microsoft Visio-ritmall som sparas på disk i XML-filformat. Mallen är avsedd att tillhandahålla en fil med grundinställningar som kan användas för att skapa flera Visio-filer med samma inställningar. Läs mer om detta filformat här.
