## XLT field

Microsoft Excel Template (.xlt) är mallfiler skapade med Microsoft Excel, som är ett kalkylprogram som ingår i Microsoft Office-paketet. Microsoft Office 97-2003 stödde att skapa nya XLT-filer samt att öppna dem. Läs mer om detta filformat här.
