## DWFX field

Design Web Format File XPS (.dwfx) representerar 2D/3D-ritning som XPS-dokument i komprimerat format för visning, granskning eller utskrift av designfiler. Den innehåller grafik och text som en del av designdata och minskar filens storlek på grund av dess komprimerade format. Läs mer om detta filformat här.
