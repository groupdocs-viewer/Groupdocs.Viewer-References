## VSX field

Visio Stencil XML File (.vsx) avser stenciler som består av ritningar och former som används för att skapa diagram i Microsoft Visio. VSX-filer sparas i XML-filformat och stöddes fram till Visio 2013. Läs mer om detta filformat här.
