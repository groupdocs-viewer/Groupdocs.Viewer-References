## VSSM field

Visio Macro-Enabled Stencil File (.vssm) är Microsoft Visio Stencil-filer som ger stöd för makron. En VSSM-fil som öppnas gör det möjligt att köra makron för att uppnå önskad formatering och placering av former i ett diagram. Läs mer om detta filformat här.
