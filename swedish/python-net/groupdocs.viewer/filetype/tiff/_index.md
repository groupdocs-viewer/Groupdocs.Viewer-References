## TIFF field

Tagged Image File Format (.tiff) representerar rasterbilder som är avsedda för användning på en mängd olika enheter som följer detta filformatstandard. Den kan beskriva tvånivå-, gråskala-, palett‑färg‑ och fullfärgsbilddata i flera färgrymder. Läs mer om detta filformat här.
