## GZIP field

Gnu Zipped File (.gzip) introducerades som ett gratisverktyg för att ersätta Compress-programmet som används i Unix-system. Sådana filer kan öppnas och extraheras med flera program, såsom WinZip som finns tillgängligt både för Windows och macOS. Läs mer om detta filformat här.
