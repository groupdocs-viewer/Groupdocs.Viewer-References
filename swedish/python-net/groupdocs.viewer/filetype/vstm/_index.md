## VSTM field

Visio Macro-Enabled Drawing Template (.vstm) är mallfiler som skapats med Microsoft Visio och som stöder makron. Till skillnad från VSDX-filer kan filer som skapas från VSTM-mallar köra makron som utvecklats i Visual Basic for Applications (VBA)-kod. Läs mer om detta filformat här.
