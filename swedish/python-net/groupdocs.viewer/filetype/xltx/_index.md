## XLTX field

Excel Open XML Spreadsheet Template (.xltx) representerar Microsoft Excel-mallar som är baserade på Office OpenXML-filformatsspecifikationerna. Den används för att skapa en standardmallfil som kan användas för att generera XLSX-filer som har samma inställningar som specificerade i XLTX-filen. Läs mer om detta filformat här.
