## XLTM field

Microsoft Excel Macro-Enabled Template (.xltm) representerar filer som genereras av Microsoft Excel som makroaktiverade mallfiler. XLTM-filer är liknande XLTX i struktur förutom att den senare inte stödjer att skapa mallfiler med makron. Läs mer om detta filformat här.
