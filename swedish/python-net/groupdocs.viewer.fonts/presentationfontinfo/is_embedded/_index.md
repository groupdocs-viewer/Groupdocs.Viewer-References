## is_embedded property

Egenskapen indikerar om teckensnittet är inbäddat i dokumentet och laddat in i [`Viewer`](/viewer/python-net/groupdocs.viewer/viewer/)‑instansen (`True`), eller om det är ett systemteckensnitt (`False`).

Kalkylbladsdokument kan inte innehålla inbäddade teckensnitt, så denna egenskap returnerar alltid `False` för dem.
