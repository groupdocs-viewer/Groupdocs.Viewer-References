Paketet tillhandahåller hjälp- och verktygsklasser för olika funktioner.

Dessa klasser erbjuder bekväma metoder och funktioner för att hjälpa till i olika operationer.

De viktigaste klasserna i detta paket är:

 *  [MemoryCleaner](../../com.groupdocs.viewer.utils/memorycleaner) - Provides methods to clean up resources and free memory.
 *  [PathUtils](../../com.groupdocs.viewer.utils/pathutils) - Represents the type for working with paths.

För mer information om hur du använder verktygsklasserna i paketet com.groupdocs.viewer.utils, se [GroupDocs.Viewer Dokumentation][].
