Paketet tillhandahåller funktionalitet för att använda anpassade modeller i cacheimplementation.

Huvudklassen i detta paket är [CacheableFactory](../../com.groupdocs.viewer.caching.extra/cacheablefactory), som hjälper till att anpassa cachen genom att tillhandahålla ytterligare funktionalitet.

För mer information om att använda anpassade modeller i cache-implementation i GroupDocs.Viewer, se [GroupDocs.Viewer Documentation][].
