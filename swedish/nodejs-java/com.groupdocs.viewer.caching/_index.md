Paketet tillhandahåller klasser för anpassning av cachebeteende.

De huvudsakliga klasserna och gränssnitten i detta paket är:

 *  [CacheKeys](../../com.groupdocs.viewer.caching/cachekeys) - Provides methods to retrieve unique identifiers for the cache entry.
 *  [FileCache](../../com.groupdocs.viewer.caching/filecache) - Represents a local on-disk cache.

Gränssnittet [Cache](../../com.groupdocs.viewer.caching/cache) definierar de metoder som krävs för att lagra renderade dokument och dokumentresurser i cachen.

För mer information om att anpassa cachebeteendet i GroupDocs.Viewer, vänligen se [GroupDocs.Viewer Documentation][].


[GroupDocs.Viewer Documentation]: https://docs.groupdocs.com/viewer/java/
