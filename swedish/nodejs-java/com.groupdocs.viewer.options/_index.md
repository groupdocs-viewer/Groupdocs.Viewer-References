Paketet tillhandahåller klasser för att specificera ytterligare alternativ vid rendering av dokument.

Den innehåller alternativ för rendering av olika dokumentformat, definiering av behörigheter och säkerhetsinställningar, specificering av vattenstämpelns egenskaper och hämtning av information om vyer.

De viktigaste klasserna i detta paket är:

 *  [ArchiveOptions](../../com.groupdocs.viewer.options/archiveoptions) - Provides options for rendering archive files.
 *  [PdfOptions](../../com.groupdocs.viewer.options/pdfoptions) - Provides options for rendering PDF documents.
 *  [WordProcessingOptions](../../com.groupdocs.viewer.options/wordprocessingoptions) - Provides options for rendering word processing documents.

För mer detaljer om konfiguration av loggsystemet i GroupDocs.Viewer och anpassning av hantering av loggmeddelanden, vänligen se [GroupDocs.Viewer Documentation][].


[GroupDocs.Viewer Documentation]: https://docs.groupdocs.com/viewer/java/
