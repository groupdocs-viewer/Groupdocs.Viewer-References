Paketet tillhandahåller klasser för att konfigurera loggningssystemet i GroupDocs.Viewer.


Genom att använda dessa klasser kan du styra hur loggmeddelanden hanteras, till exempel genom att skriva dem till
en fil eller dirigera dem till en specifik logger‑implementation.

De viktigaste klasserna i detta paket är:

* [FileLogger](../../com.groupdocs.viewer.logging/filelogger) - Writes log messages to a file.
* [ViewerLogger](../../com.groupdocs.viewer.logging/viewerlogger) - Implements logging messages to an integrated or user-defined logger.


För mer information om konfiguration av loggsystemet i GroupDocs.Viewer och anpassning av loggmeddelandehantering,
se gärna [GroupDocs.Viewer Documentation](../https://docs.groupdocs.com/viewer/java/).
