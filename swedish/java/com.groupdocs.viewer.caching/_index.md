Paketet tillhandahåller klasser för att anpassa cachebeteende.

De viktigaste klasserna och gränssnitten i detta paket är:

* [CacheKeys](../../com.groupdocs.viewer.caching/cachekeys) - Provides methods to retrieve unique identifiers for the cache entry.
* [FileCache](../../com.groupdocs.viewer.caching/filecache) - Represents a local on-disk cache.


Gränssnittet [Cache](../../com.groupdocs.viewer.caching/cache) definierar metoder som krävs för att lagra renderade dokument.
och dokumentresurser i cachen.


För mer information om anpassning av cachebeteende i GroupDocs.Viewer, se
[GroupDocs.Viewer Documentation](../https://docs.groupdocs.com/viewer/java/).

| Klass | Beskrivning |
| --- | --- |
| [CacheKeys](../com.groupdocs.viewer.caching/cachekeys) | Tillhandahåller metoder för att hämta det unika identifieraren för en cachepost. |
