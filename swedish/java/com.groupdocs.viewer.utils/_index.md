Paketet tillhandahåller hjälpar- och verktygsklasser för olika funktioner.


Dessa klasser erbjuder bekväma metoder och funktioner för att hjälpa till i olika operationer.

De viktigaste klasserna i detta paket är:

* [CancellationToken](../../com.groupdocs.viewer.utils/cancellationtoken) - Propagates a request to cancel rendering.
* [CancellationTokenSource](../../com.groupdocs.viewer.utils/cancellationtokensource) - Creates and signals a [CancellationToken](../../com.groupdocs.viewer.utils/cancellationtoken).
* [MemoryCleaner](../../com.groupdocs.viewer.utils/memorycleaner) - Provides methods to clean up resources and free memory.
* [PathUtils](../../com.groupdocs.viewer.utils/pathutils) - Represents the type for working with paths.


För mer detaljer om hur man använder verktygsklasserna i paketet com.groupdocs.viewer.utils,
se gärna [GroupDocs.Viewer Documentation](../https://docs.groupdocs.com/viewer/java/).



## Klasser

| [MemoryCleaner](../com.groupdocs.viewer.utils/memorycleaner) | Rensar olika resurser för att frigöra minne. |
