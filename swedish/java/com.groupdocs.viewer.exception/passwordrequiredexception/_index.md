public class PasswordRequiredException extends GroupDocsViewerException

Detta undantag kastas när ett lösenord krävs för att ladda dokumentet.
Detta undantag uppstår vanligtvis när man försöker läsa in eller öppna ett dokument som är krypterat eller lösenordsskyddat utan att ange ett giltigt lösenord.
