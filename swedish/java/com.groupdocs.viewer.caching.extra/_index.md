Paketet tillhandahåller funktionalitet för att använda anpassade modeller i cacheimplementering.


Huvudklassen i detta paket är [CacheableFactory](../../com.groupdocs.viewer.caching.extra/cacheablefactory),
som hjälper till att anpassa cachen genom att tillhandahålla ytterligare funktionalitet.


För mer information om att använda anpassade modeller i cache-implementationen i GroupDocs.Viewer, se
[GroupDocs.Viewer Documentation](../https://docs.groupdocs.com/viewer/java/).
