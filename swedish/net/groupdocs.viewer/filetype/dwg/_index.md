## FileType.DWG field

AutoCAD Drawing Database File (.dwg) representerar proprietära binära filer som används för att innehålla 2D- och 3D-designdata. Till skillnad från DXF, som är ASCII-filer, representerar DWG det binära filformatet för CAD (Computer Aided Design)-ritningar. Läs mer om detta filformat [här](https://wiki.fileformat.com/cad/dwg).
