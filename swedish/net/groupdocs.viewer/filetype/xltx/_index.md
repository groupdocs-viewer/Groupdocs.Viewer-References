## FileType.XLTX field

Excel Open XML Spreadsheet Template (.xltx) representerar Microsoft Excel Template som är baserade på Office OpenXML-filformatspecifikationerna. Den används för att skapa en standardmallfil som kan användas för att generera XLSX-filer som har samma inställningar som specificeras i XLTX-filen. Läs mer om detta filformat [här](https://wiki.fileformat.com/spreadsheet/xltx).
