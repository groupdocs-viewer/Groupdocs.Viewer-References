## FileType.GZIP field

Gnu Zipped File (.gzip) introducerades som ett fritt verktyg för att ersätta Compress‑programmet som användes i Unix‑system. Sådana filer kan öppnas och extraheras med flera program såsom WinZip, som finns tillgängligt både på Windows och macOS. Läs mer om detta filformat [här](https://wiki.fileformat.com/compression/gz).
