## WordProcessingSubstitutedFontInfo structure

Inkapslar metainformation och binära data för ett teckensnitt från ett WordProcessing-dokument, som ursprungligen inte används i det dokument som laddas in i [`Viewer`](../../groupdocs.viewer/viewer)-instansen, men fungerar som ett ersättningsteckensnitt för de som inte kan hittas på målmaskinen. Ersättningsteckensnitt finns endast för WordProcessing-formatfamiljen.

```csharp
public struct WordProcessingSubstitutedFontInfo : IFontInfo
```
