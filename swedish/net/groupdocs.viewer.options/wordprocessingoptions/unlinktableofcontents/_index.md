## WordProcessingOptions.UnlinkTableOfContents property

När du renderar till HTML eller PDF kan du sätta detta alternativ till `true` för att inaktivera navigering från innehållsförteckningen. Vid HTML-rendering kommer `a`-taggar med relativa länkar att ersättas med `span`-taggar, vilket tar bort funktionaliteten men bevarar det visuella utseendet. Vid PDF-rendering kommer innehållsförteckningen att renderas som vanlig text utan länkar till dokumentsektioner.

```csharp
public bool UnlinkTableOfContents { get; set; }
```

### Anmärkningar

Standardvärdet är `false`.

För detaljer, se [dokumentationen](https://docs.groupdocs.com/viewer/net/render-word-documents/#unlink-table-of-contents).
