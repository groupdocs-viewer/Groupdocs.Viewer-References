## WordProcessingOptions.VerticalResolution property

Hämtar eller anger den vertikala upplösningen för genererade bilder i punkter per tum. Detta alternativ används endast vid rendering av WordProcessing-dokument till PNG- eller JPEG-format.

```csharp
public int VerticalResolution { get; set; }
```

### Anmärkningar

Standardvärdet är 96 DPI. Minsta möjliga värde - 72 DPI, största möjliga värde - 600 DPI. Om ett användarspecificerat värde ligger utanför dessa gränser, kommer det minsta eller största möjliga värdet att tillämpas.
