## SearchHighlightOptions.IsSearchTermRegEx property

Hämtar eller anger ett värde som indikerar om söktermen ska behandlas som ett reguljärt uttryck eller som en textliteral. Standard är `false` — behandla som en textliteral.

```csharp
public bool IsSearchTermRegEx { get; set; }
```

### Anmärkningar

Om `true` tolkas [`SearchTerm`](../searchterm) som ett .NET‑Regex‑mönster.

Om `false` söks [`SearchTerm`](../searchterm) som en textsträng i dokumentet.
