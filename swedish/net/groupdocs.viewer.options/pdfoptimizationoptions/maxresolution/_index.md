## PdfOptimizationOptions.MaxResolution property

Ställer in den maximala upplösningen i den genererade PDF-filen.

```csharp
public int MaxResolution { get; set; }
```

### Anmärkningar

För att möjliggöra detta alternativ, ställ in egenskaperna [`CompressImages`](../compressimages) och `MaxResolution` till `true`.

Standardvärdet är `300`.

För kodexempel, se denna [dokumentation](https://docs.groupdocs.com/viewer/net/optimization-pdf-set-max-resolution/).
