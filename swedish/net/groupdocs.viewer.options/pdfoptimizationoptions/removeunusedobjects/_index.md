## PdfOptimizationOptions.RemoveUnusedObjects property

Tar bort oanvända (föräldralösa) objekt från en PDF-fil, som finns i PDF-dokumentet men som inte refereras från resursordböckerna på någon sida och därför inte används alls. Aktivering av denna egenskap (`true`) minskar storleken på den genererade PDF-dokumentet. Som standard är den inaktiverad (`false`).

public bool RemoveUnusedObjects { get; set; }
