## PdfViewOptions.ImageHeight property

Ställer in höjden på en utdata bild (i pixlar).

```csharp
public int ImageHeight { get; set; }
```

### Anmärkningar

Använd den här egenskapen för att ange höjden på utdata bilden (i pixlar). GroupDocs.Viewer tillämpar denna egenskap när en enskild bild renderas till HTML endast. För detaljer, se [dokumentationen](https://docs.groupdocs.com/viewer/net/set-image-size-limits-when-rendering-to-pdf/).

Om du anger den här egenskapen ignoreras egenskapen [`ImageMaxHeight`](../imagemaxheight).
