## PdfViewOptions.ImageWidth property

Ställer in bredden på en utdata bild (i pixlar).

```csharp
public int ImageWidth { get; set; }
```

### Anmärkningar

Använd den här egenskapen för att ange bredden på utdata bilden (i pixlar). GroupDocs.Viewer tillämpar denna egenskap när en enskild bild renderas till PDF. För detaljer, se [dokumentationen](https://docs.groupdocs.com/viewer/net/set-image-size-limits-when-rendering-to-pdf/).

Om du anger den här egenskapen ignoreras egenskapen [`ImageMaxWidth`](../imagemaxwidth).
