## PdfViewOptions.ImageMaxHeight property

Ställer in den maximala höjden på en utdata bild (i pixlar).

```csharp
public int ImageMaxHeight { get; set; }
```

### Anmärkningar

Använd den här egenskapen för att ange den maximala höjden på en utdata bild (i pixlar). GroupDocs.Viewer tillämpar denna egenskap när en enskild bild renderas till PDF. För detaljer, se [dokumentationen](https://docs.groupdocs.com/viewer/net/set-image-size-limits-when-rendering-to-pdf/).

Om du anger egenskapen [`ImageHeight`](../imageheight) ignoreras denna egenskap.
