## LoadOptions.TryRepair property

När den är aktiverad försöker GroupDocs.Viewer reparera strukturell korruption i PDF-dokument. Standardvärdet är `false`.

```csharp
public bool TryRepair { get; set; }
```

### Anmärkningar

Denna funktion åtgärdar följande problem i ett PDF-dokument:

* Broken references within the document (incorrect object offsets in the Cross-reference list).
* Missing critical elements like root object, page object, or page content.
* Circular references (Form X-object referencing itself).
