## HtmlViewOptions.ExcludeFonts property

Inaktiverar att lägga till några typsnitt i HTML-dokumentet.

```csharp
public bool ExcludeFonts { get; set; }
```

### Anmärkningar

Som standard bäddar GroupDocs.Viewer in de teckensnitt som används i dokumentet i HTML-markup, och den här egenskapen har värdet `false`. För att förhindra inbäddning av teckensnitt, sätt den här egenskapen till `true`.

För detaljer och kodexempel, se [dokumentation](https://docs.groupdocs.com/viewer/net/exclude-fonts/).
