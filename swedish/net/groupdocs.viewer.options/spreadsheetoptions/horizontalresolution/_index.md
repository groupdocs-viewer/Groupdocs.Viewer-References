## SpreadsheetOptions.HorizontalResolution property

Hämtar eller anger den horisontella upplösningen för genererade bilder i punkter per tum. Detta alternativ används endast vid rendering av kalkylblad till PNG‑ eller JPEG‑format.

```csharp
public int HorizontalResolution { get; set; }
```

### Anmärkningar

Standardvärdet är 96 DPI. Minsta möjliga värde - 72 DPI, största möjliga värde - 600 DPI. Om ett användarspecificerat värde ligger utanför dessa gränser, kommer det minsta eller största möjliga värdet att tillämpas.
