## PdfOptions.EnableFontHinting property

Aktiverar typsnittshintning.

```csharp
public bool EnableFontHinting { get; set; }
```

### Anmärkningar

Fonthintning justerar hur ett konturtypsnitt visas. Gäller endast TTF-typsnitt som används i källdokumentet. Detta alternativ är tillgängligt för rendering till PNG- eller JPG-format. Standardvärdet är `false`.

För kodexempel, se [dokumentationen](https://docs.groupdocs.com/viewer/net/render-pdf-documents/#enable-font-hinting).
