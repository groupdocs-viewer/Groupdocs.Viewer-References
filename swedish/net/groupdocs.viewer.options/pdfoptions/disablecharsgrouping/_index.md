## PdfOptions.DisableCharsGrouping property

Inaktiverar symbolgruppering för exakt symbolplacering under sidrendering.

```csharp
public bool DisableCharsGrouping { get; set; }
```

### Anmärkningar

När du konverterar PDF-filer grupperar GroupDocs.Viewer enskilda tecken till ord för förbättrad renderingsprestanda. Om ditt dokument innehåller hieroglyfer eller specialtecken kan du vilja förbjuda teckengruppning för att säkerställa en mer exakt layout. Standardvärdet är `false`.

För kodexempel, se [dokumentationen](https://docs.groupdocs.com/viewer/net/render-pdf-documents/#disable-character-grouping).
