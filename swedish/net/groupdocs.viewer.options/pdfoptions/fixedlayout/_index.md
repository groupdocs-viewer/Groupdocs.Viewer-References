## PdfOptions.FixedLayout property

Aktiverar rendering av PDF- och EPUB-dokument till HTML med en fast layout.

```csharp
public bool FixedLayout { get; set; }
```

### Anmärkningar

PDF- och EPUB-dokument renderas först till HTML med en fast layout för att behålla utseendet på källdokumentet. Denna fasta layout innebär att alla HTML-element har exakta positioner inom en behållare med en bestämd storlek. Att ändra storlek på webbläsarfönstret påverkar inte positionen och storleken på element i dokumentet.

Detta alternativ är endast tillgängligt vid rendering till HTML. Standardvärdet är `true`. För att rendera med en flytande layout, sätt denna egenskap till `false`.

Vid rendering till flytande layout hoppas bilder över. Använd flytande layout när du renderar PDF-dokument med textinnehåll.

För kodexempel, se [dokumentationen](https://docs.groupdocs.com/viewer/net/render-pdf-documents/#create-html-with-fluid-layout).
