## PdfOptions.DisableFontLicenseVerifications property

Inaktiverar alla licensrestriktioner för alla teckensnitt i det aktuella XPS/OXPS-dokumentet.

```csharp
public bool DisableFontLicenseVerifications { get; set; }
```

### Anmärkningar

Många operationer med typsnitt kan inte utföras om de är förbjudna av licensen för detta typsnitt. Till exempel kan vissa typsnitt inte bäddas in i PDF-dokument om licensreglerna förbjuder inbäddning för detta typsnitt. Detta alternativ låter dig hoppa över verifiering av dessa regler.

Var försiktig när du använder detta flagga. När den är aktiverad betyder det att personen som sätter flaggan tar fullt ansvar för eventuella licens-/lagbrott på sig själv. Så han tar det på egen risk. Det rekommenderas starkt att endast använda detta flagga när du är helt säker på att du inte bryter mot upphovsrättslagen. Standardvärdet är `false`.

För kodexempel, se [dokumentationen](https://docs.groupdocs.com/viewer/net/render-pdf-documents/#skip-font-license-verification-when-rendering-xps-and-oxps-files).
