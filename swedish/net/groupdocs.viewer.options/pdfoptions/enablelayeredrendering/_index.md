## PdfOptions.EnableLayeredRendering property

Aktiverar rendering av text och grafik i den ursprungliga PDF-dokumentets z-ordning vid rendering till HTML.

```csharp
public bool EnableLayeredRendering { get; set; }
```

### Anmärkningar

Som standard renderar GroupDocs.Veiewer text och grafik som ett enda lager i HTML. Detta alternativ låter dig ordna objekt i samma ordning som i källfilen. Standardvärdet är `false`.

För kodexempel, se [dokumentationen](https://docs.groupdocs.com/viewer/net/render-pdf-documents/#enable-multi-layer-rendering).
