## PdfOptions.RenderOriginalPageSize property

Ställer in utsidans storlek till samma som käll-PDF-dokumentets sidstorlek.

```csharp
public bool RenderOriginalPageSize { get; set; }
```

### Anmärkningar

Som standard beräknar GroupDocs.Viewer utdata bildsidors storlek för bättre renderingskvalitet. Aktivera detta alternativ för att säkerställa att utdata sidor har samma storlek som källdokumentets PDF-sidors storlek (i pixlar). Standardvärdet är `false`.

Detta alternativ är tillgängligt för rendering till PNG- eller JPG-format.

För kodexempel, se [dokumentationen](https://docs.groupdocs.com/viewer/net/render-pdf-documents/#preserve-the-size-of-document-pages).
