## PdfOptions.DisableCopyProtection property

Stänger av skydd mot kopiering av innehåll vid rendering till HTML.

```csharp
public bool DisableCopyProtection { get; set; }
```

### Anmärkningar

När PDF-filer renderas med skydd mot kopiering av text och bilder till HTML lägger GroupDocs.Viewer till ett 'inert' HTML-attribut i HTML BODY-taggen. Standardvärdet för detta alternativ är `false`, vilket indikerar att 'intent'-attributet endast läggs till om PDF-dokumentet är skyddat.

För kodexempel, se [dokumentationen](https://docs.groupdocs.com/viewer/net/render-pdf-documents/#disable-copy-protection).
