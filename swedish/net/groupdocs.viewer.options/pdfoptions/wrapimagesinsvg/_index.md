## PdfOptions.WrapImagesInSvg property

Aktiverar inbäddning av varje bild i HTML-utdata i en SVG-tag för att förbättra kvaliteten.

```csharp
public bool WrapImagesInSvg { get; set; }
```

### Anmärkningar

Som standard, när PDF- och Page Layout-filer renderas till HTML, renderas alla bilder som en enda PNG-bild. Den renderade PNG-bilden används som bakgrund för utdata HTML-dokumentet.

Detta alternativ är tillgängligt när [PDF- och Page Layout-filformat](https://docs.groupdocs.com/viewer/net/supported-document-formats/#pdf-and-page-layout-file-formats) renderas till HTML med inbäddade och externa resurser. Det möjliggör att varje bild i utdata HTML-dokumentet omsluts av en SVG-tag. Standardvärdet är `false`.

För kodexempel, se [dokumentationen](https://docs.groupdocs.com/viewer/net/render-pdf-documents/#enclose-images-in-svg-when-rendering-pdf-and-page-layout-files).
