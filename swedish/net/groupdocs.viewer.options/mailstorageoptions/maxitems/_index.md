## MailStorageOptions.MaxItems property

Ställer in det maximala antalet meddelanden eller objekt som ska renderas.

```csharp
public int MaxItems { get; set; }
```

### Anmärkningar

E-postlagringsdatafiler kan vara stora och att hämta alla meddelanden kan ta betydande tid. Denna egenskap begränsar det maximala antalet meddelanden eller objekt som renderas. Standardvärdet är 0 – alla meddelanden renderas.

För kodexempel, se [dokumentationen](https://docs.groupdocs.com/viewer/net/render-lotus-notes-database-files/#limit-the-number-of-items-to-render).
