## BaseViewOptions.RemoveComments property

Inaktiverar rendering av kommentarer när den är satt till `true`. Som standard är den `false` — alla kommentarer visas.

```csharp
public bool RemoveComments { get; set; }
```

### Anmärkningar

Vissa dokumentformat som PDF och WordProcessing kan innehålla kommentarer. Som standard renderar GroupDocs.Viewer dem. När detta alternativ är satt till `true` kan kommentarer uteslutas från det resulterande dokumentet.

Detta alternativ ersätter den föråldrade egenskapen 'RenderComments'.
