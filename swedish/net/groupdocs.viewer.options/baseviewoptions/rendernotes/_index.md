## BaseViewOptions.RenderNotes property

Aktiverar rendering av anteckningar och annotationer för vissa format

```csharp
public bool RenderNotes { get; set; }
```

### Anmärkningar

Vissa format, såsom presentationer eller Microsoft Project-filer, kan innehålla anteckningar. Dessutom kan PDF-filer ha popup-anteckningar (ballongtips) som är dolda som standard och endast synliga i en PDF-visare när muspekaren hålls över dem. Som standard renderar GroupDocs.Viewer inte sådana anteckningar och annotationer (`false`). För att göra detta, sätt den här egenskapen till `true`.

För kodexempel, se [dokumentationen](https://docs.groupdocs.com/viewer/net/render-presentations/#render-speaker-notes).
