## SearchHighlightOptions class

로드된 문서에서 텍스트를 검색하고 강조 표시하기 위한 옵션을 [`Viewer`](/viewer/python-net/groupdocs.viewer/viewer/) 클래스에 제공합니다.

SearchHighlightOptions 유형은 다음 멤버를 노출합니다:

### 생성자
| 생성자 | 설명 |
| :- | :- |
| [__init__](/viewer/python-net/groupdocs.viewer.options/searchhighlightoptions/__init__/) |  |

### 속성
| 속성 | 설명 |
| :- | :- |
| [background_color](/viewer/python-net/groupdocs.viewer.options/searchhighlightoptions/background_color/) | 강조 표시를 위한 배경 색상. |
| [foreground_color](/viewer/python-net/groupdocs.viewer.options/searchhighlightoptions/foreground_color/) | 강조 표시를 위한 전경(텍스트) 색상. |
| [is_search_term_reg_ex](/viewer/python-net/groupdocs.viewer.options/searchhighlightoptions/is_search_term_reg_ex/) | 이 속성은 검색어를 정규식으로 처리할지 텍스트 리터럴로 처리할지를 나타냅니다. 기본값은 False이며, 텍스트 리터럴로 처리합니다. |
| [search_term](/viewer/python-net/groupdocs.viewer.options/searchhighlightoptions/search_term/) | 검색할 텍스트(또는 [`SearchHighlightOptions.is_search_term_reg_ex`](/viewer/python-net/groupdocs.viewer.options/searchhighlightoptions/is_search_term_reg_ex/) 속성이 True인 경우 정규식 패턴). |
