## Field class

이메일 메시지 필드(예: From, To, Subject 등)를 나타냅니다.

자세한 내용은 문서를 참조하십시오.

Field 유형은 다음 멤버를 노출합니다:

### 메서드
| 메서드 | 설명 |
| :- | :- |
| [to_string](/viewer/python-net/groupdocs.viewer.options/field/to_string/) | 현재 객체를 나타내는 문자열을 반환합니다. |

### 속성
| 속성 | 설명 |
| :- | :- |
| [name](/viewer/python-net/groupdocs.viewer.options/field/name/) | 필드 이름입니다. |
