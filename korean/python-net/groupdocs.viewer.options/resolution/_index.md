## Resolution class

출력 문서의 이미지 해상도를 설정하는 옵션을 포함합니다.

Resolution 형식은 다음 멤버를 노출합니다:

### 생성자
| 생성자 | 설명 |
| :- | :- |
| [__init__](/viewer/python-net/groupdocs.viewer.options/resolution/__init__/#value) | DPI 단위로 해상도를 초기화합니다. |

### 속성
| 속성 | 설명 |
| :- | :- |
| [value](/viewer/python-net/groupdocs.viewer.options/resolution/value/) | 품질 DPI. |

### 필드
| 필드 | 설명 |
| :- | :- |
| [DPI330](/viewer/python-net/groupdocs.viewer.options/resolution/dpi330/) | 고해상도(HD) 디스플레이에 적합한 좋은 품질. |
| [DPI220](/viewer/python-net/groupdocs.viewer.options/resolution/dpi220/) | 대부분의 프린터와 화면에서 뛰어난 품질. |
| [DPI150](/viewer/python-net/groupdocs.viewer.options/resolution/dpi150/) | 웹 페이지와 프로젝터에 적합합니다. |
| [DPI96](/viewer/python-net/groupdocs.viewer.options/resolution/dpi96/) | 웹 페이지와 프로젝터에 적합합니다. |
| [DPI72](/viewer/python-net/groupdocs.viewer.options/resolution/dpi72/) | 기본 압축 수준. |
| [DOCUMENT_RESOLUTION](/viewer/python-net/groupdocs.viewer.options/resolution/document_resolution/) | 기본 압축 수준 - 문서와 동일하게. |
