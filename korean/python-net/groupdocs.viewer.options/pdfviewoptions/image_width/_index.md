## image_width property

출력 이미지의 너비(픽셀 단위)입니다.

이 속성을 사용하여 출력 이미지 너비(픽셀 단위)를 설정합니다. GroupDocs.Viewer는 단일 이미지를 PDF로 렌더링할 때 이 속성을 적용합니다. 자세한 내용은 문서를 참조하십시오.

이 속성을 설정하면, [`PdfViewOptions.ImageMaxWidth`](/viewer/python-net/groupdocs.viewer.options/pdfviewoptions/image_max_width/) 속성이 무시됩니다.
