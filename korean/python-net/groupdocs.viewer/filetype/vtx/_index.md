## VTX field

Visio Template XML File (.vtx)은 XML 파일 형식으로 디스크에 저장되는 Microsoft Visio 드로잉 템플릿입니다. 이 템플릿은 동일한 설정을 가진 여러 Visio 파일을 만들 때 사용할 수 있는 기본 설정이 포함된 파일을 제공하도록 설계되었습니다. 여기에서 이 파일 형식에 대해 자세히 알아보세요.
