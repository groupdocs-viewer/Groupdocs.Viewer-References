## XPS field

XML Paper Specification File (.xps)는 Microsoft에서 만든 XML Paper Specification을 기반으로 하는 페이지 레이아웃 파일을 나타냅니다. 이 형식은 EMF 파일 형식을 대체하기 위해 Microsoft에서 개발되었으며 PDF 파일 형식과 유사하지만 문서의 레이아웃, 외관 및 인쇄 정보를 XML로 사용합니다. 이 파일 형식에 대해 자세히 알아보려면 여기에서 확인하세요.
