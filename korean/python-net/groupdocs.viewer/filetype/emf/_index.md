## EMF field

Enhanced Windows Metafile (.emf)은 디바이스 독립적으로 그래픽 이미지를 나타냅니다. EMF 메타파일은 순차적인 가변 길이 레코드로 구성되어 있어, 어떤 출력 장치에서도 파싱 후 저장된 이미지를 렌더링할 수 있습니다. 이 파일 형식에 대해 자세히 알아보려면 여기.
