## ISO field

ISO 광디스크 이미지 파일은 CD 또는 DVD와 같은 광디스크 전체 데이터를 나타내는 비압축 아카이브 디스크 이미지 파일이며, ISO-9660 표준을 기반으로 합니다. 이 파일 형식에 대해 자세히 알아보려면 여기에서 확인하세요.
