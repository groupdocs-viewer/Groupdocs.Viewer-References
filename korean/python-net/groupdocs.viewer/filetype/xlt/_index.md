## XLT field

Microsoft Excel 템플릿(.xlt)은 Microsoft Excel로 만든 템플릿 파일이며, Microsoft Excel은 Microsoft Office 제품군의 일부인 스프레드시트 응용 프로그램입니다. Microsoft Office 97-2003은 새로운 XLT 파일을 만들고 열 수 있었습니다. 이 파일 형식에 대해 자세히 알아보려면 여기에서 확인하십시오.
