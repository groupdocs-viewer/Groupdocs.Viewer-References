## DWFX field

Design Web Format File XPS (.dwfx)는 XPS 문서 형식으로 압축된 2D/3D 도면을 제공하여 디자인 파일을 보기, 검토 또는 인쇄할 수 있게 합니다. 이 파일은 그래픽과 텍스트를 디자인 데이터의 일부로 포함하며, 압축 형식 덕분에 파일 크기가 감소합니다. 이 파일 형식에 대해 자세히 알아보려면 여기에서 확인하세요.
