## VSDM field

Visio Macro-Enabled Drawing (.vsdm)은 매크로를 지원하는 Microsoft Visio 애플리케이션으로 만든 드로잉 파일입니다. VSDM 파일은 VSDX와 유사한 OPC/XML 드로잉이지만, 파일이 열릴 때 매크로를 실행할 수 있는 기능도 제공합니다. 여기에서 이 파일 형식에 대해 자세히 알아보세요.
