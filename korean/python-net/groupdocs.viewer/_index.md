주 GroupDocs.Viewer 네임스페이스와 최상위 API 클래스.

### 클래스
| 클래스 | 설명 |
| :- | :- |
| [`FileType`](/viewer/python-net/groupdocs.viewer/filetype/) | 파일 유형을 나타내며 GroupDocs.Viewer에서 지원하는 모든 파일 유형 목록을 가져오는 메서드를 제공합니다. |
| [`IAuxDisposable`](/viewer/python-net/groupdocs.viewer/iauxdisposable/) | 표준 `System.IDisposable` 인터페이스를 확장하여 객체의 현재 상태를 가져오고 해제 이벤트에 구독할 수 있게 합니다. |
| [`License`](/viewer/python-net/groupdocs.viewer/license/) | GroupDocs.Viewer 라이선스를 관리합니다. |
| [`Metered`](/viewer/python-net/groupdocs.viewer/metered/) | 사용량 기반(종량제) 라이선스를 관리합니다. |
| [`Viewer`](/viewer/python-net/groupdocs.viewer/viewer/) | 문서 렌더링 프로세스를 제어하는 주요 클래스를 나타냅니다. |
| [`ViewerSettings`](/viewer/python-net/groupdocs.viewer/viewersettings/) | [`Viewer`](/viewer/python-net/groupdocs.viewer/viewer/) 동작을 사용자 정의하기 위한 설정을 정의합니다. |
