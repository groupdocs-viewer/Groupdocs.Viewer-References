## HtmlViewOptions.FontsToExclude property

HTML 문서에서 제외할 폰트 이름 목록입니다.

```csharp
public List<string> FontsToExclude { get; set; }
```

### 비고

HTML 문서에 추가된 글꼴은 출력 뷰의 안정성을 향상시키지만 동시에 렌더링 결과의 크기를 증가시킵니다. 이 옵션을 사용하면 안정성과 출력 크기 사이의 균형을 맞출 수 있습니다. 대부분의 시스템에 설치되어 있는 일반적인 글꼴 이름을 포함하십시오.

이 속성은 [`ExcludeFonts`](../excludefonts) 옵션이 비활성화된 경우에만 적용됩니다.

자세한 내용 및 코드 예제는 [documentation](https://docs.groupdocs.com/viewer/net/exclude-fonts/)을(를) 참조하십시오.
