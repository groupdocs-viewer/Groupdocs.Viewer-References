## PdfOptions.DisableCharsGrouping property

페이지 렌더링 중 정확한 기호 위치 지정을 위해 기호 그룹화를 비활성화합니다.

```csharp
public bool DisableCharsGrouping { get; set; }
```

### 비고

PDF 파일을 변환할 때, GroupDocs.Viewer는 개별 문자를 단어로 그룹화하여 렌더링 성능을 향상시킵니다. 문서에 상형문자나 특수 기호가 포함된 경우, 보다 정확한 레이아웃을 위해 문자 그룹화를 금지하고 싶을 수 있습니다. 기본값은 `false`입니다.
