## PdfOptions.WrapImagesInSvg property

출력 품질을 향상시키기 위해 출력 HTML 문서의 각 이미지를 SVG 태그로 감싸도록 활성화합니다.

```csharp
public bool WrapImagesInSvg { get; set; }
```

### 비고

기본적으로 PDF 및 페이지 레이아웃 파일을 HTML로 렌더링할 때 모든 이미지가 하나의 PNG 이미지로 렌더링됩니다. 렌더링된 PNG 이미지는 출력 HTML 문서의 배경으로 사용됩니다.

이 옵션은 [PDF and Page Layout file formats](https://docs.groupdocs.com/viewer/net/supported-document-formats/#pdf-and-page-layout-file-formats)를 HTML로 렌더링하면서 임베드 및 외부 리소스를 사용할 때 사용할 수 있습니다. 출력 HTML 문서의 각 이미지를 SVG 태그로 감싸도록 합니다. 기본값은 `false`입니다.

코드 예제는 [documentation](https://docs.groupdocs.com/viewer/net/render-pdf-documents/#enclose-images-in-svg-when-rendering-pdf-and-page-layout-files)을(를) 참조하십시오.
