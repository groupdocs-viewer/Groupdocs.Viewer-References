## PdfOptions.DisableFontLicenseVerifications property

현재 XPS/OXPS 문서의 모든 글꼴에 대한 라이선스 제한을 비활성화합니다.

```csharp
public bool DisableFontLicenseVerifications { get; set; }
```

### 비고

폰트에 대한 많은 작업은 해당 폰트의 라이선스에 의해 금지된 경우 실행할 수 없습니다. 예를 들어, 라이선스 규칙이 해당 폰트의 임베딩을 금지하면 일부 폰트를 PDF 문서에 삽입할 수 없습니다. 이 옵션을 사용하면 이러한 규칙의 검증을 건너뛸 수 있습니다.

이 플래그를 사용할 때는 주의하십시오. 이 플래그가 설정되면 해당 플래그를 설정한 사람이 가능한 라이선스/법 위반에 대한 모든 책임을 스스로 부담한다는 의미입니다. 따라서 자신의 위험 부담 하에 사용해야 합니다. 저작권법을 위반하지 않겠다는 확신이 있을 때만 이 플래그를 사용하는 것이 강력히 권장됩니다. 기본값은 `false`입니다.

코드 예제는 [documentation](https://docs.groupdocs.com/viewer/net/render-pdf-documents/#skip-font-license-verification-when-rendering-xps-and-oxps-files)을(를) 참조하십시오.
