## PdfOptions.RenderOriginalPageSize property

출력 페이지 크기를 소스 PDF 문서의 페이지 크기와 동일하게 설정합니다.

```csharp
public bool RenderOriginalPageSize { get; set; }
```

### 비고

기본적으로 GroupDocs.Viewer는 더 나은 렌더링 품질을 위해 출력 이미지 페이지 크기를 계산합니다. 이 옵션을 활성화하면 출력 페이지가 원본 PDF 문서의 페이지 크기(픽셀 단위)와 동일하게 됩니다. 기본값은 `false`입니다.

이 옵션은 PNG 또는 JPG 형식으로 렌더링할 때 사용할 수 있습니다.

코드 예제는 [documentation](https://docs.groupdocs.com/viewer/net/render-pdf-documents/#preserve-the-size-of-document-pages)을(를) 참조하십시오.
