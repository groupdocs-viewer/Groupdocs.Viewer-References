## PdfOptions.EnableLayeredRendering property

HTML로 렌더링할 때 원본 PDF 문서의 Z-순서대로 텍스트와 그래픽을 렌더링하도록 활성화합니다.

```csharp
public bool EnableLayeredRendering { get; set; }
```

### 비고

기본적으로 GroupDocs.Veiewer는 HTML에서 텍스트와 그래픽을 단일 레이어로 렌더링합니다. 이 옵션을 사용하면 객체를 원본 파일과 동일한 순서대로 배치할 수 있습니다. 기본값은 `false`입니다.

코드 예제는 [documentation](https://docs.groupdocs.com/viewer/net/render-pdf-documents/#enable-multi-layer-rendering)을(를) 참조하십시오.
