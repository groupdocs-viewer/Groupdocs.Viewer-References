## PdfOptions.DisableCopyProtection property

HTML로 렌더링할 때 콘텐츠 복사 보호를 해제합니다.

```csharp
public bool DisableCopyProtection { get; set; }
```

### 비고

PDF 파일을 HTML로 렌더링하면서 텍스트와 이미지 복사를 방지하는 보호가 적용된 경우, GroupDocs.Viewer는 HTML BODY 태그에 'inert' HTML 속성을 추가합니다. 이 옵션의 기본값은 `false`이며, 이는 PDF 문서가 보호된 경우에만 'intent' HTML 속성이 추가된다는 것을 의미합니다.

코드 예제는 [documentation](https://docs.groupdocs.com/viewer/net/render-pdf-documents/#disable-copy-protection) 를 참조하십시오.
