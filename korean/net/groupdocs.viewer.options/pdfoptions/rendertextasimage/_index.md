## PdfOptions.RenderTextAsImage property

PDF 파일의 텍스트를 HTML 출력에서 이미지로 렌더링하도록 활성화합니다.

```csharp
public bool RenderTextAsImage { get; set; }
```

### 비고

이 옵션을 `true`로 설정하면 GroupDocs.Viewer는 HTML 출력에서 텍스트를 이미지로 렌더링합니다. 이렇게 하면 텍스트를 선택할 수 없게 되고 문자 렌더링이 향상되어 HTML에서 PDF와 같은 외관을 보장합니다. 기본값은 `false`입니다.

이 옵션은 HTML로 렌더링할 때 사용할 수 있습니다.

코드 예제는 [documentation](https://docs.groupdocs.com/viewer/net/render-pdf-documents/#render-text-as-an-image) 를 참조하십시오.
