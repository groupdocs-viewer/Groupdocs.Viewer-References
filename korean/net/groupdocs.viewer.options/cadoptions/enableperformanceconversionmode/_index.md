## CadOptions.EnablePerformanceConversionMode property

`true` 로 설정하면 CAD 계열의 모든 형식에 대해 특수한 성능 중심 변환 모드가 활성화됩니다 — 이 모드에서는 변환 속도가 훨씬 빨라지지만 결과 문서의 품질이 크게 악화됩니다. 기본값은 비활성화(`false`)이며 — 결과 문서의 품질은 성능을 희생하고 가능한 최상의 수준을 유지합니다.

public bool EnablePerformanceConversionMode { get; set; }
