## PresentationOptions.RenderHeaderFooterPlaceholders property

슬라이드의 머리글 및 바닥글에 자리 표시자를 렌더링하도록 활성화합니다. 기본값은 비활성화(`false`)입니다. 이 옵션은 프레젠테이션의 네 가지 렌더링 모드인 HTML, PDF, PNG 및 JPEG에 모두 적용됩니다. [`RenderToPureHtml`](../rendertopurehtml)을 사용하여 프레젠테이션을 순수 HTML/CSS 마크업으로 렌더링할 때는 적용되지 않습니다.

public bool RenderHeaderFooterPlaceholders { get; set; }
