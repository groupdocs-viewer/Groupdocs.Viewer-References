## WordProcessingOptions.UnlinkTableOfContents property

HTML 또는 PDF로 렌더링할 때, 목차에서의 탐색을 비활성화하려면 이 옵션을 `true` 로 설정할 수 있습니다. HTML 렌더링의 경우, 상대 링크가 있는 `a` 태그가 `span` 태그로 교체되어 기능은 제거되지만 시각적 모양은 유지됩니다. PDF 렌더링의 경우, 목차가 문서 섹션에 대한 링크 없이 일반 텍스트로 렌더링됩니다.

```csharp
public bool UnlinkTableOfContents { get; set; }
```

### 비고

기본값은 `false`입니다.
