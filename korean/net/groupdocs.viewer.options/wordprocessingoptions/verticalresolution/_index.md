## WordProcessingOptions.VerticalResolution property

생성된 이미지의 세로 해상도를 인치당 도트(dpi) 단위로 가져오거나 설정합니다. 이 옵션은 WordProcessing 문서를 PNG 또는 JPEG 형식으로 렌더링할 때만 사용됩니다.

```csharp
public int VerticalResolution { get; set; }
```

### 비고

기본값은 96 DPI입니다. 최소값은 72 DPI, 최대값은 600 DPI입니다. 사용자가 지정한 값이 이 범위를 벗어나면 최소값 또는 최대값이 적용됩니다.
