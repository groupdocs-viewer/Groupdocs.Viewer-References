## MailStorageOptions.MaxItems property

렌더링할 최대 메시지 또는 항목 수를 설정합니다.

```csharp
public int MaxItems { get; set; }
```

### 비고

메일 저장 데이터 파일은 크기가 클 수 있으며 모든 메시지를 검색하는 데 상당한 시간이 걸릴 수 있습니다. 이 속성은 렌더링되는 메시지 또는 항목의 최대 수를 제한합니다. 기본값은 0이며, 모든 메시지가 렌더링됩니다.
