## PdfOptimizationOptions.RemoveUnusedObjects property

PDF 파일에서 사용되지 않는(고아) 객체를 제거합니다. 이러한 객체는 PDF 문서에 존재하지만 어떤 페이지의 리소스 사전에서도 참조되지 않아 전혀 사용되지 않습니다. 이 속성을 활성화(`true`)하면 출력 PDF 문서 크기가 감소합니다. 기본값은 비활성화(`false`)입니다.

public bool RemoveUnusedObjects { get; set; }
