## PdfOptimizationOptions.RemoveUnusedStreams property

PDF 파일에서 사용되지 않는(고아) 스트림을 제거합니다. 이러한 스트림은 페이지의 리소스 사전에서 여전히 참조되지만 실제로 페이지 내용에서는 전혀 사용되지 않습니다. 기본값은 비활성화(`false`)이며, 이를 활성화(`true`)하면 출력 PDF 문서 크기가 감소합니다.

public bool RemoveUnusedStreams { get; set; }
