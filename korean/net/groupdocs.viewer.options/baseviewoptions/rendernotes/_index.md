## BaseViewOptions.RenderNotes property

일부 형식에 대해 노트와 주석 렌더링을 활성화합니다.

```csharp
public bool RenderNotes { get; set; }
```

### 비고

프레젠테이션이나 Microsoft 프로젝트 파일과 같은 일부 형식에는 노트가 포함될 수 있습니다. 또한 PDF 파일에는 기본적으로 숨겨져 있으며 마우스 커서를 올려놓을 때만 PDF 뷰어에서 보이는 팝업 주석(풍선 힌트)이 있을 수 있습니다. 기본적으로 GroupDocs.Viewer는 이러한 노트와 주석을 렌더링하지 않습니다 (`false`). 이를 수행하려면 이 속성을 `true`로 설정하십시오.

코드 예제는 [documentation](https://docs.groupdocs.com/viewer/net/render-presentations/#render-speaker-notes) 를 참조하십시오.
