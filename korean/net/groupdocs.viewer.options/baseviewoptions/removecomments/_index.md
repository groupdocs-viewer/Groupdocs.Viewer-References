## BaseViewOptions.RemoveComments property

`true` 로 설정하면 주석 렌더링을 비활성화합니다. 기본값은 `false`이며, 모든 주석이 표시됩니다.

```csharp
public bool RemoveComments { get; set; }
```

### 비고

PDF 및 WordProcessing과 같은 일부 문서 형식에는 주석이 포함될 수 있습니다. 기본적으로 GroupDocs.Viewer는 이를 렌더링합니다. 이 옵션을 `true`로 설정하면 결과 문서에서 주석이 제외될 수 있습니다.

이 옵션은 이전의 'RenderComments' 속성을 대체합니다.
