## OutlookOptions.MaxItemsInFolder property

하나의 폴더에서 렌더링할 수 있는 최대 메시지 또는 항목 수입니다.

```csharp
public int MaxItemsInFolder { get; set; }
```

### 비고

Outlook 데이터 파일은 크기가 클 수 있으며 모든 메시지를 가져오는 데 상당한 시간이 걸릴 수 있습니다. 이 속성은 렌더링되는 메시지 또는 항목의 최대 수를 제한합니다. 기본값은 `50`입니다. 모든 메시지를 렌더링하려면 값을 `0`으로 설정하십시오.

코드 예제는 [documentation](https://docs.groupdocs.com/viewer/net/render-outlook-data-files/#limit-the-number-of-folder-items-to-render)를 참조하십시오.
