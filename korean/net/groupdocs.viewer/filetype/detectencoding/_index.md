## DetectEncoding(string) {#detectencoding_1}

경로를 통해 텍스트 [`TXT`](../txt), [`TSV`](../tsv), 및 [`CSV`](../csv) 파일의 인코딩을 감지하려고 시도합니다.

```csharp
public static Encoding DetectEncoding(string filePath)
```

| 매개변수 | 유형 | 설명 |
| --- | --- | --- |
| filePath | String | 파일 이름 또는 파일 경로입니다. |

### 반환 값

파일 인코딩 감지에 실패하면 인코딩 또는 null을 반환합니다.

### 예시

이 예제는 텍스트 파일 인코딩을 감지하는 방법을 보여줍니다.

```csharp
Encoding encoding = FileType.DetectEncoding("message.txt");
```
