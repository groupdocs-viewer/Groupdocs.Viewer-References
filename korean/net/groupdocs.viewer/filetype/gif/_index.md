## FileType.GIF field

Graphical Interchange Format File (.gif)은 고도로 압축된 이미지 유형입니다. 각 GIF 이미지에서는 일반적으로 픽셀당 최대 8비트, 전체 이미지에서 최대 256색을 허용합니다. 이 파일 형식에 대해 자세히 알아보려면 [here](https://wiki.fileformat.com/image/gif)에서 확인하세요.
