문서를 로드하려면 비밀번호가 필요할 때 이 예외가 발생합니다.
이 예외는 암호화되었거나 비밀번호로 보호된 문서를 유효한 비밀번호를 제공하지 않고 로드하거나 열려고 시도할 때 일반적으로 발생합니다.
