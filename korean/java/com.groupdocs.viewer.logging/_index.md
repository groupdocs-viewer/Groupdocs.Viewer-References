이 패키지는 GroupDocs.Viewer의 로깅 시스템을 구성하기 위한 클래스를 제공합니다.


이러한 클래스를 사용하면 로그 메시지를 처리하는 방식을 제어할 수 있으며, 예를 들어 이를
파일에 기록하거나 특정 로거 구현으로 전달할 수 있습니다.

이 패키지의 주요 클래스는 다음과 같습니다:

* [FileLogger](../../com.groupdocs.viewer.logging/filelogger) - Writes log messages to a file.
* [ViewerLogger](../../com.groupdocs.viewer.logging/viewerlogger) - Implements logging messages to an integrated or user-defined logger.


GroupDocs.Viewer에서 로깅 시스템을 구성하고 로그 메시지 처리를 사용자 지정하는 방법에 대한 자세한 내용은
다음 문서를 참조하십시오 [GroupDocs.Viewer Documentation](../https://docs.groupdocs.com/viewer/java/).

| 클래스 | 설명 |
| --- | --- |

| [ViewerLogger](../com.groupdocs.viewer.logging/viewerlogger) | 전역 뷰어 로거. |
