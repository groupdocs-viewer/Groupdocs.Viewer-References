이 패키지는 문서 작업 중 발생할 수 있는 예외에 대한 클래스를 제공합니다.

이 패키지의 주요 클래스는 다음과 같습니다:

 *  com.groupdocs.viewer.exception.ArchiveSecurityException - Thrown when an archive being opened exceeds specified limits.
 *  [FileNotFoundException](../../com.groupdocs.viewer.exception/filenotfoundexception) - Represents an exception thrown when a file or directory is not found.
 *  [GroupDocsViewerException](../../com.groupdocs.viewer.exception/groupdocsviewerexception) - Represents generic errors that occur during document processing.

GroupDocs.Viewer에서 예외를 처리하는 방법에 대한 자세한 내용은 [GroupDocs.Viewer Documentation][]을 참조하십시오.


[GroupDocs.Viewer Documentation]: https://docs.groupdocs.com/viewer/java/


## 클래스

| 클래스 | 설명 |
| --- | --- |
| [ArchiveSecurityException](../com.groupdocs.viewer.exception/archivesecurityexception) | 열려는 아카이브가 ArchiveSecurityOptions에 지정된 제한을 초과할 경우 이 예외가 발생합니다. |
| [FileNotFoundException](../com.groupdocs.viewer.exception/filenotfoundexception) | 파일이나 디렉터리를 찾을 수 없을 때 이 예외가 발생합니다. |
| [GroupDocsViewerException](../com.groupdocs.viewer.exception/groupdocsviewerexception) | 이 예외는 문서 처리 중에 발생할 수 있는 일반적인 오류를 나타냅니다. |
| [IncorrectPasswordException](../com.groupdocs.viewer.exception/incorrectpasswordexception) | 지정된 비밀번호가 올바르지 않을 때 이 예외가 발생합니다. |
| [NotSupportedException](../com.groupdocs.viewer.exception/notsupportedexception) | 요청된 작업이 지원되지 않을 때 이 예외가 발생합니다. |
| [PasswordRequiredException](../com.groupdocs.viewer.exception/passwordrequiredexception) | 문서를 로드하려면 비밀번호가 필요할 때 이 예외가 발생합니다. |
