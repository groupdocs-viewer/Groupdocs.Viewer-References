该包提供用于配置 GroupDocs.Viewer 中日志系统的类。


通过使用这些类，您可以控制日志消息的处理方式，例如将其写入
文件，或将其定向到特定的日志记录器实现。

此包中的主要类有：

* [FileLogger](../../com.groupdocs.viewer.logging/filelogger) - Writes log messages to a file.
* [ViewerLogger](../../com.groupdocs.viewer.logging/viewerlogger) - Implements logging messages to an integrated or user-defined logger.


有关在 GroupDocs.Viewer 中配置日志系统和自定义日志消息处理的更多详细信息，
请参阅 [GroupDocs.Viewer Documentation](../https://docs.groupdocs.com/viewer/java/)。
