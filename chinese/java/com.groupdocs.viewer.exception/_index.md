该包提供在处理文档时可能出现的异常类。

此包中的主要类有：

* com.groupdocs.viewer.exception.ArchiveSecurityException - Thrown when an archive being opened exceeds specified limits.
* [FileNotFoundException](../../com.groupdocs.viewer.exception/filenotfoundexception) - Represents an exception thrown when a file or directory is not found.
* [GroupDocsViewerException](../../com.groupdocs.viewer.exception/groupdocsviewerexception) - Represents generic errors that occur during document processing.


有关在 GroupDocs.Viewer 中处理异常的更多详细信息，请参阅
[GroupDocs.Viewer Documentation](../https://docs.groupdocs.com/viewer/java/).



## 类

| 类 | 描述 |
| --- | --- |
| [ArchiveSecurityException](../com.groupdocs.viewer.exception/archivesecurityexception) | 当打开的归档文件超出 ArchiveSecurityOptions 中指定的任何限制时，会抛出此异常。 |
| [FileNotFoundException](../com.groupdocs.viewer.exception/filenotfoundexception) | 当未找到文件或目录时，会抛出此异常。 |
| [GroupDocsViewerException](../com.groupdocs.viewer.exception/groupdocsviewerexception) | 此异常表示在文档处理期间可能出现的通用错误。 |
| [IncorrectPasswordException](../com.groupdocs.viewer.exception/incorrectpasswordexception) | 当指定的密码不正确时，会抛出此异常。 |
| [NotSupportedException](../com.groupdocs.viewer.exception/notsupportedexception) | 当请求的操作不受支持时，会抛出此异常。 |
| [PasswordRequiredException](../com.groupdocs.viewer.exception/passwordrequiredexception) | 当加载文档需要密码时，会抛出此异常。 |
