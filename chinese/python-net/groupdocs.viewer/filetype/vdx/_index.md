## VDX field

Visio Drawing XML File (.vdx) 表示在 Microsoft Visio 中创建的任何绘图或图表，但以 XML 格式保存，扩展名为 .VDX。Visio 绘图 XML 文件是在 Microsoft 开发的 Visio 软件中创建的。了解更多关于此文件格式的信息。
