## VSX field

Visio Stencil XML File (.vsx) 指用于在 Microsoft Visio 中创建图表的包含绘图和形状的模板。VSX 文件以 XML 文件格式保存，并在 Visio 2013 之前受支持。了解更多关于此文件格式的信息。
