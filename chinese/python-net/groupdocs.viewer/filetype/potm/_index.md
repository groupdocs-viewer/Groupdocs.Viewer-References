## POTM field

PowerPoint Open XML Macro-Enabled Presentation Template (.potm) 是支持宏的 Microsoft PowerPoint 模板文件。POTM 文件由 PowerPoint 2007 或以上版本创建，包含可用于创建进一步演示文稿的默认设置。了解更多关于此文件格式的信息。
