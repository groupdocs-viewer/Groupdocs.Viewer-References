## VTX field

Visio Template XML File (.vtx) 是以 XML 文件格式保存到磁盘的 Microsoft Visio 绘图模板。该模板旨在提供一个具有基本设置的文件，可用于创建多个具有相同设置的 Visio 文件。了解更多关于此文件格式的信息。
