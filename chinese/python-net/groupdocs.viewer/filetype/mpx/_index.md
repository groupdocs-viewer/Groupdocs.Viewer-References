## MPX field

Microsoft Project Exchange 文件 (.mpx) 是一种 ASCII 文件格式，用于在 Microsoft Project (MSP) 与其他支持 MPX 文件格式的应用程序（如 Primavera Project Planner、Sciforma 和 Timerline Precision Estimating）之间传输项目信息。了解更多关于此文件格式的信息，请点击此处。
