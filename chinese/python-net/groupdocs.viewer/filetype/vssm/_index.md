## VSSM field

Visio Macro-Enabled Stencil File (.vssm) 是支持宏的 Microsoft Visio 模板文件。打开 VSSM 文件后即可运行宏，以实现对图表中形状的所需格式化和放置。了解更多关于此文件格式的信息。
