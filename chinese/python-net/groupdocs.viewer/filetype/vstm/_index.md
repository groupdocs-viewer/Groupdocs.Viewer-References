## VSTM field

Visio Macro-Enabled Drawing Template (.vstm) 是由支持宏的 Microsoft Visio 创建的模板文件。与 VSDX 文件不同，使用 VSTM 模板创建的文件可以运行在 Visual Basic for Applications (VBA) 代码中开发的宏。了解更多关于此文件格式的信息。
