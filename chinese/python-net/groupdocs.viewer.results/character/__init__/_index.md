| 参数 | 类型 | 描述 |
| :- | :- | :- |
| character | `str` | 字符。 |
| x | `float` | 包含字符的矩形在页面布局中左上角的 X 坐标。 |
| y | `float` | 包含字符的矩形在页面布局中左上角的 Y 坐标。 |
| width | `float` | 包含单个字符的矩形的宽度（像素）。 |
| height | `float` | 包含单个字符的矩形的高度（像素）。 |
