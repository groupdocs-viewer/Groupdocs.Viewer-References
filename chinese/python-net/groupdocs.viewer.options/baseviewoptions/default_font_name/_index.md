## default_font_name property

当缺少所需字体时，用于渲染的文档默认字体。

使用此属性为文档设置默认字体。GroupDocs.Viewer 在渲染时会使用此字体，而不是任何未安装的字体。

代码示例请参阅文档：https://docs.groupdocs.com/viewer/net/replace-missing-font/
