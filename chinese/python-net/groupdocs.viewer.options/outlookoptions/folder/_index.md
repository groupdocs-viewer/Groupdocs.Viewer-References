## folder property

要呈现的文件夹名称（例如 Inbox、Sent Item 或 Deleted Items）。

在渲染 Outlook 数据文件时，GroupDocs.Viewer 会渲染文件中所有文件夹（包括嵌套文件夹）中的消息。使用此属性可渲染特定文件夹中的项目。
