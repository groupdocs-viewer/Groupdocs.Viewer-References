## remove_java_script property

此属性决定在渲染包含脚本的输入文档时，是否从生成的 HTML 文档的链接中移除 JavaScript 源代码。默认启用（`True`）。

有关移除 JavaScript 的详细信息，请参阅文档：https://docs.groupdocs.com/viewer/net/rendering-to-html/#preserving-or-disabling-javascript-when-rendering-to-html
