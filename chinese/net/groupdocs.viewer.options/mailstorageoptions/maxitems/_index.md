## MailStorageOptions.MaxItems property

设置要呈现的消息或项目的最大数量。

```csharp
public int MaxItems { get; set; }
```

### 备注

邮件存储数据文件可能很大，检索所有消息可能需要相当长的时间。此属性限制渲染的消息或项目的最大数量。默认值为 0——渲染所有消息。

有关代码示例，请参阅[文档](https://docs.groupdocs.com/viewer/net/render-lotus-notes-database-files/#limit-the-number-of-items-to-render)。
