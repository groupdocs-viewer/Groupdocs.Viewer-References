## BaseViewOptions.RenderNotes property

为某些格式启用渲染注释和标注

```csharp
public bool RenderNotes { get; set; }
```

### 备注

某些格式，例如演示文稿或 Microsoft 项目文件，可能包含备注。此外，PDF 文件可能具有弹出注释（气泡提示），默认情况下是隐藏的，仅在 PDF 查看器中将鼠标光标指向它们时才可见。默认情况下，GroupDocs.Viewer 不会渲染此类备注和注释（`false`）。要启用此功能，请将此属性设置为 `true`。

代码示例，请参见 [文档](https://docs.groupdocs.com/viewer/net/render-presentations/#render-speaker-notes)。
