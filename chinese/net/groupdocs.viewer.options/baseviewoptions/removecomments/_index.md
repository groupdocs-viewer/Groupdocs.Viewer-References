## BaseViewOptions.RemoveComments property

当设置为 `true` 时禁用渲染评论。默认是 `false` — 显示所有评论。

```csharp
public bool RemoveComments { get; set; }
```

### 备注

某些文档格式，如 PDF 和 WordProcessing，可能包含评论。默认情况下，GroupDocs.Viewer 会渲染它们。将此选项设置为 `true` 时，评论可能会从生成的文档中排除。

此选项取代已废弃的 'RenderComments' 属性。
