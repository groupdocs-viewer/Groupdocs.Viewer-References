## PdfViewOptions.ImageHeight property

设置输出图像的高度（像素）。

```csharp
public int ImageHeight { get; set; }
```

### 备注

使用此属性设置输出图像高度（以像素为单位）。GroupDocs.Viewer 在仅将单个图像渲染为 HTML 时会应用此属性。详情请参阅[文档](https://docs.groupdocs.com/viewer/net/set-image-size-limits-when-rendering-to-pdf/)。

如果设置了此属性，则 [`ImageMaxHeight`](../imagemaxheight) 属性将被忽略。
