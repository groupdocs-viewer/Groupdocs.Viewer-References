## PdfViewOptions.ImageWidth property

设置输出图像的宽度（像素）。

```csharp
public int ImageWidth { get; set; }
```

### 备注

使用此属性设置输出图像宽度（以像素为单位）。GroupDocs.Viewer 在将单个图像渲染为 PDF 时会应用此属性。详情请参阅[文档](https://docs.groupdocs.com/viewer/net/set-image-size-limits-when-rendering-to-pdf/)。

如果设置了此属性，则 [`ImageMaxWidth`](../imagemaxwidth) 属性将被忽略。
