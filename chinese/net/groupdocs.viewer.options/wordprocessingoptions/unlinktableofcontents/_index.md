## WordProcessingOptions.UnlinkTableOfContents property

在渲染为 HTML 或 PDF 时，您可以将此选项设置为 `true` 以禁用目录的导航。对于 HTML 渲染，带有相对链接的 `a` 标签将被替换为 `span` 标签，虽然功能被移除，但保持视觉外观。对于 PDF 渲染，目录将以纯文本形式渲染，不包含指向文档章节的链接。

```csharp
public bool UnlinkTableOfContents { get; set; }
```

### 备注

默认值为 `false`。

详情请参阅[文档](https://docs.groupdocs.com/viewer/net/render-word-documents/#unlink-table-of-contents)。
