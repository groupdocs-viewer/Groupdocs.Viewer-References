## CadOptions.EnablePerformanceConversionMode property

将此标志设置为 `true` 可为 CAD 系列的所有格式启用一种专注于性能的特殊转换模式——在此模式下，转换速度大幅提升，但生成文档的质量显著下降。默认情况下该标志为禁用 (`false`) —— 生成文档的质量在性能的代价下达到最佳可能水平。

```csharp
public bool EnablePerformanceConversionMode { get; set; }
```
