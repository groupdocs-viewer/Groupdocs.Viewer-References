## SpreadsheetOptions.HorizontalResolution property

获取或设置生成图像的水平分辨率（每英寸点数）。此选项仅在将电子表格渲染为 PNG 或 JPEG 格式时使用。

```csharp
public int HorizontalResolution { get; set; }
```

### 备注

默认值为 96 DPI。最小可能值为 72 DPI，最大可能值为 600 DPI。如果用户指定的值超出这些范围，将使用最小或最大可能值。
