## HtmlViewOptions.FontsToExclude property

要从 HTML 文档中排除的字体名称列表。

```csharp
public List<string> FontsToExclude { get; set; }
```

### 备注

添加到 HTML 文档中的字体可以提升输出视图的稳定性，但同时会增加渲染结果的体积。此选项可让您在稳定性和输出大小之间取得平衡。请包含在大多数系统中常用且已安装的字体名称。

请注意，仅当 [`ExcludeFonts`](../excludefonts) 选项被禁用时，此属性才会生效。

有关详细信息和代码示例，请参阅[文档](https://docs.groupdocs.com/viewer/net/exclude-fonts/)。
