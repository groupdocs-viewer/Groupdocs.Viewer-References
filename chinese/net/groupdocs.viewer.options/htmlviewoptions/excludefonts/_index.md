## HtmlViewOptions.ExcludeFonts property

禁用向 HTML 文档中添加任何字体。

```csharp
public bool ExcludeFonts { get; set; }
```

### 备注

默认情况下，GroupDocs.Viewer 会将文档中使用的字体嵌入到 HTML 标记中，此属性的默认值为 `false`。若要阻止嵌入字体，请将此属性设置为 `true`。

有关详细信息和代码示例，请参阅[文档](https://docs.groupdocs.com/viewer/net/exclude-fonts/)。
