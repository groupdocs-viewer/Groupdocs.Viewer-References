## SearchHighlightOptions.IsSearchTermRegEx property

获取或设置一个值，指示搜索词是应被视为正则表达式还是文本字面量。默认值为 `false` — 视为文本字面量。

```csharp
public bool IsSearchTermRegEx { get; set; }
```

### 备注

如果为 `true`，[`SearchTerm`](../searchterm) 将被解释为 .NET 正则表达式模式。

如果为 `false`，[`SearchTerm`](../searchterm) 将在文档中作为文本字面量进行搜索。
