## OutlookOptions.MaxItemsInFolder property

一个文件夹中可以呈现的消息或项目的最大数量。

```csharp
public int MaxItemsInFolder { get; set; }
```

### 备注

Outlook 数据文件可能很大，检索所有消息可能需要相当长的时间。此属性限制渲染的消息或项目的最大数量。默认值为 `50`。要渲染所有消息，请将该值设为 `0`。

代码示例请参阅[文档](https://docs.groupdocs.com/viewer/net/render-outlook-data-files/#limit-the-number-of-folder-items-to-render)。
