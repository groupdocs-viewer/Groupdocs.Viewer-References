## PdfOptions.WrapImagesInSvg property

启用将输出 HTML 文档中的每个图像包装在 SVG 标签中，以提升输出质量。

```csharp
public bool WrapImagesInSvg { get; set; }
```

### 备注

默认情况下，将 PDF 和页面布局文件渲染为 HTML 时，所有图像都会渲染为一个 PNG 图像。渲染的 PNG 图像用作输出 HTML 文档的背景。

当将 [PDF 和页面布局文件格式](https://docs.groupdocs.com/viewer/net/supported-document-formats/#pdf-and-page-layout-file-formats) 渲染为带有嵌入式和外部资源的 HTML 时，此选项可用。它允许将输出 HTML 文档中的每个图像包装在 SVG 标签中。默认值为 `false`。

有关代码示例，请参阅[文档](https://docs.groupdocs.com/viewer/net/render-pdf-documents/#enclose-images-in-svg-when-rendering-pdf-and-page-layout-files)。
