## PdfOptions.DisableCopyProtection property

在渲染为 HTML 时关闭内容复制保护。

```csharp
public bool DisableCopyProtection { get; set; }
```

### 备注

在将受防复制文本和图像保护的 PDF 文件渲染为 HTML 时，GroupDocs.Viewer 会在 HTML BODY 标签上添加一个 'inert' HTML 属性。此选项的默认值为 `false`，表示仅在 PDF 文档受保护时才会添加 'intent' HTML 属性。

代码示例请参见 [文档](https://docs.groupdocs.com/viewer/net/render-pdf-documents/#disable-copy-protection)。
