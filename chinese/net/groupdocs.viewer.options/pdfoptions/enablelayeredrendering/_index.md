## PdfOptions.EnableLayeredRendering property

在渲染为 HTML 时，启用按原始 PDF 文档的 Z 顺序渲染文本和图形。

```csharp
public bool EnableLayeredRendering { get; set; }
```

### 备注

默认情况下，GroupDocs.Veiewer 在 HTML 中将文本和图形渲染为单层。此选项允许您按源文件中的相同顺序排列对象。默认值为 `false`。

有关代码示例，请参阅[文档](https://docs.groupdocs.com/viewer/net/render-pdf-documents/#enable-multi-layer-rendering)。
