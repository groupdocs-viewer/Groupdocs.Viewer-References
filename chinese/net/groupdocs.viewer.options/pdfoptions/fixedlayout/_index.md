## PdfOptions.FixedLayout property

启用将 PDF 和 EPUB 文档以固定布局渲染为 HTML。

```csharp
public bool FixedLayout { get; set; }
```

### 备注

PDF 和 EPUB 文档最初会渲染为具有固定布局的 HTML，以保持源文档的外观。此固定布局意味着所有 HTML 元素在具有设定大小的容器内具有精确的位置。调整浏览器窗口大小不会影响文档中元素的位置和大小。

此选项仅在渲染为 HTML 时可用。默认值为 `true`。若要使用流式布局渲染，请将此属性设置为 `false`。

在渲染为流式布局时，图像会被跳过。请在渲染包含文本内容的 PDF 文档时使用流式布局。

代码示例请参见 [文档](https://docs.groupdocs.com/viewer/net/render-pdf-documents/#create-html-with-fluid-layout)。
