## PdfOptions.DisableFontLicenseVerifications property

禁用当前 XPS/OXPS 文档中所有字体的任何许可证限制。

```csharp
public bool DisableFontLicenseVerifications { get; set; }
```

### 备注

如果字体的许可证禁止某些操作，则这些操作无法执行。例如，如果许可证规则禁止嵌入，则某些字体无法嵌入到 PDF 文档中。此选项允许您跳过这些规则的验证。

使用此标志时请谨慎。设置后，意味着设置此标志的人需自行承担可能的许可证/法律违规责任。因此，他需自行承担风险。强烈建议仅在完全确信不会侵犯版权法时才使用此标志。默认值为 `false`。

有关代码示例，请参阅[文档](https://docs.groupdocs.com/viewer/net/render-pdf-documents/#skip-font-license-verification-when-rendering-xps-and-oxps-files)。
