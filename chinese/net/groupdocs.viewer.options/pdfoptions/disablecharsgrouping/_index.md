## PdfOptions.DisableCharsGrouping property

在页面渲染期间禁用符号分组，以实现精确的符号定位。

```csharp
public bool DisableCharsGrouping { get; set; }
```

### 备注

在转换 PDF 文件时，GroupDocs.Viewer 会将单个字符组合成单词，以提升渲染性能。如果您的文档包含象形文字或特殊符号，您可能想禁止字符分组，以确保更精确的布局。默认值为 `false`。

代码示例请参见 [文档](https://docs.groupdocs.com/viewer/net/render-pdf-documents/#disable-character-grouping)。
