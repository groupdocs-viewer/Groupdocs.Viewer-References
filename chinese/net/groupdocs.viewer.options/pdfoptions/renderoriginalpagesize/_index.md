## PdfOptions.RenderOriginalPageSize property

将输出页面尺寸设置为与源 PDF 文档的页面尺寸相同。

```csharp
public bool RenderOriginalPageSize { get; set; }
```

### 备注

默认情况下，GroupDocs.Viewer 会计算输出图像的页面大小以获得更好的渲染质量。启用此选项可确保输出页面的大小与源 PDF 文档的页面大小（以像素为单位）相同。默认值为 `false`。

此选项可用于渲染为 PNG 或 JPG 格式。

有关代码示例，请参阅[文档](https://docs.groupdocs.com/viewer/net/render-pdf-documents/#preserve-the-size-of-document-pages)。
