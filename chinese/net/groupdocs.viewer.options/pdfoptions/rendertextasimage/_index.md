## PdfOptions.RenderTextAsImage property

启用在 HTML 输出中将 PDF 文件中的文本渲染为图像。

```csharp
public bool RenderTextAsImage { get; set; }
```

### 备注

当此选项设置为 `true` 时，GroupDocs.Viewer 会在 HTML 输出中将文本渲染为图像。这使得文本不可选择，并增强字符渲染，确保 HTML 中呈现类似 PDF 的外观。默认值为 `false`。

此选项适用于渲染为 HTML。

代码示例请参见 [文档](https://docs.groupdocs.com/viewer/net/render-pdf-documents/#render-text-as-an-image)。
