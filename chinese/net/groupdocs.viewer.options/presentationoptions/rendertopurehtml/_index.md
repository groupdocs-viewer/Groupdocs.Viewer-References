## PresentationOptions.RenderToPureHtml property

为演示文稿启用新的 HTML 渲染模式——在此模式下，演示文稿文件将渲染为 **pure HTML/CSS markup**，不使用 SVG 图像。默认情况下已禁用（`false`）——使用现有的基于 SVG 的 HTML 渲染器。

public bool RenderToPureHtml { get; set; }
