## PresentationOptions.RenderHeaderFooterPlaceholders property

在幻灯片的页眉和页脚中启用占位符渲染。默认情况下禁用（`false`）。此选项适用于演示文稿的所有四种渲染模式：HTML、PDF、PNG 和 JPEG。使用[`RenderToPureHtml`](../rendertopurehtml) 将演示文稿渲染为纯 HTML/CSS 标记时不适用。

public bool RenderHeaderFooterPlaceholders { get; set; }
