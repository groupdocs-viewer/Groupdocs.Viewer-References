## PdfOptimizationOptions.RemoveUnusedStreams property

移除 PDF 文件中未使用（孤立）的流，这些流仍然在页面的资源字典中被引用，但实际上从未在页面内容中使用。默认情况下已禁用（`false`），启用后（`true`）将减小输出 PDF 文档的大小。

public bool RemoveUnusedStreams { get; set; }
