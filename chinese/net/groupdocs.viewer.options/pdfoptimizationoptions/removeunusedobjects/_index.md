## PdfOptimizationOptions.RemoveUnusedObjects property

移除 PDF 文件中未使用（孤立）的对象，这些对象位于 PDF 文档中，但未在任何页面的资源字典中被引用，因此根本未被使用。激活此属性（`true`）将减小输出 PDF 文档的大小。默认情况下已禁用（`false`）。

public bool RemoveUnusedObjects { get; set; }
