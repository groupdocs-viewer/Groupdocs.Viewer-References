## FileType.XPS field

XML Paper Specification File (.xps) 表示基于 Microsoft 创建的 XML Paper Specification 的页面布局文件。此格式由 Microsoft 开发，用于取代 EMF 文件格式，类似于 PDF 文件格式，但在文档的布局、外观和打印信息中使用 XML。了解更多关于此文件格式的信息，请访问[此处](https://wiki.fileformat.com/page-description-language/xps)。
