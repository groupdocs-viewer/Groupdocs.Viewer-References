El paquete proporciona clases e interfaces que representan los resultados del renderizado de documentos.

Estas clases encapsulan información sobre varios elementos y componentes del documento renderizado, como páginas, adjuntos, vistas, recursos y más.

Las clases principales en este paquete son:

 *  [Page](../../com.groupdocs.viewer.results/page) - Represents a single page that can be viewed.
 *  [Attachment](../../com.groupdocs.viewer.results/attachment) - Represents an attachment file contained by an email message, archive, PDF document, or Outlook data file.
 *  [PdfViewInfo](../../com.groupdocs.viewer.results/pdfviewinfo) - Represents view information for a PDF document.

Para obtener más detalles sobre el trabajo con los resultados de renderizado de documentos usando GroupDocs.Viewer, consulte la [Documentación de GroupDocs.Viewer][].


[GroupDocs.Viewer Documentation]: https://docs.groupdocs.com/viewer/java/
