El paquete proporciona clases para configurar el sistema de registro en GroupDocs.Viewer.

Al usar estas clases, puede controlar cómo se manejan los mensajes de registro, como escribirlos en un archivo o dirigirlos a una implementación de registrador específica.

Las clases principales en este paquete son:

 *  [FileLogger](../../com.groupdocs.viewer.logging/filelogger) - Writes log messages to a file.
 *  [ViewerLogger](../../com.groupdocs.viewer.logging/viewerlogger) - Implements logging messages to an integrated or user-defined logger.

Para obtener más detalles sobre la configuración del sistema de registro en GroupDocs.Viewer y la personalización del manejo de mensajes de registro, consulte la [GroupDocs.Viewer Documentation][].


[GroupDocs.Viewer Documentation]: https://docs.groupdocs.com/viewer/java/
