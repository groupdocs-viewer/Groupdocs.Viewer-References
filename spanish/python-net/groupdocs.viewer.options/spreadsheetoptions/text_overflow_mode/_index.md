## text_overflow_mode property

El modo de desbordamiento de texto para representar documentos de hoja de cálculo en HTML. El valor predeterminado es `TextOverflowMode.OverlayIfNextIsEmpty`, que imita el comportamiento predeterminado de MS Excel.
