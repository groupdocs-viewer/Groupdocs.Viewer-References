## detect_encoding property

La propiedad permite la detección de codificación para los archivos [`FileType.txt`](/viewer/python-net/groupdocs.viewer/filetype/txt/), [`FileType.csv`](/viewer/python-net/groupdocs.viewer/filetype/csv/), y [`FileType.tsv`](/viewer/python-net/groupdocs.viewer/filetype/tsv/).

Si no se puede detectar la codificación, se utiliza el valor predeterminado [`LoadOptions.encoding`](/viewer/python-net/groupdocs.viewer.options/loadoptions/encoding/). Para un ejemplo de código, consulte la documentación.
