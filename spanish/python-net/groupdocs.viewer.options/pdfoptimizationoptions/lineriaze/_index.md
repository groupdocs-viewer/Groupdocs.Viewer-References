## lineriaze property

La propiedad permite la optimización del archivo PDF de salida para su visualización en línea con un navegador web.

Esta optimización permite que un navegador muestre las primeras páginas de un archivo PDF al abrir el documento, en lugar de esperar a que se descargue todo el archivo. Para un ejemplo de código, consulte la documentación.
