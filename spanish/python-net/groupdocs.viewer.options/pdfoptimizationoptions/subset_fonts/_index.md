## subset_fonts property

La propiedad crea subconjuntos de fuentes en el archivo PDF de salida.

Si el archivo usa fuentes incrustadas, contiene todos los datos de fuentes. GroupDocs.Viewer puede crear subconjuntos de fuentes incrustadas para reducir el tamaño del archivo. Para un ejemplo de código, consulte la documentación.
