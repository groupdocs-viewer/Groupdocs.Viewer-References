## enable_font_hinting property

La propiedad habilita el font hinting.

El hinting de fuentes ajusta cómo se muestra una fuente de contorno. Solo se aplica a fuentes TTF utilizadas en el documento de origen. Esta opción está disponible para renderizar a formatos PNG o JPG. El valor predeterminado es False.
