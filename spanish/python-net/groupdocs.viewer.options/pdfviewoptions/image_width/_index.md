## image_width property

El ancho de la imagen de salida en píxeles.

Utilice esta propiedad para establecer el ancho de la imagen de salida (en píxeles). GroupDocs.Viewer aplica esta propiedad al renderizar una sola imagen a PDF. Para obtener más detalles, consulte la documentación.

Si establece esta propiedad, la propiedad [`PdfViewOptions.ImageMaxWidth`](/viewer/python-net/groupdocs.viewer.options/pdfviewoptions/image_max_width/) se ignora.
