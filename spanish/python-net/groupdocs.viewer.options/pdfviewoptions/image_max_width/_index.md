## image_max_width property

El ancho máximo de una imagen de salida en píxeles.

Utilice esta propiedad para establecer el ancho máximo de la imagen de salida (en píxeles). GroupDocs.Viewer aplica esta propiedad al renderizar una sola imagen a PDF. Para obtener más detalles, consulte la documentación.

Si establece la propiedad [`PdfViewOptions.ImageWidth`](/viewer/python-net/groupdocs.viewer.options/pdfviewoptions/image_width/), esta propiedad se ignora.
