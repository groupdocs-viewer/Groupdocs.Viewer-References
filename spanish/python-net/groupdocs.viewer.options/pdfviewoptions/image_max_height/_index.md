## image_max_height property

La altura máxima de una imagen de salida en píxeles.

Utilice esta propiedad para establecer la altura máxima de la imagen de salida (en píxeles). GroupDocs.Viewer aplica esta propiedad al renderizar una sola imagen a PDF. Para obtener más detalles, consulte la documentación.

Si establece la propiedad [`PdfViewOptions.ImageHeight`](/viewer/python-net/groupdocs.viewer.options/pdfviewoptions/image_height/), esta propiedad se ignora.
