## max_width property

El ancho máximo de una imagen de salida en píxeles.

Utilice esta propiedad para establecer el ancho máximo de la imagen de salida (en píxeles). Para un ejemplo de código, consulte la documentación: https://docs.groupdocs.com/viewer/net/set-image-size-limits-when-rendering-to-png-jpg/

Si establece la propiedad [`PngViewOptions.width`](/viewer/python-net/groupdocs.viewer.options/pngviewoptions/width/), esta propiedad se ignora.
