## minify property

La propiedad habilita la minificación del contenido HTML y de los recursos HTML.

La compresión del contenido de salida (HTML, CSS y SVG) es una de las formas de optimizar el archivo HTML. Para hacerlo, establezca esta propiedad en `True`.
