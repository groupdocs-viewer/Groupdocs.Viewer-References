## remove_java_script property

La propiedad determina si el código fuente de JavaScript se elimina de los enlaces en los documentos HTML generados al renderizar documentos de entrada que contienen scripts. Habilitado por defecto (`True`).

Para obtener detalles sobre la eliminación de JavaScript, consulte la documentación: https://docs.groupdocs.com/viewer/net/rendering-to-html/#preserving-or-disabling-javascript-when-rendering-to-html
