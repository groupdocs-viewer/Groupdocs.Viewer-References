## Resolution class

Contiene una opción para establecer la resolución de las imágenes en el documento de salida.

El tipo Resolution expone los siguientes miembros:

### Constructores
| Constructor | Descripción |
| :- | :- |
| [__init__](/viewer/python-net/groupdocs.viewer.options/resolution/__init__/#value) | Inicializa la resolución en DPI. |

### Propiedades
| Propiedad | Descripción |
| :- | :- |
| [value](/viewer/python-net/groupdocs.viewer.options/resolution/value/) | El DPI de calidad. |

### Campos
| Campo | Descripción |
| :- | :- |
| [DPI330](/viewer/python-net/groupdocs.viewer.options/resolution/dpi330/) | Buena calidad para pantallas de alta definición (HD). |
| [DPI220](/viewer/python-net/groupdocs.viewer.options/resolution/dpi220/) | Calidad excelente en la mayoría de impresoras y pantallas. |
| [DPI150](/viewer/python-net/groupdocs.viewer.options/resolution/dpi150/) | Adecuado para páginas web y proyectores. |
| [DPI96](/viewer/python-net/groupdocs.viewer.options/resolution/dpi96/) | Adecuado para páginas web y proyectores. |
| [DPI72](/viewer/python-net/groupdocs.viewer.options/resolution/dpi72/) | Nivel de compresión predeterminado. |
| [DOCUMENT_RESOLUTION](/viewer/python-net/groupdocs.viewer.options/resolution/document_resolution/) | Nivel de compresión predeterminado - como en el documento. |
