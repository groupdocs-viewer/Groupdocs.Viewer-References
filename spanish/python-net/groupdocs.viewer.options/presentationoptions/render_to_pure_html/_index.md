## render_to_pure_html property

La propiedad habilita un nuevo modo de representación HTML para documentos de Presentación — en este modo los archivos se representan en marcado HTML/CSS puro sin imágenes SVG. Por defecto está deshabilitado (`False`) y se utiliza el renderizador HTML basado en SVG existente.

Para un ejemplo de código, consulte la documentación en https://docs.groupdocs.com/viewer/net/render-presentations/#generate-pure-htmlcss-markup.
