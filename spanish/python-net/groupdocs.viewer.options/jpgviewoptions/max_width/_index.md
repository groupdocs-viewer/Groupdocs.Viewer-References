## max_width property

El ancho máximo de una imagen de salida en píxeles.

Utiliza esta propiedad para establecer el ancho máximo de la imagen de salida (en píxeles). Para un ejemplo de código, consulta la documentación en https://docs.groupdocs.com/viewer/net/set-image-size-limits-when-rendering-to-png-jpg/.

Si la propiedad `Width` está establecida, esta propiedad se ignora.
