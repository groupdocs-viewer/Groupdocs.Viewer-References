## extract_text property

La propiedad permite la extracción de texto.

Use esta propiedad para obtener el texto contenido en un documento fuente y sus coordenadas. Luego puede usar estos datos para añadir texto seleccionable sobre la imagen o para implementar una búsqueda de texto en la renderización basada en imágenes.

Para un ejemplo de código, consulta la documentación en https://docs.groupdocs.com/viewer/net/image-viewer-get-text-coordinates/.
