### Ejemplo

```python
from groupdocs.viewer import Viewer
from groupdocs.viewer.options import JpgViewOptions

def render_to_jpg():
    # Cargar un documento (p. ej., Excel, Numbers o imagen)
    with Viewer("invoice.xlsx") as viewer:
        # Crear opciones de vista JPG con un patrón de archivo de salida.
        # {0} será reemplazado por el número de página.
        view_options = JpgViewOptions("output_{0}.jpg")
        # Establecer el tamaño deseado de la imagen de salida en píxeles.
        view_options.width = 800
        view_options.height = 900
        # Renderizar el documento a archivos JPEG.
        viewer.view(view_options)

if __name__ == "__main__":
    render_to_jpg()
```
