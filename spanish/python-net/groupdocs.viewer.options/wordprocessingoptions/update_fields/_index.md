## update_fields property

La propiedad determina si los campos de ciertos tipos se actualizan antes de guardar el documento WordProcessing en formatos HTML, PDF, PNG o JPEG. El valor predeterminado es True, lo que significa que los campos se actualizan.

Para más detalles, consulte la documentación: https://docs.groupdocs.com/viewer/net/render-word-documents/#disable-updating-fields-when-saving
