## width property

El ancho de la imagen de salida (en píxeles, solo para renderizar a PNG/JPG).

Utilice esta propiedad para establecer el ancho de la imagen de salida (en píxeles). Para un ejemplo de código, consulte la documentación.

Si estableces esta propiedad, la propiedad [`ViewInfoOptions.MaxWidth`](/viewer/python-net/groupdocs.viewer.options/viewinfooptions/max_width/) se ignora.
