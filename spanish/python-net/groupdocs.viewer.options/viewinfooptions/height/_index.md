## height property

La altura de la imagen de salida (en píxeles, solo para renderizar a PNG/JPG).

Utiliza esta propiedad para establecer la altura de la imagen de salida (en píxeles). Para un ejemplo de código, consulta la documentación.

Si estableces esta propiedad, la propiedad [`ViewInfoOptions.max_height`](/viewer/python-net/groupdocs.viewer.options/viewinfooptions/max_height/) se ignora.
