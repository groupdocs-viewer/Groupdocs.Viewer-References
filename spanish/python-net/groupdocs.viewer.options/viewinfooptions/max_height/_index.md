## max_height property

La altura máxima de una imagen de salida (en píxeles, solo para renderizar a PNG/JPG).

Use esta propiedad para establecer la altura máxima de la imagen de salida (en píxeles). Para un ejemplo de código, consulte la documentación.

Si establece la propiedad [`ViewInfoOptions.Height`](/viewer/python-net/groupdocs.viewer.options/viewinfooptions/height/), esta propiedad se ignora.
