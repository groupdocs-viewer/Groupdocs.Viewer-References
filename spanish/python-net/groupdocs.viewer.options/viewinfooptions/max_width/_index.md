## max_width property

El ancho máximo de una imagen de salida en píxeles (solo para renderizar a PNG/JPG).

Utiliza esta propiedad para establecer el ancho máximo de la imagen de salida (en píxeles). Para un ejemplo de código, consulta la documentación.

Si estableces la propiedad [`ViewInfoOptions.Width`](/viewer/python-net/groupdocs.viewer.options/viewinfooptions/width/), esta propiedad se ignora.
