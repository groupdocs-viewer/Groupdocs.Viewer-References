## default_font_name property

La fuente predeterminada para un documento utilizada durante el renderizado cuando falta una fuente requerida.

Utilice esta propiedad para establecer la fuente predeterminada para un documento. GroupDocs.Viewer usa esta fuente durante el renderizado en lugar de cualquier fuente no instalada.

Para ver ejemplos de código, consulte la documentación: https://docs.groupdocs.com/viewer/net/replace-missing-font/
