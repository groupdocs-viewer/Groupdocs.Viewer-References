## BaseViewOptions class

Representa las opciones básicas de renderizado.

El tipo BaseViewOptions expone los siguientes miembros:

### Propiedades
| Propiedad | Descripción |
| :- | :- |
| [archive_options](/viewer/python-net/groupdocs.viewer.options/baseviewoptions/archive_options/) | Las opciones de vista de archivos de archivo. |
| [cad_options](/viewer/python-net/groupdocs.viewer.options/baseviewoptions/cad_options/) | Las opciones de vista de dibujos CAD. |
| [default_font_name](/viewer/python-net/groupdocs.viewer.options/baseviewoptions/default_font_name/) | La fuente predeterminada para un documento utilizada durante el renderizado cuando falta una fuente requerida. |
| [email_options](/viewer/python-net/groupdocs.viewer.options/baseviewoptions/email_options/) | Las opciones de vista de mensajes de correo electrónico. |
| [mail_storage_options](/viewer/python-net/groupdocs.viewer.options/baseviewoptions/mail_storage_options/) | Las opciones de vista de archivos de datos de almacenamiento de correo. |
| [outlook_options](/viewer/python-net/groupdocs.viewer.options/baseviewoptions/outlook_options/) | Las opciones de vista de archivos de datos de Microsoft Outlook. |
| [pdf_options](/viewer/python-net/groupdocs.viewer.options/baseviewoptions/pdf_options/) | Las opciones de vista de documentos PDF. |
| [presentation_options](/viewer/python-net/groupdocs.viewer.options/baseviewoptions/presentation_options/) | Las opciones de vista de archivos de presentación. |
| [project_management_options](/viewer/python-net/groupdocs.viewer.options/baseviewoptions/project_management_options/) | Las opciones de vista de archivos de gestión de proyectos. |
| [remove_comments](/viewer/python-net/groupdocs.viewer.options/baseviewoptions/remove_comments/) | La propiedad desactiva la renderización de comentarios cuando se establece en True. Por defecto es False, por lo que se muestran todos los comentarios. |
| [render_comments](/viewer/python-net/groupdocs.viewer.options/baseviewoptions/render_comments/) | La propiedad habilita o deshabilita la renderización de comentarios. |
| [render_hidden_pages](/viewer/python-net/groupdocs.viewer.options/baseviewoptions/render_hidden_pages/) | La propiedad habilita la renderización de páginas ocultas. |
| [render_notes](/viewer/python-net/groupdocs.viewer.options/baseviewoptions/render_notes/) | La propiedad habilita la renderización de notas y anotaciones para algunos formatos. |
| [spreadsheet_options](/viewer/python-net/groupdocs.viewer.options/baseviewoptions/spreadsheet_options/) | Las opciones de vista de archivos de hoja de cálculo. |
| [text_options](/viewer/python-net/groupdocs.viewer.options/baseviewoptions/text_options/) | Las opciones de texto para renderizar archivos de texto. |
| [visio_rendering_options](/viewer/python-net/groupdocs.viewer.options/baseviewoptions/visio_rendering_options/) | Las opciones de vista de archivos Visio. |
| [web_document_options](/viewer/python-net/groupdocs.viewer.options/baseviewoptions/web_document_options/) | Las opciones de vista de archivos Web. |
| [word_processing_options](/viewer/python-net/groupdocs.viewer.options/baseviewoptions/word_processing_options/) | Las opciones de vista de archivos de procesamiento de texto. |
