## folder property

El nombre de la carpeta (p. ej., Bandeja de entrada, Elementos enviados o Elementos eliminados) a renderizar.

Al renderizar un archivo de datos de Outlook, GroupDocs.Viewer renderiza mensajes de todas las carpetas contenidas en el archivo (incluyendo carpetas anidadas). Use esta propiedad para renderizar elementos de una carpeta específica.
