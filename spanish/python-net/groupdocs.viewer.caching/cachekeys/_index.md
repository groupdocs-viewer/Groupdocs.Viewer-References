## CacheKeys class

Proporciona métodos para obtener el identificador único de la entrada de caché.

El tipo CacheKeys expone los siguientes miembros:

### Métodos
| Método | Descripción |
| :- | :- |
| [get_attachment_key](/viewer/python-net/groupdocs.viewer.caching/cachekeys/get_attachment_key/#attachment_id) | Devuelve un identificador único para la entrada de caché que representa el archivo adjunto. |
| [get_attachments_key](/viewer/python-net/groupdocs.viewer.caching/cachekeys/get_attachments_key/) | Devuelve un identificador único para la entrada de caché que representa una colección de objetos [`Attachment`](/viewer/python-net/groupdocs.viewer.results/attachment/). |
| [get_file_info_key](/viewer/python-net/groupdocs.viewer.caching/cachekeys/get_file_info_key/) | Devuelve un identificador único para la entrada de caché que representa el objeto [`ViewInfo`](/viewer/python-net/groupdocs.viewer.results/viewinfo/). |
| [get_file_key](/viewer/python-net/groupdocs.viewer.caching/cachekeys/get_file_key/#extension) | Devuelve un identificador único para la entrada de caché que representa un archivo. |
| [get_page_key](/viewer/python-net/groupdocs.viewer.caching/cachekeys/get_page_key/#page_number-extension) | Devuelve un identificador único para la entrada de caché que representa el archivo de página. |
| [get_resource_filter](/viewer/python-net/groupdocs.viewer.caching/cachekeys/get_resource_filter/#page_number) | Devuelve una cadena de filtro para buscar entradas de caché que representan objetos [`Resource`](/viewer/python-net/groupdocs.viewer.results/resource/). |
| [get_resource_key](/viewer/python-net/groupdocs.viewer.caching/cachekeys/get_resource_key/#page_number-resource) | Devuelve un identificador único para la entrada de caché que representa el objeto [`Resource`](/viewer/python-net/groupdocs.viewer.results/resource/). |
| [get_view_info_key](/viewer/python-net/groupdocs.viewer.caching/cachekeys/get_view_info_key/) | Devuelve un identificador único para la entrada de caché que representa el objeto [`ViewInfo`](/viewer/python-net/groupdocs.viewer.results/viewinfo/). |
