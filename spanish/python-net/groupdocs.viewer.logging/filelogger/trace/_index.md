## trace {#message}

Escribe un mensaje de rastreo en el registro. Los mensajes de registro de rastreo proporcionan información generalmente útil sobre el flujo de la aplicación.

```python
def trace(self, message):
    ...
```

| Parámetro | Tipo | Descripción |
| :- | :- | :- |
| message | `str` | El mensaje de traza. |

| Lanza | Descripción |
| :- | :- |
| `ValueError` | Se lanza cuando `message` es None. |
