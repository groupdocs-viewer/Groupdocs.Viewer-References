## STL field

Stereolithography File (.stl) es un formato de archivo intercambiable que representa la geometría de superficie tridimensional. El formato de archivo se utiliza en varios campos como el prototipado rápido, la impresión 3D y la fabricación asistida por computadora. Obtén más información sobre este formato de archivo aquí.
