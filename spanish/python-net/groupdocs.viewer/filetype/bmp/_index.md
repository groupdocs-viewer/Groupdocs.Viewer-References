## BMP field

El archivo de imagen Bitmap (.bmp) se utiliza para almacenar imágenes digitales bitmap. Estas imágenes son independientes del adaptador gráfico y también se denominan formato de archivo bitmap independiente del dispositivo (DIB). Obtenga más información sobre este formato de archivo aquí.
