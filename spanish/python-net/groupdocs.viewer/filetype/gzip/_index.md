## GZIP field

Gnu Zipped File (.gzip) se introdujo como una utilidad gratuita para reemplazar el programa Compress usado en sistemas Unix. Estos archivos pueden abrirse y extraerse con varias aplicaciones, como WinZip, que está disponible tanto para Windows como para MacOS. Obtén más información sobre este formato de archivo aquí.
