## PPTX field

Las presentaciones PowerPoint Open XML (.pptx) son archivos de presentación creados con la popular aplicación Microsoft PowerPoint. A diferencia de la versión anterior del formato de archivo de presentación PPT, que era binario, el formato PPTX se basa en el formato de presentación Open XML de Microsoft PowerPoint. Obtenga más información sobre este formato de archivo aquí.
