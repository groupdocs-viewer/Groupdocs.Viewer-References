## WMZ field

Compressed Windows Metafile (.wmz) representa el Metarchivo de Microsoft Windows (WMF) comprimido en archivo GZIP, para almacenar datos de imágenes en formato vectorial y bitmap. Obtenga más información sobre este formato de archivo aquí.
