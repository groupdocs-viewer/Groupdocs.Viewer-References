## VST field

Visio Drawing Template (.vst) son archivos de imagen vectorial creados con Microsoft Visio y actúan como plantilla para crear más archivos. Estos archivos de plantilla están en formato binario y contienen el diseño y la configuración predeterminados que se utilizan para crear nuevos dibujos Visio. Obtenga más información sobre este formato de archivo aquí.
