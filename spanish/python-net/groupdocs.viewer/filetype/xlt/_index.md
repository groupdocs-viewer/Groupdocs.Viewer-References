## XLT field

Microsoft Excel Template (.xlt) son archivos de plantilla creados con Microsoft Excel, que es una aplicación de hoja de cálculo incluida en la suite Microsoft Office. Microsoft Office 97-2003 permitía crear nuevos archivos XLT así como abrirlos. Obtenga más información sobre este formato de archivo aquí.
