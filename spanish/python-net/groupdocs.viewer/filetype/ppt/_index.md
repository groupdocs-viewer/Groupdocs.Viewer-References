## PPT field

La presentación PowerPoint (.ppt) representa un archivo PowerPoint que consiste en una colección de diapositivas para mostrarse como presentación. Especifica el formato de archivo binario utilizado por Microsoft PowerPoint 97-2003. Obtenga más información sobre este formato de archivo aquí.
