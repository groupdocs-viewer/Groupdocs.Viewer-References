## XLTM field

Microsoft Excel Macro-Enabled Template (.xltm) representa archivos que son generados por Microsoft Excel como plantillas con macros. Los archivos XLTM son similares a XLTX en estructura, salvo que este último no admite crear plantillas con macros. Obtenga más información sobre este formato de archivo aquí.
