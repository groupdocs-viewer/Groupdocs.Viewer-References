## EXCEL_2003XML field

Excel 2003 XML (SpreadsheetML) representa el formato binario de Excel. Estos archivos pueden ser creados por Microsoft Excel así como por otros programas de hoja de cálculo similares, como OpenOffice Calc o Apple Numbers. Obtenga más información sobre este formato de archivo aquí.
