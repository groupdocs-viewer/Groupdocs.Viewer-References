## VSTX field

Visio Drawing Template (.vstx) son archivos de plantilla de dibujo creados con Microsoft Visio 2013 y versiones posteriores. Estos archivos VSTX proporcionan un punto de partida para crear dibujos Visio, guardados como archivos .VSDX, con diseño y configuraciones predeterminados. Obtenga más información sobre este formato de archivo aquí.
