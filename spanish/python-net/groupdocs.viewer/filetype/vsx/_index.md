## VSX field

Visio Stencil XML File (.vsx) se refiere a plantillas que consisten en dibujos y formas utilizados para crear diagramas en Microsoft Visio. Los archivos VSX se guardan en formato XML y fueron compatibles hasta Visio 2013. Obtenga más información sobre este formato de archivo aquí.
