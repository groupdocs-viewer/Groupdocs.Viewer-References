## GZ field

Gnu Zipped File (.gz) son archivos comprimidos creados con la aplicación de compresión gzip. Puede contener varios archivos comprimidos y se usa comúnmente en sistemas UNIX y Linux. Obtén más información sobre este formato de archivo aquí.
