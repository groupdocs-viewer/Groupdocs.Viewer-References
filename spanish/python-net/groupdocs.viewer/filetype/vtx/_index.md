## VTX field

Visio Template XML File (.vtx) es una plantilla de dibujo de Microsoft Visio que se guarda en disco en formato XML. La plantilla está diseñada para proporcionar un archivo con configuraciones básicas que pueden usarse para crear múltiples archivos Visio con los mismos ajustes. Obtenga más información sobre este formato de archivo aquí.
