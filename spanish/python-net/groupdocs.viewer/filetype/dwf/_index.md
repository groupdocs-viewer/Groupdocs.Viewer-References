## DWF field

Design Web Format File (.dwf) representa dibujos 2D/3D en formato comprimido para ver, revisar o imprimir archivos de diseño. Contiene gráficos y texto como parte de los datos de diseño y reduce el tamaño del archivo gracias a su formato comprimido. Obtén más información sobre este formato de archivo aquí.
