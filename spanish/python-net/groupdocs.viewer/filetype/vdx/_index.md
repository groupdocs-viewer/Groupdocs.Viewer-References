## VDX field

Visio Drawing XML File (.vdx) representa cualquier dibujo o gráfico creado en Microsoft Visio, pero guardado en formato XML con extensión .VDX. Un archivo XML de dibujo Visio se crea en el software Visio, desarrollado por Microsoft. Obtenga más información sobre este formato de archivo aquí.
