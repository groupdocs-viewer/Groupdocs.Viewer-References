## SVGZ field

El archivo Scalable Vector Graphics (.svgz) es un archivo de gráficos vectoriales escalables que utiliza un formato de texto basado en XML, comprimido con GZIP, para describir la apariencia de una imagen. Obtenga más información sobre este formato de archivo aquí.
