## DOCX field

Microsoft Word Open XML Document (.docx) es un formato muy conocido para documentos de Microsoft Word. Introducido a partir de 2007 con la publicación de Microsoft Office 2007, la estructura de este nuevo formato de documento cambió de binario simple a una combinación de archivos XML y binarios. Obtenga más información sobre este formato de archivo aquí.
