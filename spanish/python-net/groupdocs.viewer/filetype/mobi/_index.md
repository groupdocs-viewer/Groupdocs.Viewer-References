## MOBI field

El eBook Mobipocket (.mobi) es uno de los formatos de archivo de libro electrónico más utilizados. El formato es una mejora del antiguo formato OEB (Open Ebook Format) y se utilizó como formato propietario para Mobipocket Reader. Obtenga más información sobre este formato de archivo aquí.
