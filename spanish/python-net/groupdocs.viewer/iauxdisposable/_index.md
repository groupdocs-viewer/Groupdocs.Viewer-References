## IAuxDisposable class

Amplía la interfaz estándar `System.IDisposable`, permite obtener el estado actual de un objeto y suscribirse a un evento de eliminación.

El tipo IAuxDisposable expone los siguientes miembros:

### Propiedades
| Propiedad | Descripción |
| :- | :- |
| [is_disposed](/viewer/python-net/groupdocs.viewer/iauxdisposable/is_disposed/) | La propiedad indica si un recurso ya está eliminado (`True`) o no (`False`). |
