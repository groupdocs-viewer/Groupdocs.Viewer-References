## is_embedded property

La propiedad indica si la fuente está incrustada dentro del documento y cargada en la instancia de [`Viewer`](/viewer/python-net/groupdocs.viewer/viewer/) (`True`), o si es una fuente del sistema (`False`).

Los documentos de hoja de cálculo no pueden contener fuentes incrustadas, por lo que esta propiedad siempre devuelve `False` para ellos.
