El espacio de nombres proporciona diferentes clases de excepciones.

## Clases

| Clase | Descripción |
| --- | --- |
| [GroupDocsViewerException](./groupdocsviewerexception) | Representa los errores genéricos que ocurren durante el procesamiento de documentos. |
| [IncorrectPasswordException](./incorrectpasswordexception) | La excepción que se lanza cuando la contraseña especificada es incorrecta. |
| [InvalidFontFormatException](./invalidfontformatexception) | La excepción que se lanza al intentar abrir, cargar, guardar o procesar de alguna manera algún contenido, que presumiblemente es una fuente de formato compatible (conocido), pero que en realidad es una fuente de formato inesperado y/o no compatible o no es una fuente en absoluto. |
| [InvalidImageFormatException](./invalidimageformatexception) | La excepción que se lanza al intentar abrir, cargar, guardar o procesar de alguna manera algún contenido, que presumiblemente es una imagen (raster o vector), pero que en realidad es una imagen de formato inesperado y/o no compatible o no es una imagen en absoluto. |
| [PasswordRequiredException](./passwordrequiredexception) | La excepción que se lanza cuando se requiere una contraseña para cargar el documento. |
