## FileType.PNG field

Portable Network Graphic (.png) es un tipo de formato de archivo de imagen raster que utiliza compresión sin pérdida. Este formato de archivo se creó como reemplazo del Graphics Interchange Format (GIF) y no tiene limitaciones de derechos de autor. Obtenga más información sobre este formato de archivo [aquí](https://wiki.fileformat.com/image/png).
