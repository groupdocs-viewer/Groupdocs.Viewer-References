## FileType.BMP field

Bitmap Image File (.bmp) se utiliza para almacenar imágenes digitales bitmap. Estas imágenes son independientes del adaptador gráfico y también se denominan formato de archivo bitmap independiente del dispositivo (DIB). Obtén más información sobre este formato de archivo [aquí](https://wiki.fileformat.com/image/bmp).
