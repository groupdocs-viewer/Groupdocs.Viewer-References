## FileType.VDX field

Visio Drawing XML File (.vdx) representa cualquier dibujo o diagrama creado en Microsoft Visio, pero guardado en formato XML con extensión .VDX. Un archivo Visio Drawing XML se crea en el software Visio, desarrollado por Microsoft. Obtén más información sobre este formato de archivo [aquí](https://wiki.fileformat.com/image/vdx).
