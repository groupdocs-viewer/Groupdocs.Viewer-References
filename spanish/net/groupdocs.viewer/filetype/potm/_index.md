## FileType.POTM field

La plantilla de presentación Open XML con macros de PowerPoint (.potm) son archivos de plantilla de Microsoft PowerPoint con soporte para macros. Los archivos POTM se crean con PowerPoint 2007 o superior y contienen configuraciones predeterminadas que pueden usarse para crear más archivos de presentación. Obtenga más información sobre este formato de archivo [aquí](https://wiki.fileformat.com/presentation/potm).
