## FileType.XLTX field

Excel Open XML Spreadsheet Template (.xltx) representa la plantilla de Microsoft Excel basada en las especificaciones del formato de archivo Office OpenXML. Se utiliza para crear un archivo de plantilla estándar que puede emplearse para generar archivos XLSX que presenten la misma configuración especificada en el archivo XLTX. Obtenga más información sobre este formato de archivo [aquí](https://wiki.fileformat.com/spreadsheet/xltx).
