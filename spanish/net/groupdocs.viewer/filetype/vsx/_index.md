## FileType.VSX field

Visio Stencil XML File (.vsx) se refiere a plantillas que consisten en dibujos y formas que se utilizan para crear diagramas en Microsoft Visio. Los archivos VSX se guardan en formato XML y fueron compatibles hasta Visio 2013. Obtén más información sobre este formato de archivo [aquí](https://wiki.fileformat.com/image/vsx).
