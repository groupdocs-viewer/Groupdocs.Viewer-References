## FileType.VST field

Visio Drawing Template (.vst) son archivos de imagen vectorial creados con Microsoft Visio y funcionan como plantilla para crear archivos adicionales. Estos archivos de plantilla están en formato binario y contienen el diseño y la configuración predeterminados que se utilizan para crear nuevos dibujos Visio. Obtén más información sobre este formato de archivo [aquí](https://wiki.fileformat.com/image/vst).
