## FileType.VSDX field

Visio Drawing (.vsdx) representa el formato de archivo de Microsoft Visio introducido a partir de Microsoft Office 2013. Fue desarrollado para reemplazar el formato de archivo binario, .VSD, que es compatible con versiones anteriores de Microsoft Visio. Obtén más información sobre este formato de archivo [aquí](https://wiki.fileformat.com/image/vsdx).
