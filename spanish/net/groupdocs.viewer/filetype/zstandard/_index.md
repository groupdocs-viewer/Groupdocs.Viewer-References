## FileType.Zstandard field

El archivo ZST es un archivo comprimido que se genera con el algoritmo de compresión Zstandard (zstd). Es un archivo comprimido creado con compresión sin pérdida mediante el algoritmo. Los archivos ZST pueden usarse para comprimir diferentes tipos de archivos como bases de datos, sistemas de archivos, redes y juegos. Obtenga más información sobre este formato de archivo [aquí](https://docs.fileformat.com/compression/zst/).
