## FileType.VSTM field

Visio Macro-Enabled Drawing Template (.vstm) son archivos de plantilla creados con Microsoft Visio que admiten macros. A diferencia de los archivos VSDX, los archivos creados a partir de plantillas VSTM pueden ejecutar macros desarrolladas en código Visual Basic for Applications (VBA). Obtén más información sobre este formato de archivo [aquí](https://wiki.fileformat.com/image/vstm).
