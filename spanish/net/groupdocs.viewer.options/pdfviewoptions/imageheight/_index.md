## PdfViewOptions.ImageHeight property

Establece la altura de una imagen de salida (en píxeles).

```csharp
public int ImageHeight { get; set; }
```

### Observaciones

Utilice esta propiedad para establecer la altura de la imagen de salida (en píxeles). GroupDocs.Viewer aplica esta propiedad al renderizar una sola imagen solo a HTML. Para obtener más información, consulte la [documentación](https://docs.groupdocs.com/viewer/net/set-image-size-limits-when-rendering-to-pdf/).

Si establece esta propiedad, la propiedad [`ImageMaxHeight`](../imagemaxheight) se ignora.
