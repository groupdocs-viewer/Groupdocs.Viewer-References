## PdfViewOptions.ImageWidth property

Establece el ancho de una imagen de salida (en píxeles).

```csharp
public int ImageWidth { get; set; }
```

### Observaciones

Utilice esta propiedad para establecer el ancho de la imagen de salida (en píxeles). GroupDocs.Viewer aplica esta propiedad al renderizar una sola imagen a PDF. Para obtener más información, consulte la [documentación](https://docs.groupdocs.com/viewer/net/set-image-size-limits-when-rendering-to-pdf/).

Si establece esta propiedad, la propiedad [`ImageMaxWidth`](../imagemaxwidth) se ignora.
