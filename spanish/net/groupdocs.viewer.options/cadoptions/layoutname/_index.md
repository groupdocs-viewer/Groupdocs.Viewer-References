## CadOptions.LayoutName property

El nombre del diseño específico a renderizar. El nombre del diseño distingue entre mayúsculas y minúsculas.

```csharp
public string LayoutName { get; set; }
```

### Observaciones

Esta opción está disponible solo para los dibujos CAD que admiten diseños: [`DXF`](../../../groupdocs.viewer/filetype/dxf), [`DWG`](../../../groupdocs.viewer/filetype/dwg), [`DWT`](../../../groupdocs.viewer/filetype/dwt), [`DWF`](../../../groupdocs.viewer/filetype/dwf) y [`DWFX`](../../../groupdocs.viewer/filetype/dwfx); por defecto solo se renderiza el Modelo.
