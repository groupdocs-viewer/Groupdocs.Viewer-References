## CadOptions.RenderLayouts property

Marcar si los diseños del documento CAD deben renderizarse.

```csharp
public bool RenderLayouts { get; set; }
```

### Observaciones

Esta opción está disponible solo para los dibujos CAD que admiten diseños [`DXF`](../../../groupdocs.viewer/filetype/dxf), [`DWG`](../../../groupdocs.viewer/filetype/dwg), [`DWT`](../../../groupdocs.viewer/filetype/dwt) y [`DWF`](../../../groupdocs.viewer/filetype/dwf), y [`DWFX`](../../../groupdocs.viewer/filetype/dwfx). Por defecto solo se renderiza el Modelo.
