## Security.PermissionsPassword property

La contraseña requerida para cambiar la configuración de permisos. Con una contraseña de permisos puede restringir la impresión, la modificación y la extracción de datos.

```csharp
public string PermissionsPassword { get; set; }
```

### Observaciones

Utilice una contraseña de permisos para restringir la impresión, la modificación y la extracción de datos. Para un ejemplo de código, consulte la [documentación](https://docs.groupdocs.com/viewer/net/protect-pdf-documents/).
