## PdfOptimizationOptions.ResizeImages property

Permite establecer la resolución máxima en el archivo PDF de salida.

```csharp
public bool ResizeImages { get; set; }
```

### Observaciones

Para habilitar esta opción, establezca la propiedad [`CompressImages`](../compressimages) en `true`. Esta opción permite establecer la propiedad [`MaxResolution`](../maxresolution). Para ver un ejemplo de código, consulte esta [documentación](https://docs.groupdocs.com/viewer/net/optimization-pdf-set-max-resolution/).
