## PdfOptimizationOptions.Lineriaze property

Habilita la optimización del archivo PDF de salida para su visualización en línea con un navegador web.

```csharp
public bool Lineriaze { get; set; }
```

### Observaciones

Esta optimización permite que un navegador muestre las primeras páginas de un archivo PDF al abrir el documento, en lugar de esperar a que se descargue todo el archivo. Para ver un ejemplo de código, consulte esta [documentación](https://docs.groupdocs.com/viewer/net/optimization-pdf-for-web/).
