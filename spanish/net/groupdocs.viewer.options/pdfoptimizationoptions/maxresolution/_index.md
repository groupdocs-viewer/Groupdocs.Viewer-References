## PdfOptimizationOptions.MaxResolution property

Establece la resolución máxima en el archivo PDF de salida.

```csharp
public int MaxResolution { get; set; }
```

### Observaciones

Para habilitar esta opción, establezca las propiedades [`CompressImages`](../compressimages) y `MaxResolution` en `true`.

El valor predeterminado es `300`.

Para un ejemplo de código, consulte esta [documentación](https://docs.groupdocs.com/viewer/net/optimization-pdf-set-max-resolution/).
