## PdfOptimizationOptions.SubsetFonts property

Crea subconjuntos de fuentes en el archivo PDF de salida.

```csharp
public bool SubsetFonts { get; set; }
```

### Observaciones

Si el archivo utiliza fuentes incrustadas, contiene todos los datos de la fuente. GroupDocs.Viewer puede subestablecer fuentes incrustadas para reducir el tamaño del archivo. Para un ejemplo de código, consulte esta [documentación](https://docs.groupdocs.com/viewer/net/optimization-pdf-subset-fonts/).
