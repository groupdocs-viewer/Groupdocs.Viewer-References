## PdfOptimizationOptions.OptimizeSpreadsheets property

Habilita la optimización de hojas de cálculo en los archivos PDF.

```csharp
public bool OptimizeSpreadsheets { get; set; }
```

### Observaciones

Esta optimización permite reducir el tamaño del archivo de salida configurando líneas de borde. Además, elimina los caracteres Arial y Times New Roman de los códigos 32-127.

Para un ejemplo de código, consulte esta [documentación](https://docs.groupdocs.com/viewer/net/optimization-pdf-spreadsheets/).
