## OutlookOptions.Folder property

Establece el nombre de la carpeta (p. ej., Inbox, Sent Item o Deleted Items) a renderizar.

```csharp
public string Folder { get; set; }
```

### Observaciones

Al renderizar un archivo de datos de Outlook, GroupDocs.Viewer renderiza mensajes de todas las carpetas contenidas en el archivo (incluidas las carpetas anidadas). Utilice esta propiedad para renderizar elementos de una carpeta específica.

Para un ejemplo de código, consulte esta [documentación](https://docs.groupdocs.com/viewer/net/render-outlook-data-files/#render-a-specific-folder).
