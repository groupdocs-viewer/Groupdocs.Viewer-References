## WordProcessingOptions.UpdateFields property

Obtiene o establece un valor que determina si los campos de ciertos tipos deben actualizarse antes de guardar el documento WordProcessing de entrada en los formatos de salida HTML, PDF, PNG o JPEG. El valor predeterminado para esta propiedad es `true` — los campos se actualizarán antes de guardar.

```csharp
public bool UpdateFields { get; set; }
```
