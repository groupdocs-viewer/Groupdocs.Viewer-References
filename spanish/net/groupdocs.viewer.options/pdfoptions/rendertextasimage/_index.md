## PdfOptions.RenderTextAsImage property

Habilita el renderizado de textos en los archivos PDF como una imagen en la salida HTML.

```csharp
public bool RenderTextAsImage { get; set; }
```

### Observaciones

Cuando esta opción está establecida en `true`, GroupDocs.Viewer renderiza el texto como una imagen en la salida HTML. Esto hace que el texto no sea seleccionable y mejora el renderizado de caracteres, garantizando una apariencia similar a PDF en HTML. El valor predeterminado es `false`.

Esta opción está disponible para renderizar a HTML.

Para ver un ejemplo de código, consulte la [documentación](https://docs.groupdocs.com/viewer/net/render-pdf-documents/#render-text-as-an-image).
