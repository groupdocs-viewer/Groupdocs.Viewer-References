## PdfOptions.EnableFontHinting property

Habilita el hinting de fuentes.

```csharp
public bool EnableFontHinting { get; set; }
```

### Observaciones

El ajuste de hinting de fuentes modifica cómo se muestra una fuente contorneada. Solo se aplica a fuentes TTF usadas en el documento de origen. Esta opción está disponible para renderizar a formatos PNG o JPG. El valor predeterminado es `false`.

Para un ejemplo de código, consulte la [documentación](https://docs.groupdocs.com/viewer/net/render-pdf-documents/#enable-font-hinting).
