## PdfOptions.EnableLayeredRendering property

Habilita el renderizado de texto y gráficos en el orden Z del documento PDF original al renderizar a HTML.

```csharp
public bool EnableLayeredRendering { get; set; }
```

### Observaciones

Por defecto, GroupDocs.Veiewer renderiza texto y gráficos como una sola capa en HTML. Esta opción le permite organizar los objetos en el mismo orden que en el archivo de origen. El valor predeterminado es `false`.

Para un ejemplo de código, consulte la [documentación](https://docs.groupdocs.com/viewer/net/render-pdf-documents/#enable-multi-layer-rendering).
