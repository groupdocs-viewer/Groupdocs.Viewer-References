## BaseViewOptions.DefaultFontName property

Establece la fuente predeterminada para un documento.

```csharp
public string DefaultFontName { get; set; }
```

### Observaciones

Utilice esta propiedad para establecer la fuente predeterminada para un documento. GroupDocs.Viewer usa esta fuente durante el renderizado en lugar de cualquier fuente no instalada.

Para ejemplos de código, consulte la [documentación](https://docs.groupdocs.com/viewer/net/replace-missing-font/).
