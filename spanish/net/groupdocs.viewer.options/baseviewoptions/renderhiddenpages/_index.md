## BaseViewOptions.RenderHiddenPages property

Habilita la representación de páginas ocultas.

```csharp
public bool RenderHiddenPages { get; set; }
```

### Observaciones

Algunos archivos, como presentaciones o hojas de cálculo, pueden contener páginas ocultas. De forma predeterminada, GroupDocs.Viewer no renderiza estas páginas. Para hacerlo, establezca esta propiedad en `true`.

Para un ejemplo de código, consulte la [documentación](https://docs.groupdocs.com/viewer/net/render-presentations/#render-hidden-slides).
