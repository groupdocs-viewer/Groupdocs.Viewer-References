## HtmlViewOptions.Minify property

Habilita la minificación del contenido HTML y los recursos HTML.

```csharp
public bool Minify { get; set; }
```

### Observaciones

La compresión del contenido de salida (HTML, CSS y SVG) es una de las formas de optimizar el archivo HTML. Para ello, establezca esta propiedad en `true`.

Para un ejemplo de código, consulte la [documentación](https://docs.groupdocs.com/viewer/net/minify-html/).
