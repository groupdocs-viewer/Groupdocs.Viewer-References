## HtmlViewOptions.ExcludeFonts property

Desactiva la incorporación de cualquier fuente en el documento HTML.

```csharp
public bool ExcludeFonts { get; set; }
```

### Observaciones

Por defecto, GroupDocs.Viewer incrusta las fuentes usadas en el documento en el marcado HTML, y esta propiedad tiene un valor `false`. Para evitar incrustar fuentes, establezca esta propiedad en `true`.

Para obtener más detalles y un ejemplo de código, consulte la [documentación](https://docs.groupdocs.com/viewer/net/exclude-fonts/).
