## HtmlViewOptions.RenderResponsive property

Habilita la renderización responsiva.

```csharp
public bool RenderResponsive { get; set; }
```

### Observaciones

El diseño responsivo tiene como objetivo que las páginas web se rendericen bien en una variedad de dispositivos. Para renderizar con un diseño responsivo, establezca esta propiedad en `true`.

Para ver un ejemplo de código, consulte la [documentación](https://docs.groupdocs.com/viewer/net/render-with-responsive-layout/).
