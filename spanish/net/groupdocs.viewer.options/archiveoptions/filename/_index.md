## ArchiveOptions.FileName property

Establece el nombre del archivo de archivo mostrado.

```csharp
public FileName FileName { get; set; }
```

### Observaciones

Por defecto, GroupDocs.Viewer muestra el nombre del archivo del archivo comprimido en el encabezado de cada página. Para cambiar o ocultar este nombre, establezca esta propiedad.

Para obtener más información y un ejemplo de código, consulte la [documentación](https://docs.groupdocs.com/viewer/net/render-archive-files/#specify-the-archive-document-name).
