## ArchiveOptions.Folder property

Establece la carpeta que se renderizará.

```csharp
public string Folder { get; set; }
```

### Observaciones

Por defecto, GroupDocs.Viewer renderiza los elementos de todas las carpetas contenidas en el archivo comprimido. Para renderizar elementos de una carpeta específica, establezca esta propiedad.

Para un ejemplo de código, consulte la [documentación](https://docs.groupdocs.com/viewer/net/render-archive-files/#render-a-specific-folder).
