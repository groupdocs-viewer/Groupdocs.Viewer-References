## PresentationOptions.RenderToPureHtml property

Habilita un nuevo modo de renderizado HTML para los documentos de Presentation — en este modo los archivos de Presentation se renderizan a **pure HTML/CSS markup**, sin imágenes SVG. Por defecto está desactivado (`false`) — se usa el renderizador HTML basado en SVG existente.

```csharp
public bool RenderToPureHtml { get; set; }
```
