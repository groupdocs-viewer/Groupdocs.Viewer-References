## ViewInfoOptions.MaxWidth property

Establece el ancho máximo de una imagen de salida (en píxeles, solo para renderizar a PNG/JPG).

```csharp
public int MaxWidth { get; set; }
```

### Observaciones

Utilice esta propiedad para establecer el ancho máximo de la imagen de salida (en píxeles). Para el ejemplo de código, consulte la [documentación](https://docs.groupdocs.com/viewer/net/set-image-size-limits-when-rendering-to-png-jpg/).

Si establece la propiedad [`Width`](../width), esta propiedad se ignora.
