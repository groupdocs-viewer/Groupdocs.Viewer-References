## ViewInfoOptions.Width property

El ancho de la imagen de salida (en píxeles, solo para renderizar a PNG/JPG).

```csharp
public int Width { get; set; }
```

### Observaciones

Utilice esta propiedad para establecer el ancho de la imagen de salida (en píxeles). Para un ejemplo de código, consulte la [documentación](https://docs.groupdocs.com/viewer/net/image-viewer-adjust-image-size/).

Si establece esta propiedad, la propiedad [`MaxWidth`](../maxwidth) se ignora.
