## ViewInfoOptions.MaxHeight property

Establece la altura máxima de una imagen de salida (en píxeles, solo para renderizar a PNG/JPG).

```csharp
public int MaxHeight { get; set; }
```

### Observaciones

Utilice esta propiedad para establecer la altura máxima de la imagen de salida (en píxeles). Para el ejemplo de código, consulte la [documentación](https://docs.groupdocs.com/viewer/net/set-image-size-limits-when-rendering-to-png-jpg/).

Si establece la propiedad [`Height`](../height), esta propiedad se ignora.
