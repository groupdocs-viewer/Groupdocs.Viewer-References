## JpgViewOptions.Height property

Establece la altura de una imagen de salida (en píxeles).


### Observaciones

Utilice esta propiedad para establecer la altura de la imagen de salida (en píxeles). Para un ejemplo de código, consulte la [documentación](https://docs.groupdocs.com/viewer/net/image-viewer-adjust-image-size/).

Si establece esta propiedad, la propiedad [`MaxHeight`](../maxheight) se ignora.
