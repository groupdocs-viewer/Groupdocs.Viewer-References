## JpgViewOptions.Quality property

Establece la calidad de la imagen de salida.

```csharp
public byte Quality { get; set; }
```

### Observaciones

Utilice esta propiedad para ajustar la calidad de las imágenes. El valor debe estar entre 1 (calidad mínima) y 100. El valor predeterminado es 90.

Para un ejemplo de código, consulte la [documentación](https://docs.groupdocs.com/viewer/net/image-viewer-adjust-quality-for-jpg/).
