## SpreadsheetOptions.VerticalResolution property

Obtiene o establece la resolución vertical para las imágenes generadas en puntos por pulgada. Esta opción se usa solo al renderizar hojas de cálculo a formatos PNG o JPEG.

```csharp
public int VerticalResolution { get; set; }
```

### Observaciones

El valor predeterminado es 96 DPI. El valor mínimo posible es 72 DPI, el valor máximo posible es 600 DPI. Si el valor especificado por el usuario está fuera de estos límites, se aplicará el valor mínimo o máximo posible.
