## PresentationFontInfo.IsEmbedded property

Indica si esta fuente está incrustada dentro del documento, cargada en la instancia [`Viewer`](../../../groupdocs.viewer/viewer) (`true`), o si es una fuente del sistema (`false`). Los documentos de hoja de cálculo no pueden contener fuentes incrustadas, por lo que para ellos esta propiedad siempre devuelve `false`.

public bool IsEmbedded { get; }
