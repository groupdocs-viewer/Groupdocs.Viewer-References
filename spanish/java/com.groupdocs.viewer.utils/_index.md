El paquete proporciona clases auxiliares y utilitarias para diversas funcionalidades.


Estas clases ofrecen métodos y funcionalidades convenientes para ayudar en diferentes operaciones.

Las clases principales en este paquete son:

* [CancellationToken](../../com.groupdocs.viewer.utils/cancellationtoken) - Propagates a request to cancel rendering.
* [CancellationTokenSource](../../com.groupdocs.viewer.utils/cancellationtokensource) - Creates and signals a [CancellationToken](../../com.groupdocs.viewer.utils/cancellationtoken).
* [MemoryCleaner](../../com.groupdocs.viewer.utils/memorycleaner) - Provides methods to clean up resources and free memory.
* [PathUtils](../../com.groupdocs.viewer.utils/pathutils) - Represents the type for working with paths.


Para obtener más detalles sobre el uso de las clases utilitarias en el paquete com.groupdocs.viewer.utils,
por favor consulte la [GroupDocs.Viewer Documentation](../https://docs.groupdocs.com/viewer/java/).

| Clase | Descripción |

| [MemoryCleaner](../com.groupdocs.viewer.utils/memorycleaner) | Limpia diferentes recursos para liberar memoria. |
