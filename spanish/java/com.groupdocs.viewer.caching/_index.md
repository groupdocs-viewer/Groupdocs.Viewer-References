El paquete proporciona clases para personalizar el comportamiento del caché.

Las principales clases e interfaces en este paquete son:

* [CacheKeys](../../com.groupdocs.viewer.caching/cachekeys) - Provides methods to retrieve unique identifiers for the cache entry.
* [FileCache](../../com.groupdocs.viewer.caching/filecache) - Represents a local on-disk cache.


La interfaz [Cache](../../com.groupdocs.viewer.caching/cache) define los métodos necesarios para almacenar documentos renderizados
y los recursos del documento en la caché.


Para obtener más detalles sobre la personalización del comportamiento de caché en GroupDocs.Viewer, consulte el
[GroupDocs.Viewer Documentation](../https://docs.groupdocs.com/viewer/java/).

| [FileCache](../com.groupdocs.viewer.caching/filecache) | Representa una caché local en disco. |
