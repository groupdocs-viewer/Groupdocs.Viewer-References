El paquete proporciona clases para configurar el sistema de registro en GroupDocs.Viewer.


Al usar estas clases, puedes controlar cómo se manejan los mensajes de registro, como escribirlos en
un archivo o dirigirlos a una implementación específica de registrador.

Las clases principales en este paquete son:

* [FileLogger](../../com.groupdocs.viewer.logging/filelogger) - Writes log messages to a file.
* [ViewerLogger](../../com.groupdocs.viewer.logging/viewerlogger) - Implements logging messages to an integrated or user-defined logger.


Para obtener más detalles sobre la configuración del sistema de registro en GroupDocs.Viewer y la personalización del manejo de mensajes de registro,
por favor consulte la [GroupDocs.Viewer Documentation](../https://docs.groupdocs.com/viewer/java/).
