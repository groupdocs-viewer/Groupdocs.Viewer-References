El paquete proporciona clases para especificar opciones adicionales al renderizar documentos.


Incluye opciones para renderizar varios formatos de documento, definir permisos y configuraciones de seguridad,
especificar propiedades de marca de agua y obtener información sobre vistas.

Las clases principales en este paquete son:

* [ArchiveOptions](../../com.groupdocs.viewer.options/archiveoptions) - Provides options for rendering archive files.
* [PdfOptions](../../com.groupdocs.viewer.options/pdfoptions) - Provides options for rendering PDF documents.
* [WordProcessingOptions](../../com.groupdocs.viewer.options/wordprocessingoptions) - Provides options for rendering word processing documents.


Para obtener más detalles sobre la configuración del sistema de registro en GroupDocs.Viewer y la personalización del manejo de mensajes de registro,
por favor consulte la [GroupDocs.Viewer Documentation](../https://docs.groupdocs.com/viewer/java/).
