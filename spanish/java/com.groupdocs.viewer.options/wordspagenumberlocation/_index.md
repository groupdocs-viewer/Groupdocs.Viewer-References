Controla si se debe aplicar forzosamente la numeración de páginas al documento WordProcessing cargado y, de ser así, dónde colocar los números de página.

## Campos

| Campo | Descripción |
| --- | --- |
|  | [NOT_APPLY](#NOT-APPLY) | Deja el documento WordProcessing cargado intacto. |
|
|  | [TOP_LEFT](#TOP-LEFT) | Coloca el número de página en la esquina superior izquierda de la página. |
|
|  | [TOP_CENTER](#TOP-CENTER) | Coloca el número de página en el centro superior de la página. |
|
|  | [TOP_RIGHT](#TOP-RIGHT) | Coloca el número de página en la esquina superior derecha de la página. |
|
|  | [BOTTOM_LEFT](#BOTTOM-LEFT) | Coloca el número de página en la esquina inferior izquierda de la página. |
|
|  | [BOTTOM_CENTER](#BOTTOM-CENTER) | Coloca el número de página en el centro inferior de la página. |
|
|  | [BOTTOM_RIGHT](#BOTTOM-RIGHT) | Coloca el número de página en la esquina inferior derecha de la página. |
|
