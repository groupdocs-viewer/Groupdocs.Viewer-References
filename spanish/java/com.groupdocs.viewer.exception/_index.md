El paquete proporciona clases para excepciones que pueden ocurrir al trabajar con un documento.

Las clases principales en este paquete son:

* com.groupdocs.viewer.exception.ArchiveSecurityException - Thrown when an archive being opened exceeds specified limits.
* [FileNotFoundException](../../com.groupdocs.viewer.exception/filenotfoundexception) - Represents an exception thrown when a file or directory is not found.
* [GroupDocsViewerException](../../com.groupdocs.viewer.exception/groupdocsviewerexception) - Represents generic errors that occur during document processing.


Para obtener más detalles sobre el manejo de excepciones en GroupDocs.Viewer, consulte el
[GroupDocs.Viewer Documentation](../https://docs.groupdocs.com/viewer/java/).



## Clases

| Clase | Descripción |
| --- | --- |
| [ArchiveSecurityException](../com.groupdocs.viewer.exception/archivesecurityexception) | Esta excepción se lanza cuando un archivo que se está abriendo supera cualquiera de los límites especificados en ArchiveSecurityOptions. |
| [FileNotFoundException](../com.groupdocs.viewer.exception/filenotfoundexception) | Esta excepción se lanza cuando no se encuentra un archivo o directorio. |
| [GroupDocsViewerException](../com.groupdocs.viewer.exception/groupdocsviewerexception) | Esta excepción representa errores genéricos que pueden ocurrir durante el procesamiento de documentos. |
| [IncorrectPasswordException](../com.groupdocs.viewer.exception/incorrectpasswordexception) | Esta excepción se lanza cuando la contraseña especificada es incorrecta. |
| [NotSupportedException](../com.groupdocs.viewer.exception/notsupportedexception) | Esta excepción se lanza cuando la operación solicitada no es compatible. |
| [PasswordRequiredException](../com.groupdocs.viewer.exception/passwordrequiredexception) | Esta excepción se lanza cuando se requiere una contraseña para cargar el documento. |
